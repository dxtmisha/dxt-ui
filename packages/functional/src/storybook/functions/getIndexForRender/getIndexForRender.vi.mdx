# `getIndexForRender`

Tạo `key` tổng hợp cho component từ tên, các chỉ số và id. Các định danh được nối bằng dấu chấm; CSS class được bỏ qua.

### Tham số:
- `name: string | any` — Tên hoặc thẻ của thành phần (phần cơ sở của key).
- `props?: T` — Các thuộc tính của thành phần (dùng để trích xuất `index` và `id`; `class` không ảnh hưởng đến key).
- `index?: string` — Một chỉ số bên ngoài tùy chọn.

### Trả về:
`string | undefined` — Khóa tổng hợp đã được tạo, hoặc `undefined` nếu không thể tạo khóa.

### Ví dụ tạo key:

```typescript
import { getIndexForRender } from '@dxtmisha/functional'

// 1. Chỉ có tên
getIndexForRender('li') 
// => 'li'

// 2. Tên + chỉ số bên ngoài
getIndexForRender('div', {}, 'row-1') 
// => 'div.row-1'

// 3. Tên + chỉ số từ props + id (bỏ qua class)
getIndexForRender('button', { 
  index: 'primary', 
  class: 'btn-large', 
  id: 'submit-01' 
}) 
// => 'button.primary.submit-01'

// 4. Đầy đủ các thành phần (đối số bên ngoài + mọi thứ từ props)
getIndexForRender('span', { 
  index: 'p-idx', 
  class: 'text-red', 
  id: 'id-99' 
}, 'arg-idx') 
// => 'span.arg-idx.p-idx.id-99'

// 5. Trường hợp trống
getIndexForRender(undefined)
// => undefined
```

### Logic lắp ghép key

Key được lắp ghép theo chuỗi:
1.  **`name`** (nếu `name` là chuỗi, không có dấu chấm ở đầu)
2.  `+ .index` (nếu đối số `index` được truyền vào)
3.  `+ .props.index` (nếu có trong thuộc tính và là một chuỗi)
4.  `+ .props.id` (nếu có trong thuộc tính)

CSS class và style không tham gia tạo key. Thay đổi giao diện phải giữ nguyên định danh node, focus và trạng thái component. Với các phần tử cùng cấp trong danh sách, truyền định danh ổn định khác nhau qua `props.key`, `index` hoặc `props.id`.
