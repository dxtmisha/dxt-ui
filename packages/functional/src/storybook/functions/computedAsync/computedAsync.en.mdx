# `computedAsync`

Creates a computed property that can handle asynchronous getters. Unlike Vue's standard `computed`, `computedAsync` accepts async functions, synchronous functions, or raw values — the result is automatically resolved and exposed as a reactive computed ref. Initialization is lazy and occurs upon first access to the property.

Only the current evaluation updates the result; late results and errors from previous evaluations are ignored. The watcher belongs to the effect scope where the property was created, even when first accessed later. Pending results are discarded when that scope stops. On the server, only `initialState` is returned without evaluating the getter.

A resolved value matching the `ignore` argument (defaulting to `undefined`) is ignored and does not overwrite previous data. A current getter error clears the data and is reported through `ErrorCenter` with group `functional` and code `computed-async`. Reactive dependencies must be accessed before the first `await` statement because dependencies accessed after an asynchronous pause are not tracked by the watcher.

**Parameters:**
- `getter: (() => Promise<R>) | (() => R) | R` — An async function, synchronous function, or raw value to compute the result from.
- `initialState?: (() => I) | I` — The initial result or a factory evaluated once when the property is created (supports a distinct type `I`).
- `ignore?: R` — A value to ignore (defaulting to `undefined`, preserving previous data).
- `debugOptions?: DebuggerOptions` — Options used for debugging reactive computations, supported by Vue.js.

**Returns:**
`ComputedRef<R | I | undefined>` — A reactive computed ref containing the resolved result of the getter.

```typescript
import { computedAsync } from '@dxtmisha/functional'

// Initial state
const status = computedAsync(async () => {
  await new Promise(resolve => setTimeout(resolve, 1000))
  return 'online'
}, 'offline')
// status.value is 'offline' immediately, and 'online' after 1 second

// Async getter
const data = computedAsync(async () => {
  const response = await fetch('/api/data')
  return response.json()
})

// Sync getter
const label = computedAsync(() => 'Hello, World!')

// Raw value
const count = computedAsync(42)
```
