# `computedAsync`

Tạo một thuộc tính computed có thể xử lý các getter bất đồng bộ. Khác với `computed` thông thường của Vue, `computedAsync` cho phép truyền vào hàm bất đồng bộ, hàm đồng bộ, hoặc giá trị trực tiếp — kết quả sẽ tự động được giải quyết và trở thành một computed ref phản ứng. Khởi tạo ở chế độ lazy (lười biếng) và chỉ xảy ra khi truy cập thuộc tính lần đầu tiên.

Chỉ lần tính toán hiện tại được cập nhật kết quả; kết quả và lỗi đến muộn từ các lần trước bị bỏ qua. Watcher thuộc về phạm vi hiệu ứng nơi thuộc tính được tạo, kể cả khi lần đọc đầu tiên xảy ra sau đó. Khi phạm vi dừng, các kết quả đang chờ không còn được áp dụng. Trên máy chủ, chỉ trả về `initialState` mà không thực thi getter.

Giá trị giải quyết khớp với đối số `ignore` (mặc định là `undefined`) sẽ bị bỏ qua và không ghi đè dữ liệu trước đó. Lỗi từ getter hiện tại sẽ xóa dữ liệu và được chuyển tới `ErrorCenter` với nhóm `functional` và mã `computed-async`. Các phụ thuộc phản ứng (reactive dependencies) phải được đọc trước câu lệnh `await` đầu tiên, vì các phụ thuộc được truy cập sau khi tạm dừng bất đồng bộ sẽ không được theo dõi bởi watcher.

**Tham số:**
- `getter: (() => Promise<R>) | (() => R) | R` — Hàm bất đồng bộ, hàm đồng bộ, hoặc giá trị trực tiếp dùng để tính toán kết quả.
- `initialState?: (() => I) | I` — Giá trị ban đầu hoặc hàm được gọi một lần khi tạo thuộc tính (hỗ trợ kiểu dữ liệu riêng biệt `I`).
- `ignore?: R` — Giá trị cần loại trừ khỏi kết quả (mặc định là `undefined`, giữ lại dữ liệu trước đó).
- `debugOptions?: DebuggerOptions` — Tùy chọn dùng để gỡ lỗi các phép tính phản ứng, được hỗ trợ bởi Vue.js.

**Trả về:**
`ComputedRef<R | I | undefined>` — Một computed ref phản ứng chứa kết quả đã được giải quyết từ getter.

```typescript
import { computedAsync } from '@dxtmisha/functional'

// Trạng thái ban đầu
const status = computedAsync(async () => {
  await new Promise(resolve => setTimeout(resolve, 1000))
  return 'online'
}, 'offline')
// status.value là 'offline' ngay lập tức, và 'online' sau 1 giây

// Getter bất đồng bộ
const data = computedAsync(async () => {
  const response = await fetch('/api/data')
  return response.json()
})

// Getter đồng bộ
const label = computedAsync(() => 'Hello, World!')

// Giá trị trực tiếp
const count = computedAsync(42)
```
