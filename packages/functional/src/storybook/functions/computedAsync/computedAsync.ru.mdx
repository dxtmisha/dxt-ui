# `computedAsync`

Создаёт вычисляемое свойство, которое может обрабатывать асинхронные геттеры. В отличие от стандартного `computed` из Vue, `computedAsync` позволяет передавать асинхронные функции, синхронные функции или прямые значения — результат автоматически разворачивается и становится реактивным. Инициализация происходит лениво при первом обращении к свойству.

Результат обновляет только актуальное вычисление: поздние результаты и ошибки предыдущих запусков игнорируются. Наблюдатель принадлежит области эффектов, в которой создано свойство, даже если первое чтение произошло позже; при остановке области ожидающие результаты больше не применяются. На сервере возвращается только `initialState`, без выполнения геттера.

Без аргумента `ignore` возвращённый `undefined` очищает предыдущие данные. Чтобы сохранить прежние данные при таком результате, явно передайте третий аргумент `undefined`. Ошибка актуального геттера очищает данные и передаётся в `ErrorCenter` с группой `functional` и кодом `computed-async`.

**Параметры:**
- `getter: (() => Promise<R>) | (() => R) | R` — Асинхронная функция, синхронная функция или прямое значение для вычисления результата.
- `initialState?: (() => R) | R` — Начальное значение результата или функция, вычисляемая один раз при создании.
- `ignore?: R` — Явно переданное значение, которое не будет установлено в результат. Если аргумент отсутствует, значения не исключаются.
- `debugOptions?: DebuggerOptions` — Опции отладки реактивных вычислений Vue.js.

**Возвращает:**
`ComputedRef<R | undefined>` — Реактивное вычисляемое свойство с результатом выполнения геттера.

```typescript
import { computedAsync } from '@dxtmisha/functional'

// Начальное значение
const status = computedAsync(async () => {
  await new Promise(resolve => setTimeout(resolve, 1000))
  return 'online'
}, 'offline')
// status.value будет 'offline' сразу, и 'online' через 1 секунду

// Асинхронный геттер
const data = computedAsync(async () => {
  const response = await fetch('/api/data')
  return response.json()
})

// Синхронный геттер
const label = computedAsync(() => 'Hello, World!')

// Прямое значение
const count = computedAsync(42)
```
