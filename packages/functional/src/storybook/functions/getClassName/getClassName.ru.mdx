# `getClassName`

Утилитарная функция, которая извлекает и нормализует свойство `class` из заданного объекта свойств с помощью `normalizeClass` из Vue. Поддерживает строки, объекты и массивы, возвращая нормализованную строку классов или `undefined`, если класс пуст или отсутствует.

**Параметры:**
- `props?: T | unknown` — Объект свойств компонента, который может содержать свойство `class`.

**Возвращает:**
`string | undefined` — Нормализованное имя класса в виде строки, если оно присутствует и не пустое, в противном случае `undefined`.

```typescript
import { getClassName } from '@dxtmisha/functional'

// Возвращает 'my-custom-class'
const className1 = getClassName({ class: 'my-custom-class', otherProp: 1 })

// Возвращает 'active' (синтаксис объектов)
const className2 = getClassName({ class: { active: true, disabled: false } })

// Возвращает 'c1 c2' (синтаксис массивов)
const className3 = getClassName({ class: ['c1', 'c2'] })

// Возвращает undefined, так как 'class' отсутствует или пуст
const className4 = getClassName({ otherProp: 1 })
```
