# `render`

Обёртка над функцией Vue `h` (hyperscript), которая автоматически формирует ключи компонентов из стабильных идентификаторов.

**Параметры:**
- `name: string | any` — Имя или тег компонента для рендеринга.
- `props?: T` — Свойства, передаваемые компоненту.
- `children?: RawChildren | RawSlots` — Дочерние элементы или слоты компонента.
- `index?: string` — Необязательный индекс или идентификатор, используемый для генерации ключа.

**Возвращает:**
`VNode` — Отрендеренный виртуальный узел.

```typescript
import { render } from '@dxtmisha/functional'

// Рендерит div с автоматически сгенерированным ключом
const vnode = render('div', { class: 'container' }, 'Привет, мир')
// key => 'div'

// Рендерит компонент с определенным индексом для генерации ключа
const item = render('my-component', { data: itemData }, null, 'item-1')
// key => 'my-component.item-1'
```

### Генерация ключа

Явный `props.key` сохраняется. Если он отсутствует, ключ формируется из следующих идентификаторов по порядку: строковое имя компонента записывается без точки в начале, остальные идентификаторы добавляются через точку:

1.  **`name`** — если `name` является строкой.
2.  **`.index`** — из четвёртого аргумента `render`.
3.  **`.props.index`** — если передан строкой.
4.  **`.props.id`** — если ID указан в `props`.

CSS-классы не влияют на автоматически сформированный ключ, поэтому их смена сохраняет DOM-узел и состояние компонента. Намеренное изменение явного `props.key` по-прежнему может заменить узел. Для соседних элементов списка передавайте уникальные стабильные ключи или идентификаторы: само имя компонента не гарантирует уникальность.
