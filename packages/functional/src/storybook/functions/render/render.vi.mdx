# `render`

Hàm bao bọc `h` (hyperscript) của Vue, tự động tạo key cho component từ các định danh ổn định.

**Tham số:**
- `name: string | any` — Tên hoặc thẻ của thành phần cần render.
- `props?: T` — Các thuộc tính truyền vào thành phần.
- `children?: RawChildren | RawSlots` — Các thành phần con hoặc slot của thành phần.
- `index?: string` — Một chỉ số hoặc định danh tùy chọn được sử dụng để tạo key.

**Trả về:**
`VNode` — Node ảo đã được render.

```typescript
import { render } from '@dxtmisha/functional'

// Render một div với key được tạo tự động
const vnode = render('div', { class: 'container' }, 'Chào thế giới')
// key => 'div'

// Render một thành phần với index cụ thể để tạo key
const item = render('my-component', { data: itemData }, null, 'item-1')
// key => 'my-component.item-1'
```

### Cách tạo Key

Giá trị `props.key` được chỉ định sẽ được giữ nguyên. Nếu không có, key được tạo từ các định danh sau theo thứ tự: tên component dạng chuỗi không có dấu chấm ở đầu, các định danh tiếp theo được nối bằng dấu chấm:

1.  **`name`** — nếu `name` là chuỗi.
2.  **`.index`** — từ tham số thứ tư của `render`.
3.  **`.props.index`** — nếu được truyền dưới dạng chuỗi.
4.  **`.props.id`** — nếu ID được chỉ định trong `props`.

CSS class không ảnh hưởng đến key tự động, nên thay đổi class giữ nguyên DOM node và trạng thái component. Thay đổi có chủ ý đối với `props.key` vẫn có thể thay thế node. Với các phần tử cùng cấp trong danh sách, cung cấp key hoặc định danh ổn định duy nhất; chỉ tên component không đảm bảo tính duy nhất.
