# `computedEternity`

Создаёт вычисляемое свойство, которое вычисляется по требованию и кешируется. Значение обновляется автоматически при изменении реактивных зависимостей, но только если к нему был осуществлён доступ хотя бы один раз. Наблюдатель запускается в `EffectScopeGlobal` и остаётся активным на протяжении всей работы приложения, что удобно для свойств, которые должны сохраняться глобально после первого обращения.

Если асинхронные вычисления пересекаются, значение обновляет только последнее вычисление; результаты и ошибки устаревших вычислений игнорируются. Пока последнее вычисление ожидается, сохраняется предыдущее значение или `initialState`. Вне DOM-среды (SSR) вычисление пропускается и возвращается начальное значение.

При ошибке актуального вычисления кешированное значение сбрасывается к `initialState`, а ошибка передаётся в `ErrorCenter` (группа `functional`, код `computed-eternity`). Попытка записи в возвращаемый ref также отправляет ошибку только для чтения в `ErrorCenter`. Реактивные зависимости должны читаться до первого выражения `await`.

**Параметры:**
- `getter: (() => Promise<T> | T) | Promise<T> | T` — Синхронная или асинхронная функция, промис или прямое значение; реактивные зависимости отслеживаются до первого `await`.
- `initialState?: (() => I) | I` — Начальное кешированное значение или фабрика, выполняемая сразу при создании ref.

**Возвращает:**
`Ref<ComputedEternityValue<T, I>>` — Реактивный custom ref с начальным или последним актуальным результатом.

```typescript
import { ref } from 'vue'
import { computedEternity } from '@dxtmisha/functional'

// Начальное значение
const status = computedEternity(async () => {
  await new Promise(resolve => setTimeout(resolve, 1000))
  return 'online'
}, 'offline')
// status.value будет 'offline' до завершения выполнения геттера

// Асинхронный геттер - будет вызван только при первом обращении к 'data.value'
const data = computedEternity(async () => {
  const response = await fetch('/api/data')
  return response.json()
})

// Реактивная зависимость с начальным значением
const count = ref(1)
const double = computedEternity(() => count.value * 2, 0)
```
