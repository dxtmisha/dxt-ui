# `computedEternity`

Creates a computed property that is evaluated on demand and cached. The value is updated automatically when reactive dependencies change, but only after it has been accessed at least once. The watcher runs inside `EffectScopeGlobal` and remains active throughout the application's lifecycle, making it suitable for properties that should persist globally after the first access.

When asynchronous evaluations overlap, only the latest evaluation can update the value; results and errors from older evaluations are ignored. While the latest evaluation is pending, the previous resolved value or `initialState` is retained. Without a DOM runtime (SSR), evaluation is skipped and the initial state is returned.

If the current evaluation throws or rejects, the cached value resets to `initialState` and the error is reported through `ErrorCenter` (group `functional`, code `computed-eternity`). Assigning a value to the returned ref also reports a read-only error through `ErrorCenter`. Reactive dependencies must be accessed before the first `await` statement.

**Parameters:**
- `getter: (() => Promise<T> | T) | Promise<T> | T` — A synchronous or asynchronous evaluator function, promise, or direct value; reactive dependencies are tracked before the first `await`.
- `initialState?: (() => I) | I` — The initial cached value or a factory executed immediately when the ref is created.

**Returns:**
`Ref<ComputedEternityValue<T, I>>` — A reactive custom ref containing the initial or latest resolved result of the getter.

```typescript
import { ref } from 'vue'
import { computedEternity } from '@dxtmisha/functional'

// Initial state
const status = computedEternity(async () => {
  await new Promise(resolve => setTimeout(resolve, 1000))
  return 'online'
}, 'offline')
// status.value is 'offline' until the getter resolves

// Async getter - will only be called when 'data.value' is first accessed
const data = computedEternity(async () => {
  const response = await fetch('/api/data')
  return response.json()
})

// Reactive dependency with initial value
const count = ref(1)
const double = computedEternity(() => count.value * 2, 0)
```
