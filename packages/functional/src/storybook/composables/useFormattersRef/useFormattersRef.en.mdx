# `useFormattersRef`

A composable for reactive formatting of data lists based on specified rules for each property.

**Parameters:**
- `list: RefType<List | undefined>` — source data list (Ref or ComputedRef).
- `options: Options` — formatting settings for each property:
    - `type: FormattersType` — formatter type (`currency`, `date`, `name`, `number`, `plural`, `unit`).
    - `options?: object` — additional settings for the specific formatter (e.g., currency code, date format).
    - `transformation?: function` — custom function for value transformation.

**Returns (`UseFormattersRef<List, Options>`):**
- `listFormat: ComputedRef<FormattersReturn<List, Options>>` — formatted data list. For each property specified in `options`, a corresponding `{property}Format` field is added to the items. Automatically updates when `GeoRef` locale changes.
- `length: ComputedRef<number>` — count of records in the list.

### Generic Constraints

- `Options extends FormattersOptionsList` — type of formatting options for each property.
- `List extends FormattersListProp` — type of the source list (can be an array or a single item).

## Usage Example

```typescript
import { ref } from 'vue'
import { useFormattersRef } from '@dxtmisha/functional'
import { FormattersType } from '@dxtmisha/functional-basic'

const items = ref([
  { id: 1, price: 100, firstName: 'John', lastName: 'Doe' },
  { id: 2, price: 250, firstName: 'Jane', lastName: 'Smith' }
])

const { listFormat } = useFormattersRef(items, {
  price: { type: FormattersType.currency },
  name: { type: FormattersType.name }
})

// listFormat.value will contain:
// [
//   { ..., priceFormat: '$100.00', nameFormat: 'John Doe' },
//   { ..., priceFormat: '$250.00', nameFormat: 'Jane Smith' }
// ]
```
