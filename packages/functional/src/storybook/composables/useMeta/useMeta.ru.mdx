# `useMeta`

Composable для реактивного управления мета-тегами (HTML, Open Graph, Twitter Card) с автоматической синхронизацией DOM. Использует паттерн singleton — все компоненты используют одно состояние мета-тегов.

Для изменения значений предпочтительно использовать `setTitle()`, `setDescription()` и остальные `set…` методы. Прямая запись в публичные refs также поддерживается: при SSR метаданные обновляются синхронно, в браузере несколько изменений объединяются в одно обновление.

**Возвращает:**
- `title: Ref<string>` — реактивный заголовок страницы (без суффикса).
- `description: Ref<string>` — реактивный мета-тег description.
- `keyword: Ref<string>` — реактивный мета-тег keywords.
- `image: Ref<string>` — реактивный URL изображения для Open Graph / Twitter Card.
- `canonical: Ref<string>` — реактивный канонический URL.
- `robots: Ref<MetaRobots>` — реактивная директива robots.
- `author: Ref<string>` — реактивный мета-тег author.
- `siteName: Ref<string>` — реактивное название сайта.
- `getHtmlMeta(): string` — генерирует HTML-строку для всех мета-тегов (полезно для SSR).
- `setTitle(value: string): void` — устанавливает заголовок страницы.
- `setKeywords(value: string): void` — устанавливает ключевые слова.
- `setDescription(value: string): void` — устанавливает описание страницы.
- `setImage(value: string): void` — устанавливает URL изображения.
- `setCanonical(value: string): void` — устанавливает канонический URL.
- `setRobots(value: MetaRobots): void` — устанавливает директиву robots.
- `setAuthor(value: string): void` — устанавливает автора.
- `setSiteName(value: string): void` — устанавливает название сайта.
- `setSuffix(suffix: string): void` — устанавливает суффикс для заголовка страницы.
- `meta: Meta` — базовый экземпляр `Meta`.

## Пример использования

```typescript
import { useMeta } from '@dxtmisha/functional'

const { setTitle, setDescription } = useMeta()

setTitle('Заголовок страницы')
setDescription('Описание моей крутой страницы')
```
