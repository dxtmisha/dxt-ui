# DesignLifecycleAbstract Class

Abstract marker class for dependencies with synchronous component lifecycle callbacks. `DesignLogicAbstract` invokes these callbacks only on instances derived from this class.

## Key Features

- **Optional callbacks** — either callback may be omitted.
- **Synchronous contract** — callbacks return `void`.
- **Explicit invocation** — constructing a dependency does not run callbacks.

## Initialization

Extend this abstract class; do not instantiate it directly.

## Behavior and lifecycle

This class has no public methods. Subclasses supply readonly `onMounted?: (scope?: EffectScope) => void` and `onUnmounted?: (scope?: EffectScope) => void` properties receiving the active Vue `EffectScope`. Asynchronous work and its cleanup belong to the subclass.

## Usage

```typescript
import { DesignLifecycleAbstract } from '@dxtmisha/functional'
import type { EffectScope } from 'vue'

class Dependency extends DesignLifecycleAbstract {
  mounted = false
  override readonly onMounted = (_scope?: EffectScope): void => { this.mounted = true }
  override readonly onUnmounted = (_scope?: EffectScope): void => { this.mounted = false }
}
```

## Properties

- `onMounted: ((scope?: EffectScope) => void) | undefined` — Optional synchronous mount callback receiving the active Vue effect scope.
- `onUnmounted: ((scope?: EffectScope) => void) | undefined` — Optional synchronous cleanup callback receiving the Vue effect scope.

## Methods

No public methods; use the properties described above.
