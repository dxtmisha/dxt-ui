# Класс DesignLifecycleAbstract

Абстрактный базовый класс зависимостей с синхронными обработчиками жизненного цикла. `DesignLogicAbstract` вызывает эти обработчики только у экземпляров, наследующих этот класс.

## Ключевые особенности

- **Необязательные обработчики** — любой обработчик можно не реализовывать.
- **Синхронный контракт** — обработчики возвращают `void`.
- **Явный вызов** — создание зависимости не запускает обработчики.

## Инициализация

Наследуйте абстрактный класс; не создавайте его напрямую.

## Поведение и жизненный цикл

У класса нет публичных методов. Подклассы реализуют readonly-свойства `onMounted?: (scope?: EffectScope) => void` и `onUnmounted?: (scope?: EffectScope) => void`, получающие активную область эффектов Vue `EffectScope`. Асинхронную работу и её очистку организует подкласс.

## Использование

```typescript
import { DesignLifecycleAbstract } from '@dxtmisha/functional'
import type { EffectScope } from 'vue'

class Dependency extends DesignLifecycleAbstract {
  mounted = false
  override readonly onMounted = (_scope?: EffectScope): void => { this.mounted = true }
  override readonly onUnmounted = (_scope?: EffectScope): void => { this.mounted = false }
}
```

## Свойства

- `onMounted: ((scope?: EffectScope) => void) | undefined` — Необязательный синхронный обработчик монтирования, получающий активную область эффектов Vue.
- `onUnmounted: ((scope?: EffectScope) => void) | undefined` — Необязательный синхронный обработчик очистки, получающий область эффектов Vue.

## Методы

Публичных методов нет; используйте описанные выше свойства.
