# Класс ListDataRef

Реактивная модель списка: нормализация, вложенные группы, выбор, фокус и поиск. Предоставляет вычисляемые верхнеуровневые и плоские представления, не рисуя UI и не изменяя входное выделение.

## Ключевые особенности

- **Нормализация** — принимает массивы названий, массивы объектов и словари.
- **Вложенные группы** — `group` и `menu` раскрываются через кэшированные подсписки.
- **Реактивное состояние** — ссылки управляют выбором, фокусом, поиском и лимитами.

## Инициализация

`constructor( list: RefOrNormal<ListListInput | undefined>, focus?: RefType<ListSelectedItem | undefined>, highlight?: RefType<string | undefined>, highlightLengthStart?: RefType<number | undefined>, filterMode?: RefType<boolean | undefined>, selected?: RefType<ListSelectedList | undefined>, keyValue?: RefType<string | undefined>, keyLabel?: RefType<string | undefined>, lite?: RefType<number | undefined>, min: RefOrNormal<number | string | undefined> = 0, max: RefOrNormal<number | string | undefined> = 9_999_999, parent?: string )`

**Параметры:**

- `list: RefOrNormal<ListListInput | undefined>` — Входной список либо словарь, может быть реактивным.
- `focus?: RefType<ListSelectedItem | undefined>` — Ссылка на индекс фокуса.
- `highlight?: RefType<string | undefined>` — Ссылка на поисковый запрос.
- `highlightLengthStart?: RefType<number | undefined>` — Ссылка на минимальную длину поиска; при отсутствии 2.
- `filterMode?: RefType<boolean | undefined>` — Ссылка на режим фильтра, копируемый в fullData.
- `selected?: RefType<ListSelectedList | undefined>` — Ссылка на один выбранный идентификатор либо массив.
- `keyValue?: RefType<string | undefined>` — Ссылка на имя поля значения; по умолчанию value.
- `keyLabel?: RefType<string | undefined>` — Ссылка на имя поля метки; по умолчанию label.
- `lite?: RefType<number | undefined>` — Ссылка на порог упрощённого списка.
- `min: RefOrNormal<number | string | undefined> = 0` — Минимум выбора; по умолчанию 0.
- `max: RefOrNormal<number | string | undefined> = 9_999_999` — Максимум выбора; по умолчанию 9_999_999.
- `parent?: string` — Индекс родителя либо undefined для корневого уровня.

## Поведение и жизненный цикл

Только `list`, `min` и `max` принимают обычные значения либо ссылки; фокус, поиск, выбор, имена ключей, порог lite и режим фильтра передаются ссылками. Массивы названий используют строковые позиции как индексы и числовые позиции как значения. Объекты предпочитают явный `index`, затем примитивное `value`. `map` раскрывает `item`, `group` и `menu`; `mapItems` содержит только конечные элементы. Навигация за границу возвращает первый или последний элемент. Лимиты влияют на вычисляемое состояние; класс не изменяет выбор. Флаг минимума означает достижение минимума. `getFocusItem()` ищет только на текущем уровне. Замена ссылки списка очищает кэш подсписков; замена источника группы пересоздаёт её подсписок. Для очистки наблюдателя списка используйте область эффектов.

## Использование

```typescript
import { ListDataRef } from '@dxtmisha/functional'
import { ref } from 'vue'

const selected = /*#__PURE__*/ ref(['a'])
const focus = /*#__PURE__*/ ref('a')
const highlight = /*#__PURE__*/ ref('Ap')
const list = /*#__PURE__*/ new ListDataRef(
  [{ label: 'Apple', value: 'a' }, { label: 'Banana', value: 'b' }],
```

## Свойства

- `data: ComputedRef<ListList>` — Нормализованные записи текущего уровня.
- `liteData: ComputedRef<ListList>` — Сокращённые записи при превышении порога lite; иначе нормализованные данные целиком.
- `fullData: ComputedRef<ListDataFull>` — Записи текущего уровня с focus, highlight, filterMode, selected и disabled. Явное disabled имеет приоритет.
- `map: ComputedRef<ListList>` — Плоские записи item/group/menu с сохранением заголовков групп.
- `mapItems: ComputedRef<ListList>` — Конечные item из плоской карты.
- `items: ComputedRef<ListList>` — Записи item/group/menu из плоской карты.
- `highlightFirstItem: ComputedRef<number>` — Позиция первого совпадения в карте либо -1 при отсутствии совпадения или коротком запросе. Проверяет label, index и search.
- `isSelected: ComputedRef<boolean>` — Совпадает ли хотя бы один конечный элемент с входным выбором.
- `isSelectedMin: ComputedRef<boolean>` — Истина при достижении положительного минимума выбранными элементами текущей группы.
- `isSelectedMax: ComputedRef<boolean>` — Истина при достижении положительного максимума выбранными элементами текущей группы. Ложное значение максимума использует лимит по умолчанию.
- `selectedList: ComputedRef<ListList>` — Выбранные конечные элементы всей плоской карты.
- `selectedListInGroup: ComputedRef<ListList>` — Выбранные записи текущего уровня.
- `selectedNames: ComputedRef<ListNames>` — Метки выбранных конечных элементов.
- `selectedValues: ComputedRef<Array<ListDataItem['value']>>` — Значения выбранных конечных элементов с сохранением нуля и false.

## Методы

### Проверки состояния

- `isLite(): boolean` — Истина, если длина текущего уровня превышает ненулевой порог lite.

- `isFocus(): boolean` — Проверяет индекс фокуса в плоской карте.

- `isHighlight(): boolean` — Сообщает, найдено ли совпадение в карте.

- `isHighlightActive(): boolean` — Истина, если запрос короче порога либо найдено хотя бы одно совпадение.

### Количество и значения состояния

- `getLength(): number` — Возвращает количество записей текущего уровня.

- `getLengthByMap(): number` — Возвращает размер плоской карты, включая группы и меню.

- `getLengthByItems(): number` — Возвращает количество item/group/menu в плоской карте.

- `getFocus(): ListSelectedItem | undefined` — Возвращает переданное значение фокуса.

- `getFocusItem(): ListDataItem | undefined` — Ищет запись в фокусе только на текущем уровне.

- `getHighlight(): string | undefined` — Возвращает текст поиска.

- `getHighlightLengthStart(): number` — Возвращает минимальную длину поиска, по умолчанию 2.

- `getSelected(): ListSelectedList | undefined` — Возвращает переданное одиночное выделение либо массив выделений.

### Поиск элементов

- `getItemByIndex(index?: string): { key: number, item: ListDataItem } | undefined` — Ищет запись в плоской карте и возвращает ключ карты и элемент.

- `getItemByKey(key: number): ListDataItem | undefined` — Возвращает запись по позиции плоской карты либо undefined.

- `getFirstItemByParent(parent: string | undefined): ListDataItem | undefined` — Возвращает первую запись item/group/menu с указанным родителем.

- `getLastItemByParent(parent: string | undefined): ListDataItem | undefined` — Возвращает последнюю запись item/group/menu с указанным родителем.

### Навигация

#### `getSelectedByStep`

`getSelectedByStep(step: number): ListSelectedItem | undefined`

Перемещается от первого выделенного конечного элемента на указанный шаг. Без выделенного элемента возвращает индекс первого. Для пустого списка возвращает `undefined`.

**Параметры:**

- `step: number` — Шаг навигации со знаком.

**Возвращает:** `ListSelectedItem | undefined` — Запрошенное значение либо объект согласно сигнатуре.

```typescript
const index = /*#__PURE__*/ list.getSelectedByStep(1)
```

#### `getItemByStep`

`getItemByStep(item: ListDataItem, step: number): ListDataItem | undefined`

Перемещается по карте конечных элементов. Положительный шаг за границу возвращает первый, отрицательный — последний элемент. Нулевой шаг сохраняет найденный элемент.

**Параметры:**

- `item: ListDataItem` — Текущая запись списка.
- `step: number` — Шаг навигации со знаком.

**Возвращает:** `ListDataItem | undefined` — Запрошенное значение либо объект согласно сигнатуре.

```typescript

const next = current && list.getItemByStep(current.item, 1)
```

### Вложенные списки

#### `getSubList`

`getSubList(item: ListDataItem): ListDataRef`

Возвращает кэшированную дочернюю модель с общими ссылками состояния и лимитами. Пересоздаёт её при замене источника группы; родитель — индекс группы.

**Параметры:**

- `item: ListDataItem` — Элемент либо выходной массив согласно сигнатуре.

**Возвращает:** `ListDataRef` — Кэшированная дочерняя модель списка.

```typescript
const grouped = /*#__PURE__*/ new ListDataRef([{ type: 'group', index: 'fruit', label: 'Fruit', value: ['Apple'] }])
const group = grouped.data.value[0]
const children = group && grouped.getSubList(group)
```
