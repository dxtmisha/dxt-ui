# ListDataRef Class

Reactive list model for normalization, nested groups, selection, focus and search matching. It exposes computed top-level and flattened views without rendering UI or mutating the selected input.

## Key Features

- **Normalization** — accepts arrays of labels, object arrays and records.
- **Nested groups** — `group` and `menu` recurse through cached sublists.
- **Reactive state** — refs control selection, focus, search and limits.

## Initialization

`constructor( list: RefOrNormal<ListListInput | undefined>, focus?: RefType<ListSelectedItem | undefined>, highlight?: RefType<string | undefined>, highlightLengthStart?: RefType<number | undefined>, filterMode?: RefType<boolean | undefined>, selected?: RefType<ListSelectedList | undefined>, keyValue?: RefType<string | undefined>, keyLabel?: RefType<string | undefined>, lite?: RefType<number | undefined>, min: RefOrNormal<number | string | undefined> = 0, max: RefOrNormal<number | string | undefined> = 9_999_999, parent?: string )`

**Parameters:**

- `list: RefOrNormal<ListListInput | undefined>` — Input list or record, optionally reactive.
- `focus?: RefType<ListSelectedItem | undefined>` — Focused index ref.
- `highlight?: RefType<string | undefined>` — Search query ref.
- `highlightLengthStart?: RefType<number | undefined>` — Minimum search-length ref; defaults to 2 when omitted.
- `filterMode?: RefType<boolean | undefined>` — Filter-mode ref copied into fullData.
- `selected?: RefType<ListSelectedList | undefined>` — Ref with a single selected identifier or an array.
- `keyValue?: RefType<string | undefined>` — Value-field name ref; defaults to value.
- `keyLabel?: RefType<string | undefined>` — Label-field name ref; defaults to label.
- `lite?: RefType<number | undefined>` — Ref for the simplified-list threshold.
- `min: RefOrNormal<number | string | undefined> = 0` — Selection minimum; defaults to 0.
- `max: RefOrNormal<number | string | undefined> = 9_999_999` — Selection maximum; defaults to 9_999_999.
- `parent?: string` — Parent index, or undefined for the root level.

## Behavior and lifecycle

Only `list`, `min` and `max` accept ordinary values or refs; focus, highlight, selected, key names, lite threshold and filter mode are ref parameters. Simple label arrays use string positions as indexes and numeric positions as values. Object items prefer explicit `index`, then a primitive `value`. `map` flattens `item`, `group` and `menu`; `mapItems` includes only leaf items. Navigation wraps to the first or last item when a step goes out of range. Limits affect computed state; this class does not enforce selection mutations. The minimum flag means the minimum has been reached. `getFocusItem()` searches only the current level. Replacing a list ref clears sublist caches; replacing a group source recreates its cached sublist. Use an owning effect scope to dispose the list-ref watcher.

## Usage

```typescript

import { ref } from 'vue'

const selected = /*#__PURE__*/ ref(['a'])
```

## Properties

- `data: ComputedRef<ListList>` — Normalized entries at the current level.
- `liteData: ComputedRef<ListList>` — Reduced entries only when the lite threshold is exceeded; otherwise the full normalized data.
- `fullData: ComputedRef<ListDataFull>` — Current-level entries enriched with focus, highlight, filterMode, selected and disabled. An explicit disabled value takes precedence.
- `map: ComputedRef<ListList>` — Flattened item/group/menu entries, retaining group headers.
- `mapItems: ComputedRef<ListList>` — Leaf item entries from the flattened map.
- `items: ComputedRef<ListList>` — Item/group/menu entries from the flattened map.
- `highlightFirstItem: ComputedRef<number>` — First matching map position, or -1 for no match or a query below the threshold. Matches label, index or search.
- `isSelected: ComputedRef<boolean>` — Whether at least one leaf matches the selected input.
- `isSelectedMin: ComputedRef<boolean>` — True when a positive minimum is reached by current-group selections.
- `isSelectedMax: ComputedRef<boolean>` — True when a positive maximum is reached by current-group selections. A falsy maximum uses the default limit.
- `selectedList: ComputedRef<ListList>` — Selected leaves across the flattened map.
- `selectedListInGroup: ComputedRef<ListList>` — Selected entries at the current level.
- `selectedNames: ComputedRef<ListNames>` — Labels of selected leaves.
- `selectedValues: ComputedRef<Array<ListDataItem['value']>>` — Values of selected leaves, preserving zero and false.

## Methods

### State checks

- `isLite(): boolean` — True when the nonzero lite threshold is exceeded by the current-level length.

- `isFocus(): boolean` — Checks the focused index against the flattened map.

- `isHighlight(): boolean` — Reports whether search found a map entry.

- `isHighlightActive(): boolean` — True when the query is below the minimum length or at least one match exists.

### Counts and state values

- `getLength(): number` — Returns the current-level item count.

- `getLengthByMap(): number` — Returns the flattened map count, including group and menu entries.

- `getLengthByItems(): number` — Returns the item/group/menu count from the flattened map.

- `getFocus(): ListSelectedItem | undefined` — Returns the supplied focus value.

- `getFocusItem(): ListDataItem | undefined` — Finds the focused entry at the current level only.

- `getHighlight(): string | undefined` — Returns the search text.

- `getHighlightLengthStart(): number` — Returns the search-length threshold, defaulting to 2.

- `getSelected(): ListSelectedList | undefined` — Returns the single selection or selection array supplied to the model.

### Lookup

- `getItemByIndex(index?: string): { key: number, item: ListDataItem } | undefined` — Looks up an entry in the flattened map and returns its map key and item.

- `getItemByKey(key: number): ListDataItem | undefined` — Returns the entry at a flattened-map position, or undefined.

- `getFirstItemByParent(parent: string | undefined): ListDataItem | undefined` — Returns the first item/group/menu entry with the supplied parent.

- `getLastItemByParent(parent: string | undefined): ListDataItem | undefined` — Returns the last item/group/menu entry with the supplied parent.

### Nested lists

#### `getSubList`

`getSubList(item: ListDataItem): ListDataRef`

Returns a cached child model sharing state refs and limits. Recreates it when the group’s source identity changes; the parent is the group index.

**Parameters:**

- `item: ListDataItem` — Item or output array as specified by the signature.

**Returns:** `ListDataRef` — Cached child list model.

```typescript
const grouped = /*#__PURE__*/ new ListDataRef([{ type: 'group', index: 'fruit', label: 'Fruit', value: ['Apple'] }])
const group = grouped.data.value[0]
const children = group && grouped.getSubList(group)
```
