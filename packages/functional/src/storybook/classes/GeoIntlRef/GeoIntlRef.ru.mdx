# Класс GeoIntlRef

Реактивный фасад `GeoIntl` для чисел, валют, дат, названий и сортировки с учётом локали. Методы возвращают вычисляемые ссылки, отслеживающие поддерживаемые входные ссылки и явную локаль либо резервную локаль `GeoRef`. Используйте нереактивный GeoIntl, если вычисляемые обновления не нужны.

## Ключевые особенности

- **Вычисляемые результаты** — читайте значение через `.value`.
- **Интеграция Intl** — опции чисел, дат, названий и относительного времени.
- **Сортировка без мутаций** — исходные массивы копируются.

## Инициализация

`constructor(code?: RefOrNormal<string>)`

**Параметры:**

- `code?: RefOrNormal<string>` — Код локали, страны или языка; ссылка поддерживается согласно сигнатуре.

## Поведение и жизненный цикл

Используйте обычный `GeoIntl`, если реактивность не нужна. `RefOrNormal<T>` принимает значение либо ref/computed Vue, но не функцию-геттер. Опции передаются обычными объектами, если сигнатура явно не содержит `RefOrNormal`. Относительное время пересчитывается при изменении зависимостей, без таймера. Передайте `todayValue` для фиксированной точки отсчёта. Списки месяцев и дней недели начинаются с `{ label: "", value: undefined }`; затем месяцы используют 1–12, дни недели — стандартные коды в порядке локали. Единицы размера файла повышаются при значении больше 1024, а не равном 1024. Преобразование чисел и резервные значения определяет `GeoIntl`.

- `relativeOptions?: Intl.RelativeTimeFormatStyle | Intl.RelativeTimeFormatOptions` — Стиль либо опции Intl относительного времени.
- `dateOptions?: Intl.DateTimeFormatOptions['month'] | Intl.DateTimeFormatOptions` — Стиль либо опции Intl даты за пределами лимита.
- `type?: GeoDate` — Формат вывода либо типы событий согласно сигнатуре.

**Возвращает:** `ComputedRef<string>` — Вычисляемый результат; читайте через .value.


### Сортировка по локали

#### `sort`

`sort<T>( data: RefOrNormal<T[]>, compareFn: (a: T, b: T) => [string, string] = (a, b) => [a as string, b as string] ): ComputedRef<T[]>`

Возвращает отсортированную копию по правилам локали. Для массива объектов передайте функцию, возвращающую две сравниваемые строки.

**Параметры:**

- `data: RefOrNormal<T[]>` — Входной массив; не изменяется.
- `compareFn: (a: T, b: T) => [string, string] = (a, b) => [a as string, b as string]` — Преобразует две записи в две строки для сравнения Intl.Collator.

**Возвращает:** `ComputedRef<T[]>` — Вычисляемый результат; читайте через .value.

```typescript
const sorted = /*#__PURE__*/ formatter.sort(ref([{ label: 'café' }, { label: 'apple' }]), (first, second) => [first.label, second.label])
```
