# GeoIntlRef Class

Reactive `GeoIntl` facade for numbers, money, dates, names and locale-aware sorting. Methods return computed refs that track supported value refs and the explicit locale or `GeoRef` fallback. Use the nonreactive GeoIntl class when computed updates are unnecessary.

## Key Features

- **Saved computations** — read results through `.value`.
- **Intl integration** — number, date, display-name and relative-time options.
- **Immutable sorting** — input arrays are copied.

## Initialization

`constructor(code?: RefOrNormal<string>)`

**Parameters:**

- `code?: RefOrNormal<string>` — Locale, country or language code; a ref is supported where declared.

## Behavior and lifecycle

Use plain `GeoIntl` when reactivity is unnecessary. `RefOrNormal<T>` accepts a value or Vue ref/computed, not a getter function. Options are ordinary objects unless their signature explicitly uses `RefOrNormal`. Relative results are computed when dependencies change; they do not run a timer. Supply `todayValue` for a fixed reference date. Month and weekday lists start with `{ label: "", value: undefined }`; months then use 1–12 and weekdays use native day codes in locale order. File-size unit promotion occurs above 1024, not at 1024. Numeric formatting delegates coercion and fallback behavior to `GeoIntl`.

## Usage

```typescript
import { GeoIntlRef } from '@dxtmisha/functional'
import { ref } from 'vue'
```

- `display( value?: RefOrNormal<string>, typeOptions?: Intl.DisplayNamesOptions['type'] | Intl.DisplayNamesOptions ): ComputedRef<string>` — Returns a localized display name for the requested Intl type.

### Locale sorting

#### `sort`

`sort<T>( data: RefOrNormal<T[]>, compareFn: (a: T, b: T) => [string, string] = (a, b) => [a as string, b as string] ): ComputedRef<T[]>`

Returns a sorted copy using locale collation. For object arrays, provide a mapper returning the two comparison strings.

**Parameters:**

- `data: RefOrNormal<T[]>` — Input array; it is not mutated.
- `compareFn: (a: T, b: T) => [string, string] = (a, b) => [a as string, b as string]` — Maps two entries to the two strings compared by Intl.Collator.

**Returns:** `ComputedRef<T[]>` — Computed result; read it through .value.

```typescript
const sorted = /*#__PURE__*/ formatter.sort(ref([{ label: 'café' }, { label: 'apple' }]), (first, second) => [first.label, second.label])
```
