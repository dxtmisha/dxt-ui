# Lớp GeoIntlRef

Facade phản ứng của `GeoIntl` cho số, tiền tệ, ngày, tên và sắp xếp theo locale. Phương thức trả computed ref theo dõi ref đầu vào được hỗ trợ và locale cụ thể hoặc dự phòng `GeoRef`. Dùng GeoIntl không phản ứng khi không cần cập nhật computed.

## Tính năng chính

- **Kết quả computed** — đọc qua `.value`.
- **Tích hợp Intl** — tùy chọn số, ngày, tên và thời gian tương đối.
- **Sắp xếp không thay đổi nguồn** — mảng đầu vào được sao chép.

## Khởi tạo

`constructor(code?: RefOrNormal<string>)`

**Tham số:**

- `code?: RefOrNormal<string>` — Mã locale, quốc gia hoặc ngôn ngữ; hỗ trợ ref theo chữ ký.

## Hành vi và vòng đời

Dùng `GeoIntl` thường nếu không cần phản ứng. `RefOrNormal<T>` nhận giá trị hoặc ref/computed Vue, không nhận hàm getter. Tùy chọn là đối tượng thường trừ khi chữ ký dùng `RefOrNormal`. Thời gian tương đối chỉ tính lại khi phụ thuộc đổi, không chạy bộ hẹn giờ. Truyền `todayValue` để cố định ngày tham chiếu. Danh sách tháng và ngày tuần bắt đầu bằng `{ label: "", value: undefined }`; tháng dùng 1–12, ngày tuần dùng mã chuẩn theo thứ tự locale. Đơn vị dung lượng tệp chỉ tăng khi lớn hơn 1024. `GeoIntl` quyết định ép kiểu số và giá trị dự phòng.

## Cách dùng

```typescript
import { GeoIntlRef } from '@dxtmisha/functional'
import { ref } from 'vue'

const locale = /*#__PURE__*/ ref('en-US')
const amount = /*#__PURE__*/ ref(0)
const formatter = /*#__PURE__*/ new GeoIntlRef(locale)
const formatted = /*#__PURE__*/ formatter.currency(amount, ref('USD'))
amount.value = 1234.5
locale.value = 'vi-VN'
```

## Phương thức

### Tên hiển thị

- `display( value?: RefOrNormal<string>, typeOptions?: Intl.DisplayNamesOptions['type'] | Intl.DisplayNamesOptions ): ComputedRef<string>` — Trả tên địa phương hóa cho loại Intl được yêu cầu.

- `languageName( value?: RefOrNormal<string>, style?: Intl.RelativeTimeFormatStyle ): ComputedRef<string>` — Trả tên ngôn ngữ được địa phương hóa.

- `countryName( value?: RefOrNormal<string>, style?: Intl.RelativeTimeFormatStyle ): ComputedRef<string>` — Trả tên khu vực được địa phương hóa.

### Số

#### `number`

`number( value: RefOrNormal<NumberOrString>, options?: Intl.NumberFormatOptions ): ComputedRef<string>`

Định dạng số hoặc chuỗi số theo locale và tùy chọn số.

**Tham số:**

- `value: RefOrNormal<NumberOrString>` — Giá trị để định dạng; hỗ trợ ref theo chữ ký.
- `options?: Intl.NumberFormatOptions` — Tùy chọn cấu hình.

**Trả về:** `ComputedRef<string>` — Kết quả computed; đọc qua .value.

```typescript
const number = /*#__PURE__*/ formatter.number(amount, { maximumFractionDigits: 2 })
```

#### `plural`

`plural( value: RefOrNormal<NumberOrString>, words: string, options?: Intl.PluralRulesOptions, optionsNumber?: Intl.NumberFormatOptions ): ComputedRef<string>`

Chọn dạng số nhiều và định dạng số lượng. Truyền các biến thể từ phân cách bằng dấu gạch đứng theo `GeoIntl`.

**Tham số:**

- `options?: Intl.PluralRulesOptions` — Tùy chọn cấu hình.
- `optionsNumber?: Intl.NumberFormatOptions` — Tùy chọn định dạng số lượng.

**Trả về:** `ComputedRef<string>` — Kết quả computed; đọc qua .value.

### Tiền tệ và đơn vị

#### `currency`

`currency( value: RefOrNormal<NumberOrString>, currencyOptions?: RefOrNormal<string | Intl.NumberFormatOptions>, numberOnly = false ): ComputedRef<string>`

Định dạng tiền bằng mã tiền hoặc đối tượng tùy chọn phản ứng. `numberOnly` bỏ biểu diễn tiền tệ.

**Tham số:**

- `value: RefOrNormal<NumberOrString>` — Giá trị để định dạng; hỗ trợ ref theo chữ ký.
- `currencyOptions?: RefOrNormal<string | Intl.NumberFormatOptions>` — Mã tiền tệ hoặc tùy chọn số Intl.
- `numberOnly = false` — Bỏ biểu diễn tiền tệ; mặc định false.

**Trả về:** `ComputedRef<string>` — Kết quả computed; đọc qua .value.

```typescript
const money = /*#__PURE__*/ formatter.currency(amount, ref('USD'), false)
```

#### `unit`

`unit( value: RefOrNormal<NumberOrString>, unitOptions?: string | Intl.NumberFormatOptions ): ComputedRef<string>`

Định dạng số với đơn vị Intl; không chuyển đổi đơn vị theo khu vực.

**Tham số:**

- `value: RefOrNormal<NumberOrString>` — Giá trị để định dạng; hỗ trợ ref theo chữ ký.
- `unitOptions?: string | Intl.NumberFormatOptions` — Mã đơn vị hoặc tùy chọn số Intl.

**Trả về:** `ComputedRef<string>` — Kết quả computed; đọc qua .value.

```typescript
const distance = /*#__PURE__*/ formatter.unit(amount, 'meter')
```

#### `sizeFile`

`sizeFile( value: RefOrNormal<NumberOrString>, unitOptions: 'byte' | 'kilobyte' | 'megabyte' | 'gigabyte' | 'terabyte' | 'petabyte' | Intl.NumberFormatOptions = 'byte' ): ComputedRef<string>`

Định dạng dung lượng tệp bắt đầu từ đơn vị được truyền. Đơn vị chuỗi tăng khi giá trị vượt 1024; đối tượng tùy chọn được chuyển cho định dạng đơn vị.

**Tham số:**

- `value: RefOrNormal<NumberOrString>` — Giá trị để định dạng; hỗ trợ ref theo chữ ký.
- `unitOptions: 'byte'
      | 'kilobyte'
      | 'megabyte'
      | 'gigabyte'
      | 'terabyte'
      | 'petabyte'
      | Intl.NumberFormatOptions = 'byte'` — Mã đơn vị hoặc tùy chọn số Intl.

**Trả về:** `ComputedRef<string>` — Kết quả computed; đọc qua .value.

```typescript
const size = /*#__PURE__*/ formatter.sizeFile(2048, 'byte')
```

### Định dạng ngày

Định dạng ngày bằng kiểu Geo, tùy chọn ngày và tùy chọn đồng hồ 24 giờ.

**Tham số:**

- `type?: GeoDate` — Kiểu đầu ra hoặc loại sự kiện theo chữ ký.
- `styleOptions?: Intl.DateTimeFormatOptions['month'] | Intl.DateTimeFormatOptions` — Kiểu Intl hoặc tùy chọn định dạng.
- `hour24?: boolean` — Có dùng đồng hồ 24 giờ hay không.

**Trả về:** `ComputedRef<string>` — Kết quả computed; đọc qua .value.

```typescript

```

### Tên lịch và giờ

- `month( value?: RefOrNormal<NumberOrStringOrDate>, style?: Intl.DateTimeFormatOptions['month'] ): ComputedRef<string>` — Trả tên tháng của ngày được truyền.

- `months( style?: Intl.DateTimeFormatOptions['month'] ): ComputedRef<ItemValue<number | undefined>[]>` — Trả mục giữ chỗ rồi 12 tháng đánh số 1–12.

- `weekday( value?: RefOrNormal<NumberOrStringOrDate>, style?: Intl.DateTimeFormatOptions['weekday'] ): ComputedRef<string>` — Trả tên ngày tuần của ngày được truyền.

- `weekdays( style?: Intl.DateTimeFormatOptions['weekday'] ): ComputedRef<ItemValue<number | undefined>[]>` — Trả mục giữ chỗ rồi bảy ngày tuần theo thứ tự locale.

- `time(value: RefOrNormal<NumberOrStringOrDate>): ComputedRef<string>` — Định dạng ngày được truyền thành giờ địa phương.

### Thời gian tương đối

#### `relative`

`relative( value: RefOrNormal<NumberOrStringOrDate>, styleOptions?: Intl.RelativeTimeFormatStyle | Intl.RelativeTimeFormatOptions, todayValue?: Date ): ComputedRef<string>`

Định dạng ngày tương đối so với ngày tham chiếu theo cách chọn đơn vị của GeoIntl.

**Tham số:**

- `value: RefOrNormal<NumberOrStringOrDate>` — Giá trị để định dạng; hỗ trợ ref theo chữ ký.
- `styleOptions?: Intl.RelativeTimeFormatStyle | Intl.RelativeTimeFormatOptions` — Kiểu Intl hoặc tùy chọn định dạng.
- `todayValue?: Date` — Ngày tham chiếu; bỏ qua thì dùng ngày hiện tại khi tính.

**Trả về:** `ComputedRef<string>` — Kết quả computed; đọc qua .value.

```typescript
const relative = /*#__PURE__*/ formatter.relative('2025-01-03', 'long', new Date(2025, 0, 1))
```

#### `relativeLimit`

`relativeLimit( value: RefOrNormal<NumberOrStringOrDate>, limit: number, todayValue?: Date, relativeOptions?: Intl.RelativeTimeFormatStyle | Intl.RelativeTimeFormatOptions, dateOptions?: Intl.DateTimeFormatOptions['month'] | Intl.DateTimeFormatOptions, type?: GeoDate, hour24?: boolean ): ComputedRef<string>`

Dùng định dạng tương đối trong khoảng ±limit ngày có tính biên. Ngoài khoảng đó dùng định dạng ngày với mọi tùy chọn ngày đã truyền.

**Tham số:**

- `value: RefOrNormal<NumberOrStringOrDate>` — Giá trị để định dạng; hỗ trợ ref theo chữ ký.
- `limit: number` — Giới hạn thời gian tương đối theo ngày, có tính biên.
- `todayValue?: Date` — Ngày tham chiếu; bỏ qua thì dùng ngày hiện tại khi tính.
- `relativeOptions?: Intl.RelativeTimeFormatStyle | Intl.RelativeTimeFormatOptions` — Kiểu hoặc tùy chọn Intl cho thời gian tương đối.
- `dateOptions?: Intl.DateTimeFormatOptions['month'] | Intl.DateTimeFormatOptions` — Kiểu hoặc tùy chọn Intl cho ngày ngoài giới hạn.
- `type?: GeoDate` — Kiểu đầu ra hoặc loại sự kiện theo chữ ký.
- `hour24?: boolean` — Có dùng đồng hồ 24 giờ hay không.

**Trả về:** `ComputedRef<string>` — Kết quả computed; đọc qua .value.

```typescript
const label = /*#__PURE__*/ formatter.relativeLimit('2025-01-05', 2, new Date(2025, 0, 1), 'long', 'long', 'date', true)
```

### Sắp xếp theo locale

#### `sort`

`sort<T>( data: RefOrNormal<T[]>, compareFn: (a: T, b: T) => [string, string] = (a, b) => [a as string, b as string] ): ComputedRef<T[]>`

Trả bản sao được sắp theo locale. Với mảng đối tượng, truyền hàm trả hai chuỗi để so sánh.

**Tham số:**

- `data: RefOrNormal<T[]>` — Mảng đầu vào; không bị thay đổi.
- `compareFn: (a: T, b: T) => [string, string] = (a, b) => [a as string, b as string]` — Ánh xạ hai mục thành hai chuỗi so sánh bằng Intl.Collator.

**Trả về:** `ComputedRef<T[]>` — Kết quả computed; đọc qua .value.

```typescript
const sorted = /*#__PURE__*/ formatter.sort(ref([{ label: 'café' }, { label: 'apple' }]), (first, second) => [first.label, second.label])
```
