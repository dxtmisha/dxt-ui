# Lớp GeoRef

Facade phản ứng tĩnh cho ngữ cảnh địa lý hiện tại. Lưu shallow ref tới `Geo.getItem()` và các phép chiếu computed qua `ServerStorage`.

## Tính năng chính

- **Ref dùng chung** — getter dùng lại ref đã lưu trong ngữ cảnh hiện tại.
- **Cập nhật locale** — `set()` thay mục địa lý và cập nhật phép chiếu.
- **Ngữ cảnh SSR** — quyền sở hữu bộ nhớ đệm theo `ServerStorage`.

## Hành vi và vòng đời

Dữ liệu quốc gia khác locale được yêu cầu: `en-VN` có ngôn ngữ quốc gia `vi` và ngôn ngữ vị trí `en`. `getFirstDay()` trả ký hiệu như `Mo` hoặc `Su`, không phải mã số. `setValueDefault()` cấu hình dự phòng; cookie locale hiện có có thể được ưu tiên. Khởi tạo lưu trữ yêu cầu trước SSR và đọc ref trong ngữ cảnh sở hữu.

## Cách dùng

```typescript
import { GeoRef } from '@dxtmisha/functional'

const country = /*#__PURE__*/ GeoRef.getCountry()
const language = /*#__PURE__*/ GeoRef.getLocationLanguage()
GeoRef.set('en-VN')
country.value // 'VN'
language.value // 'en'
```

## Phương thức

### Ngữ cảnh hiện tại

- `get(): Ref<GeoItemFull>` — Trả ref mục địa lý đã lưu.

- `getCountry(): ComputedRef<string>` — Trả mã quốc gia.

- `getLanguage(): ComputedRef<string>` — Trả ngôn ngữ trong dữ liệu quốc gia.

- `getStandard(): ComputedRef<string>` — Trả mã locale chuẩn.

- `getFirstDay(): ComputedRef<string>` — Trả ký hiệu ngày đầu tuần từ dữ liệu quốc gia.

- `getLocation(): ComputedRef<string>` — Trả locale vị trí hiện tại.

- `getLocationCountry(): ComputedRef<string>` — Trả phần quốc gia của vị trí được yêu cầu.

- `getLocationLanguage(): ComputedRef<string>` — Trả phần ngôn ngữ của vị trí được yêu cầu.

### Cấu hình locale

#### `set`

`set(code: string): void`

Đặt locale Geo hiện tại có lưu trữ và thay mục phản ứng.

**Tham số:**

- `code: string` — Mã locale, quốc gia hoặc ngôn ngữ.

**Trả về:** `void` — Không có giá trị trả về.

```typescript
GeoRef.set('vi-VN')
```

#### `setValueDefault`

`setValueDefault(code?: string | (() => string)): void`

Đặt mã hoặc hàm dự phòng Geo và làm mới mục phản ứng từ Geo.

**Tham số:**

- `code?: string | (() => string)` — Mã locale dự phòng hoặc hàm tạo mã.

**Trả về:** `void` — Không có giá trị trả về.

```typescript
GeoRef.setValueDefault(() => 'vi-VN')
```
