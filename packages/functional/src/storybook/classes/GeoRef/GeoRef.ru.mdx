# Класс GeoRef

Статический реактивный фасад текущего географического контекста. Кэширует поверхностную ссылку на `Geo.getItem()` и вычисляемые проекции через `ServerStorage`.

## Ключевые особенности

- **Общие ссылки** — повторные вызовы используют кэш текущего контекста.
- **Изменение локали** — `set()` заменяет географические данные и обновляет проекции.
- **Контекст SSR** — владелец кэша определяется `ServerStorage`.

## Поведение и жизненный цикл

Данные страны и запрошенная локаль различаются: у `en-VN` язык страны — `vi`, а язык местоположения — `en`. `getFirstDay()` возвращает обозначение дня, например `Mo` или `Su`, а не числовой код. `setValueDefault()` задаёт резервное значение; существующая cookie локали может иметь приоритет. Перед SSR инициализируйте хранилище запроса и читайте ссылки в контексте их владельца.

## Использование

```typescript
import { GeoRef } from '@dxtmisha/functional'

const country = /*#__PURE__*/ GeoRef.getCountry()
const language = /*#__PURE__*/ GeoRef.getLocationLanguage()
GeoRef.set('en-VN')
country.value // 'VN'
language.value // 'en'
```

## Методы

### Текущий контекст

- `get(): Ref<GeoItemFull>` — Возвращает кэшированную ссылку на географические данные.

- `getCountry(): ComputedRef<string>` — Возвращает код страны.

- `getLanguage(): ComputedRef<string>` — Возвращает язык из данных страны.

- `getStandard(): ComputedRef<string>` — Возвращает стандартный код локали.

- `getFirstDay(): ComputedRef<string>` — Возвращает обозначение первого дня недели из данных страны.

- `getLocation(): ComputedRef<string>` — Возвращает текущую локаль местоположения.

- `getLocationCountry(): ComputedRef<string>` — Возвращает сегмент страны запрошенного местоположения.

- `getLocationLanguage(): ComputedRef<string>` — Возвращает языковой сегмент запрошенного местоположения.

### Настройка локали

#### `set`

`set(code: string): void`

Устанавливает текущую локаль Geo с сохранением и заменяет реактивные данные.

**Параметры:**

- `code: string` — Код локали, страны или языка; ссылка поддерживается согласно сигнатуре.

**Возвращает:** `void` — Нет возвращаемого значения.

```typescript
GeoRef.set('vi-VN')
```

#### `setValueDefault`

`setValueDefault(code?: string | (() => string)): void`

Устанавливает резервный код Geo либо фабрику и обновляет реактивные данные из Geo.

**Параметры:**

- `code?: string | (() => string)` — Резервный код локали либо фабрика.

**Возвращает:** `void` — Нет возвращаемого значения.

```typescript
GeoRef.setValueDefault(() => 'vi-VN')
```
