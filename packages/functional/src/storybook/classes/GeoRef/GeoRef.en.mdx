# GeoRef Class

Static reactive facade for the current geographic context. It caches a shallow ref to `Geo.getItem()` and computed projections through `ServerStorage`.

## Key Features

- **Shared refs** — repeated getters reuse cached refs in the current context.
- **Locale updates** — `set()` replaces the geographic item and refreshes projections.
- **SSR context** — cache ownership follows `ServerStorage`.

## Behavior and lifecycle

Country metadata and requested locale are distinct: `en-VN` has country language `vi` and location language `en`. `getFirstDay()` returns a weekday token such as `Mo` or `Su`, not a numeric code. `setValueDefault()` configures the fallback; an existing locale cookie can take precedence. Initialize request storage before SSR use and read refs within their owning request context.

## Usage

```typescript
import { GeoRef } from '@dxtmisha/functional'

const country = /*#__PURE__*/ GeoRef.getCountry()
const language = /*#__PURE__*/ GeoRef.getLocationLanguage()
GeoRef.set('en-VN')
country.value // 'VN'
language.value // 'en'
```

## Methods

### Current context

- `get(): Ref<GeoItemFull>` — Returns the cached geographic item ref.

- `getCountry(): ComputedRef<string>` — Returns the country code.

- `getLanguage(): ComputedRef<string>` — Returns the country metadata language.

- `getStandard(): ComputedRef<string>` — Returns the standard locale code.

- `getFirstDay(): ComputedRef<string>` — Returns the first-weekday token from country metadata.

- `getLocation(): ComputedRef<string>` — Returns the current location locale.

- `getLocationCountry(): ComputedRef<string>` — Returns the country segment of the requested location.

- `getLocationLanguage(): ComputedRef<string>` — Returns the language segment of the requested location.

### Locale configuration

#### `set`

`set(code: string): void`

Sets the current Geo locale with persistence enabled and replaces the reactive item.

**Parameters:**

- `code: string` — Locale, country or language code.

**Returns:** `void` — No return value.

```typescript
GeoRef.set('vi-VN')
```

#### `setValueDefault`

`setValueDefault(code?: string | (() => string)): void`

Sets the Geo fallback code or factory and refreshes the reactive item from Geo.

**Parameters:**

- `code?: string | (() => string)` — Fallback locale code or factory.

**Returns:** `void` — No return value.

```typescript
GeoRef.setValueDefault(() => 'vi-VN')
```
