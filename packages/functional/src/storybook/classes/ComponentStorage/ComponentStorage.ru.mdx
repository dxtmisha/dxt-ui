# Класс ComponentStorage

Статический фасад для хранения и получения компонентов Vue со свойствами по умолчанию. Использует единый общий экземпляр `ComponentStorageInstance` для всего процесса (включая SSR).

## Ключевые особенности

- **Статический интерфейс** — регистрация и получение компонентов без необходимости ручного создания экземпляра.
- **Ленивая инициализация** — единый экземпляр `ComponentStorageInstance` создаётся только при первом обращении через `getItem()`.
- **Интеграция с `dxtFunctionalPlugin`** — автоматически наполняется при передаче опции `components` в плагин инициализации приложения.

## Использование

```typescript
import { ComponentStorage } from '@dxtmisha/functional'
import { defineComponent, h } from 'vue'

const MyButton = /*#__PURE__*/ defineComponent({
  name: 'MyButton',
  render: () => h('button')
})

ComponentStorage.add('button', MyButton, { class: 'btn-base' })
const resolved = /*#__PURE__*/ ComponentStorage.get('button', { class: 'btn-primary' })
```

## Методы

### Получение и проверка

#### `get`

`static get< C extends Component = Component, P extends ItemList = ItemList >( name: string, props?: P ): ComponentStorageReturn<C, P> | undefined`

Получает зарегистрированный компонент по имени и объединяет его свойства по умолчанию с переданными свойствами.

**Параметры:**

- `name: string` — Название компонента.
- `props?: P` — Дополнительные свойства для объединения со свойствами по умолчанию.

**Возвращает:** `ComponentStorageReturn<C, P> | undefined` — Компонент с объединёнными свойствами или `undefined`, если не найден.

```typescript
const item = /*#__PURE__*/ ComponentStorage.get('button', { disabled: true })
```

#### `has`

`static has(name: string): boolean`

Проверяет, зарегистрирован ли в хранилище компонент с указанным именем.

**Параметры:**

- `name: string` — Название компонента.

**Возвращает:** `boolean` — `true`, если компонент существует.

```typescript
const exists = /*#__PURE__*/ ComponentStorage.has('button')
```

#### `getItem`

`static getItem(): ComponentStorageInstance`

Возвращает общий экземпляр `ComponentStorageInstance`.

**Возвращает:** `ComponentStorageInstance` — Общий экземпляр `ComponentStorageInstance`.

```typescript
const instance = /*#__PURE__*/ ComponentStorage.getItem()
```

### Регистрация

#### `add`

`static add< C extends Component = Component, P extends ItemList = ItemList >( name: string, component: C, props?: P ): void`

Регистрирует Vue компонент с необязательными свойствами по умолчанию в хранилище.

**Параметры:**

- `name: string` — Название компонента.
- `component: C` — Vue компонент.
- `props?: P` — Свойства по умолчанию для компонента.

**Возвращает:** `void` — Нет возвращаемого значения.

```typescript
ComponentStorage.add('button', MyButton, { type: 'button' })
```

#### `addList`

`static addList(list: ComponentStorageList): void`

Регистрирует список Vue компонентов с их свойствами по умолчанию в хранилище.

**Параметры:**

- `list: ComponentStorageList` — Список элементов регистрации компонентов.

**Возвращает:** `void` — Нет возвращаемого значения.

```typescript
ComponentStorage.addList([
  { name: 'button', component: MyButton, props: { type: 'button' } }
])
```
