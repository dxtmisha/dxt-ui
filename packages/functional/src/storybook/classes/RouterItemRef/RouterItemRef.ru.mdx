# Класс RouterItemRef

Статический фасад установленного Vue Router, сохранённого через `ServerStorage`. Разрешает именованные маршруты в свойства href и запускает навигацию.

## Ключевые особенности

- **Именованные ссылки** — сохраняет параметры, query, hash и базу истории.
- **Регистрация** — `set()` заменяет, `setOneTime()` устанавливает только при отсутствии.
- **Необязательный роутер** — без регистрации возвращает undefined для ссылки либо пустые href-свойства.

## Поведение и жизненный цикл

`rawToHref()` обрабатывает только объекты со строковым `name`; объекты path и URL-строки возвращают `{}`. Неизвестное имя маршрута может вызвать ошибку Vue Router. `push()` возвращает `void`, не предоставляя Promise навигации; для ожидания и обработки ошибок используйте роутер напрямую. Перед SSR инициализируйте хранилище запроса.

## Использование

```typescript
import { RouterItemRef } from '@dxtmisha/functional'

```

## Методы

### Регистрация

- `get(): Router` — Возвращает зарегистрированный роутер; фактически он может отсутствовать.

- `set(router: Router): void` — Сохраняет или заменяет роутер текущего контекста.

- `setOneTime(router: Router): void` — Регистрирует роутер только при отсутствии сохранённого.

### Ссылки и навигация

#### `getLink`

`getLink( name: string, params?: RouteParamsRawGeneric, query?: LocationQueryRaw, hash?: string ): string | undefined`

Разрешает именованное местоположение в `router.resolve(...).href`; без роутера возвращает `undefined`.

**Параметры:**

- `name: string` — Имя зарегистрированного маршрута.
- `params?: RouteParamsRawGeneric` — Параметры именованного маршрута.
- `query?: LocationQueryRaw` — Параметры строки запроса маршрута.
- `hash?: string` — Фрагмент маршрута с начальным #.

**Возвращает:** `string | undefined` — Запрошенная строка либо undefined при отсутствии.

```typescript
const link = /*#__PURE__*/ RouterItemRef.getLink('user', { id: 0 }, { page: 1 }, '#details')
```

#### `getHref`

`getHref( name?: string, params?: RouteParamsRawGeneric, query?: LocationQueryRaw, hash?: string ): ConstrHrefProps`

Возвращает `{ href }` для непустой разрешённой ссылки, иначе `{}`.

**Параметры:**

- `name?: string` — Имя зарегистрированного маршрута.
- `params?: RouteParamsRawGeneric` — Параметры именованного маршрута.
- `query?: LocationQueryRaw` — Параметры строки запроса маршрута.
- `hash?: string` — Фрагмент маршрута с начальным #.

**Возвращает:** `ConstrHrefProps` — Запрошенное значение либо объект согласно сигнатуре.

```typescript
const props = /*#__PURE__*/ RouterItemRef.getHref('user', { id: 0 })
```

#### `rawToHref`

`rawToHref( to?: string | RouteLocationRaw ): ConstrHrefProps`

Преобразует именованное местоположение в href-свойства, сохраняя параметры, query и hash.

**Параметры:**

- `to?: string | RouteLocationRaw` — Необработанное местоположение маршрута.

**Возвращает:** `ConstrHrefProps` — Запрошенное значение либо объект согласно сигнатуре.

```typescript
const props = /*#__PURE__*/ RouterItemRef.rawToHref({ name: 'user', params: { id: 0 }, hash: '#details' })
```

#### `push`

`push(to: string | RouteLocationRaw): void`

Запускает навигацию при наличии зарегистрированного роутера.

**Параметры:**

- `to: string | RouteLocationRaw` — Необработанное местоположение маршрута.

**Возвращает:** `void` — Нет возвращаемого значения.

```typescript
RouterItemRef.push({ name: 'user', params: { id: 0 } })
```
