# Lớp RouterItemRef

Facade tĩnh cho Vue Router đã đăng ký qua `ServerStorage`. Phân giải tuyến có tên thành thuộc tính href và thực hiện điều hướng.

## Tính năng chính

- **Liên kết có tên** — giữ params, query, hash và đường dẫn cơ sở của router.
- **Đăng ký** — `set()` thay thế, `setOneTime()` chỉ đặt khi chưa có.
- **Router tùy chọn** — chưa đăng ký cho liên kết undefined hoặc thuộc tính href rỗng.

## Hành vi và vòng đời

`rawToHref()` chỉ xử lý đối tượng có `name` kiểu chuỗi; đối tượng path và chuỗi URL trả `{}`. Tên tuyến không biết có thể gây lỗi Vue Router. `push()` trả `void`, không trả promise điều hướng; dùng router trực tiếp khi cần chờ hoặc xử lý lỗi. Khởi tạo lưu trữ yêu cầu trước SSR.

## Cách dùng

```typescript
import { RouterItemRef } from '@dxtmisha/functional'
import { createMemoryHistory, createRouter } from 'vue-router'

const router = /*#__PURE__*/ createRouter({
  history: createMemoryHistory('/app/'),
  routes: [{ path: '/users/:id', name: 'user', component: { render: () => null } }]
})
RouterItemRef.set(router)
const href = /*#__PURE__*/ RouterItemRef.getHref('user', { id: 0 }, { page: 1 }, '#details')
```

## Phương thức

### Đăng ký

- `get(): Router` — Trả router đã đăng ký; lúc chạy có thể chưa có.

- `set(router: Router): void` — Lưu hoặc thay router trong ngữ cảnh hiện tại.

- `setOneTime(router: Router): void` — Chỉ đăng ký router khi chưa lưu router nào.

### Liên kết và điều hướng

#### `getLink`

`getLink( name: string, params?: RouteParamsRawGeneric, query?: LocationQueryRaw, hash?: string ): string | undefined`

Phân giải vị trí có tên thành `router.resolve(...).href`; trả `undefined` nếu chưa có router.

**Tham số:**

- `name: string` — Tên tuyến đã đăng ký.
- `params?: RouteParamsRawGeneric` — Tham số tuyến có tên.
- `query?: LocationQueryRaw` — Tham số truy vấn tuyến.
- `hash?: string` — Phân đoạn tuyến gồm dấu # đầu.

**Trả về:** `string | undefined` — Chuỗi được yêu cầu hoặc undefined khi không có.

```typescript
const link = /*#__PURE__*/ RouterItemRef.getLink('user', { id: 0 }, { page: 1 }, '#details')
```

#### `getHref`

`getHref( name?: string, params?: RouteParamsRawGeneric, query?: LocationQueryRaw, hash?: string ): ConstrHrefProps`

Trả `{ href }` cho liên kết phân giải không rỗng, ngược lại `{}`.

**Tham số:**

- `name?: string` — Tên tuyến đã đăng ký.
- `params?: RouteParamsRawGeneric` — Tham số tuyến có tên.
- `query?: LocationQueryRaw` — Tham số truy vấn tuyến.
- `hash?: string` — Phân đoạn tuyến gồm dấu # đầu.

**Trả về:** `ConstrHrefProps` — Giá trị hoặc đối tượng được yêu cầu theo chữ ký.

```typescript
const props = /*#__PURE__*/ RouterItemRef.getHref('user', { id: 0 })
```

#### `rawToHref`

`rawToHref( to?: string | RouteLocationRaw ): ConstrHrefProps`

Chuyển vị trí thô có tên thành thuộc tính href, giữ params, query và hash.

**Tham số:**

- `to?: string | RouteLocationRaw` — Vị trí tuyến thô.

**Trả về:** `ConstrHrefProps` — Giá trị hoặc đối tượng được yêu cầu theo chữ ký.

```typescript
const props = /*#__PURE__*/ RouterItemRef.rawToHref({ name: 'user', params: { id: 0 }, hash: '#details' })
```

#### `push`

`push(to: string | RouteLocationRaw): void`

Bắt đầu điều hướng khi router đã đăng ký.

**Tham số:**

- `to: string | RouteLocationRaw` — Vị trí tuyến thô.

**Trả về:** `void` — Không có giá trị trả về.

```typescript
RouterItemRef.push({ name: 'user', params: { id: 0 } })
```
