# RouterItemRef Class

Static facade for an installed Vue Router instance stored through `ServerStorage`. It resolves named routes to href properties and dispatches navigation.

## Key Features

- **Named links** — preserves params, query, hash and router history base.
- **Registration** — `set()` replaces, `setOneTime()` initializes only if absent.
- **Optional router** — absent registration gives undefined links or empty href props.

## Behavior and lifecycle

`rawToHref()` accepts only object locations with a string `name`; path objects and URL strings return `{}`. Unknown registered route names may throw from Vue Router. `push()` returns `void` and does not expose the navigation promise; use the router directly when awaiting navigation or handling failures. Initialize request storage before SSR use.

## Usage

```typescript
import { RouterItemRef } from '@dxtmisha/functional'
import { createMemoryHistory, createRouter } from 'vue-router'

const router = /*#__PURE__*/ createRouter({
  history: createMemoryHistory('/app/'),

})

```

## Methods

### Registration

- `get(): Router` — Returns the registered router; it may be absent at runtime.

- `set(router: Router): void` — Stores or replaces the router in the current context.

- `setOneTime(router: Router): void` — Registers the router only if no router has been stored.

### Links and navigation

#### `getLink`

`getLink( name: string, params?: RouteParamsRawGeneric, query?: LocationQueryRaw, hash?: string ): string | undefined`

Resolves a named location to `router.resolve(...).href`, or returns `undefined` without a router.

**Parameters:**

- `name: string` — Registered route name.
- `params?: RouteParamsRawGeneric` — Named-route parameters.
- `query?: LocationQueryRaw` — Route query parameters.
- `hash?: string` — Route fragment including its leading #.

**Returns:** `string | undefined` — Requested string, or undefined when unavailable.

```typescript
const link = /*#__PURE__*/ RouterItemRef.getLink('user', { id: 0 }, { page: 1 }, '#details')
```

#### `getHref`

`getHref( name?: string, params?: RouteParamsRawGeneric, query?: LocationQueryRaw, hash?: string ): ConstrHrefProps`

Returns `{ href }` for a nonempty resolved link, otherwise `{}`.

**Parameters:**

- `name?: string` — Registered route name.
- `params?: RouteParamsRawGeneric` — Named-route parameters.
- `query?: LocationQueryRaw` — Route query parameters.
- `hash?: string` — Route fragment including its leading #.

**Returns:** `ConstrHrefProps` — The requested value or object as declared in the signature.

```typescript
const props = /*#__PURE__*/ RouterItemRef.getHref('user', { id: 0 })
```

#### `rawToHref`

`rawToHref( to?: string | RouteLocationRaw ): ConstrHrefProps`

Converts a named raw location to href props, retaining params, query and hash.

**Parameters:**

- `to?: string | RouteLocationRaw` — Raw route location.

**Returns:** `ConstrHrefProps` — The requested value or object as declared in the signature.

```typescript
const props = /*#__PURE__*/ RouterItemRef.rawToHref({ name: 'user', params: { id: 0 }, hash: '#details' })
```

#### `push`

`push(to: string | RouteLocationRaw): void`

Starts router navigation when a router is registered.

**Parameters:**

- `to: string | RouteLocationRaw` — Raw route location.

**Returns:** `void` — No return value.

```typescript
RouterItemRef.push({ name: 'user', params: { id: 0 } })
```
