# Lớp DesignLogicAbstract

Bộ điều phối trừu tượng cho phụ thuộc logic thành phần. Lớp giữ phạm vi hiệu ứng Vue hiện tại, đầu vào dùng chung và tạo, lưu phụ thuộc theo khóa chuỗi khi cần.

## Tính năng chính

- **Khởi tạo lười** — hàm tạo tham số chỉ chạy khi tạo đối tượng lần đầu.
- **Quyền sở hữu phạm vi** — hiệu ứng phụ thuộc thuộc phạm vi hoạt động đã lưu.
- **Vòng đời** — nhận diện callback đồng bộ thông qua `DesignLifecycleAbstract`.

## Khởi tạo

`constructor( props: Readonly<P>, element: Ref<E | undefined>, naming: DesignName, components?: DesignComponents<COMP, P>, slots?: SLOTS, emits?: ConstrEmit<EMITS>, constructors?: Partial<CONSTRUCTORS>, hasLifecycle: boolean = true )`

**Tham số:**

- `props: Readonly<P>` — Thuộc tính đầu vào.
- `element: Ref<E | undefined>` — Ref phần tử gốc.
- `naming: DesignName` — Tiện ích DesignName dùng chung.
- `components?: DesignComponents<COMP, P>` — Bộ đăng ký thành phần kết nối.
- `slots?: SLOTS` — Bộ đăng ký slot có tên.
- `emits?: ConstrEmit<EMITS>` — Hàm phát sự kiện thành phần.
- `constructors?: Partial<CONSTRUCTORS>` — Ghi đè hàm dựng phụ thuộc.
- `hasLifecycle: boolean = true` — Có đăng ký hook vòng đời thành phần; mặc định true.

## Hành vi và vòng đời

Tham số kiểu: E là phần tử gốc, COMP là bộ đăng ký thành phần, EMITS là sự kiện, SLOTS là slot, P là thuộc tính và CONSTRUCTORS là bản đồ hàm dựng phụ thuộc. Tạo đối tượng trong `setup()` hoặc `effectScope()` đang hoạt động. Nếu thiếu phạm vi hoạt động đã lưu hoặc hàm tạo, tra cứu trả về `undefined` lúc chạy dù kiểu trả về khai báo là đối tượng phụ thuộc. `constructors` ưu tiên hơn `constructorItems[name].item`. Điều kiện được theo dõi khi gắn thành phần: giá trị đúng tạo phụ thuộc, giá trị sai không hủy phụ thuộc. Chỉ thành phần Vue đăng ký hook; `hasLifecycle = false` tắt đăng ký. SSR không gọi callback phía trình duyệt. Khi gắn, callback của phụ thuộc hiện có chạy trước, tiếp theo là khởi tạo điều kiện và callback của logic. Phụ thuộc tạo muộn được gắn ngay. Lỗi callback phụ thuộc được thu thập, gửi tới `ErrorCenter` rồi ném dưới dạng `AggregateError` sau khi duyệt hết callback; callback logic tiếp theo không chạy trên nhánh lỗi này.

## Cách dùng

```typescript
import { DesignLogicAbstract, DesignName } from '@dxtmisha/functional'
import { effectScope, ref } from 'vue'

class Dependency {}

class Logic extends DesignLogicAbstract<
  HTMLElement, {}, {}, {}, {}, { dependency: typeof Dependency }
> {
  protected readonly constructorItems = { dependency: { item: Dependency } }

  constructor() {
    super({}, ref<HTMLElement>(), new DesignName('d1.example'))
  }
}

const scope = /*#__PURE__*/ effectScope()
const logic = /*#__PURE__*/ scope.run(() => new Logic())
const dependency = /*#__PURE__*/ logic?.getInstance('dependency')
scope.stop()
```

## Phương thức

### Truy cập phụ thuộc

#### `getInstance`

`getInstance<K extends keyof CONSTRUCTORS & string>(name: K): ConstrInstance<CONSTRUCTORS, K>`

Trả phụ thuộc đã lưu hoặc tạo trong phạm vi hoạt động đã giữ. Tham số lấy từ hàm `parameters()` tùy chọn. Lỗi khởi tạo không được lưu nên có thể thử lại.

**Tham số:**

- `name: K` — Khóa chuỗi của hàm dựng phụ thuộc.

**Trả về:** `ConstrInstance<CONSTRUCTORS, K>` — Đối tượng phụ thuộc đã lưu hoặc vừa tạo.

```typescript
const dependency = /*#__PURE__*/ logic?.getInstance('dependency')
```

### Truy cập rút gọn

- `i<K extends keyof CONSTRUCTORS & string>(name: K): ConstrInstance<CONSTRUCTORS, K>` — Gọi `getInstance()` với cùng khóa và kết quả.
