# Класс EffectScopeGlobal

Статическая точка входа для эффектов в лениво созданной отсоединённой области Vue. Область кэшируется через `ServerStorage`; при SSR её владелец определяется инициализированным контекстом запроса.

## Ключевые особенности

- **Ленивая область** — создаётся при первом `run()`.
- **Отдельный срок жизни** — остановка области компонента не останавливает эти эффекты.
- **Сохранение результата** — результат и ошибки обработчика передаются вызывающему коду.

## Поведение и жизненный цикл

Перед SSR инициализируйте `ServerStorage` контекстом текущего запроса. Класс не предоставляет метода остановки; при необходимости отдельной очистки возвращайте из обработчика соответствующие функции. Асинхронная работа после `await` не включается в область автоматически.

## Использование

```typescript

import { ref, watch } from 'vue'

const source = /*#__PURE__*/ ref(0)
const observed = /*#__PURE__*/ ref(0)

```

## Методы

### Выполнение эффектов

#### `run`

`run<T>(fn: () => T): T | undefined`

Синхронно выполняет обработчик в кэшированной отсоединённой области эффектов и возвращает результат.

**Параметры:**

- `fn: () => T` — Обработчик для выполнения в отсоединённой области.

**Возвращает:** `T | undefined` — Результат обработчика либо undefined для неактивной сохранённой области.

```typescript
const result = /*#__PURE__*/ EffectScopeGlobal.run(() => 0)
```
