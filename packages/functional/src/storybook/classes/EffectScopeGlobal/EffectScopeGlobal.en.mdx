# EffectScopeGlobal Class

Static entry point for running effects in a lazily created detached Vue scope. The scope is cached through `ServerStorage`, so SSR ownership follows the initialized request context.

## Key Features

- **Lazy scope** — created on the first `run()`.
- **Detached lifetime** — stopping a calling component scope does not stop these effects.
- **Return preservation** — callback results and thrown errors propagate to the caller.

## Behavior and lifecycle

Initialize `ServerStorage` with the current request context before SSR use. This class exposes no stop method; callbacks should return cleanup handles when the caller needs individual teardown. It does not make asynchronous callback work part of the scope after an `await`.

## Usage

```typescript

import { ref, watch } from 'vue'

const observed = /*#__PURE__*/ ref(0)

  observed.value = value

```

## Methods

### Effect execution

#### `run`

`run<T>(fn: () => T): T | undefined`

Runs the callback synchronously inside the cached detached effect scope and returns its result.

**Parameters:**

- `fn: () => T` — Callback to execute inside the detached scope.

**Returns:** `T | undefined` — Callback result, or undefined when the stored scope is inactive.

```typescript
const result = /*#__PURE__*/ EffectScopeGlobal.run(() => 0)
```
