# Lớp EffectScopeGlobal

Điểm truy cập tĩnh để chạy hiệu ứng trong phạm vi Vue tách rời được tạo lười. Phạm vi được lưu qua `ServerStorage`; quyền sở hữu SSR phụ thuộc ngữ cảnh yêu cầu đã khởi tạo.

## Tính năng chính

- **Phạm vi lười** — tạo khi gọi `run()` lần đầu.
- **Vòng đời tách rời** — dừng phạm vi thành phần gọi không dừng các hiệu ứng này.
- **Giữ kết quả** — kết quả và lỗi callback được chuyển về bên gọi.

## Hành vi và vòng đời

Khởi tạo `ServerStorage` bằng ngữ cảnh yêu cầu hiện tại trước khi dùng SSR. Lớp không có phương thức dừng; callback nên trả hàm dọn dẹp khi bên gọi cần dừng riêng. Công việc bất đồng bộ sau `await` không tự thuộc phạm vi.

## Cách dùng

```typescript
import { EffectScopeGlobal } from '@dxtmisha/functional'
import { ref, watch } from 'vue'

const source = /*#__PURE__*/ ref(0)
const observed = /*#__PURE__*/ ref(0)
const stop = /*#__PURE__*/ EffectScopeGlobal.run(() => watch(source, value => {
  observed.value = value
}))
stop?.()
```

## Phương thức

### Thực thi hiệu ứng

#### `run`

`run<T>(fn: () => T): T | undefined`

Chạy callback đồng bộ trong phạm vi hiệu ứng tách rời đã lưu và trả kết quả.

**Tham số:**

- `fn: () => T` — Callback chạy trong phạm vi tách rời.

**Trả về:** `T | undefined` — Kết quả callback hoặc undefined khi phạm vi đã lưu không hoạt động.

```typescript
const result = /*#__PURE__*/ EffectScopeGlobal.run(() => 0)
```
