# Класс DesignName

Помощник именования компонентов по БЭМ. Конструктор берёт первые два сегмента `design.component`, нормализует их и сохраняет названия дизайна и класса компонента.

## Ключевые особенности

- **Кэш имён** — независимое состояние каждого экземпляра.
- **БЭМ** — модификаторы используют `--`, элементы — `__`.
- **CSS-переменные** — системные свойства содержат сегмент `-sys-`.

## Инициализация

`constructor(name: string)`

**Параметры:**

- `name: string` — Имя компонента с префиксом дизайна, например d1.button.

## Поведение и жизненный цикл

Сегменты могут содержать числа и `undefined`. Объединение не фильтрует значения: `0` сохраняется, а `undefined` создаёт пустой сегмент. При отсутствии сегментов разделитель остаётся в конце. Каждый исходный сегмент обрабатывается `toCamelCase`: например, `d1.buttonGroup` превращается в `d1-buttonGroup`.

## Использование

```typescript
import { DesignName } from '@dxtmisha/functional'

const naming = /*#__PURE__*/ new DesignName('d1.buttonGroup')
naming.getName() // 'd1-buttonGroup'
naming.getStatusClass('size', 0) // 'd1-buttonGroup--size--0'
naming.getSubClass('label') // 'd1-buttonGroup__label'
naming.getStyle('width') // '--d1-buttonGroup-sys-width'
```

## Методы

### Основные имена

- `getDesign(): string` — Возвращает первый нормализованный сегмент имени.

- `getName(): string` — Возвращает нормализованное имя класса компонента.

### БЭМ и CSS-переменные

- `getStatusClass(...names: (string | number | undefined)[]): string` — Объединяет сегменты модификатора через `--` после имени компонента.

- `getSubClass(...names: (string | number | undefined)[]): string` — Объединяет сегменты элемента через `__` после имени компонента.

- `getStyle(...names: (string | number | undefined)[]): string` — Формирует имя CSS-переменной с префиксом `--` и пространством имён `-sys-`.
