# Класс DatetimeRef

Реактивная обёртка над `Datetime`. Синхронизирует входную дату с рабочим `Date`, предоставляет вычисляемые поля календаря и обновляет их после изменений через `getDatetime()`.

## Ключевые особенности

- **Обязательная дата** — строка, временная метка или `Date`, напрямую либо в ссылке.
- **Календарные поля** — месяцы нумеруются от 1 до 12.
- **Форматирование** — локализованный и стандартный вывод представлены вычисляемыми ссылками.

## Инициализация

`constructor( date: RefOrNormal<NumberOrStringOrDate>, type: RefOrNormal<GeoDate> = 'date', code: RefOrNormal<string> = Geo.getLocation() )`

**Параметры:**

- `date: RefOrNormal<NumberOrStringOrDate>` — Обязательная дата, временная метка либо строка даты.
- `type: RefOrNormal<GeoDate> = 'date'` — Формат вывода даты; конструктор использует date по умолчанию.
- `code: RefOrNormal<string> = Geo.getLocation()` — Код локали, страны или языка; ссылка поддерживается согласно сигнатуре.

## Поведение и жизненный цикл

Локаль по умолчанию берётся из `Geo.getLocation()` при создании. Для последующих изменений передайте ссылку на локаль. Наблюдатели даты, типа и локали используют планировщик Vue: после изменения ссылок дождитесь `nextTick()`. Изменения через `getDatetime()` уведомляют синхронно. `getItem()` сохраняет исходную ссылку и не перезаписывается изменениями базового класса. Для очистки наблюдателей используйте область эффектов. Присваивайте новый `Date` в `getDate().value` либо меняйте дату через `getDatetime()`: встроенные мутации `Date` сами не уведомляют Vue.

## Использование

```typescript
import { DatetimeRef } from '@dxtmisha/functional'
import { effectScope, nextTick, ref } from 'vue'

const source = /*#__PURE__*/ ref('2024-02-29T12:00:00')
const code = /*#__PURE__*/ ref('en-US')

await nextTick()
code.value = 'vi-VN'
await nextTick()
scope.stop()
```

## Методы

### Исходное состояние

- `getItem(): Ref<NumberOrStringOrDate>` — Возвращает исходную входную ссылку.

- `getDate(): Ref<Date>` — Возвращает ссылку на рабочий Date, синхронизированную с базовым классом.

- `getDatetime(): Datetime` — Возвращает изменяемую базовую утилиту для календарных операций.

### Календарные поля

- `getYear(): ComputedRef<number>` — Возвращает полный год по местному времени.

- `getMonth(): ComputedRef<number>` — Возвращает месяц по местному времени, от 1 до 12.

- `getDay(): ComputedRef<number>` — Возвращает день месяца по местному времени.

- `getHour(): ComputedRef<number>` — Возвращает час по местному времени, от 0 до 23.

- `getMinute(): ComputedRef<number>` — Возвращает минуты по местному времени, от 0 до 59.

- `getSecond(): ComputedRef<number>` — Возвращает секунды по местному времени, от 0 до 59.

- `getMaxDay(): ComputedRef<number>` — Возвращает число дней текущего месяца с учётом високосного года.

- `getHoursType(): ComputedRef<GeoHours>` — Возвращает формат часов локали: строку `12` или `24`.

- `getFirstDayCode(): ComputedRef<GeoFirstDay>` — Возвращает код первого дня недели локали: воскресенье — 0.

### Форматирование

#### `locale`

`locale( type?: GeoDate, styleOptions?: Intl.DateTimeFormatOptions['month'] | Intl.DateTimeFormatOptions ): ComputedRef<string>`

Возвращает локализованный вывод текущего типа формата, если тип не указан явно.

**Параметры:**

- `type?: GeoDate` — Формат вывода даты; конструктор использует date по умолчанию.
- `styleOptions?: Intl.DateTimeFormatOptions['month'] | Intl.DateTimeFormatOptions` — Стиль Intl либо параметры форматирования.

**Возвращает:** `ComputedRef<string>` — Вычисляемый результат; читайте через .value.

```typescript
const formatted = /*#__PURE__*/ datetime?.locale('date', 'long')
```

#### `standard`

`standard(timeZone = true as boolean): ComputedRef<string>`

Возвращает стандартное представление базовой утилиты для текущего типа. `timeZone` управляет выводом часового пояса в форматах со временем.

**Параметры:**

- `timeZone = true as boolean` — Выводить ли часовой пояс; по умолчанию true.

**Возвращает:** `ComputedRef<string>` — Вычисляемый результат; читайте через .value.

```typescript
const standard = /*#__PURE__*/ datetime?.standard(false)
```
