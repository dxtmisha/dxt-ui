# Lớp DatetimeRef

Lớp bọc phản ứng cho `Datetime`. Đồng bộ ref ngày đầu vào với `Date` đang dùng, cung cấp trường lịch computed và cập nhật sau thay đổi qua `getDatetime()`.

## Tính năng chính

- **Ngày bắt buộc** — nhận chuỗi ngày, dấu thời gian hoặc `Date`, trực tiếp hoặc qua ref.
- **Trường lịch** — tháng được đánh số từ 1 đến 12.
- **Định dạng** — kết quả địa phương hóa và chuẩn đều là computed ref.

## Khởi tạo

`constructor( date: RefOrNormal<NumberOrStringOrDate>, type: RefOrNormal<GeoDate> = 'date', code: RefOrNormal<string> = Geo.getLocation() )`

**Tham số:**

- `date: RefOrNormal<NumberOrStringOrDate>` — Ngày, dấu thời gian hoặc chuỗi ngày bắt buộc.
- `type: RefOrNormal<GeoDate> = 'date'` — Kiểu đầu ra ngày; hàm dựng mặc định date.
- `code: RefOrNormal<string> = Geo.getLocation()` — Mã locale, quốc gia hoặc ngôn ngữ; hỗ trợ ref theo chữ ký.

## Hành vi và vòng đời

Locale mặc định được lấy từ `Geo.getLocation()` lúc tạo. Truyền ref locale để theo dõi thay đổi về sau. Watcher ngày, kiểu và locale dùng lịch Vue; chờ `nextTick()` sau khi đổi ref. Thay đổi qua `getDatetime()` thông báo đồng bộ. `getItem()` giữ ref đầu vào gốc và không bị ghi lại bởi thay đổi lớp cơ sở. Dùng phạm vi hiệu ứng để dọn watcher. Gán `Date` mới cho `getDate().value` hoặc sửa qua `getDatetime()`; sửa trực tiếp bên trong `Date` không tự thông báo Vue.

## Cách dùng

```typescript
import { DatetimeRef } from '@dxtmisha/functional'
import { effectScope, nextTick, ref } from 'vue'

const source = /*#__PURE__*/ ref('2024-02-29T12:00:00')
const code = /*#__PURE__*/ ref('en-US')
const scope = /*#__PURE__*/ effectScope()
const datetime = /*#__PURE__*/ scope.run(() => new DatetimeRef(source, 'date', code))
const formatted = /*#__PURE__*/ datetime?.locale()
source.value = '2025-01-01T00:00:00'
await nextTick()
code.value = 'vi-VN'
await nextTick()
scope.stop()
```

## Phương thức

### Trạng thái bên dưới

- `getItem(): Ref<NumberOrStringOrDate>` — Trả ref đầu vào ban đầu.

- `getDate(): Ref<Date>` — Trả ref Date đang dùng, đồng bộ với lớp cơ sở.

- `getDatetime(): Datetime` — Trả tiện ích cơ sở có thể thay đổi để thao tác lịch.

### Trường lịch

- `getYear(): ComputedRef<number>` — Trả năm đầy đủ theo giờ địa phương.

- `getMonth(): ComputedRef<number>` — Trả tháng địa phương từ 1 đến 12.

- `getDay(): ComputedRef<number>` — Trả ngày trong tháng theo giờ địa phương.

- `getHour(): ComputedRef<number>` — Trả giờ địa phương từ 0 đến 23.

- `getMinute(): ComputedRef<number>` — Trả phút địa phương từ 0 đến 59.

- `getSecond(): ComputedRef<number>` — Trả giây địa phương từ 0 đến 59.

- `getMaxDay(): ComputedRef<number>` — Trả số ngày trong tháng hiện tại, có tính năm nhuận.

- `getHoursType(): ComputedRef<GeoHours>` — Trả định dạng đồng hồ locale dưới dạng chuỗi `12` hoặc `24`.

- `getFirstDayCode(): ComputedRef<GeoFirstDay>` — Trả mã ngày đầu tuần theo locale: Chủ nhật là 0.

### Định dạng

#### `locale`

`locale( type?: GeoDate, styleOptions?: Intl.DateTimeFormatOptions['month'] | Intl.DateTimeFormatOptions ): ComputedRef<string>`

Trả định dạng địa phương theo kiểu hiện tại trừ khi truyền kiểu cụ thể.

**Tham số:**

- `type?: GeoDate` — Kiểu đầu ra ngày; hàm dựng mặc định date.
- `styleOptions?: Intl.DateTimeFormatOptions['month'] | Intl.DateTimeFormatOptions` — Kiểu Intl hoặc tùy chọn định dạng.

**Trả về:** `ComputedRef<string>` — Kết quả computed; đọc qua .value.

```typescript
const formatted = /*#__PURE__*/ datetime?.locale('date', 'long')
```

#### `standard`

`standard(timeZone = true as boolean): ComputedRef<string>`

Trả biểu diễn chuẩn của tiện ích cơ sở cho kiểu hiện tại. `timeZone` điều khiển phần múi giờ khi định dạng có thời gian.

**Tham số:**

- `timeZone = true as boolean` — Có thêm thông tin múi giờ; mặc định true.

**Trả về:** `ComputedRef<string>` — Kết quả computed; đọc qua .value.

```typescript
const standard = /*#__PURE__*/ datetime?.standard(false)
```
