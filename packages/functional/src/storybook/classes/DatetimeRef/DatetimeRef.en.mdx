# DatetimeRef Class

Reactive wrapper around `Datetime`. It synchronizes input date refs with a working `Date`, exposes computed calendar fields, and refreshes those fields after mutations through `getDatetime()`.

## Key Features

- **Required date** — accepts a date string, timestamp or `Date`, directly or as a ref.
- **Calendar fields** — months are numbered from 1 to 12.
- **Formatting** — localized and standard output are computed refs.

## Initialization

`constructor( date: RefOrNormal<NumberOrStringOrDate>, type: RefOrNormal<GeoDate> = 'date', code: RefOrNormal<string> = Geo.getLocation() )`

**Parameters:**

- `date: RefOrNormal<NumberOrStringOrDate>` — Required input date, timestamp or date string.
- `type: RefOrNormal<GeoDate> = 'date'` — Date output format; the constructor defaults to date.
- `code: RefOrNormal<string> = Geo.getLocation()` — Locale, country or language code; a ref is supported where declared.

## Behavior and lifecycle

The default locale is captured from `Geo.getLocation()` at construction. Pass a locale ref to track later changes. Input/type/locale watchers follow Vue scheduling; await `nextTick()` after updating those refs. Mutations through `getDatetime()` notify synchronously. `getItem()` retains the original input ref and is not rewritten by base-class mutations. Use an effect scope to dispose watchers. Assign a new `Date` to `getDate().value` or mutate through `getDatetime()`; native in-place `Date` changes do not trigger Vue by themselves.

## Usage

```typescript
import { DatetimeRef } from '@dxtmisha/functional'
import { effectScope, nextTick, ref } from 'vue'

const source = /*#__PURE__*/ ref('2024-02-29T12:00:00')
const code = /*#__PURE__*/ ref('en-US')
const scope = /*#__PURE__*/ effectScope()

const formatted = /*#__PURE__*/ datetime?.locale()
source.value = '2025-01-01T00:00:00'
await nextTick()
code.value = 'vi-VN'
await nextTick()
scope.stop()
```

## Methods

### Underlying state

- `getItem(): Ref<NumberOrStringOrDate>` — Returns the original input ref.

- `getDate(): Ref<Date>` — Returns the working Date ref synchronized with the base class.

- `getDatetime(): Datetime` — Returns the mutable base utility for calendar operations.

### Calendar fields

- `getYear(): ComputedRef<number>` — Returns the full local year.

- `getMonth(): ComputedRef<number>` — Returns the local month, numbered 1–12.

- `getDay(): ComputedRef<number>` — Returns the local day of the month.

- `getHour(): ComputedRef<number>` — Returns the local hour, 0–23.

- `getMinute(): ComputedRef<number>` — Returns local minutes, 0–59.

- `getSecond(): ComputedRef<number>` — Returns local seconds, 0–59.

- `getMaxDay(): ComputedRef<number>` — Returns the number of days in the current month, including leap years.

- `getHoursType(): ComputedRef<GeoHours>` — Returns the locale clock format, `12` or `24` as a string.

- `getFirstDayCode(): ComputedRef<GeoFirstDay>` — Returns the locale first weekday code: Sunday is 0.

### Formatting

#### `locale`

`locale( type?: GeoDate, styleOptions?: Intl.DateTimeFormatOptions['month'] | Intl.DateTimeFormatOptions ): ComputedRef<string>`

Returns localized output using the current format type unless an explicit type is supplied.

**Parameters:**

- `type?: GeoDate` — Date output format; the constructor defaults to date.
- `styleOptions?: Intl.DateTimeFormatOptions['month'] | Intl.DateTimeFormatOptions` — Intl style or formatting options.

**Returns:** `ComputedRef<string>` — Computed result; read it through .value.

```typescript
const formatted = /*#__PURE__*/ datetime?.locale('date', 'long')
```

#### `standard`

`standard(timeZone = true as boolean): ComputedRef<string>`

Returns the base utility’s standard representation for the current type. `timeZone` controls timezone output where that format includes time.

**Parameters:**

- `timeZone = true as boolean` — Whether to include timezone information; defaults to true.

**Returns:** `ComputedRef<string>` — Computed result; read it through .value.

```typescript
const standard = /*#__PURE__*/ datetime?.standard(false)
```
