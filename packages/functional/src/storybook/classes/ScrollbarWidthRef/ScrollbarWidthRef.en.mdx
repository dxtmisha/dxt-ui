# ScrollbarWidthRef Class

Reactive wrapper for asynchronous scrollbar measurement. In a DOM runtime it requests the scrollbar flag and pixel width independently through `ScrollbarWidth`.

## Key Features

- **Initial state** — `item` is undefined and `width` is 0.
- **Independent results** — flag and width may resolve in either order.
- **SSR safety** — no browser measurement is requested outside a DOM runtime.

## Initialization

`constructor()`

## Behavior and lifecycle

`is` means the flag is defined: both `true` and `false` set readiness to true. It does not guarantee that the independent width promise has completed. The wrapper performs one measurement at construction and does not subscribe to resize events. It has no public methods beyond construction.

## Usage

```typescript
import { ScrollbarWidthRef } from '@dxtmisha/functional'

const scrollbar = /*#__PURE__*/ new ScrollbarWidthRef()
const ready = scrollbar.is
const width = scrollbar.width
```

## Properties

- `item: Ref<boolean | undefined>` — Result of ScrollbarWidth.is(): true for a measured width other than -1 that is at most 8 pixels; initially undefined.
- `width: Ref<number>` — Width in pixels; initially 0 and updated independently.
- `is: ComputedRef<boolean>` — True once item is defined, regardless of the flag value or width readiness.

## Methods

No public methods; use the properties described above.
