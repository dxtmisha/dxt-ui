# Класс ScrollbarWidthRef

Реактивная обёртка асинхронного измерения полосы прокрутки. В DOM-среде независимо запрашивает флаг и ширину в пикселях через `ScrollbarWidth`.

## Ключевые особенности

- **Начальное состояние** — `item` равен undefined, `width` равен 0.
- **Независимые результаты** — флаг и ширина могут разрешиться в любом порядке.
- **SSR** — вне DOM измерения браузера не запрашиваются.

## Инициализация

`constructor()`

## Поведение и жизненный цикл

`is` означает, что флаг определён: и `true`, и `false` переводят готовность в true. Это не гарантирует завершения независимого Promise ширины. Обёртка измеряет один раз при создании и не подписывается на resize. Публичных методов, кроме конструктора, нет.

## Использование

```typescript
import { ScrollbarWidthRef } from '@dxtmisha/functional'

const scrollbar = /*#__PURE__*/ new ScrollbarWidthRef()
const ready = scrollbar.is
const width = scrollbar.width
```

## Свойства

- `item: Ref<boolean | undefined>` — Результат ScrollbarWidth.is(): true для измеренной ширины не равной -1 и не больше 8 пикселей; изначально undefined.
- `width: Ref<number>` — Ширина в пикселях; изначально 0, обновляется независимо.
- `is: ComputedRef<boolean>` — Истина после определения item независимо от значения флага и готовности ширины.

## Методы

Публичных методов нет; используйте описанные выше свойства.
