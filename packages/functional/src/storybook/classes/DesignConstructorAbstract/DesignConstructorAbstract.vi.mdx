# Lớp DesignConstructorAbstract

Hàm dựng kết xuất Vue trừu tượng kết hợp đặt tên, ref phần tử gốc, thành phần kết nối tùy chọn, thuộc tính, slot, dữ liệu công khai và computed lớp CSS/kiểu. Tạo lớp con cụ thể trong `setup()` thành phần.

## Tính năng chính

- **Kết hợp** — lớp CSS gốc hợp nhất logic, tùy chọn và thuộc tính ngoài.
- **Kiểu** — hợp nhất theo độ ưu tiên: logic, tùy chọn, kiểu từ bên ngoài.
- **Slot** — fragment có khóa giữ nhóm slot và theo dõi thay đổi slot.

## Khởi tạo

`constructor( name: string, props: Readonly<P>, options?: ConstrOptions<COMP, EMITS, P> )`

**Tham số:**

- `name: string` — Tên thành phần, phụ thuộc, slot hoặc tuyến theo phương thức.
- `props: Readonly<P>` — Thuộc tính đầu vào.
- `options?: ConstrOptions<COMP, EMITS, P>` — Tùy chọn cấu hình.

## Hành vi và vòng đời

Tham số kiểu: `E` là phần tử gốc; `COMP` là bộ đăng ký; `EMITS` là sự kiện; `EXPOSE` là dữ liệu công khai; `SLOTS` là slot; `CLASSES` là bản đồ lớp CSS; `P` là thuộc tính. Triển khai `initExpose`, `initClasses`, `initStyles` và `initRender`. Hàm dựng khởi tạo trạng thái ngay; gọi `render()` một lần trong `setup()` để lấy hàm kết xuất. `getAttrs()` loại `class` và `style`. Mục lớp CSS từ tùy chọn ghi đè mục logic cùng tên, trừ `main` được chuẩn hóa từ cả ba nguồn. `expose()` luôn thêm ref gốc dưới tên `elementHtml`.

## Cách dùng

```typescript
import { DesignConstructorAbstract } from '@dxtmisha/functional'
import { defineComponent, h, type VNode } from 'vue'

class ExampleDesign extends DesignConstructorAbstract<
  HTMLElement, {}, {}, {}, {}, { main: string }, {}
> {
  constructor() { super('d1.example', {}) }
  protected initExpose(): {} { return {} }
  protected initClasses(): { main: string } { return { main: 'd1-example' } }
  protected initStyles(): {} { return {} }
  protected initRender(): VNode {
    return h('div', {
      ...this.getAttrs(),
      ref: this.element,
      class: this.classes?.value.main,
      style: this.styles?.value
    })
  }
}

const Example = /*#__PURE__*/ defineComponent({
  inheritAttrs: false,
  setup(_props, context) {
    const design = new ExampleDesign()
    context.expose(design.expose())
    return design.render()
  }
})
```

## Phương thức

### Thuộc tính và đặt tên

- `getAttrs(): ConstrItem` — Trả đối tượng thuộc tính mới không có `class` và `style`.

- `getKeyClass<K extends keyof CLASSES>(name: K & string)` — Trả khóa phần tử con và lớp CSS computed hiện tại.

- `getNaming(): DesignName` — Trả đối tượng `DesignName` của hàm dựng này.

### Kết xuất và công khai

#### `render`

`render(): () => VNode | VNode[] | undefined`

Đăng ký theo dõi thay slot và trả hàm kết xuất qua `initRender()`.

**Trả về:** `() => VNode | VNode[] | undefined` — Giá trị hoặc đối tượng được yêu cầu theo chữ ký.

```typescript
const render = /*#__PURE__*/ design.render()
```

#### `expose`

`expose(): ConstrExpose<E, EXPOSE>`

Kết hợp dữ liệu `initExpose()` với ref gốc `elementHtml`.

**Trả về:** `ConstrExpose<E, EXPOSE>` — Giá trị hoặc đối tượng được yêu cầu theo chữ ký.

```typescript
context.expose(design.expose())
```

### Điểm mở rộng được bảo vệ

#### `initExpose`

`initExpose(): EXPOSE`

Triển khai trong lớp con để trả dữ liệu công khai.

**Trả về:** `EXPOSE` — Giá trị hoặc đối tượng được yêu cầu theo chữ ký.

```typescript
protected initExpose(): {} { return {} }
```

#### `initClasses`

`initClasses(): Partial<CLASSES>`

Triển khai trong lớp con để trả bản đồ lớp CSS logic trước khi hợp nhất.

**Trả về:** `Partial<CLASSES>` — Giá trị hoặc đối tượng được yêu cầu theo chữ ký.

```typescript
protected initClasses(): { main: string } { return { main: 'd1-example' } }
```

#### `initStyles`

`initStyles(): ConstrStyles`

Triển khai trong lớp con để trả kiểu trước khi áp dụng tùy chọn và thuộc tính ngoài.

**Trả về:** `ConstrStyles` — Giá trị hoặc đối tượng được yêu cầu theo chữ ký.

```typescript
protected initStyles(): {} { return {} }
```

#### `initRender`

`initRender(): VNode | VNode[] | undefined`

Triển khai cây VNode. Kết quả có thể là một nút, mảng hoặc `undefined`.

**Trả về:** `VNode | VNode[] | undefined` — Giá trị hoặc đối tượng được yêu cầu theo chữ ký.

```typescript
protected initRender(): VNode { return h('div', { ref: this.element }) }
```

#### `initSlot`

`initSlot<K extends keyof SLOTS>( name: K, children?: VNode[], props: ConstrItem = {} ): VNode | undefined`

Kết xuất slot có tên thành fragment có khóa và tùy chọn thêm fragment vào `children`. Slot thiếu trả `undefined` và không đổi mảng.

**Tham số:**

- `name: K` — Khóa slot có tên.
- `children?: VNode[]` — Nội dung con hoặc mảng tích lũy VNode tùy chọn.
- `props: ConstrItem = {}` — Thuộc tính slot có phạm vi; mặc định đối tượng rỗng.

**Trả về:** `VNode | undefined` — Giá trị hoặc đối tượng được yêu cầu theo chữ ký.

```typescript
const children: VNode[] = []
this.initSlot('default', children, { value: 0 })
```
