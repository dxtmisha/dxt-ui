# Класс DesignConstructorAbstract

Абстрактный конструктор рендеринга Vue: объединяет именование, ссылку на корневой элемент, подключённые компоненты, атрибуты, слоты, экспортируемые данные и вычисляемые классы/стили. Создавайте конкретный подкласс в `setup()` компонента.

## Ключевые особенности

- **Композиция** — классы корня объединяют логику, опции и внешние атрибуты.
- **Стили** — объединяются в порядке приоритета: логика, опции, внешние стили.
- **Слоты** — фрагменты с ключами сохраняют группы слотов и отслеживают замену слотов.

## Инициализация

`constructor( name: string, props: Readonly<P>, options?: ConstrOptions<COMP, EMITS, P> )`

**Параметры:**

- `name: string` — Имя компонента, зависимости, слота или маршрута согласно методу.
- `props: Readonly<P>` — Входные свойства.
- `options?: ConstrOptions<COMP, EMITS, P>` — Параметры настройки.

## Поведение и жизненный цикл

Параметры типов: `E` — корневой элемент; `COMP` — реестр компонентов; `EMITS` — события; `EXPOSE` — экспортируемые данные; `SLOTS` — слоты; `CLASSES` — карта классов; `P` — свойства. Реализуйте `initExpose`, `initClasses`, `initStyles` и `initRender`. Конструктор сразу инициализирует состояние; вызовите `render()` один раз в `setup()`, чтобы получить функцию рендеринга. `getAttrs()` исключает `class` и `style`. Записи классов опций, кроме `main`, заменяют одноимённые записи логики; `main` нормализуется из всех трёх источников. `expose()` всегда добавляет ссылку на корень как `elementHtml`.

## Использование

```typescript
import { DesignConstructorAbstract } from '@dxtmisha/functional'
import { defineComponent, h, type VNode } from 'vue'

class ExampleDesign extends DesignConstructorAbstract<
  HTMLElement, {}, {}, {}, {}, { main: string }, {}
> {
  constructor() { super('d1.example', {}) }
  protected initExpose(): {} { return {} }
  protected initClasses(): { main: string } { return { main: 'd1-example' } }
  protected initStyles(): {} { return {} }
  protected initRender(): VNode {
    return h('div', {
      ...this.getAttrs(),
      ref: this.element,
      class: this.classes?.value.main,
      style: this.styles?.value
    })
  }
}

const Example = /*#__PURE__*/ defineComponent({
  inheritAttrs: false,
  setup(_props, context) {
    const design = new ExampleDesign()
    context.expose(design.expose())
    return design.render()
  }
})
```

## Методы

### Атрибуты и именование

- `getAttrs(): ConstrItem` — Возвращает новый объект атрибутов без `class` и `style`.

- `getKeyClass<K extends keyof CLASSES>(name: K & string)` — Возвращает ключ подэлемента и его текущее вычисляемое значение класса.

- `getNaming(): DesignName` — Возвращает экземпляр `DesignName` этого конструктора.

### Рендеринг и внешний API

#### `render`

`render(): () => VNode | VNode[] | undefined`

Регистрирует отслеживание замены слотов и возвращает функцию, делегирующую рендеринг `initRender()`.

**Возвращает:** `() => VNode | VNode[] | undefined` — Запрошенное значение либо объект согласно сигнатуре.

```typescript
const render = /*#__PURE__*/ design.render()
```

#### `expose`

`expose(): ConstrExpose<E, EXPOSE>`

Объединяет данные `initExpose()` со ссылкой на корень `elementHtml`.

**Возвращает:** `ConstrExpose<E, EXPOSE>` — Запрошенное значение либо объект согласно сигнатуре.

```typescript
context.expose(design.expose())
```

### Защищённые точки расширения

#### `initExpose`

`initExpose(): EXPOSE`

Реализуйте в подклассе для получения внешнего API.

**Возвращает:** `EXPOSE` — Запрошенное значение либо объект согласно сигнатуре.

```typescript
protected initExpose(): {} { return {} }
```

#### `initClasses`

`initClasses(): Partial<CLASSES>`

Реализуйте в подклассе для получения карты классов логики перед объединением.

**Возвращает:** `Partial<CLASSES>` — Запрошенное значение либо объект согласно сигнатуре.

```typescript
protected initClasses(): { main: string } { return { main: 'd1-example' } }
```

#### `initStyles`

`initStyles(): ConstrStyles`

Реализуйте в подклассе для получения стилей до применения опций и атрибутов.

**Возвращает:** `ConstrStyles` — Запрошенное значение либо объект согласно сигнатуре.

```typescript
protected initStyles(): {} { return {} }
```

#### `initRender`

`initRender(): VNode | VNode[] | undefined`

Реализуйте дерево VNode. Результат — один узел, массив или `undefined`.

**Возвращает:** `VNode | VNode[] | undefined` — Запрошенное значение либо объект согласно сигнатуре.

```typescript
protected initRender(): VNode { return h('div', { ref: this.element }) }
```

#### `initSlot`

`initSlot<K extends keyof SLOTS>( name: K, children?: VNode[], props: ConstrItem = {} ): VNode | undefined`

Рендерит именованный слот как фрагмент с ключом и при необходимости добавляет фрагмент в `children`. Отсутствующий слот возвращает `undefined`, не меняя массив.

**Параметры:**

- `name: K` — Ключ именованного слота.
- `children?: VNode[]` — Дочернее содержимое либо необязательный массив VNode.
- `props: ConstrItem = {}` — Свойства scoped-слота; по умолчанию пустой объект.

**Возвращает:** `VNode | undefined` — Запрошенное значение либо объект согласно сигнатуре.

```typescript
const children: VNode[] = []
this.initSlot('default', children, { value: 0 })
```
