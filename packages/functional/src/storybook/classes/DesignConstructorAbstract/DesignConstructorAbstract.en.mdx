# DesignConstructorAbstract Class

Abstract Vue rendering constructor combining naming, a root element ref, optional connected components, attrs, slots, exposed data, and computed class/style composition. Instantiate a concrete subclass during component `setup()`.

## Key Features

- **Composition** — root classes combine logic, options and external attrs.
- **Styles** — logic, options and external styles merge in that precedence order.
- **Slots** — keyed fragments preserve slot groups and reactive slot replacement.

## Initialization

`constructor( name: string, props: Readonly<P>, options?: ConstrOptions<COMP, EMITS, P> )`

**Parameters:**

- `name: string` — Component, dependency, slot or route name according to the method.
- `props: Readonly<P>` — Input properties.
- `options?: ConstrOptions<COMP, EMITS, P>` — Configuration options.

## Behavior and lifecycle

Generic parameters: `E` is the root element; `COMP` the component registry; `EMITS` events; `EXPOSE` exposed data; `SLOTS` slots; `CLASSES` class map; `P` props. Implement `initExpose`, `initClasses`, `initStyles` and `initRender`. The constructor initializes state directly; call `render()` once during `setup()` to obtain the render function. `getAttrs()` excludes `class` and `style`. Non-root class entries from options replace matching logic entries; `main` is normalized from all three sources. `expose()` always adds the root ref as `elementHtml`.

## Usage

```typescript
import { DesignConstructorAbstract } from '@dxtmisha/functional'
import { defineComponent, h, type VNode } from 'vue'

class ExampleDesign extends DesignConstructorAbstract<
  HTMLElement, {}, {}, {}, {}, { main: string }, {}
> {
  constructor() { super('d1.example', {}) }
  protected initExpose(): {} { return {} }
  protected initClasses(): { main: string } { return { main: 'd1-example' } }
  protected initStyles(): {} { return {} }
  protected initRender(): VNode {
    return h('div', {
      ...this.getAttrs(),
      ref: this.element,
      class: this.classes?.value.main,
      style: this.styles?.value
    })
  }
}

const Example = /*#__PURE__*/ defineComponent({
  inheritAttrs: false,
  setup(_props, context) {
    const design = new ExampleDesign()
    context.expose(design.expose())
    return design.render()
  }
})
```

## Methods

### Attributes and naming

- `getAttrs(): ConstrItem` — Returns a new attribute object without `class` and `style`.

- `getKeyClass<K extends keyof CLASSES>(name: K & string)` — Returns a sub-element key and its current computed class entry.

- `getNaming(): DesignName` — Returns this constructor’s `DesignName` instance.

### Rendering and exposure

#### `render`

`render(): () => VNode | VNode[] | undefined`

Registers slot-change tracking and returns a function delegating rendering to `initRender()`.

**Returns:** `() => VNode | VNode[] | undefined` — The requested value or object as declared in the signature.


#### `expose`

`expose(): ConstrExpose<E, EXPOSE>`

Combines `initExpose()` data with the root ref under `elementHtml`.

**Returns:** `ConstrExpose<E, EXPOSE>` — The requested value or object as declared in the signature.

```typescript

```

#### `initRender`

`initRender(): VNode | VNode[] | undefined`

Implement the VNode tree. The result may be one node, an array, or `undefined`.

**Returns:** `VNode | VNode[] | undefined` — The requested value or object as declared in the signature.

```typescript
protected initRender(): VNode { return h('div', { ref: this.element }) }
```

#### `initSlot`

`initSlot<K extends keyof SLOTS>( name: K, children?: VNode[], props: ConstrItem = {} ): VNode | undefined`

Renders a named slot as a keyed fragment and optionally appends that fragment to `children`. Missing slots return `undefined` without modifying the array.

**Parameters:**

- `name: K` — Named slot key.
- `children?: VNode[]` — Child content or an optional VNode accumulator.
- `props: ConstrItem = {}` — Scoped-slot properties; defaults to an empty object.

**Returns:** `VNode | undefined` — The requested value or object as declared in the signature.

```typescript
const children: VNode[] = []
this.initSlot('default', children, { value: 0 })
```
