# GeoFlagRef Class

Reactive wrapper around `GeoFlag` for country and language metadata and flag icon identifiers. The internal base instance follows the supplied code ref or the current `GeoRef` location.

## Key Features

- **Reactive code** — saved computed results follow code changes.
- **Explicit lookup** — method code arguments override the constructor’s lookup code.
- **Catalogs** — filtered lists and national-language lists are available.

## Initialization

`constructor( code?: RefOrNormal<string | undefined> )`

**Parameters:**

- `code?: RefOrNormal<string | undefined>` — Locale, country or language code; a ref is supported where declared.

## Behavior and lifecycle

`getCode()` returns a plain string snapshot. Other getters return computed refs. `getFlag()` returns an icon identifier such as `f-vn`, not an image URL. An omitted codes array requests the base catalog; an empty array returns an empty list. Catalog ordering and unknown-code handling are delegated to `GeoFlag`.

## Usage

```typescript
import { GeoFlagRef } from '@dxtmisha/functional'
import { ref } from 'vue'

const code = /*#__PURE__*/ ref('vi-VN')
const flags = /*#__PURE__*/ new GeoFlagRef(code)
const icon = /*#__PURE__*/ flags.getFlag()
const countries = /*#__PURE__*/ flags.getList(ref(['VN', 'US']))

```

### Catalogs

- `getList(codes?: RefOrNormal<string[] | undefined>): ComputedRef<GeoFlagItem[]>` — Returns country flag items, optionally filtered by reactive codes.

- `getListLanguage(codes?: RefOrNormal<string[] | undefined>): ComputedRef<GeoFlagItem[]>` — Returns language flag items, optionally filtered by reactive codes.

- `getNational(codes?: RefOrNormal<string[] | undefined>): ComputedRef<GeoFlagNational[]>` — Returns country names in national languages.

- `getNationalLanguage(codes?: RefOrNormal<string[] | undefined>): ComputedRef<GeoFlagNational[]>` — Returns language names in national languages.
