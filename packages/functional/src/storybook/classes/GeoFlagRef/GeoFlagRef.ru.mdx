# Класс GeoFlagRef

Реактивная обёртка над `GeoFlag` для данных стран, языков и идентификаторов иконок флагов. Базовый экземпляр следует переданной ссылке на код либо текущему местоположению `GeoRef`.

## Ключевые особенности

- **Реактивный код** — сохранённые вычисляемые результаты следуют изменениям кода.
- **Явный поиск** — код метода имеет приоритет над кодом поиска конструктора.
- **Каталоги** — доступны отфильтрованные списки и названия на национальных языках.

## Инициализация

`constructor( code?: RefOrNormal<string | undefined> )`

**Параметры:**

- `code?: RefOrNormal<string | undefined>` — Код локали, страны или языка; ссылка поддерживается согласно сигнатуре.

## Поведение и жизненный цикл

Метод `getCode()` возвращает обычную строку на момент вызова. Остальные геттеры возвращают вычисляемые ссылки. `getFlag()` возвращает идентификатор иконки, например `f-vn`, а не URL изображения. Отсутствие массива кодов запрашивает базовый каталог; пустой массив даёт пустой список. Порядок каталога и обработка неизвестных кодов определяются `GeoFlag`.

## Использование

```typescript
import { GeoFlagRef } from '@dxtmisha/functional'
import { ref } from 'vue'

const code = /*#__PURE__*/ ref('vi-VN')
const flags = /*#__PURE__*/ new GeoFlagRef(code)
const icon = /*#__PURE__*/ flags.getFlag()
const countries = /*#__PURE__*/ flags.getList(ref(['VN', 'US']))
code.value = 'en-US'
```

## Методы

### Текущий код

- `getCode(): string` — Возвращает текущий базовый код строкой.

### Поиск одной записи

#### `get`

`get(code?: RefOrNormal<string>): ComputedRef<GeoFlagItem | undefined>`

Возвращает данные страны по явному либо текущему базовому коду.

**Параметры:**

- `code?: RefOrNormal<string>` — Код локали, страны или языка; ссылка поддерживается согласно сигнатуре.

**Возвращает:** `ComputedRef<GeoFlagItem | undefined>` — Вычисляемый результат; читайте через .value.

```typescript
const result = /*#__PURE__*/ flags.get(code)
```

### Каталоги

- `getList(codes?: RefOrNormal<string[] | undefined>): ComputedRef<GeoFlagItem[]>` — Возвращает флаги стран с необязательной фильтрацией реактивным списком кодов.

- `getListLanguage(codes?: RefOrNormal<string[] | undefined>): ComputedRef<GeoFlagItem[]>` — Возвращает флаги языков с необязательной фильтрацией реактивным списком кодов.

- `getNational(codes?: RefOrNormal<string[] | undefined>): ComputedRef<GeoFlagNational[]>` — Возвращает названия стран на национальных языках.

- `getNationalLanguage(codes?: RefOrNormal<string[] | undefined>): ComputedRef<GeoFlagNational[]>` — Возвращает названия языков на национальных языках.
