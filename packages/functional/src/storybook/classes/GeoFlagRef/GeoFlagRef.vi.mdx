# Lớp GeoFlagRef

Lớp bọc phản ứng cho `GeoFlag`, cung cấp dữ liệu quốc gia, ngôn ngữ và mã biểu tượng cờ. Đối tượng cơ sở theo ref mã được truyền hoặc vị trí `GeoRef` hiện tại.

## Tính năng chính

- **Mã phản ứng** — kết quả computed đã lưu theo thay đổi mã.
- **Tra cứu cụ thể** — mã truyền cho phương thức ưu tiên hơn mã tra cứu của hàm dựng.
- **Danh mục** — hỗ trợ danh sách lọc và tên bằng ngôn ngữ bản địa.

## Khởi tạo

`constructor( code?: RefOrNormal<string | undefined> )`

**Tham số:**

- `code?: RefOrNormal<string | undefined>` — Mã locale, quốc gia hoặc ngôn ngữ; hỗ trợ ref theo chữ ký.

## Hành vi và vòng đời

`getCode()` trả chuỗi tại thời điểm gọi. Getter khác trả computed ref. `getFlag()` trả mã biểu tượng như `f-vn`, không phải URL ảnh. Bỏ qua mảng mã sẽ lấy danh mục cơ sở; mảng rỗng cho danh sách rỗng. Thứ tự danh mục và xử lý mã không biết do `GeoFlag` quyết định.

## Cách dùng

```typescript
import { GeoFlagRef } from '@dxtmisha/functional'
import { ref } from 'vue'

const code = /*#__PURE__*/ ref('vi-VN')
const flags = /*#__PURE__*/ new GeoFlagRef(code)
const icon = /*#__PURE__*/ flags.getFlag()
const countries = /*#__PURE__*/ flags.getList(ref(['VN', 'US']))
code.value = 'en-US'
```

## Phương thức

### Mã hiện tại

- `getCode(): string` — Trả mã cơ sở hiện tại dưới dạng chuỗi.

### Tra cứu một mục

- `code?: RefOrNormal<string>` — Mã locale, quốc gia hoặc ngôn ngữ; hỗ trợ ref theo chữ ký.

**Trả về:** `ComputedRef<GeoFlagItem | undefined>` — Kết quả computed; đọc qua .value.

### Danh mục

- `getList(codes?: RefOrNormal<string[] | undefined>): ComputedRef<GeoFlagItem[]>` — Trả mục cờ quốc gia, có thể lọc bằng mã phản ứng.

- `getListLanguage(codes?: RefOrNormal<string[] | undefined>): ComputedRef<GeoFlagItem[]>` — Trả mục cờ ngôn ngữ, có thể lọc bằng mã phản ứng.

- `getNational(codes?: RefOrNormal<string[] | undefined>): ComputedRef<GeoFlagNational[]>` — Trả tên quốc gia bằng ngôn ngữ bản địa.

- `getNationalLanguage(codes?: RefOrNormal<string[] | undefined>): ComputedRef<GeoFlagNational[]>` — Trả tên ngôn ngữ bằng ngôn ngữ bản địa.
