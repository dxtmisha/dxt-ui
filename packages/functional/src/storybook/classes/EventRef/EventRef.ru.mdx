# Класс EventRef

Реактивное расширение `EventItem` для событий DOM и окна. Отслеживает переданные в конструктор ссылки на цель и контрольный элемент; владеющая область эффектов Vue останавливает слушатели при завершении.

## Ключевые особенности

- **Смена цели** — активные слушатели переносятся при изменении ссылки.
- **Явный запуск** — создание само по себе не включает прослушивание.
- **Унаследованное управление** — цепочки вызовов, несколько типов событий и detail предоставляет `EventItem`.

## Инициализация

`constructor( elementSelector?: RefOrNormal<ElementOrString<E> | undefined>, elementSelectorControl?: RefOrNormal<ElementOrString<HTMLElement>>, type: string | string[] = ['click'], listener?: EventListenerDetail<O, D>, options?: EventOptions, detail?: D )`

**Параметры:**

- `elementSelector?: RefOrNormal<ElementOrString<E> | undefined>` — Целевой элемент либо селектор.
- `elementSelectorControl?: RefOrNormal<ElementOrString<HTMLElement>>` — Необязательный контрольный элемент либо селектор для проверки присутствия в DOM.
- `type: string | string[] = ['click']` — Тип события либо массив; по умолчанию click.
- `listener?: EventListenerDetail<O, D>` — Обработчик события, получающий событие и сохранённый detail.
- `options?: EventOptions` — Параметры настройки.
- `detail?: D` — Пользовательские данные события.

## Поведение и жизненный цикл

Параметры типов: `E` — цель, `O` — событие, `D` — пользовательский detail. Ссылки принимают только входы цели и контрольного элемента конструктора; унаследованные сеттеры принимают обычные значения. Перенос слушателей выполняется после очередного обновления Vue. Вне области эффектов вызывайте `stop()` вручную. Удаление контрольного элемента проверяется при обработке события. `resize` использует `ResizeObserver`, `scroll-sync` — кадры анимации.

## Использование

```typescript
import { EventRef } from '@dxtmisha/functional'
import { effectScope, ref } from 'vue'

const target = /*#__PURE__*/ ref<HTMLElement>()
const clicks = /*#__PURE__*/ ref(0)
const scope = /*#__PURE__*/ effectScope()
const listener = /*#__PURE__*/ scope.run(() => new EventRef(
  target, undefined, 'click', () => { clicks.value++ }
).start())
scope.stop()
```

## Методы

### Управление слушателями (унаследовано)

#### `start`

`start(): this`

Включает прослушивание; повторные вызовы не дублируют подписки.

**Возвращает:** `this` — Текущий экземпляр для цепочек вызовов.

```typescript
listener?.start()
```

#### `stop`

`stop(): this`

Удаляет активных слушателей и наблюдателей; допускает повторные вызовы.

**Возвращает:** `this` — Текущий экземпляр для цепочек вызовов.

```typescript
listener?.stop()
```

#### `toggle`

`toggle(activity: boolean): this`

Запускает или останавливает согласно логическому аргументу.

**Параметры:**

- `activity: boolean` — Требуемое состояние прослушивания.

**Возвращает:** `this` — Текущий экземпляр для цепочек вызовов.

```typescript
listener?.toggle(false)
```

#### `reset`

`reset(): this`

Переподключает активного слушателя; неактивного оставляет остановленным.

**Возвращает:** `this` — Текущий экземпляр для цепочек вызовов.

```typescript
listener?.reset()
```

### Состояние и настройки (унаследовано)

- `isActive(): boolean` — Сообщает, включено ли прослушивание.

- `getElement(): E | undefined` — Возвращает текущую разрешённую цель.

- `setElement(elementSelector?: ElementOrString<E>): this` — Меняет цель и перезапускает активных слушателей.

- `setElementControl<EC extends HTMLElement>(elementSelector?: ElementOrString<EC>): this` — Меняет элемент проверки присутствия в DOM.

- `setType(type: string | string[]): this` — Меняет типы событий и перезапускает активных слушателей.

- `setListener(listener: EventListenerDetail<O, D>): this` — Заменяет обработчик.

- `setOptions(options?: EventOptions): this` — Заменяет опции с повторным подключением при активности.

- `setDetail(detail?: D): this` — Заменяет detail, передаваемый вторым аргументом обработчика.

### Отправка событий (унаследовано)

#### `dispatch`

`dispatch(detail: D | undefined = this.detail): this`

Отправляет CustomEvent для каждого настроенного типа. Переданный detail попадает в event.detail; второй аргумент обработчика остаётся сохранённым detail слушателя.

**Параметры:**

- `detail: D | undefined = this.detail` — Пользовательские данные события.

**Возвращает:** `this` — Текущий экземпляр для цепочек вызовов.

```typescript
listener?.dispatch({ source: 'manual' })
```
