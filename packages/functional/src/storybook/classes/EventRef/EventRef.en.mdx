# EventRef Class

Reactive extension of `EventItem` for DOM or window listeners. Constructor target and control refs are watched for changes; an owning Vue effect scope stops listeners on disposal.

## Key Features

- **Target rebinding** — active listeners move when the target ref changes.
- **Explicit start** — construction alone does not enable listening.
- **Inherited controls** — chaining, multiple event types and custom detail are provided by `EventItem`.

## Initialization

`constructor( elementSelector?: RefOrNormal<ElementOrString<E> | undefined>, elementSelectorControl?: RefOrNormal<ElementOrString<HTMLElement>>, type: string | string[] = ['click'], listener?: EventListenerDetail<O, D>, options?: EventOptions, detail?: D )`

**Parameters:**

- `elementSelector?: RefOrNormal<ElementOrString<E> | undefined>` — Target element or selector.
- `elementSelectorControl?: RefOrNormal<ElementOrString<HTMLElement>>` — Optional control element or selector for DOM presence checks.
- `type: string | string[] = ['click']` — Event type or array; defaults to click.
- `listener?: EventListenerDetail<O, D>` — Event callback receiving event and stored detail.
- `options?: EventOptions` — Configuration options.
- `detail?: D` — Custom event data.

## Behavior and lifecycle

`E` is the target type, `O` the event type and `D` custom detail. Only the constructor target/control inputs accept refs; inherited setters accept unwrapped values. Watchers rebind after Vue’s next update. Outside an effect scope, call `stop()` manually. Control-element removal is checked when an event is handled. `resize` uses `ResizeObserver`; `scroll-sync` uses animation-frame scheduling.

## Usage

```typescript
import { EventRef } from '@dxtmisha/functional'
import { effectScope, ref } from 'vue'

const target = /*#__PURE__*/ ref<HTMLElement>()
const clicks = /*#__PURE__*/ ref(0)
const scope = /*#__PURE__*/ effectScope()
const listener = /*#__PURE__*/ scope.run(() => new EventRef(
  target, undefined, 'click', () => { clicks.value++ }
).start())
scope.stop()
```

## Methods

### Listener control (inherited)

#### `start`

`start(): this`

Enables listening; repeated calls do not duplicate subscriptions.

**Returns:** `this` — The current instance for chaining.

```typescript
listener?.start()
```

#### `stop`

`stop(): this`

Removes active listeners and observers; repeated calls are safe.

**Returns:** `this` — The current instance for chaining.

```typescript
listener?.stop()
```

#### `toggle`

`toggle(activity: boolean): this`

Starts or stops according to the boolean argument.

**Parameters:**

- `activity: boolean` — Requested listening state.

**Returns:** `this` — The current instance for chaining.

```typescript
listener?.toggle(false)
```

#### `reset`

`reset(): this`

Rebinds an active listener and leaves an inactive listener stopped.

**Returns:** `this` — The current instance for chaining.

```typescript
listener?.reset()
```

### State and configuration (inherited)

- `isActive(): boolean` — Reports whether listening is enabled.

- `getElement(): E | undefined` — Returns the current resolved target.

- `setElement(elementSelector?: ElementOrString<E>): this` — Changes the target and resets active listeners.

- `setElementControl<EC extends HTMLElement>(elementSelector?: ElementOrString<EC>): this` — Changes the element checked for DOM presence.

- `setType(type: string | string[]): this` — Changes event types and resets active listeners.

- `setListener(listener: EventListenerDetail<O, D>): this` — Replaces the callback.

- `setOptions(options?: EventOptions): this` — Replaces listener options, rebinding if active.

- `setDetail(detail?: D): this` — Replaces the detail passed as the callback’s second argument.

### Dispatch (inherited)

#### `dispatch`

`dispatch(detail: D | undefined = this.detail): this`

Dispatches a CustomEvent for each configured type. Supplied detail becomes event.detail; the callback second argument remains the stored listener detail.

**Parameters:**

- `detail: D | undefined = this.detail` — Custom event data.

**Returns:** `this` — The current instance for chaining.

```typescript
listener?.dispatch({ source: 'manual' })
```
