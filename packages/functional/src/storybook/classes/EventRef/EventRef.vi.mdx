# Lớp EventRef

Mở rộng phản ứng của `EventItem` cho sự kiện DOM hoặc cửa sổ. Theo dõi ref đích và phần tử kiểm soát từ hàm dựng; phạm vi hiệu ứng Vue sở hữu sẽ dừng lắng nghe khi kết thúc.

## Tính năng chính

- **Đổi đích** — listener đang hoạt động được chuyển khi ref đích đổi.
- **Bắt đầu tường minh** — khởi tạo không tự bật lắng nghe.
- **Điều khiển kế thừa** — `EventItem` cung cấp gọi nối tiếp, nhiều loại sự kiện và detail.

## Khởi tạo

`constructor( elementSelector?: RefOrNormal<ElementOrString<E> | undefined>, elementSelectorControl?: RefOrNormal<ElementOrString<HTMLElement>>, type: string | string[] = ['click'], listener?: EventListenerDetail<O, D>, options?: EventOptions, detail?: D )`

**Tham số:**

- `elementSelector?: RefOrNormal<ElementOrString<E> | undefined>` — Phần tử đích hoặc bộ chọn.
- `elementSelectorControl?: RefOrNormal<ElementOrString<HTMLElement>>` — Phần tử kiểm soát hoặc bộ chọn tùy chọn để kiểm tra hiện diện DOM.
- `type: string | string[] = ['click']` — Loại sự kiện hoặc mảng; mặc định click.
- `listener?: EventListenerDetail<O, D>` — Callback nhận sự kiện và detail đã lưu.
- `options?: EventOptions` — Tùy chọn cấu hình.
- `detail?: D` — Dữ liệu sự kiện tùy chỉnh.

## Hành vi và vòng đời

Tham số kiểu: `E` là đích, `O` là sự kiện, `D` là detail tùy chỉnh. Chỉ đầu vào đích/kiểm soát của hàm dựng nhận ref; setter kế thừa nhận giá trị đã mở ref. Watcher gắn lại sau lần cập nhật Vue tiếp theo. Ngoài phạm vi hiệu ứng, gọi `stop()` thủ công. Việc xóa phần tử kiểm soát được kiểm tra khi xử lý sự kiện. `resize` dùng `ResizeObserver`; `scroll-sync` dùng lịch khung hình.

## Cách dùng

```typescript
import { EventRef } from '@dxtmisha/functional'
import { effectScope, ref } from 'vue'

const target = /*#__PURE__*/ ref<HTMLElement>()
const clicks = /*#__PURE__*/ ref(0)
const scope = /*#__PURE__*/ effectScope()
const listener = /*#__PURE__*/ scope.run(() => new EventRef(
  target, undefined, 'click', () => { clicks.value++ }
).start())
scope.stop()
```

## Phương thức

### Điều khiển listener (kế thừa)

#### `start`

`start(): this`

Bật lắng nghe; gọi lặp không tạo đăng ký trùng.

**Trả về:** `this` — Đối tượng hiện tại để gọi nối tiếp.

```typescript
listener?.start()
```

#### `stop`

`stop(): this`

Gỡ listener và observer đang hoạt động; có thể gọi lặp.

**Trả về:** `this` — Đối tượng hiện tại để gọi nối tiếp.

```typescript
listener?.stop()
```

#### `toggle`

`toggle(activity: boolean): this`

Bật hoặc tắt theo tham số boolean.

**Tham số:**

- `activity: boolean` — Trạng thái lắng nghe được yêu cầu.

**Trả về:** `this` — Đối tượng hiện tại để gọi nối tiếp.

```typescript
listener?.toggle(false)
```

#### `reset`

`reset(): this`

Gắn lại listener đang hoạt động, giữ listener không hoạt động ở trạng thái dừng.

**Trả về:** `this` — Đối tượng hiện tại để gọi nối tiếp.

```typescript
listener?.reset()
```

### Trạng thái và cấu hình (kế thừa)

- `isActive(): boolean` — Cho biết lắng nghe đã bật hay chưa.

- `getElement(): E | undefined` — Trả đích hiện tại đã được phân giải.

- `setElement(elementSelector?: ElementOrString<E>): this` — Đổi đích và đặt lại listener đang hoạt động.

- `setElementControl<EC extends HTMLElement>(elementSelector?: ElementOrString<EC>): this` — Đổi phần tử dùng để kiểm tra hiện diện trong DOM.

- `setType(type: string | string[]): this` — Đổi loại sự kiện và đặt lại listener đang hoạt động.

- `setListener(listener: EventListenerDetail<O, D>): this` — Thay callback.

- `setOptions(options?: EventOptions): this` — Thay tùy chọn, gắn lại nếu đang hoạt động.

- `setDetail(detail?: D): this` — Thay detail truyền làm tham số thứ hai của callback.

### Phát sự kiện (kế thừa)

#### `dispatch`

`dispatch(detail: D | undefined = this.detail): this`

Phát CustomEvent cho từng loại đã cấu hình. Detail truyền vào là event.detail; tham số thứ hai của callback vẫn là detail listener đã lưu.

**Tham số:**

- `detail: D | undefined = this.detail` — Dữ liệu sự kiện tùy chỉnh.

**Trả về:** `this` — Đối tượng hiện tại để gọi nối tiếp.

```typescript
listener?.dispatch({ source: 'manual' })
```
