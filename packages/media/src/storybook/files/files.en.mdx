# File Icons: Connection and Integration

`@dxtmisha/media` provides a comprehensive, zero-dependency file icon and metadata subsystem designed for modern web applications and design systems. It includes 85+ vector SVG icons, automatic file type classification, and multiple connection patterns ranging from dictionary access to dynamic resolution and custom icon overrides.

## Connection Approaches

Depending on your architecture, you can connect and use file icons using three primary patterns:

1. **File Icons Dictionary & Registration (`@dxtmisha/media/files`)** — access icons by code from the `fileIcons` dictionary or initialize the static registry via `registerFileIcons()`.
2. **Dynamic Resolution via `MediaFile`** — ideal for file uploads, download lists, and tables where file paths or browser `File` objects are received at runtime.
3. **Custom Icon Registry via `MediaFileIcon`** — allows your application or theme to override built-in icons or register custom brand formats globally.

## The `files.ts` Module (`@dxtmisha/media/files`)

The `files.ts` module serves as the primary asset source for file vector icons. It exports:
- The `fileIcons` dictionary containing all registered SVG icons indexed by code.
- The `registerFileIcons()` initialization function.

Note: Individual icons are not exported as separate variables; all icons are accessed through the `fileIcons` dictionary or resolved dynamically via `MediaFile` / `MediaFiles`.

### 1. `registerFileIcons()` Helper

The `registerFileIcons()` function automatically loads all default vector icons from `fileIcons` into the `MediaFileIcon` static registry with a single call:

```typescript
import { registerFileIcons } from '@dxtmisha/media/files'

// Registers all default file icons in the MediaFileIcon registry
registerFileIcons()
```

Once called, `MediaFileIcon.get(code)` and `MediaFiles.get(code)` immediately have access to all registered vector icons across your entire application.

### 2. The `fileIcons` Dictionary

The `fileIcons` object is a typed dictionary (`MediaFileIcons`) mapping format codes, categories, and neutral identifiers to their raw SVG strings:

- **Default Neutral File Icon**: `fileIcons['file']` — the universal fallback file icon.
- **Category Neutral Icons**: `fileIcons['archive']`, `fileIcons['audio']`, `fileIcons['code']`, `fileIcons['config']`, `fileIcons['database']`, `fileIcons['document']`, `fileIcons['executable']`, `fileIcons['folder']`, `fileIcons['font']`, `fileIcons['image']`, `fileIcons['presentation']`, `fileIcons['table']`, `fileIcons['text']`, `fileIcons['vector']`, `fileIcons['video']`.
- **Specific Formats**: `fileIcons['7z']`, `fileIcons['pdf']`, `fileIcons['docx']`, `fileIcons['png']`, `fileIcons['zip']`, `fileIcons['xlsx']`, and 70+ others.

```typescript
import { fileIcons } from '@dxtmisha/media/files'

// Direct dictionary access by format or category code
const pdfSvg = fileIcons['pdf']
const documentCategorySvg = fileIcons['document']
const defaultFileSvg = fileIcons['file']
```

In Vue 3 templates:

```html
<template>
  <div class="file-item">
    <span class="file-icon" v-html="fileIcons['pdf']" />
    <span class="file-name">Annual_Report.pdf</span>
  </div>
</template>

<script setup lang="ts">
import { fileIcons } from '@dxtmisha/media/files'
</script>
```

## Dynamic Resolution with `MediaFile`

When working with user uploads, external URLs, or file records, use the `MediaFile` class. It inspects filenames, paths, and `File` objects to resolve extensions, categories, and the corresponding SVG icon automatically:

```typescript
import { MediaFile, MediaFileCategory } from '@dxtmisha/media'

// From a full remote URL with parameters
const remoteFile = new MediaFile('https://cdn.example.com/docs/spec.2026.docx?v=3#summary')

console.log(remoteFile.name)       // 'spec.2026.docx'
console.log(remoteFile.baseName)   // 'spec.2026'
console.log(remoteFile.extension)  // 'docx'
console.log(remoteFile.category)   // MediaFileCategory.document
console.log(remoteFile.isDocument()) // true

// Resolved SVG icon markup (uses custom icon if registered, or built-in SVG)
const svgMarkup = remoteFile.icon
```

### Browser `File` Object Support

`MediaFile` natively accepts standard browser `File` instances (e.g., from an `<input type="file">` or Drag-and-Drop dropzone):

```typescript
function handleFileUpload(event: Event) {
  const target = event.target as HTMLInputElement
  const file = target.files?.[0]

  if (file) {
    const media = new MediaFile(file)

    console.log(media.name)        // File name from browser
    console.log(media.mime)        // Native MIME type (e.g. 'image/png')
    console.log(media.isImage())   // true
    console.log(media.icon)        // Vector icon markup
  }
}
```

## Registering Custom Icons with `MediaFileIcon`

If your project requires custom branded file icons or needs to support proprietary file extensions, you can register them globally using `MediaFileIcon`.

### Single Icon Registration

```typescript
import { MediaFileIcon } from '@dxtmisha/media'

// Register a custom SVG icon for a format code or extension
MediaFileIcon.add('fig', '<svg viewBox="0 0 24 24"><path d="..."/></svg>')

// Check if a custom icon exists
if (MediaFileIcon.has('fig')) {
  console.log(MediaFileIcon.get('fig'))
}
```

### Batch Icon Registration

```typescript
import { MediaFileIcon } from '@dxtmisha/media'

MediaFileIcon.addList({
  sketch: '<svg class="custom-sketch">...</svg>',
  blender: '<svg class="custom-blend">...</svg>',
  cad: '<svg class="custom-cad">...</svg>'
})
```

Once registered, any call to `new MediaFile('design.sketch').icon` or `MediaFiles.get('sketch')` will automatically return your custom SVG icon.

## Catalog Lookups with `MediaFiles`

The `MediaFiles` class provides static methods to inspect the global file format catalog without instantiating objects:

```typescript
import { MediaFiles, MediaFileCategory } from '@dxtmisha/media'

// Check if a string is a link or path
MediaFiles.isLink('https://example.com/asset.zip') // true
MediaFiles.isLink('archive.zip')                   // false

// Get metadata configuration item by extension
const item = MediaFiles.get('xlsx')
console.log(item?.name)       // 'Excel'
console.log(item?.category)   // 'table'
console.log(item?.extensions) // ['xls', 'xlsx']

// Retrieve a generic category icon (e.g. for unknown images or tables)
const categoryNeutral = MediaFiles.getByCategory(MediaFileCategory.image)

// Fallback universal neutral file icon
const defaultNeutral = MediaFiles.getNeutral()
```

## Integration with `@dxtmisha/functional-basic` (`Icons`)

You can register file icons into the global `Icons` registry to make them available across all UI components:

```typescript
import { Icons } from '@dxtmisha/functional-basic'
import { fileIcons } from '@dxtmisha/media/files'

// Register into the global icon store from the fileIcons dictionary
Icons.add('file-pdf', fileIcons['pdf'])
Icons.add('file-zip', fileIcons['zip'])

// Retrieve anywhere in the application
const iconSvg = await Icons.get('file-pdf')
```

## Supported File Categories

- **Archive (`archive`)** — `zip`, `rar`, `7z`, `tar`, `gz`, `iso`
- **Audio (`audio`)** — `mp3`, `wav`, `flac`, `aac`, `ogg`, `m4a`
- **Code (`code`)** — `ts`, `js`, `json`, `html`, `css`, `py`, `cpp`, `php`
- **Document (`document`)** — `pdf`, `doc`, `docx`, `odt`, `rtf`
- **Image (`image`)** — `png`, `jpg`, `jpeg`, `gif`, `svg`, `webp`, `bmp`
- **Presentation (`presentation`)** — `ppt`, `pptx`, `odp`
- **Table (`table`)** — `xls`, `xlsx`, `csv`, `ods`
- **Video (`video`)** — `mp4`, `webm`, `mkv`, `avi`, `mov`
- **System (`system`)** — `exe`, `apk`, `dmg`, `app`
