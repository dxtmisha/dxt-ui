# MediaFile Class

The `MediaFile` class is a lightweight utility designed for parsing file paths, URLs, filenames, type codes, and `File` objects. It resolves SVG file icons, extracts file extensions and base names, and classifies files into categories (such as images, videos, documents, and archives) utilizing `MediaFiles` and `MediaFileIcon`.

## Key Features

- **Universal File Parsing** — seamlessly handles `File` instances, full URLs with query parameters and hash fragments, absolute/relative paths, filenames, dotted extensions (`.png`), and plain type codes (`png`, `pdf`, `7z`).
- **SVG Icon Resolution** — resolves SVG icon markup from the built-in library of 85+ vector file icons, falling back to category or generic neutral icons when unrecognized.
- **Custom Icon Support** — automatically applies custom SVG icons registered in `MediaFileIcon`.
- **Categorization & Format Checks** — provides instant category detection and boolean helpers (`isImage`, `isVideo`, `isDocument`, `isStandard`, etc.).
- **Zero Runtime Dependencies** — pure string manipulation and catalog lookups, fully isomorphic and safe for SSR.

## Initialization

Create an instance by providing a `File` object, file link, URL, filename, or file type code, with an optional MIME type override:

```typescript
import { MediaFile } from '@dxtmisha/media'

// From full URL
const fileFromUrl = new MediaFile('https://example.com/assets/report.pdf?v=2#page=1')

// From filename
const fileFromName = new MediaFile('archive.tar.gz')

// From extension or type code
const fileFromCode = new MediaFile('png')

// From browser File object
const fileFromInput = new MediaFile(uploadedFile)
```

## Methods

### Properties & Attributes

- `baseName: string` — returns the filename without its extension (e.g. `'archive.tar'` for `'archive.tar.gz'`).
- `blob: Blob | undefined` — returns the underlying `Blob` or `File` object if the instance was created with one.
- `category: MediaFileCategory | undefined` — returns the file category enum value (e.g. `'image'`, `'video'`, `'document'`).
- `extension: string` — returns the normalized lowercase file extension without a dot (e.g. `'png'`, `'pdf'`). **Note:** if initialized with a plain type or category code without a dot (e.g. `'archive'` or `'file'`), this code is retained in `extension` for backward compatibility (for paths without an extension, links such as `https://example.com/download`, or category MIME types like `audio/*`, returns an empty string `''`).
- `extensions: string[] | undefined` — returns the list of supported extensions associated with the file format (for standard formats, all catalog extensions like `['docx', 'dotx']`; for plain codes without dots, `[extension]`; for links and paths without an extension, `undefined`).
- `file: File | undefined` — returns the underlying browser `File` object if the instance was created with one.
- `group: MediaFileGroup | undefined` — returns the classification group of the file item (`neutral`, `category`, `standard`).
- `icon: string` — returns the resolved SVG icon markup string.
- `item: MediaFileItem` — returns the complete metadata item from the file catalog (falls back to the default neutral item).
- `mime: string | undefined` — returns the detected or explicit MIME type in canonical lowercase.
- `name: string` — returns the full filename extracted from the path or URL (stripped of query parameters and hash fragments, with URL percent-encoded characters safely decoded).

### Category & Classification Checks

- `isArchive(): boolean` — returns `true` if the file belongs to the archive category (`zip`, `rar`, `7z`, `tar`, `gz`, etc.).
- `isAudio(): boolean` — returns `true` if the file belongs to the audio category (`mp3`, `wav`, `flac`, `aac`, `ogg`, etc.).
- `isBlobUrl(): boolean` — returns `true` if the input is a Blob URL (`blob:...`).
- `isCategoryGroup(): boolean` — returns `true` if the file represents a category-level neutral icon.
- `isCode(): boolean` — returns `true` if the file is source code or a data file (`ts`, `js`, `json`, `html`, `css`, `py`, etc.).
- `isConfig(): boolean` — returns `true` if the file is a configuration file (`ini`, `env`, `conf`, `xml`, etc.).
- `isDatabase(): boolean` — returns `true` if the file is a database file (`sql`, `db`, `sqlite`, etc.).
- `isDataUrl(): boolean` — returns `true` if the input is an inline Data URL (`data:...`).
- `isDocument(): boolean` — returns `true` if the file is a document (`pdf`, `doc`, `docx`, `odt`, `rtf`, etc.).
- `isExecutable(): boolean` — returns `true` if the file is an executable or installer (`exe`, `dmg`, `apk`, `app`, `iso`, etc.).
- `isFolder(): boolean` — returns `true` if the file item represents a folder or directory.
- `isFont(): boolean` — returns `true` if the file is a font file (`ttf`, `otf`, `woff`, `woff2`, etc.).
- `isImage(): boolean` — returns `true` if the file is a raster or bitmap image (`png`, `jpg`, `jpeg`, `gif`, `webp`, etc.).
- `isNeutral(): boolean` — returns `true` if the file represents the universal default neutral file icon.
- `isPresentation(): boolean` — returns `true` if the file is a presentation (`ppt`, `pptx`, `odp`, `presentation`).
- `isStandard(): boolean` — returns `true` if the file represents a standard specific file format or extension.
- `isSystem(): boolean` — returns `true` if the file is a system or generic file.
- `isTable(): boolean` — returns `true` if the file is a spreadsheet or tabular data (`xls`, `xlsx`, `csv`, `ods`, etc.).
- `isText(): boolean` — returns `true` if the file is plain text or markdown (`txt`, `md`).
- `isUrl(): boolean` — returns `true` if the input is a remote URL with HTTP or HTTPS protocol.
- `isVector(): boolean` — returns `true` if the file is vector graphics (`svg`, `ai`, `eps`, etc.).
- `isVideo(): boolean` — returns `true` if the file is a video (`mp4`, `webm`, `mkv`, `avi`, `mov`, etc.).

### State Management

- `reset(): this` — clears all cached calculations (name, extension, MIME, metadata item) and returns the instance for chaining.

## Types

### MediaFileCategory

Enum representing file categories: `archive`, `audio`, `code`, `config`, `database`, `document`, `executable`, `folder`, `font`, `image`, `presentation`, `system`, `table`, `text`, `vector`, `video`.

### MediaFileGroup

Enum representing file item groups: `neutral`, `category`, `standard`.

### MediaFileItem

- `code: string` — unique file code or primary extension.
- `name: string` — human-readable file format label.
- `extensions?: string[]` — list of supported file extensions.
- `mime?: string` — primary MIME type.
- `icon?: string` — SVG icon markup.
- `category?: MediaFileCategoryValue` — file category enum value.
- `group?: MediaFileGroupValue` — classification group enum value.

## Usage Example

```typescript
import { MediaFile, MediaFileCategory } from '@dxtmisha/media'

const file = new MediaFile('https://domain.com/downloads/invoice.2026.pdf?download=true#top')

console.log(file.name) // 'invoice.2026.pdf'
console.log(file.baseName) // 'invoice.2026'
console.log(file.extension) // 'pdf'
console.log(file.category) // MediaFileCategory.document
console.log(file.isDocument()) // true
console.log(file.isImage()) // false

// SVG icon markup ready for rendering
const svgString = file.icon
```
