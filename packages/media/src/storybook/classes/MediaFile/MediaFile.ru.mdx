# Класс MediaFile

Класс `MediaFile` — это легковесная утилита, предназначенная для анализа путей к файлам, URL, имен файлов, кодов типов файлов и объектов `File`. Он определяет SVG-иконки файлов, извлекает расширения и базовые имена, а также классифицирует файлы по категориям (изображения, видео, документы, архивы и т.д.), опираясь на `MediaFiles` и `MediaFileIcon`.

## Ключевые возможности

- **Универсальный парсинг файлов** — корректно обрабатывает объекты `File`, полные URL с query-параметрами и хэшем, абсолютные/относительные пути, имена файлов, расширения с точкой (`.png`) и чистые коды типов (`png`, `pdf`, `7z`).
- **Определение SVG-иконок** — сопоставляет расширение с библиотекой из более чем 85 векторных иконок, используя иконку категории или нейтральную иконку по умолчанию при неизвестном формате.
- **Поддержка кастомных иконок** — автоматически использует пользовательские SVG-иконки, зарегистрированные в `MediaFileIcon`.
- **Категоризация и проверки форматов** — мгновенно определяет категорию файла и предоставляет вспомогательные методы (`isImage`, `isVideo`, `isDocument`, `isStandard` и т.д.).
- **Отсутствие зависимостей runtime** — чистое сопоставление строк и поиск по каталогу, полная изоморфность и безопасность для SSR.

## Инициализация

Создайте экземпляр класса, передав объект `File`, ссылку на файл, URL, имя файла или код типа файла с возможностью указания явного MIME-типа:

```typescript
import { MediaFile } from '@dxtmisha/media'

// Из полного URL
const fileFromUrl = new MediaFile('https://example.com/assets/report.pdf?v=2#page=1')

// Из имени файла
const fileFromName = new MediaFile('archive.tar.gz')

// Из расширения или кода типа
const fileFromCode = new MediaFile('png')

// Из браузерного объекта File
const fileFromInput = new MediaFile(uploadedFile)
```

## Методы

### Свойства и атрибуты

- `baseName: string` — возвращает имя файла без расширения (например, `'archive.tar'` для `'archive.tar.gz'`).
- `blob: Blob | undefined` — возвращает исходный объект `Blob` или `File`, если экземпляр был создан на его основе.
- `category: MediaFileCategory | undefined` — возвращает категорию файла из перечисления (например, `'image'`, `'video'`, `'document'`).
- `extension: string` — возвращает нормализованное расширение файла в нижнем регистре без точки (например, `'png'`, `'pdf'`). **Особенность:** если экземпляр инициализирован плоским кодом категории или нейтрального типа без точки (например, `'archive'` или `'file'`), этот код сохраняется в `extension` для обратной совместимости (для путей без расширения, ссылок вроде `https://example.com/download` или категорийных MIME вроде `audio/*` возвращается пустая строка `''`).
- `extensions: string[] | undefined` — возвращает список поддерживаемых расширений, связанных с форматом файла (для стандартных форматов — все зарегистрированные расширения, например `['docx', 'dotx']`; для плоских кодов без точки — `[extension]`; для ссылок и путей без расширения — `undefined`).
- `file: File | undefined` — возвращает исходный браузерный объект `File`, если экземпляр был создан на его основе.
- `group: MediaFileGroup | undefined` — возвращает классификационную группу элемента файла (`neutral`, `category`, `standard`).
- `icon: string` — возвращает разрешенную строку SVG-разметки иконки.
- `item: MediaFileItem` — возвращает полный объект метаданных из каталога файлов (при отсутствии совпадений возвращает нейтральный элемент по умолчанию).
- `mime: string | undefined` — возвращает определенный или явно переданный MIME-тип в каноническом нижнем регистре.
- `name: string` — возвращает полное имя файла, извлеченное из пути или URL (без query-параметров и хэша, с безопасным декодированием percent-encoded символов URL).

### Проверки категорий и классификации

- `isArchive(): boolean` — возвращает `true`, если файл относится к категории архивов (`zip`, `rar`, `7z`, `tar`, `gz` и др.).
- `isAudio(): boolean` — возвращает `true`, если файл относится к категории аудио (`mp3`, `wav`, `flac`, `aac`, `ogg` и др.).
- `isBlobUrl(): boolean` — возвращает `true`, если входное значение является Blob URL (`blob:...`).
- `isCategoryGroup(): boolean` — возвращает `true`, если файл представляет собой нейтральную иконку категории.
- `isCode(): boolean` — возвращает `true`, если файл является исходным кодом или файлом данных (`ts`, `js`, `json`, `html`, `css`, `py` и др.).
- `isConfig(): boolean` — возвращает `true`, если файл является конфигурационным файлом (`ini`, `env`, `conf`, `xml` и др.).
- `isDatabase(): boolean` — возвращает `true`, если файл является файлом базы данных (`sql`, `db`, `sqlite` и др.).
- `isDataUrl(): boolean` — возвращает `true`, если входное значение является Data URL (`data:...`).
- `isDocument(): boolean` — возвращает `true`, если файл является документом (`pdf`, `doc`, `docx`, `odt`, `rtf` и др.).
- `isExecutable(): boolean` — возвращает `true`, если файл является исполняемым файлом или установщиком (`exe`, `dmg`, `apk`, `app`, `iso` и др.).
- `isFolder(): boolean` — возвращает `true`, если элемент представляет собой папку или каталог.
- `isFont(): boolean` — возвращает `true`, если файл является шрифтом (`ttf`, `otf`, `woff`, `woff2` и др.).
- `isImage(): boolean` — возвращает `true`, если файл является растровым изображением (`png`, `jpg`, `jpeg`, `gif`, `webp` и др.).
- `isNeutral(): boolean` — возвращает `true`, если файл представляет собой базовую нейтральную иконку файла по умолчанию.
- `isPresentation(): boolean` — возвращает `true`, если файл является презентацией (`ppt`, `pptx`, `odp`, `presentation`).
- `isStandard(): boolean` — возвращает `true`, если файл представляет собой стандартный конкретный формат или расширение.
- `isSystem(): boolean` — возвращает `true`, если файл является системным или общим файлом.
- `isTable(): boolean` — возвращает `true`, если файл является таблицей или структурированными данными (`xls`, `xlsx`, `csv`, `ods` и др.).
- `isText(): boolean` — возвращает `true`, если файл является простым текстом или markdown (`txt`, `md`).
- `isUrl(): boolean` — возвращает `true`, если входное значение является удаленным URL с протоколом HTTP или HTTPS.
- `isVector(): boolean` — возвращает `true`, если файл является векторной графикой (`svg`, `ai`, `eps` и др.).
- `isVideo(): boolean` — возвращает `true`, если файл является видео (`mp4`, `webm`, `mkv`, `avi`, `mov` и др.).

### Управление состоянием

- `reset(): this` — сбрасывает все кэшированные вычисления (имя, расширение, MIME-тип, элемент метаданных) и возвращает текущий экземпляр для цепочки вызовов.

## Типы

### MediaFileCategory

Перечисление поддерживаемых категорий файлов: `archive`, `audio`, `code`, `config`, `database`, `document`, `executable`, `folder`, `font`, `image`, `presentation`, `system`, `table`, `text`, `vector`, `video`.

### MediaFileGroup

Перечисление классификационных групп элементов файлов: `neutral`, `category`, `standard`.

### MediaFileItem

- `code: string` — уникальный код типа файла или первичное расширение.
- `name: string` — понятное пользователю отображаемое название формата.
- `extensions?: string[]` — список поддерживаемых расширений файла.
- `mime?: string` — связанный MIME-тип.
- `icon?: string` — SVG-разметка иконки.
- `category?: MediaFileCategoryValue` — категория файла из перечисления.
- `group?: MediaFileGroupValue` — классификационная группа элемента.

## Пример использования

```typescript
import { MediaFile, MediaFileCategory } from '@dxtmisha/media'

const file = new MediaFile('https://domain.com/downloads/invoice.2026.pdf?download=true#top')

console.log(file.name) // 'invoice.2026.pdf'
console.log(file.baseName) // 'invoice.2026'
console.log(file.extension) // 'pdf'
console.log(file.category) // MediaFileCategory.document
console.log(file.isDocument()) // true
console.log(file.isImage()) // false

// SVG-разметка иконки, готовая к рендерингу
const svgString = file.icon
```
