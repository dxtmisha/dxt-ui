# MediaSocial Class

The `MediaSocial` class is a **Primary Class (Static)** designed for managing social network configurations, profile URL generation, handle extraction, and custom icon overrides across 35+ supported platforms.

## Key Features

- **Built-in Social Catalog** — preconfigured settings for over 35 global and regional social networks (e.g., GitHub, Telegram, LinkedIn, X, WeChat, Zalo).
- **Profile URL Construction** — automatically builds canonical profile links from raw usernames or handles (`getUrl`).
- **Username Extraction** — parses full profile URLs to safely extract handles by stripping prefixes and suffixes (`getValue`).
- **Custom Icon Support** — seamlessly enriches social metadata items with custom vector icons registered via `MediaSocialIcon`.
- **Static Interface** — perform all operations directly on the class without manual instantiation.

## Methods

### URL and Value Management

- `static getNickname(code: InputSocialTypeValue, value: InputSocialValue): string` — returns formatted nickname with prefix (e.g. `'@username'`) or an empty string if invalid or unsupported.
- `static getUrl(code: InputSocialTypeValue, value: InputSocialValue): string` — constructs the full profile URL from a username or partial string using the platform's configured prefix and suffix.
- `static getValue(code: InputSocialTypeValue, url: InputSocialValue): string` — extracts the raw username or profile handle from a full profile URL by removing prefixes, queries, hashes, and suffixes.

### Catalog & Retrieval

- `static get(code: InputSocialTypeValue): InputSocialItem | undefined` — returns the social network configuration by its code, merged with any custom icon registered for that platform in `MediaSocialIcon`.
- `static getList(): InputSocialList` — returns the complete array of all supported social network configuration items.

### Custom Icons

- `static addIcon(code: InputSocialTypeValue, icon: string): typeof MediaSocial` — registers a custom icon string or SVG markup for the specified social network via `MediaSocialIcon`. Returns the class constructor for method chaining.
- `static addIcons(icons: InputSocialIcons): typeof MediaSocial` — registers multiple custom icons in batch from a dictionary via `MediaSocialIcon`. Returns the class constructor for method chaining.

## Types

### `InputSocialItem<Mask = unknown>`

- `code: InputSocialTypeValue` — unique identifier code for the social network.
- `name: string` — human-readable display name of the social platform.
- `prefix?: string` — URL prefix for user profile links (e.g. `'https://github.com/'`).
- `prefixClear?: RegExp` — normalized URL prefix pattern for stripping or matching profile links.
- `suffix?: string` — URL suffix for user profile links.
- `mask?: Mask` — optional input mask configuration for form controls.
- `icon?: string` — resolved or custom icon markup/name.
- `nickname?: string` — nickname prefix symbol or string (e.g. `'@'`).
- `nicknameClear?: RegExp` — pattern to match or clean nickname value.

### InputSocialIcons

- `Partial<Record<InputSocialType, string>>` — dictionary mapping social network codes to icon markup strings or identifiers.

### InputSocialType

Enum of supported social network codes: `alipay`, `baidu`, `dingtalk`, `discord`, `douyin`, `dzen`, `facebook`, `github`, `gitlab`, `habr`, `instagram`, `line`, `linkedin`, `medium`, `messenger`, `ok`, `pinterest`, `qq`, `reddit`, `skype`, `snapchat`, `telegram`, `tiktok`, `tumblr`, `twitter`, `viber`, `vk`, `wechat`, `weibo`, `whatsapp`, `x`, `xiaohongshu`, `youtube`, `zalo`, `zhihu`.

## Usage Example

```typescript
import { MediaSocial, InputSocialType } from '@dxtmisha/media'

// Build a full profile URL from a username
const profileUrl = MediaSocial.getUrl(InputSocialType.github, 'dxtmisha')
// Result: 'https://github.com/dxtmisha'

// Extract raw username from a full profile URL
const username = MediaSocial.getValue(InputSocialType.telegram, 'https://t.me/dxtmisha')
// Result: 'dxtmisha'

// Format nickname with prefix
const nickname = MediaSocial.getNickname(InputSocialType.instagram, 'dxtmisha')
// Result: '@dxtmisha'

// Retrieve configuration item
const githubConfig = MediaSocial.get(InputSocialType.github)
console.log(githubConfig?.name) // 'GitHub'
console.log(githubConfig?.prefix) // 'https://github.com/'

// Register custom icons directly via MediaSocial (delegates to MediaSocialIcon)
MediaSocial
  .addIcon(InputSocialType.telegram, '<svg class="custom-tg">...</svg>')
  .addIcons({
    [InputSocialType.github]: '<svg class="custom-gh">...</svg>'
  })
```
