# Класс MediaSocial

Класс `MediaSocial` представляет собой **основной класс (статический)**, предназначенный для управления конфигурациями социальных сетей, генерации ссылок на профили, извлечения имени пользователя и переопределения иконок для более чем 35 поддерживаемых платформ.

## Ключевые возможности

- **Встроенный каталог платформ** — готовые конфигурации для более чем 35 международных и региональных социальных сетей (например, GitHub, Telegram, LinkedIn, X, ВКонтакте, WeChat, Zalo).
- **Построение ссылок на профили** — автоматическое формирование канонических ссылок из имени пользователя или логина (`getUrl`).
- **Извлечение имени пользователя** — парсинг полных ссылок на профили для безопасного извлечения логина путем удаления префиксов и суффиксов (`getValue`).
- **Поддержка кастомных иконок** — автоматическое обогащение метаданных платформ кастомными векторными иконками через `MediaSocialIcon`.
- **Статический интерфейс** — выполнение всех операций напрямую через класс без необходимости создания экземпляра.

## Методы

### Управление URL и значениями

- `static getNickname(code: InputSocialTypeValue, value: InputSocialValue): string` — возвращает отформатированный никнейм с префиксом (например, `'@username'`) или пустую строку, если никнеймы не поддерживаются платформой или значение невалидно.
- `static getUrl(code: InputSocialTypeValue, value: InputSocialValue): string` — строит полную ссылку на профиль по имени пользователя или частичной строке с использованием настроенного префикса и суффикса платформы.
- `static getValue(code: InputSocialTypeValue, url: InputSocialValue): string` — извлекает чистое имя пользователя или логин из полной ссылки на профиль путем удаления префиксов, параметров запроса, хэшей и суффиксов.

### Каталог и получение данных

- `static get(code: InputSocialTypeValue): InputSocialItem | undefined` — возвращает конфигурацию социальной сети по ее коду, дополненную кастомной иконкой из `MediaSocialIcon` при ее наличии.
- `static getList(): InputSocialList` — возвращает полный массив конфигураций всех поддерживаемых социальных сетей.

### Кастомные иконки

- `static addIcon(code: InputSocialTypeValue, icon: string): typeof MediaSocial` — регистрирует кастомную строку иконки или SVG-разметку для указанной социальной сети через `MediaSocialIcon`. Возвращает конструктор класса для цепочечных вызовов.
- `static addIcons(icons: InputSocialIcons): typeof MediaSocial` — регистрирует несколько кастомных иконок пакетом из переданного словаря через `MediaSocialIcon`. Возвращает конструктор класса для цепочечных вызовов.

## Типы

### `InputSocialItem<Mask = unknown>`

- `code: InputSocialTypeValue` — уникальный код-идентификатор социальной сети.
- `name: string` — отображаемое название социальной сети.
- `prefix?: string` — префикс URL для ссылки на профиль (например, `'https://github.com/'`).
- `prefixClear?: RegExp` — нормализованный шаблон регулярного выражения для сопоставления или очистки префикса URL.
- `suffix?: string` — суффикс URL для ссылки на профиль.
- `mask?: Mask` — опциональная конфигурация маски ввода для полей формы.
- `icon?: string` — имя или SVG-разметка иконки.
- `nickname?: string` — символ или строка префикса никнейма (например, `'@'`).
- `nicknameClear?: RegExp` — шаблон регулярного выражения для извлечения или очистки никнейма.

### InputSocialIcons

- `Partial<Record<InputSocialType, string>>` — словарь сопоставления кодов социальных сетей со строками разметки или идентификаторами иконок.

### InputSocialType

Перечисление (enum) кодов поддерживаемых социальных сетей: `alipay`, `baidu`, `dingtalk`, `discord`, `douyin`, `dzen`, `facebook`, `github`, `gitlab`, `habr`, `instagram`, `line`, `linkedin`, `medium`, `messenger`, `ok`, `pinterest`, `qq`, `reddit`, `skype`, `snapchat`, `telegram`, `tiktok`, `tumblr`, `twitter`, `viber`, `vk`, `wechat`, `weibo`, `whatsapp`, `x`, `xiaohongshu`, `youtube`, `zalo`, `zhihu`.

## Пример использования

```typescript
import { MediaSocial, InputSocialType } from '@dxtmisha/media'

// Построение полной ссылки на профиль по логину
const profileUrl = MediaSocial.getUrl(InputSocialType.github, 'dxtmisha')
// Результат: 'https://github.com/dxtmisha'

// Извлечение логина из полной ссылки на профиль
const username = MediaSocial.getValue(InputSocialType.telegram, 'https://t.me/dxtmisha')
// Результат: 'dxtmisha'

// Форматирование никнейма с префиксом
const nickname = MediaSocial.getNickname(InputSocialType.instagram, 'dxtmisha')
// Результат: '@dxtmisha'

// Получение объекта конфигурации
const githubConfig = MediaSocial.get(InputSocialType.github)
console.log(githubConfig?.name) // 'GitHub'
console.log(githubConfig?.prefix) // 'https://github.com/'

// Регистрация кастомных иконок напрямую через MediaSocial (делегируется в MediaSocialIcon)
MediaSocial
  .addIcon(InputSocialType.telegram, '<svg class="custom-tg">...</svg>')
  .addIcons({
    [InputSocialType.github]: '<svg class="custom-gh">...</svg>'
  })
```
