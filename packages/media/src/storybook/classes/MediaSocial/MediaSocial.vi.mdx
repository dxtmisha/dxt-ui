# Lớp MediaSocial

Lớp `MediaSocial` là một **Lớp chính (Tĩnh)** được thiết kế để quản lý cấu hình các mạng xã hội, tạo liên kết hồ sơ người dùng, trích xuất tên người dùng (handle), và quản lý biểu tượng tùy chỉnh cho hơn 35 nền tảng được hỗ trợ.

## Tính năng chính

- **Danh mục mạng xã hội tích hợp** — hỗ trợ sẵn hơn 35 mạng xã hội toàn cầu và khu vực (như GitHub, Telegram, LinkedIn, X, WeChat, Zalo).
- **Tạo URL hồ sơ cá nhân** — tự động xây dựng liên kết hồ sơ chuẩn từ tên người dùng hoặc handle (`getUrl`).
- **Trích xuất tên người dùng** — phân tích liên kết hồ sơ đầy đủ để trích xuất handle một cách an toàn bằng cách loại bỏ tiền tố và hậu tố (`getValue`).
- **Hỗ trợ biểu tượng tùy chỉnh** — tự động làm giàu dữ liệu phần tử mạng xã hội với biểu tượng vector tùy chỉnh thông qua `MediaSocialIcon`.
- **Giao diện tĩnh tiện lợi** — thực thi mọi tác vụ trực tiếp trên lớp mà không cần khởi tạo đối tượng thủ công.

## Phương thức

### Quản lý URL và giá trị

- `static getNickname(code: InputSocialTypeValue, value: InputSocialValue): string` — trả về biệt danh đã định dạng với tiền tố (ví dụ: `'@username'`) hoặc chuỗi rỗng nếu nền tảng không hỗ trợ biệt danh hoặc giá trị không hợp lệ.
- `static getUrl(code: InputSocialTypeValue, value: InputSocialValue): string` — xây dựng URL hồ sơ đầy đủ từ tên người dùng hoặc chuỗi giá trị dựa trên tiền tố và hậu tố đã cấu hình của nền tảng.
- `static getValue(code: InputSocialTypeValue, url: InputSocialValue): string` — trích xuất tên người dùng hoặc handle gốc từ một URL hồ sơ đầy đủ bằng cách loại bỏ tiền tố, truy vấn, hash và hậu tố.

### Danh mục & Truy xuất dữ liệu

- `static get(code: InputSocialTypeValue): InputSocialItem | undefined` — trả về cấu hình của mạng xã hội theo mã định danh, kết hợp với biểu tượng tùy chỉnh từ `MediaSocialIcon` nếu đã đăng ký.
- `static getList(): InputSocialList` — trả về mảng đầy đủ cấu hình của tất cả các mạng xã hội được hỗ trợ.

### Biểu tượng tùy chỉnh

- `static addIcon(code: InputSocialTypeValue, icon: string): typeof MediaSocial` — đăng ký một chuỗi biểu tượng hoặc mã SVG cho mạng xã hội cụ thể thông qua `MediaSocialIcon`. Trả về lớp để gọi phương thức nối tiếp.
- `static addIcons(icons: InputSocialIcons): typeof MediaSocial` — đăng ký hàng loạt nhiều biểu tượng tùy chỉnh từ một từ điển thông qua `MediaSocialIcon`. Trả về lớp để gọi phương thức nối tiếp.

## Kiểu dữ liệu

### `InputSocialItem<Mask = unknown>`

- `code: InputSocialTypeValue` — mã định danh duy nhất của mạng xã hội.
- `name: string` — tên hiển thị trực quan của mạng xã hội.
- `prefix?: string` — tiền tố URL cho liên kết hồ sơ người dùng (ví dụ: `'https://github.com/'`).
- `prefixClear?: RegExp` — biểu thức chính quy chuẩn hóa để khớp hoặc xóa tiền tố URL hồ sơ.
- `suffix?: string` — hậu tố URL cho liên kết hồ sơ người dùng.
- `mask?: Mask` — cấu hình mặt nạ nhập liệu tùy chọn cho trường biểu mẫu.
- `icon?: string` — tên biểu tượng hoặc mã SVG của biểu tượng.
- `nickname?: string` — ký tự hoặc chuỗi tiền tố biệt danh (ví dụ: `'@'`).
- `nicknameClear?: RegExp` — biểu thức chính quy để trích xuất hoặc làm sạch biệt danh.

### InputSocialIcons

- `Partial<Record<InputSocialType, string>>` — từ điển ánh xạ mã mạng xã hội với chuỗi biểu tượng hoặc định danh biểu tượng.

### InputSocialType

Enum các mã mạng xã hội được hỗ trợ: `alipay`, `baidu`, `dingtalk`, `discord`, `douyin`, `dzen`, `facebook`, `github`, `gitlab`, `habr`, `instagram`, `line`, `linkedin`, `medium`, `messenger`, `ok`, `pinterest`, `qq`, `reddit`, `skype`, `snapchat`, `telegram`, `tiktok`, `tumblr`, `twitter`, `viber`, `vk`, `wechat`, `weibo`, `whatsapp`, `x`, `xiaohongshu`, `youtube`, `zalo`, `zhihu`.

## Ví dụ sử dụng

```typescript
import { MediaSocial, InputSocialType } from '@dxtmisha/media'

// Xây dựng liên kết hồ sơ đầy đủ từ tên người dùng
const profileUrl = MediaSocial.getUrl(InputSocialType.github, 'dxtmisha')
// Kết quả: 'https://github.com/dxtmisha'

// Trích xuất tên người dùng từ liên kết đầy đủ
const username = MediaSocial.getValue(InputSocialType.telegram, 'https://t.me/dxtmisha')
// Kết quả: 'dxtmisha'

// Định dạng biệt danh với tiền tố
const nickname = MediaSocial.getNickname(InputSocialType.instagram, 'dxtmisha')
// Kết quả: '@dxtmisha'

// Lấy thông tin cấu hình của nền tảng
const githubConfig = MediaSocial.get(InputSocialType.github)
console.log(githubConfig?.name) // 'GitHub'
console.log(githubConfig?.prefix) // 'https://github.com/'

// Đăng ký biểu tượng tùy chỉnh trực tiếp qua MediaSocial (ủy nhiệm cho MediaSocialIcon)
MediaSocial
  .addIcon(InputSocialType.telegram, '<svg class="custom-tg">...</svg>')
  .addIcons({
    [InputSocialType.github]: '<svg class="custom-gh">...</svg>'
  })
```
