# Класс MediaFileIcon

Класс `MediaFileIcon` — это **основной статический класс (Static)**, предназначенный для регистрации, хранения, нормализации и применения пользовательских SVG-иконок для расширений и кодов типов файлов. Он выступает централизованным реестром иконок, используемым классами `MediaFiles` и `MediaFile` для переопределения стандартных векторных иконок в дизайн-системе.

## Ключевые возможности

- **Статический реестр** — хранит словарь пользовательской SVG-разметки в памяти, привязанный к нормализованным кодам файлов.
- **Нормализация кодов** — автоматически удаляет пробельные символы и приводит коды к нижнему регистру (`toCode`), обеспечивая регистронезависимый поиск.
- **Одиночная и пакетная регистрация** — предоставляет удобные методы для регистрации отдельных иконок (`add`) или массового добавления словаря (`addList`).
- **Бесшовное обогащение метаданных** — безопасно дополняет объекты конфигурации `MediaFileItem` кастомными иконками через метод `toItem`.
- **Отсутствие зависимостей runtime** — чистые строковые операции и манипуляции со словарем, полная изоморфность и безопасность для SSR.

## Инициализация

Класс является статическим и не требует создания экземпляров. Все методы вызываются напрямую через `MediaFileIcon`.

## Методы

### Реестр и управление

- `static has(code: string): boolean` — проверяет, зарегистрирована ли пользовательская иконка для указанного кода файла или расширения.
- `static get(code: string): string | undefined` — возвращает строку кастомной SVG-иконки для указанного кода или расширения, либо `undefined`, если иконка не найдена.
- `static add(code: string, icon: string): void` — регистрирует пользовательскую строку SVG-иконки для конкретного кода файла или расширения.
- `static addList(icons: MediaFileIcons): void` — пакетно регистрирует несколько пользовательских SVG-иконок из переданного словаря.

### Нормализация и трансформация элементов

- `static toCode(code: string): string` — преобразует код файла или расширение в нормализованный формат (удаление пробелов по краям и перевод в нижний регистр).
- `static toItem(item?: MediaFileItem): MediaFileItem | undefined` — создает поверхностную копию элемента файла с подстановкой кастомной иконки, если она зарегистрирована, либо возвращает элемент без изменений.

## Типы

### MediaFileIcons

- `Record<string, string>` — словарь сопоставления нормализованных кодов и расширений файлов со строками SVG-разметки.

### MediaFileItem

- `code: string` — код типа файла или расширение.
- `name: string` — понятное пользователю отображаемое название формата.
- `icon?: string` — разрешенная или кастомная SVG-разметка иконки.
- `extensions?: string[]` — список поддерживаемых расширений файла.
- `mime?: string` — связанный MIME-тип.
- `category?: MediaFileCategoryValue` — категория файла верхнего уровня.
- `group?: MediaFileGroupValue` — группа классификации (`neutral`, `category`, `standard`).

## Пример использования

```typescript
import { MediaFileIcon } from '@dxtmisha/media'

// Регистрация одной кастомной SVG-иконки
MediaFileIcon.add('sketch', '<svg class="icon-sketch">...</svg>')

// Пакетная регистрация иконок
MediaFileIcon.addList({
  psd: '<svg class="icon-psd">...</svg>',
  ai: '<svg class="icon-ai">...</svg>'
})

// Проверка наличия и получение иконки
if (MediaFileIcon.has('sketch')) {
  const iconMarkup = MediaFileIcon.get('sketch')
  console.log(iconMarkup)
}

// Нормализация кода файла
console.log(MediaFileIcon.toCode('  .DOCX  ')) // '.docx'
```
