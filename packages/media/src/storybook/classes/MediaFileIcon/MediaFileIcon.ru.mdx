# Класс MediaFileIcon

Класс `MediaFileIcon` — это **основной статический класс (Static)**, предназначенный для регистрации, хранения, нормализации и применения пользовательских SVG-иконок для расширений и кодов типов файлов. Он выступает централизованным реестром иконок, используемым классами `MediaFiles` и `MediaFile` для переопределения стандартных векторных иконок в дизайн-системе.

## Ключевые возможности

- **Статический реестр** — хранит изолированный от прототипа словарь пользовательской SVG-разметки в памяти (`Object.create(null)`), привязанный к нормализованным кодам файлов.
- **Цепочечные вызовы (Fluent Chaining)** — методы `add`, `addList` и `reset` возвращают класс `typeof MediaFileIcon`, позволяя выстраивать удобные цепочки регистрации.
- **Комплексная нормализация кодов** — автоматически удаляет граничные пробелы и точки, отсекает параметры MIME (после `;`) и приводит коды к нижнему регистру (`toCode`), обеспечивая регистронезависимый поиск.
- **Одиночная и пакетная регистрация** — предоставляет удобные методы для регистрации отдельных иконок с очисткой граничных пробелов (`add`) или массового добавления словаря (`addList`).
- **Бесшовное обогащение метаданных** — создает защитную копию объекта `MediaFileItem` с клонированием массива `extensions` и подстановкой кастомной иконки через метод `toItem`.
- **Высокая производительность** — внутренний флаг быстрого выхода (`hasCustomIcons`) обеспечивает проверку за O(1) без накладных расходов при пустом реестре.
- **Отсутствие зависимостей runtime** — чистые строковые операции и манипуляции со словарем, полная изоморфность и безопасность для SSR.

## Инициализация

Класс является статическим и не требует создания экземпляров. Все методы вызываются напрямую через `MediaFileIcon`.

## Методы

### Реестр и управление

- `static get icons(): Readonly<MediaFileIcons>` — возвращает снимок словаря всех зарегистрированных кастомных иконок для чтения (без свойств прототипа `Object.prototype`).
- `static has(code: string): boolean` — проверяет, зарегистрирована ли пользовательская иконка для указанного кода файла или расширения.
- `static get(code: string): string | undefined` — возвращает строку кастомной SVG-иконки для указанного кода или расширения, либо `undefined`, если иконка не найдена.
- `static add(code: string, icon: string): typeof MediaFileIcon` — регистрирует пользовательскую строку SVG-иконки (с автоматической обрезкой граничных пробелов) для конкретного кода файла или расширения. Возвращает класс для вызова по цепочке.
- `static addList(icons: MediaFileIcons): typeof MediaFileIcon` — пакетно регистрирует несколько пользовательских SVG-иконок из переданного словаря. Возвращает класс для вызова по цепочке.
- `static remove(code: string): boolean` — удаляет кастомную иконку по коду файла или расширению, возвращая `true`, если иконка существовала и была удалена.
- `static reset(): typeof MediaFileIcon` — полностью сбрасывает и очищает реестр всех зарегистрированных кастомных иконок. Возвращает класс для вызова по цепочке.

### Нормализация и трансформация элементов

- `static toCode(code: string): string` — преобразует код файла или расширение в нормализованный формат (удаление граничных точек и пробелов, отсечение MIME-параметров после `;` и приведение к нижнему регистру).
- `static toItem<T extends MediaFileItem | undefined = undefined>(item?: T): MediaFileItemReturn<T>` — создает защитную поверхностную копию элемента файла и его массива расширений с подстановкой кастомной иконки по каскаду приоритетов (`code` -> `extensions` -> `mime` -> `category`).

## Типы

### MediaFileIcons

- `Record<string, string>` — словарь сопоставления нормализованных кодов и расширений файлов со строками SVG-разметки.

### MediaFileItem

- `code: string` — код типа файла или расширение.
- `name: string` — понятное пользователю отображаемое название формата.
- `icon?: string` — разрешенная или кастомная SVG-разметка иконки.
- `extensions?: string[]` — список поддерживаемых расширений файла.
- `mime?: string` — связанный MIME-тип.
- `category?: MediaFileCategoryValue` — категория файла верхнего уровня.
- `group?: MediaFileGroupValue` — группа классификации (`neutral`, `category`, `standard`).

### `MediaFileItemReturn<T>`

- `T extends MediaFileItem ? MediaFileItem : undefined` — условный результирующий тип возврата в зависимости от наличия входного элемента.

## Пример использования

```typescript
import { MediaFileIcon } from '@dxtmisha/media'

// Регистрация через цепочечные вызовы (method chaining)
MediaFileIcon
  .reset()
  .add('sketch', '<svg class="icon-sketch">...</svg>')
  .addList({
    psd: '<svg class="icon-psd">...</svg>',
    ai: '<svg class="icon-ai">...</svg>'
  })

// Проверка наличия и получение иконки
if (MediaFileIcon.has('sketch')) {
  const iconMarkup = MediaFileIcon.get('sketch')
  console.log(iconMarkup)
}

// Получение снимка всех зарегистрированных иконок
const allIcons = MediaFileIcon.icons
console.log(allIcons.sketch)

// Нормализация кода файла (отсекает пробелы, краевые точки и параметры MIME)
console.log(MediaFileIcon.toCode('  ..DOCX..  ')) // 'docx'
console.log(MediaFileIcon.toCode('text/plain; charset=utf-8')) // 'text/plain'

// Удаление конкретной иконки
MediaFileIcon.remove('sketch')

// Полный сброс всех зарегистрированных иконок
MediaFileIcon.reset()
```
