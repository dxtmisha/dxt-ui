# Глобальные токены и медиа (src/media)

Каталог `src/media` предназначен для хранения глобальных дизайн-токенов и медиа-ресурсов (иконок) вашей дизайн-системы. Структура файлов и набор токенов в каждом проекте индивидуальны и зависят от требований вашего дизайна.

## 1. Структура каталога

Пример базовой организации:

```
src/media/
├── icons/                   # SVG-иконки проекта
│   └── *.svg
├── tokens/                  # JSON-файлы дизайн-токенов (цвета, сетки, отступы и др.)
│   └── *.json
└── properties.json          # Главный файл конфигурации глобальных токенов
```

## 2. Конфигурация токенов (properties.json)

Файл `src/media/properties.json` объединяет токены проекта, распределяет их по категориям и определяет, как они будут скомпилированы:

```json
{
  "ref": {
    "value": {
      "file|ref": "tokens/ref.json"
    },
    "_type": "var",
    "_category": "root"
  },
  "sys": {
    "value": {
      "file|sys": "tokens/sys.json"
    },
    "_type": "var",
    "_category": "root"
  },
  "color": {
    "value": {
      "file|color": "tokens/color.json"
    },
    "_category": "class"
  },
  "dark": {
    "value": {
      "file|dark": "tokens/dark.json"
    },
    "_category": "theme"
  }
}
```

- `"file|<name>": "path.json"` — подключает отдельный JSON-файл с токенами.
- `"_type": "var"` — экспортирует токены в виде CSS-переменных.
- `"_category": "root"` — корневые системные переменные.
- `"_category": "class"` — переиспользуемые группы стилей для компонентов.
- `"_category": "theme"` — токены для переопределения тем оформления (например, темного режима).

## 3. Добавление иконок (icons)

Для добавления новых иконок:
1. Поместите векторные файлы `.svg` в папку `src/media/icons/`.
2. Запустите генерацию:
   ```bash
   npm run ui
   ```

Скрипт автоматически найдет все иконки, создаст асинхронный импорт и зарегистрирует их в `Icons`. После этого иконка доступна по имени файла во всех компонентах:

```html
<d1-button icon="my-icon">Кнопка</d1-button>
```

## 4. Синхронизация

После любых изменений в токенах или добавления иконок запустите команду:

```bash
npm run ui
```

Команда пересоберет SCSS-миксины, обновит `ui-properties.scss`, подключит иконки и обновит типы.
