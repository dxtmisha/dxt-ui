# ДИРЕКТИВА ДЛЯ ИИ: ВЕРСТКА И СТИЛИЗАЦИЯ (SCSS/JSON)

**ГЛАВНОЕ ПРАВИЛО:** НИКОГДА не используйте жесткие HEX, RGB или `rgba()` при верстке. ВСЕ цвета назначаются только через системные миксины или токены JSON.

## 1. Что такое "Палитра" и когда ее использовать?

- **Что это делает:** Миксин/токен палитры (например, `paletteBackgroundColor`) генерирует динамический маршрут через CSS-переменные (привязку к базовой плотности, вроде `basic600`), а не статический цвет.
- **Зачем это нужно:** Если тема родительского контейнера меняется (например, `<div class="palette--yellow">`), компонент автоматически перекрашивается, сохраняя идеальный контраст. Вам НЕ НУЖНО писать CSS-переопределения для разных тем.
- **Когда использовать:** Используйте палитры для основных визуальных элементов компонента (фоны, основной текст, обводки), которые должны адаптироваться при смене цветовой схемы приложения.
- **Когда НЕ использовать:** Не используйте палитры для элементов, которые всегда должны оставаться фиксированного цвета независимо от темы (например, текст поверх яркой кнопки обычно должен оставаться белым для сохранения контраста — для него нужен статический токен, а не палитра).

## 2. SCSS-миксины (Использование в `.scss` и `.vue` файлах)

Эти правила строго обязательны для всех `.scss` файлов И всех блоков `<style lang="scss">` внутри Vue-компонентов.

### Динамические палитры (Адаптируются под тему)
Использовать, когда цвет элемента должен меняться при смене темы у родителя:
- `@include paletteBackgroundColor('--sys-palette-primary');`
- `@include paletteColor('--sys-palette-on-primary');`
- `@include paletteBorderColor('--sys-palette-outline');`
- `@include paletteFill('--sys-palette-primary');`
- `@include paletteStroke('--sys-palette-primary');`

### Статические цвета (Фиксированные)
Использовать, когда цвет должен ВСЕГДА оставаться неизменным, независимо от темы:
- `@include backgroundColor('--sys-background');`
- `@include color('--sys-on-surface');`
- `@include borderColor('--sys-outline');`

## 3. properties.json (Конфигурация UI)

При настройке свойств UI в JSON используйте точные токены:

### Ключи для палитр (Адаптируются под тему)
- `"palette-background": "{sys.palette.primary}"`
- `"palette-color": "{sys.palette.primary}"`
- `"palette-border": "{sys.palette.primary}"`
- `"palette-fill": "{sys.palette.primary}"`
- `"palette-stroke": "{sys.palette.primary}"`

### Статические ключи
- `"background-color": "{sys.palette.surface}"`
- `"color": "{sys.palette.onSurface}"`
- `"border-color": "{sys.palette.outline}"`

### Прозрачность (Состояния и эффекты)
Всегда используйте прозрачность для состояний (hover, focus, disabled). НИКОГДА не меняйте базовую переменную цвета для состояния.
```json
{
  "focus": { "gradient-opacity": "{sys.opacity.focus}" },
  "hover": { "gradient-opacity": "{sys.opacity.hover}" },
  "disabled": {
    "background-color": "{sys.palette.onSurface}",
    "background-opacity": "{sys.opacity.disabled}"
  }
}
```

## 4. СТРОГИЕ ЗАПРЕТЫ (ЧЕГО ДЕЛАТЬ НЕЛЬЗЯ)

1. **НЕ ПИСАТЬ** `color:`, `background-color:`, `border-color:` напрямую в SCSS или Vue-стилях (исключение: `transparent` или `inherit`).
2. **НЕ ПУТАТЬ** `paletteColor` (динамический) и `color` (статический). Если цвет зависит от темы, используйте префикс `palette`.
3. **НЕ ПИСАТЬ** CSS-переопределения для тем (например, `.palette--red .btn { ... }`). Миксины делают это автоматически.
4. **НЕ СМЕШИВАТЬ** цвет и прозрачность. Меняйте прозрачность ТОЛЬКО через `--sys-[name]-opacity` или токен `{sys.opacity.*}`.
5. **НЕ ИСПОЛЬЗОВАТЬ** жесткие веса цветов (например, `600`). Используйте только семантические имена (`primary`, `surface`, `error`).
