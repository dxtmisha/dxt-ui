# `useFigmaStorageMulti`

Composable để đồng bộ hóa dữ liệu kết hợp giữa lưu trữ tài liệu Figma (`document storage`) và lưu trữ cục bộ của người dùng (`client storage`). Cho phép quản lý linh hoạt vị trí lưu trữ dựa trên các cờ phản hồi.

**Tham số:**
- `name: string` — Tên khóa lưu trữ.
- `inDocument?: RefOrNormal<boolean>` — Cờ hoặc `Ref` để lưu trong tài liệu Figma (mặc định là `false`).
- `inLocal?: RefOrNormal<boolean>` — Cờ hoặc `Ref` để lưu cục bộ trong client storage (mặc định là `false`).
- `defaultValue?: T` — Giá trị mặc định ban đầu.

**Trả về:**
- `item: ShallowRef<T | undefined>` — Tham chiếu phản hồi đến giá trị đã lưu.
- `isDocument: Ref<boolean>` — Cờ phản hồi cho biết có lưu trong tài liệu hay không.
- `isLocal: Ref<boolean>` — Cờ phản hồi cho biết có lưu cục bộ hay không.

## Ví dụ sử dụng

```typescript
import { ref } from 'vue'
import { useFigmaStorageMulti } from '@dxtmisha/figma-ref'

const inDocument = ref(false)
const inLocal = ref(true)

const { item: apiKey } = useFigmaStorageMulti<string>(
  'user-api-key',
  inDocument,
  inLocal,
  ''
)

// Khi apiKey thay đổi, giá trị sẽ được lưu tương ứng theo các cờ inDocument / inLocal
apiKey.value = 'sk-...'
```
