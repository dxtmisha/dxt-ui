The `Group` component is a structural container designed to group related content with support for headers, descriptions, and flexible layout options. It extends `Block` with a default `<div>` root tag, `<h4>` header level (`tagHeader`), and `'group'` area context.

`Group` provides a standardized way to organize thematic subsections within a page, card, or larger `Block`, automatically linking `aria-labelledby` and `aria-describedby` to rendered header and description elements while supporting icons, captions, and slot-based customization.

**Key features:**

- **Standardized Sub-Grouping:** Groups related content using a `<div>` root tag by default (configurable via `tag`)
- **Heading Hierarchy:** Renders `<h4>` for the header label by default (`tagHeader`), fitting neatly inside `Block` (`h3`) or `Section` (`h2`)
- **Full Block Capabilities:** Inherits `headline`, `label`, `caption`, `description`, leading `icon`, and all 6 slots (`#default`, `#headline`, `#label`, `#description`, `#caption`, `#trailing`)
- **Automatic ARIA & Area Context:** Synchronizes `aria-labelledby` and `aria-describedby` and propagates `'group'` as the default reactive `area` context

**Common use cases:**

- Subsections within a page or `Block`
- Grouping elements inside a card or modal
- Organizing complex forms into logical, titled segments
- Structuring content blocks with lower-level headings
