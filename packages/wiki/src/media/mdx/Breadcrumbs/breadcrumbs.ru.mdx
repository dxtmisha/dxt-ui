Компонент `Breadcrumbs` рендерит иерархический навигационный ориентир `<nav>` из элементов `BreadcrumbItem`, отображающий текущее положение пользователя в структуре приложения.

Он автоматически переводит последний элемент массива `list` в статическое состояние текущей страницы (`readonly` с `aria-current="page"`), сохраняя явные переопределения `readonly` или `disabled` на отдельных шагах, пробрасывая общие атрибуты `itemAttrs`, локализуя метку ориентира `<nav>` через `textBreadcrumb` и перенаправляя события клика.

**Ключевые особенности:**

- **Семантический ориентир `<nav>`:** Автоматически устанавливает локализованный `aria-label` (`'Breadcrumb'` по умолчанию или значение `textBreadcrumb`)
- **Декларативный список шагов:** Генерирует цепочку `BreadcrumbItem` из `list` и объединяет общие настройки `itemAttrs`
- **Автоматическое выделение текущей страницы:** По умолчанию делает последний шаг `readonly` (`<span aria-current="page">`), уважая явный `readonly` на любом элементе
- **Единые события и скелетон:** Перенаправляет события `click` и `clickLite` от активных шагов и синхронно включает `isSkeleton` для всей цепочки

<Source
    code={`
<template>
  <Breadcrumbs
    :list="[
      { label: 'Главная', icon: 'home', to: '/' },
      { label: 'Каталог', to: '/catalog' },
      { label: 'Рабочие станции' }
    ]"
  />
</template>
  `}
    language="html"
/>

> Используйте `itemAttrs`, чтобы задать единую иконку разделителя или направление для всех элементов навигационной цепочки.
