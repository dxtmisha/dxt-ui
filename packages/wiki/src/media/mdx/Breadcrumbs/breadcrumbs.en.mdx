The `Breadcrumbs` component renders a hierarchical `<nav>` landmark trail of `BreadcrumbItem` elements representing the user's current location within an application.

It automatically marks the final item in `list` as the non-interactive current page (`readonly` with `aria-current="page"`), while preserving explicit item-level `readonly` or `disabled` overrides, forwarding shared `itemAttrs` across all steps, localizing the `<nav>` landmark label via `textBreadcrumb`, and propagating item click events.

**Key features:**

- **Semantic Landmark:** Renders a `<nav>` element with a localized `aria-label` (`'Breadcrumb'` by default, customizable via `textBreadcrumb`)
- **Declarative Trail Rendering:** Builds `BreadcrumbItem` steps from `list` and merges shared `itemAttrs` across all items
- **Automatic Current-Page State:** Defaults the last item to `readonly` (`<span aria-current="page">`) while honoring explicit `readonly` flags on any step
- **Unified Click & Skeleton Support:** Forwards `click` and `clickLite` events from interactive steps and synchronizes `isSkeleton` across the trail

<Source
    code={`
<template>
  <Breadcrumbs
    :list="[
      { label: 'Home', icon: 'home', to: '/' },
      { label: 'Catalog', to: '/catalog' },
      { label: 'Workstations' }
    ]"
  />
</template>
  `}
    language="html"
/>

> Use `itemAttrs` to apply consistent separator icons or directional settings across every step in the trail.
