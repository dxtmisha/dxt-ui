The `AlertLink` component is a specialized inline link primitive designed for contextual navigation and lightweight actions inside status alerts, banners, and feedback blocks.

It integrates click event tracking, optional visual bullet separators (`divider`) between adjacent links, keyboard accessibility (`tabindex="0"` and `role="button"` when used as an action without `href`/`to`), and text or slot content rendering.

**Key features:**

- **Contextual Inline Links:** Clean inline anchor rendering tailored for alert and notification containers
- **Adjacent Link Dividers:** Optional visual separator (`•`) rendered automatically between sibling links when `divider` is enabled
- **Flexible Navigation & Actions:** Supports native `href`, router `to` navigation, and interactive `@click` / `@click-lite` events with `value`, `index`, and `detail` payloads
- **Accessible by Default:** Preserves native anchor semantics for `href`/`to` links and adds keyboard focusability (`tabindex="0"`, `role="button"`, `Enter` activation) for action links without `href`

**Common use cases:**

- Inline help or documentation links inside informational, warning, error, or success alerts
- Grouped action links placed beneath an alert description
- Clickable retry, details, or undo triggers inside status notices
