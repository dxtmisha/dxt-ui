Компонент `TableFlex` — адаптивная таблица данных на основе flexbox, рендерящая семантическую иерархию `<div role="table">` без нативных тегов `<table>` и `<colgroup>`. Она координирует колонки, шапку, подвал, ленивый рендеринг строк, сортировку, поиск, пагинацию, выделение и липкое позиционирование.

**Основные возможности:**

- **Флекс-семантика таблицы:** Рендерит `<div role="table">` с блочными секциями подписи, шапки, строк и подвала (без нативных `<table>`/`<colgroup>`)
- **Шапка, подвал и подпись:** Поддержка многострочных `header` и `foot` (с флагом `isFoot` и слотами `#foot-<column>` / `#foot-default`), а также подписи `caption` сверху или снизу (`captionBottom`)
- **Ленивый рендеринг строк:** Виртуализирует строки данных через `lazy` (включен по умолчанию) и `defaultHeight`, сохраняя немедленный рендеринг шапки и подвала
- **Встроенный конвейер данных:** Локальный поиск (`search`, `searchColumns`, `searchOptions`), 3-состоятельная сортировка колонок (`sort`, `sortDir`, `sortFunction`, `@sort`) и клиентская пагинация (`page`, `rows`)
- **Липкие элементы:** Липкая шапка (`headerTop`), зафиксированные левые столбцы (`stickyLeft`), верхние строки (`stickyTop`) и нижний горизонтальный скроллбар (`stickyScrollBottom`)
- **Гибкая кастомизация:** Выбор строк (`selected`, `keyValue`), режим скелетона (`isSkeleton`), проброс атрибутов (`tableItemAttrs`, `tableItemColumnAttrs`, `tableRecordAttrs`, `tableRowAttrs`) и слоты

**Типовые сценарии использования:**

- Адаптивные таблицы данных для десктопных и мобильных экранов
- Большие прокручиваемые наборы данных с ленивым рендерингом строк
- Интерактивные таблицы с сортировкой, подсветкой поиска, пагинацией и кастомными слотами колонок

<script setup>
const columns = ['id', 'name', 'role', 'status']
const header = { id: 'ID', name: { label: 'Имя', showSort: true }, role: 'Должность', status: 'Статус' }
const foot = { id: 'Итого', name: '2 пользователя', role: '-', status: 'Активен' }
const list = [
  { id: '1', name: 'Алиса', role: 'Разработчик', status: 'Активен' },
  { id: '2', name: 'Боб', role: 'Дизайнер', status: 'В ожидании' }
]
</script>

<template>
  <TableFlex
    caption="Список команды"
    :columns="columns"
    :header="header"
    :foot="foot"
    :list="list"
    :headerTop="true"
    :defaultHeight="48"
    keyValue="id"
  />
</template>
  `}
    language="html"

> TableFlex объединяет оркестрацию табличных данных с современным флекс-макетом, предоставляя ARIA-семантику таблицы, ленивую загрузку строк, сортировку, поиск, пагинацию и гибкую систему слотов.
