The `TableFlex` component is a responsive flexbox-based data table that renders a semantic `<div role="table">` hierarchy without native `<table>` or `<colgroup>` elements. It orchestrates column definitions, headers, footers, lazy-rendered rows, sorting, searching, pagination, selection, and sticky positioning.

**Key features:**

- **Flexbox Table Semantics:** Renders `<div role="table">` with `<div>`-based caption, header, items, and footer regions (zero native `<table>`/`<colgroup>` tags)
- **Header, Footer & Caption Support:** Multi-row `header` and `foot` (with `isFoot` and `#foot-<column>` / `#foot-default` slots) plus top or bottom `caption` (`captionBottom`)
- **Viewport Lazy Rendering:** Virtualizes data rows via `lazy` (enabled by default) and `defaultHeight`, while keeping header and footer rows eagerly rendered
- **Built-in Data Pipeline:** Local filtering (`search`, `searchColumns`, `searchOptions`), 3-state column sorting (`sort`, `sortDir`, `sortFunction`, `@sort`), and client-side pagination (`page`, `rows`)
- **Sticky Ergonomics:** Sticky headers (`headerTop`), sticky left columns (`stickyLeft`), sticky top rows (`stickyTop`), and sticky bottom horizontal scrollbar (`stickyScrollBottom`)
- **Rich Customization:** Row selection (`selected`, `keyValue`), skeleton loading (`isSkeleton`), attribute forwarding (`tableItemAttrs`, `tableItemColumnAttrs`, `tableRecordAttrs`, `tableRowAttrs`), and granular slots

**Common use cases:**

- Responsive data tables that adapt cleanly across desktop and mobile viewports
- Large scrollable datasets benefiting from viewport-based lazy row rendering
- Interactive management grids with sorting, search highlighting, pagination, and custom column slots
