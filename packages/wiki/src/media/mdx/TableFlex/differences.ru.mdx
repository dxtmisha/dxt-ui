## Разница между Table и TableFlex

Оба компонента предоставляют единый интерфейс для работы со структурированными данными (`columns`, `header`, `list`, `sort`, `search`), но построены на разной технологической базе:

### Table

**Table** — классическая таблица на базе семантических тегов HTML (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`).

**Особенности и плюсы:**
- **Автоматический расчет ширины колонок**: Браузер самостоятельно выравнивает ширину столбцов во всех строках по самому длинному содержимому.
- **Нативная табличная семантика (A11y)**: Полная встроенная поддержка табличной структурой скринридерами из коробки.
- **Поддержка нативного `rowspan`**: Объединение ячеек по вертикали между несколькими строками работает нативно на уровне табличного движка.

**Ограничения:**
- **Ограниченная адаптивность**: Классическую сетку `<table>` сложно адаптировать под мобильные устройства (например, превратить строки в мобильные карточки).
- **Высокая нагрузка при виртуализации**: Динамическая вставка и удаление строк из `<table>` вызывают тяжелый пересчет макета браузера (reflow).

**Типичные сценарии:**
- Классические аналитические таблицы и отчеты
- Таблицы с динамической шириной колонок по тексту
- Таблицы с вертикальным объединением ячеек (`rowspan`)
- Десктопные интерфейсы без необходимости мобильной трансформации

### TableFlex

**TableFlex** — адаптивная флекс-таблица на базе блочных элементов (`<div>`) с использованием макета Flexbox (`display: flex`).

**Особенности и плюсы:**
- **Высокая гибкость и мобильная адаптивность**: Элементы легко перестраиваются под мобильные устройства и адаптивные брейкпоинты (вплоть до превращения строк в карточки).
- **Поддержка виртуального скролла и отложенной загрузки**: Эффективный рендеринг и виртуализация огромных наборов данных с помощью `TableFlexRecordLazy` (`lazy`).
- **Полный контроль над пропорциями колонок**: Точная настройка размеров колонок через `flex-grow`, `flex-basis` и `min-width: 0`.
- **Простое позиционирование зафиксированных колонок (`stickyLeft`)**: Легкая фиксация столбцов без табличных ограничений.

**Ограничения:**
- **Независимый расчет ширины ячеек**: Каждая строка является отдельным flex-контейнером. Чтобы колонки во всех строках стояли ровно, требуется задавать `min-width: 0` или явные пропорции `flex-grow`.
- **Отсутствие нативного `rowspan`**: Вертикальное объединение ячеек не поддерживается нативно из-за изолированности flex-строк.

**Типичные сценарии:**
- Списки и таблицы, адаптируемые под мобильные экраны
- Высоконагруженные таблицы с виртуализацией большого количества строк
- Таблицы с точным контролем пропорций столбцов через CSS

### Выбор компонента

- **Используйте Table**, когда нужна классическая таблица с авто-выравниванием колонок по содержимому и поддержкой `rowspan` на десктопе.
- **Используйте TableFlex**, когда нужна адаптивность под мобильные устройства, виртуальный скролл или ленивая загрузка большого объема данных.
