### `close`

Event fires when attempting to close the list after navigation has reached the root level.

**When it fires:**
- Pressing the **Escape** key when keyboard control is active
- Pressing the **ArrowLeft** key when there are no open parent submenus or groups

**Parameters:**
- None (`[]`)

<Source
    code={`
<List
  control
  :list="items"
  @close="onClose"
/>
  `}
    language="html"
