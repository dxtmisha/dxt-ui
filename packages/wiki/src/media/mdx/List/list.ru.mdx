Компонент для создания интерактивных списков с поддержкой иерархических данных, клавиатурной навигации и функциональности поиска.

List управляет отображением структурированных данных с возможностью навигации, выбора элементов и взаимодействия через клавиатуру и мышь. Компонент поддерживает различные типы элементов (обычные элементы, группы, меню, разделители, отступы, подзаголовки, HTML-контент), автоматически обрабатывает сложные иерархические структуры и предоставляет интуитивную навигацию. Встроенная система поиска работает в реальном времени с выделением совпадений по всей иерархии данных.

**Основные возможности:**

- Различные типы элементов (`item`, `group`, `menu`, `line`, `space`, `subtitle`, `html`)
- Иерархическая структура с вложенными группами и меню
- Полная клавиатурная навигация (`ArrowUp`/`ArrowDown`, `Enter`, `Space`, `Home`/`End`, `Escape`)
- Встроенный поиск в реальном времени с подсветкой совпадений и `filterMode`
- Привязка выбранных и сфокусированных элементов через `selected` и `focus`
- Облегчённый режим для больших списков (`lite` и `liteThreshold`)
- Ленивый рендеринг элементов с отслеживанием видимости и кэшированием высоты (`lazy`, `lazyMargin`, `lazyCacheHeight`)
- Настройка осей отображения (`x`/`y`), разделителей (`divider`) и стиля выбора (`selectionStyle`)
- События клика (`click`, `clickLite`) и закрытия (`close`)

**Типичные сценарии использования:**

- Навигационные меню и списки опций
- Выпадающие списки с иерархической структурой
- Каталоги товаров и категорий
- Списки настроек с группировкой
- Контекстные меню с подменю
- Фильтры с одиночным или множественным выбором

<script setup>
import { ref } from 'vue'

const selected = ref(['item2'])

const listData = ref([
  { label: 'Первый элемент', value: 'item1' },
  { label: 'Второй элемент', value: 'item2' },
  { type: 'line', value: 'line1' },
  { type: 'subtitle', value: 'sub1', label: 'Группа элементов' },
  {
    label: 'Группа с подменю',
    index: 'group1',
    type: 'group',
    value: [
      { label: 'Вложенный элемент 1', value: 'nested1' },
      { label: 'Вложенный элемент 2', value: 'nested2' }
    ]
  }
])

const handleClick = (options) => {
  if (options?.value) {
    selected.value = [String(options.value)]
  }
}
</script>

<template>
  <List
    :selected="selected"
    :list="listData"
    highlight="элемент"
    @click-lite="handleClick"
  />
</template>
  `}

> List объединяет доступную клавиатурную навигацию, фильтрацию в реальном времени и иерархическую композицию списков.
