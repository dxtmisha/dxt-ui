The `Area` component dynamically selects and renders a named slot matching the active area context provided by an ancestor or the `areaDefault` fallback property.

It retrieves the nearest provided area value via injection (`getAreaValue`). When a named slot matching the resolved area exists as an own function property on the slots object, `Area` renders that slot; otherwise it safely falls back to the `default` slot without introducing an extra wrapper DOM element.

**Key features:**

- **Context-Driven Slot Selection:** Automatically selects a named slot matching the nearest injected area value
- **Default Fallback (`areaDefault`):** Supports standalone usage or fallback resolution when no ancestor provides an area
- **Nested Context Inheritance:** Seamlessly inherits outer area values when closer providers resolve to `undefined`
- **Prototype-Safe Resolution:** Verifies own slot functions via `Object.hasOwn` and `isFunction`, preventing prototype-key lookups

**Common use cases:**

- Adapting shared content blocks across header, sidebar, content, and footer layout zones
- Building context-aware extension slots inside composite containers
- Rendering conditional layout regions without extra wrapper elements
