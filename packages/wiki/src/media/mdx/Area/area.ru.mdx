Компонент `Area` динамически выбирает и рендерит именованный слот, соответствующий активному контексту области из родительского провайдера или свойству `areaDefault`.

Он получает ближайшее внедрённое значение области через `getAreaValue`. Если на объекте слотов существует собственная функция-слот с таким именем, `Area` рендерит её; в противном случае безопасно откатывается на слот `default` без добавления лишней DOM-обёртки.

**Основные возможности:**

- **Контекстный выбор слота:** Автоматически выбирает именованный слот по ближайшему внедрённому значению области
- **Резервное значение (`areaDefault`):** Поддерживает автономное использование или fallback при отсутствии провайдера
- **Наследование вложенных областей:** Наследует значение внешнего провайдера, если более близкий возвращает `undefined`
- **Безопасная проверка слотов:** Проверяет наличие собственной функции через `Object.hasOwn` и `isFunction`, исключая обращение к ключам прототипа

**Типовые сценарии использования:**

- Адаптация общих блоков контента для шапки, боковой панели, основной зоны и подвала
- Построение контекстных слотов расширения внутри составных контейнеров
- Условный рендер областей макета без дополнительных DOM-узлов
