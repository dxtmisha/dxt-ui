The `Cell` component is a versatile container designed to display structured content rows with hierarchical text (label, caption, description), media elements, trailing accessories, and integrated interactive states.

It acts as the foundational building block for lists, navigation items, settings panels, menus, and data cards across the design system. The component pairs composable content areas with built-in Ripple tactile feedback, progressive loading indicators, and loading skeleton adapters.

**Key features:**

- **Structured Text Hierarchy:** Dedicated typography areas for primary label, supplementary caption, and extended description
- **Interactive State Machine:** Native handling of selected, disabled, readonly, focus, dynamic, and dynamicHover states
- **Flexible Media Accessories:** First-class support for leading icon, iconTop alignment, and trailing accessories
- **Responsive Skeletons & Progress:** Seamless integration with skeleton placeholder lines and circular/bar progress indicators
- **Semantic HTML & Accessibility:** Automatic ARIA role calculation (`button`, `listitem`, etc.) with keyboard interaction and custom tag wrapping
- **Composable Slot Architecture:** Fine-grained template slots for default, label, caption, description, trailing, and expandable body

**Common use cases:**

- List rows in navigation menus, drawer sidebars, and action sheets
- Settings rows and configuration toggles in preference dialogs
- User profile cards, contact entries, and directory listings
- Selectable option items in dropdown menus and search pickers
