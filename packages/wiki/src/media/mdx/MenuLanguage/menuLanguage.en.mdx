A specialized menu for selecting languages with automatic flag and localized name loading.

`MenuLanguage` extends `MenuCountry` and `Menu` specifically for language selection. It leverages `GeoFlagRef.getNationalLanguage` to populate items with national language names, localized language names, associated country flags, and optional international dialing codes (`showPhoneCode`). It supports all standard `Menu` features, including `Window`-based popups, embedded rendering, search, custom slots, and exposed navigation controls.

**Key features:**

- **Automatic Language List:** Populates language flags, localized labels, and native language descriptions via `GeoFlagRef`
- **Code Filtering:** Restricts available languages via the `list` prop (ISO 639-1 / locale or ISO 3166-1 alpha-2 codes)
- **Native & Localized Names:** Displays localized language labels alongside native language names (`description`) and supports switching display language via the `language` prop
- **Built-in Search & Highlighting:** Supports direct `showSearch`, `filterMode`, and `highlightLengthStart` props with searchable localized and native names, codes, and optional phone code captions (`showPhoneCode`)
- **Menu Capabilities:** Inherits `Window` popup positioning, `disableFocusReturn`, `v-model:selected` / `v-model:model-selected`, `menuAttrs` customization, keyboard navigation, and `expose` API

**Common use cases:**

- Language selection dropdowns in headers and navigation bars
- Localization settings in user profiles or application preferences
- Multilingual interface and content switchers
