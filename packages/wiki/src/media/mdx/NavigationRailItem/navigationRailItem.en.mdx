Compact navigation list item component designed specifically for vertical Navigation Rail bars, sidebars, and mini navigation drawers.

NavigationRailItem is tailored for vertical rail navigation interfaces. It features single leading icon support, label rendering, badge integration, divider support, ripple click effects, and progress/skeleton loading states.

**Key Features:**

- Compact vertical layout for Navigation Rail bars
- Single leading icon with customizable alignment
- Label and badge integration
- Interactive states (focus, selected, disabled, readonly)
- Divider support for section separation
- Visual ripple click feedback
- Support for links (href / Vue Router) and button/div/span tags
- Leading and body slots for custom layout extension

**Typical Use Cases:**

- Navigation Rail items in desktop and tablet apps
- Mini sidebar navigation items
- Vertical action bar buttons
