The `NavigationRailItem` component is a compact navigation item designed for vertical navigation rails, sidebars, and mini navigation drawers.

It combines leading icon rendering, label content, badge indicators, divider markers, progress loading, skeleton placeholders, ripple feedback, and ARIA accessibility attributes into a single interactive element.

**Key features:**

- **Compact Rail Layout:** Automatic layout grouping for leading icons, labels, and overlapping or inline badges
- **Interactive States:** Built-in support for `selected`, `focus`, `open`, `selectedChild`, `disabled`, `readonly`, and `divider` states
- **Loading & Skeletons:** Integrated circular progress indicator via `loading` and zero-duplication skeleton rendering via `isSkeleton`
- **Polymorphic Tag & Links:** Supports `button`, `a`, `span`, `li`, and `div` tags as well as `href` and Vue Router `to` navigation
- **Slots & Events:** Provides `leading`, `default`, and `body` slots, emits `click` and `clickLite`, and exposes `getValue` and `getDetail`

**Common use cases:**

- Vertical navigation rail items in desktop and tablet applications
- Compact sidebar and mini-drawer navigation links
- Action items with notification badges and loading states
