Компактный элемент навигационного списка, предназначенный для использования в вертикальных панелях навигации (Navigation Rail), сайдбарах и мини-меню.

NavigationRailItem адаптирован для вертикальных интерфейсов навигации. Компонент поддерживает одну ведущую иконку, метку (label), значки (badge), разделители (divider), эффект пульсации при клике и состояния загрузки (скелетон и прогресс).

**Основные возможности:**

- Компактный вертикальный макет для панелей Navigation Rail
- Одна ведущая иконка с настраиваемым выравниванием
- Встроенная интеграция метки (label) и значка (badge)
- Интерактивные состояния (фокус, выбранный, отключенный, только чтение)
- Поддержка разделителя (divider) для группировки секций
- Визуальный эффект пульсации (ripple) при клике
- Поддержка ссылок (href / Vue Router) и тегов button, a, div, span
- Слоты leading и body для расширения разметки

**Типичные сценарии использования:**

- Элементы вертикальной навигационной панели Navigation Rail
- Компактное боковое меню (Mini-sidebar navigation)
- Вертикальные панели быстрых действий
