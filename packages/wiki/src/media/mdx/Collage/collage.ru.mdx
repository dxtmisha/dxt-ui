Адаптивный медиаконтейнер и макетный движок для коллажей, галерей и сеток в стиле Bento.

Collage координирует расположение множества медиаэлементов (CollageItem) на основе CSS Grid с поддержкой различных режимов внешнего вида (appearance), настраиваемого количества колонок, адаптивных размеров ячеек и интерактивного управления выбором элементов. Компонент автоматически адаптируется под разнообразные визуальные структуры, обеспечивая плотную компоновку, ритмичное чередование или плавную плиточную кладку (masonry).

**Основные возможности:**

- Различные режимы макета (`standard`, `quilted`, `woven`, `masonryHorizontal` и `masonryVertical`)
- Настраиваемое количество колонок сетки от 1 до 12 (`columns`)
- Настройка базового размера ячейки с автоматическим расчетом (`cellSize`)
- Реактивное отслеживание выбора с поддержкой двустороннего связывания (`selected` / `v-model:selected`)
- Единая передача атрибутов дочерним элементам коллажа (`collageItemAttrs`)
- Гибкая передача данных через массив `images` с настройкой ключей значений и меток (`keyValue`, `keyLabel`)
- Делегирование событий клика с передачей данных элемента
- Метод динамического пересчета макета (`update()`), доступный через API компонента
- Слот по умолчанию для рендеринга произвольных элементов или смешанного содержимого

**Типичные сценарии использования:**

- Динамичные фотогалереи и портфолио
- Раскладки в стиле Bento для презентации возможностей и карточек дашбордов
- Медиа-пикеры с поддержкой множественного выбора элементов
- Плиточная мозаика и вертикальные ленты в стиле Pinterest
- Компактные баннеры и промо-коллажи с ритмичным чередованием плиток
