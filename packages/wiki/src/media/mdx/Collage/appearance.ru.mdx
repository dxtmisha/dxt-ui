## Режимы макета (appearance)

Свойство `appearance` определяет способ позиционирования и распределения элементов в сетке коллажа:

- `standard` — Стандартная раскладка CSS Grid с равномерным распределением колонок (`repeat(columns, minmax(cellSize, 1fr))`). Элементы занимают колонки и строки в соответствии со своим свойством `span` (например, `wide`, `tall`, `large`, `banner`, `huge`).
- `quilted` — Плотная упаковка сетки (`grid-auto-flow: dense`). Пространства, остающиеся после крупных элементов, автоматически заполняются последующими меньшими элементами, создавая цельную структуру в стиле Bento.
- `woven` — Ритмичная сетка с чередованием, где каждый второй элемент (`(row + col) % 2 === 1`) становится компактным и центрируется по вертикали (`align-self: center`), создавая эффект плетеного узора.
- `masonryHorizontal` — Динамическая горизонтальная кладка. Элементы в каждой строке рассчитывают пропорции сторон и автоматически увеличиваются через внутренний коэффициент расширения (`sys-item-grow`), полностью заполняя ширину строки без пустых промежутков.
- `masonryVertical` — Вертикальная плиточная кладка в стиле Pinterest. Колонки заполняются вертикально, а высота элементов в сетке динамически адаптируется под высоту их содержимого.

<template>
  <!-- Стандартная Bento-сетка -->
  <Collage
    :images="images"
    columns="4"
    appearance="standard"

  <Collage
    :images="images"
    columns="4"

  />

  <!-- Горизонтальная кладка с автоматическим заполнением строк -->
  <Collage

    columns="4"
    appearance="masonryHorizontal"
  />
</template>
