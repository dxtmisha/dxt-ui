Компонент для создания мобильно-оптимизированных панелей действий, выдвигающихся снизу экрана с плавной анимацией.

ActionSheet представляет собой специализированную обертку над компонентом Window с предустановленным адаптивным режимом `actionSheet`. Компонент автоматически позиционируется внизу экрана и выдвигается вверх при открытии, следуя паттернам мобильных интерфейсов iOS и Material Design. Поддерживает жесты свайпа для закрытия, интеграцию с компонентом Bars для заголовка и автоматическое управление фокусом.

**Основные возможности:**

- **Мобильная шторка и боковая панель:** Построена на базе `Window` с адаптивным позиционированием и плавной анимацией выдвижения
- **Закрытие свайпом (`touchClose`):** Поддержка touch-жестов с декоративным индикатором перетаскивания (`aria-hidden="true"`)
- **Двустороннее управление:** Синхронизация состояния через `v-model:open`, `v-model:modelOpen` или методы `expose`
- **Интеграция Bars и Actions:** Встроенная шапка `Bars` (`barsLabel`, `barsDescription`, `barsList`, `barsBackHide`) и футер `Actions` (`actionsList`, `actionsSecondary`) с автоматической связью ARIA
- **Гибкие слоты и настройка Window:** Поддержка слотов `#control`, `#title`, `#header`, `#default`, `#footer` и проброс `windowAttrs` (`persistent`, `closeButton`, `adaptive`)
- **Доступность и управление фокусом:** Захват фокуса, закрытие по `Escape` и управление возвратом фокуса (`disableFocusReturn`)

**Типичные сценарии использования:**

- Меню действий для мобильных приложений
- Списки опций и выборов
- Формы и фильтры на мобильных устройствах
- Контекстные меню для touch-интерфейсов
- Подтверждения и уведомления

<script setup>
import { ref } from 'vue'

const isOpen = ref(false)

const handleAction = (action) => {
  console.log('Выбрано действие:', action)
  isOpen.value = false
}
</script>

<template>
  <button @click="isOpen = true">Открыть действия</button>

  <ActionSheet
    v-model:open="isOpen"
    :touchClose="true"
  >
    <template #title>
      <h3>Выберите действие</h3>
    </template>

    <template #default>
      <div class="action-list">
        <button @click="handleAction('share')">Поделиться</button>
        <button @click="handleAction('copy')">Копировать ссылку</button>
        <button @click="handleAction('download')">Скачать</button>
      </div>
    </template>

    <template #footer="{ classesWindow }">
      <button :class="classesWindow.close">Отмена</button>
    </template>
  </ActionSheet>
</template>
  `}
    language="html"
/>

> ActionSheet объединяет возможности Modal, Bars и Actions с закрытием по свайпу вниз для удобных мобильных панелей действий.
