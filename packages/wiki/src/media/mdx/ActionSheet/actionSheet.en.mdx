Component for creating mobile-optimized action panels that slide up from the bottom of the screen with smooth animation.

ActionSheet is a specialized wrapper over the Window component with a preset `actionSheet` adaptive mode. The component automatically positions itself at the bottom of the screen and slides up when opened, following iOS and Material Design mobile interface patterns. Supports swipe gestures for closing, integration with the Bars component for the header, and automatic focus management.

**Key features:**

- **Mobile-Optimized Drawer & Bottom Sheet:** Built on `Window` with adaptive sheet positioning and smooth slide animation
- **Swipe-Down Dismissal (`touchClose`):** Touch gesture support with an accessible decorative drag handle (`aria-hidden="true"`)
- **Two-Way State Control:** Synchronized state via `v-model:open`, `v-model:modelOpen`, or exposed methods
- **Integrated Bars & Actions:** Built-in `Bars` header (`barsLabel`, `barsDescription`, `barsList`, `barsBackHide`) and `Actions` footer (`actionsList`, `actionsSecondary`) with automatic ARIA linkage
- **Flexible Slots & Window Configuration:** Supports `#control`, `#title`, `#header`, `#default`, and `#footer` slots plus full `windowAttrs` forwarding (`persistent`, `closeButton`, `adaptive`)
- **Accessibility & Focus Management:** Focus trapping, `Escape` dismissal, and `disableFocusReturn` support

**Common use cases:**

- Action menus for mobile applications
- Option and selection lists
- Forms and filters on mobile devices
- Context menus for touch interfaces
- Confirmations and notifications

        <button @click="handleAction('download')">Download</button>
      </div>
    </template>

    <template #footer="{ classesWindow }">
      <button :class="classesWindow.close">Cancel</button>
    </template>
  </ActionSheet>
</template>
