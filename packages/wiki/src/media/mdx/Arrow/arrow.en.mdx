The `Arrow` component renders a contextual directional pointer (callout triangle) attached to a floating container edge such as a tooltip, popover, or menu.

It supports both explicit static placement (`top`, `bottom`, `left`, `right`) and automatic direction & axis offset calculation relative to a target element (`elementTarget`), while automatically inheriting the parent container's background color, border width, border color, and border radius.

**Key features:**

- **Automatic & Static Positioning:** Supports explicit placement on any side (`top`, `bottom`, `left`, `right`) or smart `auto` detection towards the target
- **Flexible Target Binding:** Accepts either a CSS selector string or a direct `HTMLElement` reference via `elementTarget`
- **Seamless Parent Surface Inheritance:** Automatically reads parent background, border, and corner radius to render continuous borders without visual seams (`data-arrow="border"`)
- **Programmatic Synchronization:** Exposes `update()` to recalculate arrow position and shift after manual layout changes
- **Scroll & Resize Tracking:** Automatically re-evaluates placement during window resize and scroll events when `position="auto"` is active

**Common use cases:**

- Callout pointers inside tooltips, popovers, and dropdown menus
- Contextual onboarding hints and guided tours pointing to UI controls
- Floating helper badges anchored dynamically to movable or scrollable targets
