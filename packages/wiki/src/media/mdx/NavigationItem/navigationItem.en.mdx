The `NavigationItem` component is a specialized list item built for application navigation menus, sidebars, drawers, and top navigation bars.

Extending the core `ListItem` constructor, it preserves all layout slots, icon and badge integrations, selection styles, search highlighting, lazy rendering, and interactive states while defaulting to an anchor (`<a>`) element tailored for navigation structures.

**Key features:**

- **Inherited ListItem Architecture:** Full support for `leading`, `prefix`, `default`, `caption`, `suffix`, `description`, `body`, and `trailing` slots
- **Link & Tag Flexibility:** Defaults to `<a>` with `href` and router `to` support, or switches to `button`, `div`, `span`, or `li` via `tag`
- **Icons & Badges:** Leading and trailing icons with alignment (`iconAlign`, `iconTop`) plus numeric or dot status badges
- **Interactive & Selection States:** Supports `focus`, `open`, `selected`, `selectedChild`, `disabled`, `readonly`, and `selectionStyle` (`none`, `checkbox`, `radio`, `checkmark`)
- **Search, Loading & Lazy Rendering:** Includes `highlight` / `filterMode`, `loading` progress, `isSkeleton` placeholders, `lazy` visibility rendering, and ripple feedback

**Common use cases:**

- Sidebar and navigation drawer links inside `NavigationList`
- Header navigation bar items and nested menu sections
- Selectable navigation entries with counters, descriptions, or shortcut suffixes
