Специализированный элемент списка, предназначенный для использования в навигационных меню, сайдбарах и шапках приложений.

NavigationItem является расширением компонента ListItem, адаптированным для навигационных структур. Он полностью наследует функциональность ListItem (поддержка меток, описаний, иконок, значков статуса, состояний выбора и эффекта пульсации) и предоставляет оптимизированную стилизацию для элементов навигации.

**Основные возможности:**

- Наследуемая функциональность и слоты от ListItem (префикс, суффикс, метка, описание, заголовок)
- Оптимизированная визуальная стилизация элементов навигационного меню
- Поддержка иконок с гибким позиционированием
- Интеграция значков (badges) для счетчиков уведомлений и индикаторов статуса
- Интерактивные состояния (фокус, выбранный, отключенный, только чтение)
- Эффект пульсации (ripple) при клике
- Поддержка навигации по ссылкам (Router/href) и тегов button, a, div

**Типичные сценарии использования:**

- Пункты бокового навигационного меню (Sidebar navigation)
- Ссылки и элементы верхнего меню (Header menu items)
- Элементы навигационных панелей и действий
