Specialized navigation list component for building sidebars, dropdown menus, and application top bars.

NavigationList extends the core List component for application navigation. It renders NavigationItem elements with hierarchical groups and sub-menus, keyboard navigation, real-time search with text highlighting, axis orientation, disabled protection, and lite/lazy performance modes.

**Key features:**

- Core list orchestration inherited from List with navigation item defaults
- Hierarchical data support with subtitles, groups, sub-menus, dividers, spaces, and custom slots
- Full keyboard navigation with arrow keys, Home/End, Enter, and Escape (`control`)
- Real-time search filtering (`showSearch`, `filterMode`) and text highlighting (`highlight`)
- Vertical and horizontal orientation axis (`axis`) with automatic section dividers (`divider`)
- Performance-optimized `lite` and viewport `lazy` modes with height caching
- Accessibility ARIA attributes including `role`, `aria-multiselectable`, and container `disabled` propagation

**Common use cases:**

- Primary sidebar navigation menus in web applications
- Navigation dropdown menus, searchable drawers, and section switchers
- Horizontal navigation strips and multi-level workspace menus

<template>

> **Tip:** Enable `control` when integrating `NavigationList` inside popups or custom focus containers to support full arrow-key navigation and `Escape` closing out of the box.
