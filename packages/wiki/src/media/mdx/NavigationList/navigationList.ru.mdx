Специализированный навигационный список для построения сайдбаров, выпадающих меню и навигационных панелей приложения.

NavigationList расширяет базовый компонент List и адаптирован для задач навигации. Он отображает элементы NavigationItem, поддерживает иерархическую структуру с группами и подменю, клавиатурное управление, поиск с подсветкой совпадений, смену оси ориентации, блокировку через `disabled` и режимы оптимизации `lite`/`lazy`.

**Основные возможности:**

- Наследование ядра List с навигационными значениями по умолчанию
- Иерархическая структура: подзаголовки, группы, вложенные меню, разделители, отступы и HTML-слоты
- Полноценная навигация с клавиатуры со стрелками, Home/End, Enter и Escape (`control`)
- Фильтрация списка (`showSearch`, `filterMode`) и подсветка текста в реальном времени (`highlight`)
- Вертикальная и горизонтальная ориентация (`axis`) с поддержкой разделителей (`divider`)
- Оптимизированные режимы `lite` и ленивого рендеринга `lazy` с кэшированием высоты
- Полная поддержка ARIA (`role`, `aria-multiselectable`, каскадное `aria-disabled` при `disabled`)

**Типичные сценарии использования:**

- Основное навигационное меню в боковой панели приложения
- Выпадающие навигационные меню и списки с поиском
- Горизонтальные панели переключения разделов

<Source
    code={`
<template>
  <NavigationList
    :selected="selected"
    :list="[
      { label: 'Панель управления', value: 'dashboard', icon: 'dashboard' },
      { label: 'Аналитика', value: 'analytics', icon: 'insights' },
      { label: 'Настройки', value: 'settings', icon: 'settings' }
    ]"
    @click-lite="(value) => selected = value.value"
  />
</template>
  `}
    language="html"
/>

> **Совет:** Включайте `control`, если используете `NavigationList` внутри меню или панелей с клавиатурным фокусом, чтобы автоматически работали стрелки, выбор по `Enter` и закрытие по `Escape`.
