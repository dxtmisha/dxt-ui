Компонент элемента медиа, предназначенный для коллажей, галерей и сеток в стиле Bento.

CollageItem объединяет отображение изображения, настройку кадрирования и позиционирования, интерактивное состояние выбора и встроенную панель подписи CollageBar. Компонент оптимизирован для работы в CSS Grid сетках и поддерживает предустановленные модификаторы охвата (wide, tall, large, banner, huge) для построения динамичных современных Bento-раскладок с фиксированными пропорциями сторон.

**Основные возможности:**

- Полноценная интеграция изображения с кадрированием, масштабированием и позиционированием (`coordinator`, `x`, `y`)
- Пресеты охвата для Bento-сетки: `wide` (2:1), `tall` (1:2), `large` (1:1), `banner` (3:1) и `huge` (3:2)
- Интерактивное состояние выбора (`selected`) с индикатором-галочкой и анимированным оверлеем
- Настраиваемая иконка выбора (`iconCheck`) и токены отступов позиционирования (`iconPaddingX`, `iconPaddingY`)
- Встроенная панель CollageBar для заголовков (`label`), описаний и кнопок действий
- Гибкий HTML-тег для элемента тела (по умолчанию `a`, настраивается на `div` и др.)
- Обработка событий клика с поддержкой маршрутизации и передачи данных
- Слоты для тела панели и замыкающих элементов

**Типичные сценарии использования:**

- Интерактивные фотоколлажи и элементы медиагалерей
- Bento-сетки дашбордов и карточки презентации функций
- Медиа-пикеры и галереи с возможностью множественного выбора
- Промо-блоки с оверлейными панелями действий
