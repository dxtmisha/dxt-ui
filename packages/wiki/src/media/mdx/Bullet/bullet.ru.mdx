Семантический компонент-контейнер `<ul>` для отображения чистых и структурированных маркированных списков.

Компонент `Bullet` поддерживает динамический рендеринг элементов из массива строк или чисел (`list`), передачу общих свойств и атрибутов дочерним элементам (`itemAttrs`), безопасный рендеринг HTML-разметки (`html`) с автоматическим добавлением классов `BulletItem` к тегам `<li>`, состояние загрузки скелетона без дублирования разметки (`isSkeleton`), а также произвольные дочерние элементы через слот по умолчанию.

**Основные возможности:**

- Автоматический рендеринг списка из массива строк или чисел (проп `list`, включая числовой `0`)
- Передача общих атрибутов и настроек дочерним элементам списка (проп `itemAttrs`)
- Безопасный рендеринг HTML-списков (проп `html`) с очисткой опасных тегов/атрибутов и внедрением системных классов в `<li>` с сохранением существующих пользовательских классов
- Состояние загрузки скелетона без дублирования шаблона (проп `isSkeleton`), автоматически передаваемое дочерним пунктам
- Слот по умолчанию (`#default`) для ручной компоновки дочерних элементов `BulletItem`

**Типичные сценарии использования:**

- Отображение маркированных списков характеристик, правил или ключевых показателей
- Вывод форматированных списков внутри карточек, модальных окон, уведомлений и секций документации
- Рендеринг HTML-списков из Markdown или CMS с сохранением единого визуального оформления
