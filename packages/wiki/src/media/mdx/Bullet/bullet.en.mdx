A semantic `<ul>` bullet list container component designed to present structured, clean bulleted lists.

The `Bullet` component supports rendering list items dynamically from a string or numeric array (`list`), forwarding shared properties and attributes to child items (`itemAttrs`), rendering sanitized HTML list content (`html`) with automatic injection of `BulletItem` classes onto `<li>` tags, zero-duplication skeleton loading (`isSkeleton`), or custom slot children.

**Key Features:**

- Automated list rendering from a string or number array (`list` prop, including numeric `0`)
- Forwarding shared attributes and settings to child list items (`itemAttrs` prop)
- Sanitized HTML list rendering (`html` prop), stripping unsafe tags/attributes and injecting design system classes into `<li>` elements while preserving existing custom classes
- Zero-duplication skeleton loading state (`isSkeleton` prop) forwarded automatically to child items
- Default slot (`#default`) to render custom `BulletItem` structures manually

**Typical Usage Scenarios:**

- Displaying bulleted lists of product features, validation rules, or key metrics
- Rendering formatted lists inside cards, dialogs, alerts, or documentation sections
- Rendering rich HTML lists from Markdown or CMS sources with uniform list styling
