### Содержимое HTML

Компонент `Bullet` поддерживает рендеринг HTML-строк списка с помощью свойства `html`.

При передаче `html` опасные исполняемые теги, встроенные обработчики событий и небезопасные URI-схемы удаляются, а каждый элемент `<li>` автоматически получает классы элемента списка дизайн-системы (с сохранением любых уже существующих классов на теге `<li>`).
