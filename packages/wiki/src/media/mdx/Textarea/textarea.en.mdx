The `Textarea` component is a multi-line text input field combining `Field` anatomy with the `TextareaAutosize` engine.

It provides automatic height adjustment, form validation, character counting, clear button behavior, helper and warning messages, icons, and full slot customization inside a single accessible form control.

**Key features:**

- **Automatic or Fixed Sizing:** Auto-grows with content via `autosize` (default `true`) or uses fixed `rows`, `cols`, and `wrap`
- **Form Validation & Warnings:** Supports `required`, `minlength`, `maxlength`, `validationCode`, `validationMessage`, `forceShowMessage`, and non-blocking `warning` / `warningMessage`
- **Integrated Field Anatomy:** Built-in `label`, `helperMessage`, character counter (`counterShow`, `maxlength`), clear action (`cancel`), and leading/trailing icons
- **Interactive States:** Full support for `disabled`, `readonly`, `loading`, and `isSkeleton`
- **Flexible Slots & Exposed API:** Supports `leading`, `trailing`, `prefix`, `suffix`, `caption`, and `label` slots alongside `setValue`, `clear`, `checkValidity`, `getValue`, and `getValidationMessage`

**Common use cases:**

- Comment, review, and feedback forms
- User biographies, notes, and product descriptions
- Multi-line address or support ticket inputs
