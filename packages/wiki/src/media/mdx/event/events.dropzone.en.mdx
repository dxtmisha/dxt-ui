### `drop`

Event fires when files are dropped into the dropzone area or selected via file picker dialog.

**Parameters:**
- `event: DropzoneEventParameters` — object containing selected or dropped files

**DropzoneEventParameters structure:**
- `files: FileList | undefined` — list of selected or dropped files

<Source
    code={`
<script setup>
const handleDrop = (event) => {
  console.log('Selected files:', event.files)
}
</script>

<template>
  <Dropzone @drop="handleDrop" />
</template>
  `}
    language="html"
/>
