Компонент `Skeleton` — это структурный контейнер состояния загрузки, который превращает реальную разметку интерфейса и дочерние компоненты в анимированные заглушки во время асинхронного получения данных.

Компонент реализует архитектуру без дублирования шаблонов (zero-duplication): вместо поддержки отдельных блоков с `v-if` / `v-else` разработчики оборачивают рабочую разметку в `Skeleton`, добавляют утилитарные классы (`*__text`, `*__background`, `*__border`) на HTML-элементы и передают свойство `isSkeleton` компонентам дизайн-системы. При включении `active` компонент передает состояние загрузки потомкам через механизм Vue `provide` / `inject`, управляет задержками появления и скрытия (`delay`, `delayHide`), мгновенно маскирует контент через `invisible` и автоматически обновляет атрибуты доступности `aria-busy` и `aria-live`.

**Основные возможности:**

- **Разметка без дублирования:** Превращает реальные DOM-элементы и типографику в пульсирующие заглушки без клонирования шаблонов
- **Автоматическая синхронизация потомков:** Передает статус загрузки через `provide` / `inject` вложенным контейнерам `Skeleton` и дочерним компонентам со свойством `isSkeleton`
- **Классы через слот по умолчанию:** Предоставляет все 9 CSS-классов заглушек (`classText`, `classBackground`, `classBorder` и др.) через параметры слота `default`
- **Гибкое управление таймингами:** Независимые таймеры `delay` и `delayHide` предотвращают визуальное мерцание при быстрых ответах сети
- **Мгновенная маскировка контента:** Свойство `invisible` скрывает исходное содержимое сразу при активации еще до истечения задержки `delay`
- **Встроенная доступность (ARIA):** Автоматически управляет атрибутами `aria-busy` и `aria-live="polite"` на корневом элементе

**Типовые сценарии использования:**

- Карточки товаров, профили пользователей и записи в ленте во время первичной загрузки данных
- Сложные формы и панели настроек, ожидающие асинхронной загрузки конфигурации
- Таблицы данных, списки и виджеты дашбордов при переключении фильтров
- Медиагалереи и блоки аватаров с сохранением геометрии для предотвращения сдвигов макета (CLS)

import { ref } from 'vue'
import { Skeleton, Button, Input } from '@dxtmisha/constructor'

const isLoading = ref(true)

  <Skeleton :active="isLoading" :delay="360">
    <template #default="{ classText, classTextVariant, classBackground }">
      <div class="profile-card">
        <div :class="['profile-card__avatar', classBackground]">
          <img src="/avatar.jpg" alt="Аватар пользователя" />
        </div>
        <h3 :class="classText">Алекс Морган</h3>
        <p :class="classTextVariant">Ведущий продуктовый дизайнер</p>
        <Input label="Отображаемое имя" is-skeleton :disabled="isLoading" />
        <Button label="Сохранить профиль" is-skeleton :disabled="isLoading" />
      </div>
    </template>
  </Skeleton>
</template>
  `}

> Skeleton устраняет дублирование шаблонов и предотвращает сдвиги верстки, напрямую трансформируя живую разметку и компоненты в доступные заглушки загрузки.
