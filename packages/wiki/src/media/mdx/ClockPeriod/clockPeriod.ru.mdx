Компонент для выбора и переключения между периодами времени AM (до полудня) и PM (после полудня) в 12-часовом формате.

`ClockPeriod` представляет собой компактный двухкнопочный переключатель между периодами AM и PM. Он может работать в автономном режиме, поддерживать двустороннюю привязку через `v-model` или автоматически вычислять активный период на основе 24-часового значения свойства `hour`. Компонент поддерживает вертикальную и горизонтальную ориентации, полноценную навигацию с клавиатуры с помощью стрелок и клавиш переключения, настройку подписей и состояния блокировки или только для чтения.

**Основные возможности:**

- **Выбор бинарного периода**: Переключение между периодами `'am'` и `'pm'`.
- **Двусторонняя привязка (`v-model`)**: Синхронизация активного периода с внешним состоянием.
- **Автоматическое определение по часу (`hour`)**: Передача числового значения часа (`0..23`) для автоматического расчёта (`0..11` = AM, `12..23` = PM).
- **Ориентация разметки (`orientation`)**: Отображение кнопок в вертикальном (`'vertical'`, по умолчанию) или горизонтальном (`'horizontal'`) расположении.
- **Клавиатурная навигация**: Поддержка клавиш `ArrowUp`/`ArrowLeft` (AM), `ArrowDown`/`ArrowRight` (PM) и `Space`/`Enter` для переключения.
- **Настройка подписей**: Изменение текста кнопок через свойства `textAm` и `textPm`.
- **Доступность**: Семантика `role="radiogroup"` и `role="radio"` с атрибутами `aria-checked`.
- **Интерактивные состояния**: Поддержка режимов `disabled` (отключено) и `readonly` (только для чтения).

**Типичные сценарии использования:**

- 12-часовые элементы выбора времени в паре с `ClockDial`.
- Формы планирования, будильники и бронирование времени.
- Интернационализированный ввод времени в 12-часовом формате.
