Interactive button component for triggering user actions, form submissions, and navigation workflows with built-in icons, progress indicators, skeleton loading, and accessibility.

Button provides a comprehensive solution for creating consistent, accessible action elements. It encapsulates full interaction state handling (focus, active, disabled, selected, readonly), polymorphic rendering as button, link (`a`), or custom element, and integrated progress indicators with seamless loading transitions.

**Key features:**

- **Visual Variants:** Full design system styling with `primary`, `secondary`, `outline`, and `text` modes alongside custom palettes
- **Icon Support:** Integrated leading and trailing icon positioning with Material Symbols and custom SVG assets
- **Progress & Loading:** Embedded circular progress indicators with automated `aria-disabled` and loading states
- **Polymorphic Container:** Seamless rendering as native `<button>`, navigation link (`<a>` with `href`/`to`), or custom tag
- **State Management:** Complete support for `focus`, `active`, `selected`, `disabled`, and `readonly` states
- **Skeleton Mode:** Zero-duplication skeleton loading placeholders via `isSkeleton` within `DesignSkeleton`
- **Adaptive Behavior:** Flexible viewport scaling options (`block`, `iconAlways`, `auto`) and container query responsiveness
- **Accessibility & ARIA:** Comprehensive keyboard navigation, focus management, and ARIA attribute orchestration

**Common use cases:**

- **Form Actions:** Primary submit and secondary reset actions within form layouts
- **Call-to-Action Elements:** High-prominence conversion and navigation buttons
- **Navigation Controls:** Links and router navigation with button appearance
- **Toolbar Actions:** Icon-only and compact buttons in application toolbars and headers
- **Asynchronous Workflows:** Buttons with interactive progress loaders for API requests
