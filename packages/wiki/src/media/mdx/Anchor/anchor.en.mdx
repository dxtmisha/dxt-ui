The `Anchor` component creates interactive anchor links with smooth scrolling, hash synchronization, and optional click-to-copy permalink feedback.

It automatically handles navigation clicks, updates the URL hash via the History API without reloading the page, auto-scrolls on mount when `location.hash` matches, and integrates with `Tooltip` and `Icon` for copy-to-clipboard mode.

**Key features:**

- **Smooth Scrolling:** Configurable offset (`shift`) and scroll alignment (`behavior`, `block`, `inline`)
- **Hash Auto-Navigation:** Automatically scrolls into view on mount when the URL hash matches the anchor `name`
- **Clipboard Copy Mode (`isCopy`):** Copies the full URL with hash to clipboard, swaps active icon, and opens a temporary tooltip
- **Keyboard Accessibility:** Supports `aria-current="page"` in navigation mode and `role="button"` with `Enter`/`Space` activation in copy mode
- **Hidden Scroll Targets (`hide`):** Creates invisible `aria-hidden="true"` anchor points reachable via `#hash` or exposed `go()`
- **Flexible Icons & Slots:** Supports string or object `IconValue` (`iconLink`, `iconTag`, `iconContentCopy`) and `#default` / `#tooltip` slots

**Common use cases:**

- Documentation section headings with copyable permalink icons
- In-page tables of contents and jump navigation
- Invisible scroll targets for programmatic `go()` navigation
