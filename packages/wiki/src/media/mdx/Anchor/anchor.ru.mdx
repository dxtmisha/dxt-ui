Компонент `Anchor` создаёт интерактивные якорные ссылки с плавной прокруткой, синхронизацией хэша URL и опциональным копированием постоянной ссылки в буфер обмена.

Компонент автоматически обрабатывает клики, обновляет хэш через History API без перезагрузки страницы, выполняет автопрокрутку при монтировании при совпадении `location.hash`, а в режиме копирования интегрируется с `Tooltip` и `Icon`.

**Основные возможности:**

- **Плавная прокрутка:** Настраиваемое смещение (`shift`) и параметры выравнивания (`behavior`, `block`, `inline`)
- **Автонавигация по хэшу:** Автоматический переход при загрузке страницы, если `location.hash` совпадает с `name`
- **Режим копирования (`isCopy`):** Копирование полной ссылки в буфер обмена, переключение активной иконки и временный тултип обратной связи
- **Клавиатурная доступность:** `aria-current="page"` в режиме навигации и `role="button"` с активацией по `Enter`/`Space` в режиме копирования
- **Скрытые цели (`hide`):** Невидимые якорные точки (`aria-hidden="true"`), доступные по `#hash` и через метод `go()`
- **Гибкие иконки и слоты:** Строковые и объектные `IconValue` (`iconLink`, `iconTag`, `iconContentCopy`), а также слоты `#default` и `#tooltip`

**Типовые сценарии использования:**

- Заголовки разделов документации с кнопкой копирования ссылки
- Оглавления и внутренняя навигация по длинным страницам
- Невидимые точки прокрутки для программной навигации через `go()`

<template>
  <!-- Обычный навигационный якорь -->
  <Anchor name="section-1" label="Перейти к разделу" />

  <Anchor name="section-2" label="Скопировать ссылку" is-copy />

  <Anchor name="section-3" hide />

  `}

> Anchor объединяет плавную навигацию по хэшу, копирование постоянных ссылок и доступные скрытые цели прокрутки в одном лёгком компоненте.
