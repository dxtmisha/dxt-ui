The `TextDescription` component is a lightweight text primitive for rendering descriptive copy, helper notes, and captions with dynamic HTML wrapper tag support.

It delegates rendering through `DescriptionInclude` with lazy instantiation, automatically omitting empty DOM output when neither the `description` prop nor the `description` slot contains content while preserving numeric `0`, custom `descriptionId`, and merged external attributes.

**Key features:**

- **Dynamic Wrapper Tag:** Configurable semantic HTML tag (`div`, `p`, `span`, `small`, `figcaption`, etc.) via `tag` (defaults to `div`)
- **Zero-Overhead Empty State:** Lazily skips `DescriptionInclude` allocation and renders nothing for empty or whitespace-only values
- **Slot & Prop Composition:** Supports text/numeric `description` values (including `0`) and rich markup via the `description` slot
- **Accessibility Ready:** Automatically generates deterministic element IDs or applies custom `descriptionId` for `aria-describedby` associations

**Common use cases:**

- Displaying helper text and secondary instructions next to form fields
- Presenting captions, footnotes, and metadata beneath headings or cards
- Rendering semantic paragraph descriptions with unified design-system typography
