Компонент `GridItem` представляет собой отдельный элемент (ячейку) внутри контейнера сетки `Grid`.

Он управляет количеством занимаемых элементом колонок с помощью свойства `base` (от `1` до `12`, по умолчанию `1`) и выравниванием элемента внутри ячейки по поперечной оси с помощью свойства `align`, автоматически объединяя внешние HTML-атрибуты и отображая вложенный контент через слот `default`.

**Основные возможности:**

- **Управление шириной в колонках:** Настраиваемый охват от `1` до `12` колонок через свойство `base`
- **Выравнивание в ячейке:** Выравнивание элемента по поперечной оси с помощью `align` (`center`, `top`, `bottom`, `stretch`, `baseline`, `start`, `end`)
- **Защита от переполнения:** Задаёт `min-width: 0`, предотвращая растягивание колонок сетки вложенным текстом или flex-элементами
- **Гибкое содержимое:** Отображает произвольную разметку и компоненты через слот `default` и пробрасывает внешние атрибуты

**Типовые сценарии использования:**

- Поля форм и карточки виджетов на дашбордах внутри `Grid`
- Асимметричные раскладки с комбинированной шириной колонок (например, `4` + `8` или `6` + `6`)
- Вертикальное центрирование или растягивание элементов разной высоты в одной строке сетки

<Source
    code={`
<template>
  <Grid>
    <!-- Два равных элемента по 6 колонок -->
    <GridItem base="6">Элемент 1</GridItem>
    <GridItem base="6">Элемент 2</GridItem>

    <!-- Выровненный элемент на 4 колонки -->
    <GridItem base="4" align="center">Выровненный элемент</GridItem>
    <GridItem base="8" align="stretch">Растянутый элемент</GridItem>
  </Grid>
</template>
  `}
    language="html"
/>

> GridItem обеспечивает декларативный контроль над шириной в колонках и выравниванием элементов внутри контейнера Grid без написания дополнительного CSS.
