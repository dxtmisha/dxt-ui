Individual item within a Grid component. Controls how many columns the element should occupy and how it aligns within the grid cell.

**Key Features:**

- Customizable column span (`base`: `1` to `12`)
- Configurable item alignment (`align`: `center`, `top`, `bottom`, `stretch`, `baseline`, `start`, `end`)
- Granular control over grid layout structure

<Source
    code={`
<script setup>
</script>

<template>
  <Grid>
    <!-- Two equal 6-column items -->
    <GridItem base="6">Item 1</GridItem>
    <GridItem base="6">Item 2</GridItem>

    <!-- Aligned 4-column item -->
    <GridItem base="4" align="center">Centered item</GridItem>
  </Grid>
</template>
  `}
    language="html"
/>

> GridItem allows for granular control over element sizing and alignment within a Grid container without custom CSS.
