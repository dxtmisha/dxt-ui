The table header cell component representing a `<th>` tag. Extends all capabilities of `TableItem` and adds accessible header `scope`, interactive 3-state column sorting, and built-in tooltip support directly inside the header cell.

**Key Features:**

- Extends `TableItem` properties and features (alignments, dividers, tag customization, sticky settings)
- Standard HTML header tag and semantic `scope` support (`tag` defaults to `th`; `scope`: `col`, `row`, `colgroup`, `rowgroup`)
- Interactive 3-state sorting (`showSort`, `sortColumn`, `sortDir`, `aria-sort`, `@sort` event)
- Built-in tooltip support triggered by an icon (`iconTooltip` or `help-circle` default)
- Slot for placing rich HTML or custom component content inside the tooltip (`tooltip` slot)
- Tooltip customization via `tooltipLabel`, `tooltipDescription`, and `tooltipAttrs`

> TableHeaderItem is perfect for headers that require explanatory text, helping users understand data columns without cluttering the main table view.
