Компонент ячейки заголовка таблицы, представляющий тег `<th>`. Расширяет все возможности `TableItem` и добавляет семантический атрибут `scope`, интерактивную 3-состоятельную сортировку колонок и встроенную поддержку всплывающих подсказок прямо в ячейке заголовка.

**Ключевые особенности:**

- Расширяет свойства и функции `TableItem` (выравнивание, разделители, настройка тегов, липкость)
- Поддержка стандартного тега заголовка и семантического `scope` (`tag` по умолчанию `th`; `scope`: `col`, `row`, `colgroup`, `rowgroup`)
- Интерактивная 3-состоятельная сортировка (`showSort`, `sortColumn`, `sortDir`, `aria-sort`, событие `@sort`)
- Встроенная поддержка всплывающих подсказок, запускаемая иконкой (`iconTooltip` или `help-circle` по умолчанию)
- Слот для размещения сложного HTML или пользовательского содержимого внутри всплывающей подсказки (слот `tooltip`)
- Настройка подсказки через свойства `tooltipLabel`, `tooltipDescription` и `tooltipAttrs`

<Source
    code={`
<script setup>
</script>

<template>
  <table>
    <thead>
      <tr>
        <!-- Сортируемая ячейка заголовка -->
        <TableHeaderItem
          label="Имя"
          index="name"
          scope="col"
          :showSort="true"
          sortColumn="name"
          sortDir="asc"
        />

        <!-- Заголовок со встроенной подсказкой -->
        <TableHeaderItem
          label="Заголовок с подсказкой"
          scope="col"
          tooltipLabel="Пояснение"
          tooltipDescription="Это объясняет назначение данной колонки."
        />
      </tr>
    </thead>
  </table>
</template>
  `}
    language="html"
/>

> TableHeaderItem идеально подходит для заголовков, требующих пояснительного текста, помогая пользователям понять столбцы данных без загромождения основного вида таблицы.
