A phone number input component combining automatic country dial code selection, dynamic phone masking, and built-in validation.

InputPhone integrates the Field wrapper, InputPhoneDialCode country selector, and Mask formatting engine into a single component. It automatically detects the country as the user types or loads a formatted number, switches the input mask accordingly, or restricts input to a local national format when `countryBlock` is enabled.

**Key features:**

- Automatic country detection by entered phone number prefix
- Built-in `InputPhoneDialCode` selector with searchable country list, flags, and dial codes
- Dynamic phone mask formatting with `Mask` (`maskAttrs`, `countryDefault`)
- Country lock mode via `countryBlock` for national-only phone input without selector
- Built-in pattern validation (`required`, `pattern`, `validationCode`, `validationMessage`, `forceShowMessage`)
- Two-way binding (`v-model`, `v-model:value`) and exposed programmatic API (`getValue`, `setValue`, `clear`, `checkValidity`, `getValidationMessage`)
- Full slot support (`leading`, `trailing`, `prefix`, `suffix`, `label`) and accessibility (`inputmode="tel"`, ARIA popup controls)

**Common use cases:**

- User registration, checkout, and profile contact forms
- International phone inputs with country search and dial code selector
- Region-locked phone inputs for single-country forms (`countryBlock`)
- Validated contact forms with custom error messages
