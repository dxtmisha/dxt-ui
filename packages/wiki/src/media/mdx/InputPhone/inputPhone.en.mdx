A phone number input component combining automatic country dial code selection, dynamic phone masking, and built-in validation.

InputPhone integrates the Field wrapper, InputPhoneDialCode country selector, and Mask formatting engine into a single component. It automatically detects the country as the user types or pastes a phone number, switches the input mask accordingly, supports selector locking (`countryReadonly`), or restricts input to a local national format when `countryBlock` is enabled.

**Key features:**

- Automatic country detection by entered or pasted phone number prefix (supports full-selection replacement and normalizing leading `+` + national `within` prefix such as `+8` to `+7`)
- Built-in `InputPhoneDialCode` selector with searchable country list, flags, and dial codes (supports `XK` Kosovo `+383` and the full ISO country dataset)
- Country lock modes: `countryBlock` (hides selector and switches to local format) and `countryReadonly` (locks selector while keeping flag and dial code visible; auto-locks for single-country lists)
- Dynamic phone mask formatting with `Mask` (`maskAttrs`, `countryDefault`)
- Built-in validation (`required`, `pattern`, `validationCode`, `validationMessage`, `forceShowMessage`) and non-blocking warning states (`warning`, `warningMessage`, `warningId`)
- Events (`input`, `inputLite`, `change`, `changeLite`, `focus`, `blur`), two-way binding (`v-model`, `v-model:value`), and exposed programmatic API (`getValue`, `setValue`, `clear`, `checkValidity`, `getValidationMessage`)
- Full slot support (`leading`, `trailing`, `prefix`, `suffix`, `label`) and accessibility (`inputmode="tel"`, ARIA popup controls)

**Common use cases:**

- User registration, checkout, and profile contact forms
- International phone inputs with country search and dial code selector
- Region-locked phone inputs for single-country forms (`countryBlock` or `countryReadonly`)
- Validated contact forms with custom error or non-blocking warning messages
