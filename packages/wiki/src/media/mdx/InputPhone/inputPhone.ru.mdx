Компонент ввода телефонного номера с автоматическим выбором кода страны, динамической маской и встроенной валидацией.

InputPhone объединяет обёртку Field, селектор кода страны InputPhoneDialCode и движок маскирования Mask в едином интерфейсе. Компонент автоматически определяет страну по введённым цифрам, применяет соответствующую телефонную маску или фиксирует ввод в национальном формате при включённом `countryBlock`.

**Основные возможности:**

- Автоматическое определение страны по введённому префиксу номера телефона
- Встроенный селектор `InputPhoneDialCode` с поиском по странам, флагами и телефонными кодами
- Динамическое форматирование маски через `Mask` (`maskAttrs`, `countryDefault`)
- Режим блокировки страны (`countryBlock`) для ввода локального номера без селектора кода
- Встроенная валидация (`required`, `pattern`, `validationCode`, `validationMessage`, `forceShowMessage`)
- Двусторонняя привязка (`v-model`, `v-model:value`) и программный API (`getValue`, `setValue`, `clear`, `checkValidity`, `getValidationMessage`)
- Поддержка слотов (`leading`, `trailing`, `prefix`, `suffix`, `label`) и доступность (`inputmode="tel"`, ARIA-атрибуты)

**Типичные сценарии использования:**

- Формы регистрации, оформления заказа и редактирования профиля
- Поля международного номера с поиском и выбором кода страны
- Региональные формы с фиксированной страной (`countryBlock`)
- Поля контактов с обязательной проверкой формата и пользовательскими ошибками
