Компонент `BulletItem` представляет отдельный семантический пункт `<li>` внутри маркированного списка.

Он формирует визуальный маркер (`•`) с логическим позиционированием `inset-inline-start: 0` для корректной работы в режимах LTR и RTL, поддерживает строковое и числовое содержимое через `description`, произвольную разметку через слоты `#description` и `#default`, привязку `descriptionId` и скелетон загрузки через `isSkeleton`.

**Ключевые особенности:**

- **Семантический элемент `<li>`:** Рендерит нативный пункт списка с логическим выравниванием маркера для LTR и RTL
- **Гибкая передача содержимого:** Поддерживает `description` (строка или число, включая `0`), слот `#description` и слот `#default`
- **Стабильный идентификатор описания:** Привязывает явный или автоматически сгенерированный `descriptionId`
- **Скелетон без дублирования разметки:** Автоматически включает текстовый плейсхолдер при `isSkeleton`

<Source
    code={`
<template>
  <ul>
    <BulletItem description="Первый пункт списка" />
    <BulletItem description-id="point-2">
      <template #description>Второй пункт через слот</template>
    </BulletItem>
  </ul>
</template>
  `}
    language="html"
/>

> BulletItem автоматически рендерится для каждого элемента массива `list` в компоненте `Bullet` либо используется напрямую внутри `<Bullet>` или `<ul>`.
