Специализированное меню для выбора стран с автоматической загрузкой флагов и локализованных названий.

`MenuCountry` расширяет компонент `Menu` для задач выбора страны. Он использует `GeoFlagRef` для автоматического заполнения списка стран с флагами, названиями и опциональными телефонными кодами (`showPhoneCode`). Поддерживаются все возможности `Menu`: всплывающие окна на базе `Window`, встроенный режим, поиск, слоты и программное управление через `expose`.

**Основные возможности:**

- **Автоматический список стран:** Загрузка флагов и названий через `GeoFlagRef`
- **Фильтрация по кодам:** Ограничение доступных стран через свойство `list` (коды ISO 3166-1 alpha-2)
- **Телефонные коды:** Отображение префиксов `+<code>` при включённом `showPhoneCode`
- **Локализация:** Смена языка названий стран через свойство `language`
- **Возможности Menu:** Наследование позиционирования `Window`, настроек `menuAttrs`, клавиатурной навигации и `expose`-API

**Типичные сценарии использования:**

- Выпадающие списки выбора страны в формах и профиле пользователя
- Выбор страны доставки или платёжного адреса
- Селектор телефонного кода страны для полей ввода номера

<Source
    code={`
<script setup>
import { ref } from 'vue'

const selectedValue = ref('VN')
</script>

<template>
  <MenuCountry
    v-model:selected="selectedValue"
    :list="['US', 'VN', 'GB']"
    show-phone-code
    is-selected-by-value
  >
    <template #control="{ binds, selectedNames }">
      <button v-bind="binds">
        {{ selectedNames.value[0] || 'Выбрать страну' }}
      </button>
    </template>
  </MenuCountry>
</template>
  `}
    language="html"
/>

> MenuCountry объединяет локализованные справочники стран и отображение флагов с полной функциональностью всплывающего меню.
