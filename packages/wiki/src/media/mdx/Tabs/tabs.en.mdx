The `Tabs` component combines tab navigation and animated content panels into a synchronized tabbed interface.

It coordinates `TabsNavigation` for horizontal scrollable tab headers with `MotionAxis` for direction-aware panel transitions, automatically linking ARIA `tablist`, `tab`, and `tabpanel` attributes.

**Key features:**

- **Synchronized Navigation & Slides:** Automatic coordination between active tab headers and named content slots
- **Flexible Configuration:** Accepts an array of tab items or a `TabsNavigation` config object via `tabs`, plus `tabItemAttrs`, `tabsNavigationAttrs`, and `motionAxisAttrs`
- **Custom Keys & Dividers:** Supports `keyValue`, `keyLabel` (including numeric `0`), dividers, and custom tab tags
- **State Binding:** Supports two-way binding via `v-model:selected` or controlled `:selected` with `@update:selected`
- **Accessible Panels:** Wraps each slide slot in `role="tabpanel"` linked via `aria-labelledby` to its controlling tab

**Common use cases:**

- Organizing dashboard views or settings screens by category
- Switching between related data panels inside cards or modals
- Building multi-section forms or step-by-step workflows
