Компонент `Tabs` объединяет навигацию по вкладкам и анимированные панели контента в единый синхронизированный интерфейс.

Он координирует `TabsNavigation` для горизонтально прокручиваемой панели заголовков с `MotionAxis` для плавных переходов слайдов, автоматически связывая ARIA-атрибуты `tablist`, `tab` и `tabpanel`.

**Основные возможности:**

- **Синхронизированная навигация и слайды:** Автоматическая связь активного заголовка вкладки с именованными слотами контента
- **Гибкая настройка:** Принимает массив вкладок или объект конфигурации `TabsNavigation` через `tabs`, а также `tabItemAttrs`, `tabsNavigationAttrs` и `motionAxisAttrs`
- **Пользовательские ключи и разделитель:** Поддержка `keyValue`, `keyLabel` (включая числовой `0`), `divider` и пользовательских тегов вкладок
- **Управление состоянием:** Поддержка двусторонней привязки `v-model:selected` или управляемого режима `:selected` + `@update:selected`
- **Доступные панели:** Каждый слот слайда оборачивается в `role="tabpanel"` со связью `aria-labelledby` с соответствующей вкладкой

**Типовые сценарии использования:**

- Организация разделов дашборда или экранов настроек по категориям
- Переключение между связанными представлениями данных внутри карточек и модальных окон
- Построение многосекционных форм и пошаговых интерфейсов

<script setup>
import { ref } from 'vue'

const selected = ref('tab1')
const tabs = [
  { label: 'Вкладка 1', value: 'tab1' },
  { label: 'Вкладка 2', value: 'tab2' },
  { label: 'Вкладка 3', value: 'tab3' }
]
</script>

<template>
  <Tabs
    v-model:selected="selected"
    :tabs="tabs"
  >
    <template #tab1>
      Контент для Вкладки 1
    </template>
    <template #tab2>
      Контент для Вкладки 2
    </template>
    <template #tab3>
      Контент для Вкладки 3
    </template>
  </Tabs>
</template>
  `}
    language="html"

> Tabs объединяет доступную горизонтальную навигацию по вкладкам с плавными анимированными переходами панелей контента.
