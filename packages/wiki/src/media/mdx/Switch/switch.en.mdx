The `Switch` component is an interactive toggle control for binary on/off state selection with integrated accessibility (`role="switch"`), validation, descriptions, and form support.

Extending the checkbox architecture, it renders a native `<input type="checkbox" role="switch">` paired with a sliding track indicator. It coordinates two-way `v-model` and `v-model:selected` synchronization, read-only click protection (`aria-readonly`), loading indicators, and skeleton placeholders.

**Key features:**

- **Accessible Switch Semantics:** Native checkbox input enhanced with WAI-ARIA `role="switch"`, `aria-readonly`, `aria-invalid`, `aria-labelledby`, and `aria-describedby`
- **Model & Variant Sync:** Two-way `v-model` boolean binding and `v-model:selected` synchronization with `valueVariant` and `valueVariantHide`
- **Built-in Validation:** Native constraint validation, `required`, `validationMessage`, `validationCode`, and exposed validation helpers (`checkValidity`, `getValidationMessage`)
- **Rich Anatomy:** Supports `label`, `description`, `helperMessage`, `warningMessage`, `hasHtmlCode`, and `#default` / `#description` slots
- **Interactive & Loading States:** `disabled`, `readonly`, `focus`, `loading`, `indeterminate`, `isSkeleton`, `adaptive`, and `container` layout options

**Common use cases:**

- Toggling options in a settings or preferences panel
- Activating application features (e.g., dark mode, notifications, auto-save)
- Quick binary filters in lists and catalogs
- Instant state controls that take effect immediately
