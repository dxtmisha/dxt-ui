The `Grid` component is a layout container built on CSS Grid for organizing child elements into a multi-column structure.

By default, it creates a 12-column grid with `minmax(0, 1fr)` tracks and supports configuring the number of columns via a CSS custom property as well as aligning items along the cross axis using the `align` prop.

**Key features:**

- **12-Column Default Layout:** Uses CSS Grid with 12 equal-width columns by default
- **Customizable Columns:** Allows overriding the column count via the component CSS variable (`columns`)
- **Item Alignment:** Supports `center`, `top`, `bottom`, `stretch`, `baseline`, `start`, and `end` values for `align`

**Common use cases:**

- Multi-column page sections and dashboard widget layouts
- Structured form layouts with varying column spans
- Aligned card or content grids across responsive viewports
