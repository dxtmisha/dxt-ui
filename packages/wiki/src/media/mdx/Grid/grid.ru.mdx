Компонент `Grid` представляет собой контейнер макета на базе CSS Grid для организации дочерних элементов в многоколоночную структуру.

По умолчанию он создаёт 12-колоночную сетку с дорожками `minmax(0, 1fr)`, поддерживает настройку количества колонок через CSS-переменную и выравнивание элементов по поперечной оси с помощью свойства `align`.

**Основные возможности:**

- **12 колонок по умолчанию:** Использует CSS Grid с 12 колонками равной ширины
- **Настраиваемые колонки:** Позволяет переопределить количество колонок через CSS-переменную компонента (`columns`)
- **Выравнивание элементов:** Поддерживает значения `center`, `top`, `bottom`, `stretch`, `baseline`, `start` и `end` для свойства `align`

**Типовые сценарии использования:**

- Многоколоночные разделы страниц и макеты виджетов дашборда
- Структурированные макеты форм с разным числом занимаемых колонок
- Выровненные сетки карточек и контентных блоков
