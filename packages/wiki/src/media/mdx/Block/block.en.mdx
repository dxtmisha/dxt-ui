The `Block` component is a foundational structural container that organizes section content alongside optional headlines, headers, icons, captions, and descriptions.

It serves as the base layout primitive for higher-level section containers (`Group`, `Section`, `Page`), automatically wiring `aria-labelledby` and `aria-describedby` to rendered header and description elements while providing a reactive layout `area` context (`'block'` by default) to descendant components.

**Key features:**

- **Structured Header Anatomy:** Combines an overline `headline`, embedded `Header` (`label`, `caption`, `icon`, `tagHeader`, `#trailing`), and `description` inside a collapsible body header wrapper
- **Zero-Overhead Minimal Mode:** Omits the header/description wrapper and skips helper instantiation when only default body content is supplied
- **Polymorphic Root Tag:** Configurable semantic container tag (`div`, `section`, `article`, `aside`) via `tag`
- **Automatic WAI-ARIA Linking:** Synchronizes `aria-labelledby` and `aria-describedby` with generated or explicit `labelId` and `descriptionId` values
- **Cascading Area Context:** Injects `area` (`'block'` by default) into body content while preserving `'header'` inside the embedded header

**Common use cases:**

- Settings cards, dashboard panels, and form sections
- Structured article or documentation blocks with overline headlines and action buttons
- Base container for `Group`, `Section`, and `Page` layouts
