Компонент `ComponentOutlet` — это безобёрточный динамический резолвер компонентов, который находит зарегистрированный в `ComponentStorage` Vue-компонент по его имени (`name`), объединяет его предустановленные свойства по умолчанию с переданными `props` и внешними атрибутами, а затем рендерит его напрямую с пробросом всех слотов.

Компонент отделяет шаблоны приложения от прямых импортов конкретных реализаций и их базовых настроек. Когда компонент зарегистрирован в `ComponentStorage` (глобально через `dxtFunctionalPlugin` или программно через `ComponentStorage.add`), `ComponentOutlet` извлекает определение компонента и объединяет его свойства по умолчанию со свойством `props`, внешними атрибутами (`$attrs`), классами и стилями с помощью `toBinds`. Если указанное имя `name` не найдено в хранилище или не передано, `ComponentOutlet` безопасно отрисовывает содержимое слота `default`, не создавая лишних обёрточных тегов в DOM.

**Основные возможности:**

- **Безобёрточный динамический рендеринг:** Рендерит VNode разрешённого компонента напрямую без добавления промежуточного DOM-контейнера
- **Разрешение из централизованного реестра:** Извлекает компоненты из `ComponentStorage` по строковому идентификатору `name` как на клиенте, так и в SSR
- **Неразрушающее слияние свойств и стилей:** Объединяет дефолтные свойства из `ComponentStorage`, свойство `props`, внешние атрибуты, классы и инлайн-стили через `toBinds`
- **Прозрачный проброс слотов и Fallback:** Передаёт слот `default` и все именованные/scoped-слоты в целевой компонент либо рендерит слот `default` как резервную разметку, если компонент не зарегистрирован
- **Типизированный доступ к экземпляру:** Предоставляет метод `getElement<T>()` для обращения к публичному API разрешённого компонента или его DOM-элементу

**Типовые сценарии использования:**

- Отображение настраиваемых виджетов темы или плагинов, регистрируемых по имени при инициализации приложения
- Динамические секции макета, карточки дашбордов и блоки CMS с предустановленными свойствами по умолчанию
- Декларативный показ резервного (fallback) интерфейса через слот `default`, когда опциональный плагин-компонент не подключён
- Замена шаблонного кода `<component :is="...">` централизованным управлением свойствами компонентов по умолчанию

<Source
    code={`
<script setup lang="ts">
import { ComponentStorage } from '@dxtmisha/functional'
import MyBanner from './MyBanner.vue'

ComponentStorage.add('promo-banner', MyBanner, {
  variant: 'elevated',
  closable: true
})
</script>

<template>
  <!-- Разрешает 'promo-banner' и объединяет свойства по умолчанию с :props -->
  <ComponentOutlet
    name="promo-banner"
    :props="{ title: 'Специальное предложение' }"
  >
    <template #default>
      Скидка на все тарифы в течение ограниченного времени.
    </template>
  </ComponentOutlet>

  <!-- Отрисовывает резервный слот default, если компонент не зарегистрирован -->
  <ComponentOutlet name="unregistered-widget">
    <span>Резервный контент, когда виджет недоступен</span>
  </ComponentOutlet>
</template>
  `}
    language="html"
/>

> ComponentOutlet обеспечивает чистую, совместимую с SSR связь между реестром `ComponentStorage` и декларативными шаблонами Vue без лишних DOM-обёрток.
