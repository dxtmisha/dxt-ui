- `[column: string](props: TableRecordItemSlotProps): any` — Динамический слот для кастомного рендеринга ячеек столбца с указанным именем (применяется для ячеек данных, шапки и подвала).
- `header(props: { columns: string[] }): any` — Слот для кастомного содержимого шапки таблицы (`<thead>`).
- `items(props: { columns: string[] }): any` — Слот для кастомного содержимого элементов таблицы (`<tbody>`).
- `foot(props: { columns: string[] }): any` — Слот для кастомного содержимого подвала таблицы (`<tfoot>`).

> **TableRecordItemSlotProps:**
> - `item: any` — Объект данных строки для обычных ячеек или объект конфигурации заголовка для ячеек шапки.
> - `value: any` — Значение ячейки (или значение/объект заголовка).
> - `classes: { label: string, description: string }` — Вспомогательные имена классов элементов ячейки.
> - `key: string` — Уникальный ключ рендеринга.
> - `index: string` — Индекс колонки.
> - `slotsName: string` — Имя слота.
