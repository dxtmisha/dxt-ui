Table component orchestrating grid-like column indexes and list row records for tabular data visualization.

The `Table` component handles rendering structured datasets. It integrates column configurations (`columns`), header setups (`header`), dataset rows (`list`), sticky header positioning (`headerTop`), sticky left columns (`stickyLeft`), and cell formatting to deliver high-performance interactive tables.

**Key Features:**

- Structured representation of datasets in tabular form with optional `caption` (`captionBottom`, `captionDecorative`) and `colgroup` column widths (`columnsWidth`)
- Column-based data extraction via the `columns` array (or automatic inference from `header`)
- Multi-row hierarchical header (`header`) and footer (`foot`) support
- Built-in local search (`search`, `searchColumns`, `searchOptions`), sorting (`sort`, `sortDir`, `sortFunction`), and pagination (`page`, `rows`)
- Sticky headers (`headerTop`), sticky left columns (`stickyLeft`), and sticky bottom scrollbar (`stickyScrollBottom`) for large datasets
- Column-level and row-level attribute binding (`tableItemColumnAttrs`, `tableRowAttrs`), selection (`selected`), and skeleton states (`isSkeleton`)
- Custom slot support for sections and per-column cells (`header`, `items`, `foot`, `body`, `caption`, `#<column>`, `#header-<column>`, `#foot-<column>`)
