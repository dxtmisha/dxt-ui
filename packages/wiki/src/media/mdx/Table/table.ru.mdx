Компонент таблицы, координирующий сеточные индексы колонок и список строк данных для визуализации табличной информации.

Компонент `Table` обеспечивает рендеринг структурированных наборов данных. Он объединяет конфигурации колонок (`columns`), настройки шапки (`header`), массивы строк (`list`), липкую шапку (`headerTop`), зафиксированные левые колонки (`stickyLeft`) и форматирование ячеек.

**Ключевые особенности:**

- Структурированное представление наборов данных в табличном виде с поддержкой `caption` (`captionBottom`, `captionDecorative`) и ширины колонок `colgroup` (`columnsWidth`)
- Автоматическое извлечение данных на основе массива колонок `columns` (или автоопределение из `header`)
- Поддержка многоуровневых иерархических шапок (`header`) и подвалов (`foot`)
- Встроенный локальный поиск (`search`, `searchColumns`, `searchOptions`), сортировка (`sort`, `sortDir`, `sortFunction`) и пагинация (`page`, `rows`)
- Зафиксированная шапка (`headerTop`), липкие левые столбцы (`stickyLeft`) и прилипающий нижний скроллбар (`stickyScrollBottom`) для больших наборов данных
- Настройка атрибутов на уровне колонок и строк (`tableItemColumnAttrs`, `tableRowAttrs`), выделение строк (`selected`) и состояния скелетона (`isSkeleton`)
- Кастомные слоты для секций и ячеек каждого столбца (`header`, `items`, `foot`, `body`, `caption`, `#<column>`, `#header-<column>`, `#foot-<column>`)

<script setup>
const columns = ['id', 'name', 'role', 'status']
const header = { id: 'ID', name: 'Имя', role: 'Должность', status: 'Статус' }
const list = [
  { id: '1', name: 'Алиса', role: 'Разработчик', status: 'Активен' },
  { id: '2', name: 'Боб', role: 'Дизайнер', status: 'В ожидании' }
]
</script>

<template>
  <Table
    :columns="columns"
    :header="header"
    :list="list"
    :headerTop="true"
  />
</template>
  `}
    language="html"

> Table предоставляет полную оркестрацию верстки для табличных данных с поддержкой фиксации шапки, липких столбцов и переопределения слотов.
