- `[column: string](props: TableRecordItemSlotProps): any` — Dynamic slot for custom cell rendering of the specified column name (applies to data cells, header cells, and footer cells).
- `header(props: { columns: string[] }): any` — Slot for custom table header content (`<thead>`).
- `items(props: { columns: string[] }): any` — Slot for custom table items content (`<tbody>`).
- `foot(props: { columns: string[] }): any` — Slot for custom table footer content (`<tfoot>`).

> **TableRecordItemSlotProps:**
> - `item: any` — Row data object for data cells, or header configuration object for header cells.
> - `value: any` — Current cell value (or header value/object).
> - `classes: { label: string, description: string }` — Auxiliary cell element class names.
> - `key: string` — Unique rendering key.
> - `index: string` — Column index.
> - `slotsName: string` — Slot name.
