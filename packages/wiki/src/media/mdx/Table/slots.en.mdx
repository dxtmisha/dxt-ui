- `[column: string](props: TableRecordItemSlotProps): any` — Dynamic slot for custom data cell rendering of the specified column name.
- `default(props: TableRecordItemSlotProps): any` — Fallback slot for data cells without a dedicated column slot.
- `header-[column: string](props: TableRecordItemSlotProps): any` — Dynamic slot for custom header cell rendering of the specified column name.
- `header-default(props: TableRecordItemSlotProps): any` — Fallback slot for header cells without a dedicated `header-<column>` slot.
- `foot-[column: string](props: TableRecordItemSlotProps): any` — Dynamic slot for custom footer cell rendering of the specified column name.
- `foot-default(props: TableRecordItemSlotProps): any` — Fallback slot for footer cells without a dedicated `foot-<column>` slot.
- `header(props: { columns: string[] }): any` — Slot for custom table header content (`<thead>`).
- `items(props: { columns: string[] }): any` — Slot for custom table items content (`<tbody>`).
- `foot(props: { columns: string[] }): any` — Slot for custom table footer content (`<tfoot>`).

> **TableRecordItemSlotProps:**
> - `item: any` — Row data object for data cells, or header/footer configuration object for header/footer cells.
> - `value: any` — Current cell value (or header/footer value/object).
> - `classes: { label: string, description: string }` — Auxiliary cell element class names.
> - `key: string` — Unique rendering key.
> - `index: string` — Column index.
> - `slotsName: string` — Slot name.
