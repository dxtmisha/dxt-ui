The `Bleed` component is a layout wrapper that lets content expand beyond the horizontal padding of its parent container using negative inline margins.

It renders a polymorphic HTML element configured via the `tag` prop (defaulting to `div`), merges external attributes, classes, styles, and listeners cleanly with `mergeProps`, and projects inner content through the `default` slot.

**Key features:**

- **Negative Horizontal Margins:** Expands child content symmetrically beyond parent container padding
- **Polymorphic Root Tag:** Renders any semantic HTML tag (`div`, `section`, `article`, `figure`, `aside`) via `tag`
- **Safe Attribute Merging:** Preserves external `class`, `style`, and event handlers alongside design tokens
- **SSR & Hydration Safe:** Pure structural wrapper with zero browser-only runtime dependencies

**Common use cases:**

- Full-width images, galleries, and figures inside padded article columns
- Highlight banners and callout blocks spanning edge to edge
- Horizontal dividers and scrollable strips breaking out of parent padding
