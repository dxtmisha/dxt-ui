- `checkValidity(): boolean` — Проверяет, удовлетворяют ли все поля формы ограничениям валидации.
- `getValues(): FormElementsValues` — Возвращает объект «ключ-значение», содержащий текущие значения всех зарегистрированных полей формы.
- `reset(): void` — Сбрасывает все поля формы к их закешированным начальным значениям или очищает их.
- `set(name: string, value: any): void` — Устанавливает значение отдельного поля по его имени.
- `setValues(values: FormElementsValues): void` — Устанавливает значения сразу нескольких полей из переданного объекта, не изменяя неуказанные поля.
- `setValuesAll(values: FormElementsValues): void` — Устанавливает значения для всех полей формы из переданного объекта, очищая или сбрасывая все неуказанные поля.
- `submit(): void` — Программно отправляет форму через `requestSubmit()` (или `submit()`, если `requestSubmit` не поддерживается).

> **FormElementsValues:**
> - `Record<string, any>` — Объект, сопоставляющий имена полей с их значениями.
