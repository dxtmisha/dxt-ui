## Настраиваемые шаблоны отображения

Свойство `template` настраивает формат вывода счётчика с помощью плейсхолдеров.

**Доступные плейсхолдеры:**

- `[c]` — текущее количество введённых символов
- `[m]` — максимальный лимит символов (`maxlength`)

Поддерживается HTML-разметка внутри строки шаблона. Если `template` не задан, по умолчанию выводится `[c] / [m]` при наличии `maxlength` или `[c]` без него.

<Source
    code={`
<!-- Описательный формат -->
<DesignComponent
  :counter="75"
  :maxlength="150"
  template="Символов: [c] из [m]"
/>

<!-- Компактный формат -->
<DesignComponent
  :counter="42"
  :maxlength="100"
  template="[c]/[m]"
/>

<!-- С HTML для стилизации -->
<DesignComponent
  :counter="75"
  :maxlength="150"
  template="<b>[c]</b> из <i>[m]</i> символов"
/>

<!-- Только текущий счётчик с текстом -->
<DesignComponent
  :counter="42"
  template="Введено символов: [c]"
/>
  `}
    language="html"
/>
