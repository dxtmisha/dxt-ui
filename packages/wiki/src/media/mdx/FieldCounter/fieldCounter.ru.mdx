Компонент `FieldCounter` отображает текущее количество введённых символов и максимальный лимит с поддержкой пользовательских шаблонов и встроенных объявлений доступности для скринридеров.

Он автоматически выбирает формат `[c] / [m]` (при наличии `maxlength`) или `[c]` (только счётчик), поддерживает HTML-теги внутри шаблона, корректно отображает ноль (`0`) и полностью скрывается из DOM, если не заданы ни `counter`, ни `maxlength`. При входе остатка символов в пороговую зону (`maxlengthOnce`, по умолчанию 10% от `maxlength`) автоматически монтируется `aria-live="polite"` область с сообщением об остатке или превышении лимита.

**Основные возможности:**

- **Условное отображение:** Монтируется только при наличии `counter` или `maxlength` (включая `0`)
- **Два режима вывода:** Отображает `counter / maxlength` при заданном лимите или только `counter` без него
- **Гибкие шаблоны:** Настройка через `template` с плейсхолдерами `[c]` и `[m]`, включая HTML-разметку
- **Умные ARIA live-уведомления:** Автоматически включает `aria-live="polite"` при достижении порога `maxlengthOnce` (10% по умолчанию) и на границе лимита
- **Тексты доступности по умолчанию и кастомные:** Встроенные тексты переопределяются через `textCharacterRemaining` (с `[left]`) и `textCharacterLimit`

<Source
    code={`
<script setup>
import { ref } from 'vue'

const valueLength = ref(42)
</script>

<template>
  <!-- Стандартный счётчик с лимитом -->
  <DesignComponent :counter="valueLength" :maxlength="100" />

  <!-- Пользовательский шаблон с HTML-стилизацией -->
  <DesignComponent
    :counter="75"
    :maxlength="150"
    template="<b>[c]</b> / <i>[m]</i> символов"
  />

  <!-- Настраиваемый порог и тексты доступности -->
  <DesignComponent
    id="bio-counter"
    :counter="92"
    :maxlength="100"
    :maxlength-once="15"
    text-character-remaining="Осталось [left] симв."
    text-character-limit="Лимит достигнут!"
  />
</template>
  `}
    language="html"
