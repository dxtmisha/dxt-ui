The `FieldCounter` component displays entered character counts and maximum limits with customizable formatting templates and built-in screen reader live announcements.

It automatically resolves visual formatting between `[c] / [m]` (when `maxlength` is set) and `[c]` (counter-only mode), supports HTML formatting inside templates, handles `0` cleanly, and hides itself completely when both `counter` and `maxlength` are omitted. When the remaining character count enters the warning threshold (`maxlengthOnce`, defaulting to 10% of `maxlength`), it dynamically mounts an `aria-live="polite"` region announcing remaining characters or limit exceeded states.

**Key features:**

- **Automatic Conditional Visibility:** Renders only when `counter` or `maxlength` is defined (including `0`)
- **Dual Display Modes:** Displays `counter / maxlength` when limit is provided, or `counter` alone otherwise
- **Flexible Templates:** Customizable via `template` with `[c]` and `[m]` placeholders and inline HTML support
- **Smart ARIA Live Announcements:** Automatically activates `aria-live="polite"` warnings within `maxlengthOnce` threshold (default 10%) and at limit
- **Zero-Config & Custom Accessibility Texts:** Built-in fallback messages overridable via `textCharacterRemaining` (with `[left]`) and `textCharacterLimit`

    code={`
<script setup>
import { ref } from 'vue'

const valueLength = ref(42)
</script>

<template>
  <!-- Standard counter with limit -->
  <DesignComponent :counter="valueLength" :maxlength="100" />

  <!-- Custom template with HTML styling -->
  <DesignComponent
    :counter="75"
    :maxlength="150"
    template="<b>[c]</b> / <i>[m]</i> chars"
  />

  <!-- Custom threshold and accessibility messages -->
  <DesignComponent
    id="bio-counter"
    :counter="92"
    :maxlength="100"
    :maxlength-once="15"
    text-character-remaining="Only [left] chars left"
    text-character-limit="Limit reached!"
  />
</template>
  `}
