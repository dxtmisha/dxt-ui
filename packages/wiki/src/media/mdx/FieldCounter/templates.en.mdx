## Custom Display Templates

The `template` property customizes counter formatting via placeholders.

**Available placeholders:**

- `[c]` — current character count
- `[m]` — maximum character limit (`maxlength`)

Supports HTML markup inside the template string. When `template` is omitted, the default format renders `[c] / [m]` if `maxlength` is present or `[c]` when absent.

<Source
    code={`
<!-- Descriptive format -->
<DesignComponent
  :counter="75"
  :maxlength="150"
  template="Characters: [c] of [m]"
/>

<!-- Compact format -->
<DesignComponent
  :counter="42"
  :maxlength="100"
  template="[c]/[m]"
/>

<!-- HTML styling inside template -->
<DesignComponent
  :counter="75"
  :maxlength="150"
  template="<b>[c]</b> of <i>[m]</i> characters"
/>

<!-- Counter-only template -->
<DesignComponent
  :counter="42"
  template="Characters entered: [c]"
/>
  `}
    language="html"
/>
