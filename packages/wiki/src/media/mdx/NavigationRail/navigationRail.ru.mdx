Компонент вертикальной панели навигации (`NavigationRail`) для основных сайдбаров, мини-панелей и компактных меню веб-приложений.

NavigationRail отображает верхнеуровневые пункты `NavigationRailItem` и вложенные подменю из `NavigationItem`. Поддерживает отслеживание выбора, управление фокусом, клавиатурную навигацию, разделители, пользовательские слоты, каскадную блокировку `disabled` и полный набор ARIA-атрибутов.

**Основные возможности:**

- Компактный вертикальный макет для постоянных боковых панелей навигации
- Иерархическая структура данных: вложенные меню, разделители, отступы, HTML и слоты
- Навигация с клавиатуры (стрелки, Home/End, Enter, Escape) при активном `control`
- Отслеживание одиночного и множественного выбора через `selected`, `focus`, `@click` и `@click-lite`
- Каскадная блокировка `disabled`: отключает клики, клавиатуру, дочерние пункты и подменю
- Встроенные ARIA-атрибуты (`role`, `aria-multiselectable`, `aria-disabled`, `roleItem`)
- Гибкая настройка через `itemAttrs`, `itemMenuAttrs` и `itemManagementAttrs`

**Типичные сценарии использования:**

- Основная боковая панель навигации в десктопных веб-приложениях
- Компактный сайдбар с иконками и подписями для адаптивных интерфейсов
- Многоуровневые панели инструментов и настроек

<Source
    code={`
<template>
  <NavigationRail
    :selected="selected"
    :list="[
      { label: 'Главная', value: 'home', icon: 'home' },
      { label: 'Панель управления', value: 'dashboard', icon: 'dashboard' },
      { label: 'Настройки', value: 'settings', icon: 'settings' }
    ]"
    @click-lite="(value) => selected = value.value"
  />
</template>
  `}
    language="html"
/>

> **Совет:** Передайте `:disabled="true"` в `NavigationRail`, чтобы автоматически установить `aria-disabled="true"` и заблокировать клики, клавиатурную навигацию и открытие вложенных меню.
