Vertical navigation rail component designed for primary navigation sidebars, application drawer rails, and mini navigation bars.

NavigationRail displays vertical navigation options for applications. It supports keyboard navigation, item focus, selection tracking, hierarchical menus, dividers, custom item attributes, and full accessibility ARIA roles.

**Key Features:**

- Compact vertical layout for sidebars and navigation rails
- Hierarchical dataset rendering with group and menu items
- Keyboard navigation (arrows, Enter, Space) and focus management
- Selection state tracking (`v-model:selected` or `selected`)
- Section dividers and custom item attributes
- Built-in accessibility with ARIA attributes
- Support for external control mode (`control`)

**Typical Use Cases:**

- Primary sidebar navigation in desktop web applications
- Compact icon/label navigation rail in responsive layouts
- Multi-level settings or workspace navigation panels
