Vertical navigation rail component designed for primary sidebars, application drawer rails, and compact navigation bars.

NavigationRail renders top-level `NavigationRailItem` entries and nested `NavigationItem` sub-menus. It provides selection tracking, focus management, keyboard navigation, dividers, custom slots, container `disabled` protection, and full ARIA semantics.

**Key features:**

- Compact vertical layout tailored for persistent sidebars and rail navigation
- Hierarchical datasets supporting nested sub-menus, dividers, spaces, and custom HTML/slots
- Keyboard navigation with arrow keys, Home/End, Enter, and Escape when `control` is active
- Single and multi-selection tracking with `selected`, `focus`, `@click`, and `@click-lite`
- Container-wide `disabled` propagation blocking clicks, keyboard actions, and nested menus
- Built-in ARIA attributes (`role`, `aria-multiselectable`, `aria-disabled`, `roleItem`)
- Flexible attribute customization via `itemAttrs`, `itemMenuAttrs`, and `itemManagementAttrs`

**Common use cases:**

- Primary sidebar navigation rail in desktop web applications
- Compact icon-and-label drawer rail for responsive workspaces
- Multi-level tool and settings navigation panels

<Source
    code={`
<template>
  <NavigationRail
    :selected="selected"
    :list="[
      { label: 'Home', value: 'home', icon: 'home' },
      { label: 'Dashboard', value: 'dashboard', icon: 'dashboard' },
      { label: 'Settings', value: 'settings', icon: 'settings' }
    ]"
    @click-lite="(value) => selected = value.value"
  />
</template>
  `}
    language="html"
/>

> **Tip:** Set `:disabled="true"` on `NavigationRail` to cascade `aria-disabled="true"` across the rail, nested menus, and items while automatically blocking pointer and keyboard activation.
