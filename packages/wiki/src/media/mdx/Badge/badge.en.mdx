Compact visual indicator for displaying status, notification counts, or markers on interface elements with support for various display modes and automatic overflow management.

Badge provides a universal solution for creating informative indicators with flexible content configuration, positioning, and accessibility. The component supports displaying text, numbers (including numeric `0`) with maximum value limits and locale formatting, icons, and dot indicators, automatically hides when content is absent (`--hideAuto`), and integrates with the `default` slot for custom content.

**Key features:**

- **Display Modes:** Text, numeric counters (`0`, positive values), icons, and dot indicator (`dot`)
- **Overflow & Locale Formatting:** Automatic `label-max` capping (e.g., `99+`) and locale-aware number formatting via `formatting` and `language`
- **Flexible Positioning:** Relative positioning via `overlap` (`rectangular`, `circular`, `static`), `vertical` (`top`, `center`, `bottom`), and `horizontal` (`left`, `center`, `right`)
- **Visibility Control:** Manual hiding via `hide` and automatic hiding when `dot`, `icon`, `label`, and `default` slot are absent
- **Accessibility:** Supports `aria-label` on the root element while automatically applying `aria-hidden="true"` to the inner label node

**Common use cases:**

- Unread notification count indicators
- Status markers on user avatars (online/offline)
- Item counters in shopping carts or lists
- New message indicators in chats and tabs
