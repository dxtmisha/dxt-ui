The flexbox-based table cell component representing a flexbox layout item cell. Used inside flexbox row structures to display text, labels, and descriptions, and supports flex-basis spanning (`colspan` up to 12).

**Key Features:**

- Flexbox layout cell structure with `colspan` flex-basis support (up to 12)
- Cell alignment options (`align` and `alignVertical`)
- Text clamping for cells with long labels (`labelClamp`)
- Dynamic skeleton states (`isSkeleton`) for loading phases
- Sticky columns and headers support (`stickyLeft`, `stickyTop`)
- Selectable and interactive states (`selected`, `disabled`)
