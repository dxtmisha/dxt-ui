The `TableFlexItem` component is a flexbox-based table cell that renders a semantic `<div role="cell">` element inside flexbox row structures. It extends `TableItem` logic while replacing native HTML `colspan`/`rowspan` attributes with `data-colspan`/`data-rowspan` attributes for CSS flex-basis distribution (up to 12 units).

**Key features:**

- **Flexbox Cell Semantics:** Renders `<div role="cell">` by default (customizable via `tag`) with `data-colspan`, `data-rowspan`, and `data-index` attributes instead of native HTML table attributes
- **Alignment & Dividers:** Horizontal (`align`) and vertical (`alignVertical`) alignment with optional horizontal and vertical cell dividers (`dividerX`, `dividerY`)
- **Text Clamping:** Multi-line clamping for dense tabular labels via `labelClamp`
- **Sticky Positioning:** Supports sticky top headers and sticky left columns (`stickyTop`, `stickyLeft`)
- **States & Skeleton:** Integrated `selected`, `disabled` (with `aria-selected`/`aria-disabled`), and `isSkeleton` loading support
- **Flexible Slots:** Supports `default`, `description`, and `context` slots for rich cell layouts

**Common use cases:**

- Data cells inside responsive flexbox tables (`TableFlex` and `TableFlexRecord`)
- Multi-column spanning cells using proportional `colspan` values (2 to 12)
- Dense dashboards requiring text truncation, sticky columns, and skeleton placeholders
