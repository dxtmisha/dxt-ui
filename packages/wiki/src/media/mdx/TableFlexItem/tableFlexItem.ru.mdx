Компонент ячейки таблицы на основе flexbox, представляющий элемент ячейки с флекс-макетом. Используется внутри флекс-строк для отображения текста, меток и описаний, а также поддерживает расширение ширины через `colspan` (до 12).

**Ключевые особенности:**

- Макет ячейки на основе flexbox с поддержкой `colspan` flex-basis (до 12)
- Выравнивание содержимого ячейки (`align` и `alignVertical`)
- Ограничение количества строк для ячеек с длинными метками (`labelClamp`)
- Динамические состояния скелетона (`isSkeleton`) для фаз загрузки
- Поддержка липких (sticky) колонок и заголовков (`stickyLeft`, `stickyTop`)
- Выбор и интерактивные состояния ячейки (`selected`, `disabled`)

</script>

> TableFlexItem предоставляет возможности гибкого флекс-макета и представления для содержимого ячеек, обеспечивая последовательное усечение текста, выравнивание и логику скелетонов.
