The `Icon` component is an orchestrator for displaying vector icons, images, and graphic symbols with built-in state management, interactive accessibility, visual transformations, and skeleton integration.

It provides a unified interface on top of the `Image` component, managing both a primary icon (`icon`) and an alternative active icon (`iconActive`). By default, the component renders as a decorative element (`aria-hidden="true"`). When the `dynamic` mode is enabled, it automatically attaches keyboard navigation (`tabindex`, `Enter`, `Space`), click handlers (`EventClickInclude`), enabled/disabled state tracking (`EnabledInclude`), and semantic ARIA attributes (`role="button"`, `aria-label`, `aria-disabled`). It also integrates with `SkeletonInclude` via `isSkeleton` to display loading placeholders.

**Key features:**

- **Dual-Icon State Management:** Seamless switching between primary (`icon`) and active (`iconActive`) icons based on `active` with transition animations (`animationType`, `animationShow`)
- **Interactive Mode & Accessibility:** Full keyboard navigation (`tabindex`, `Enter`, `Space`), click events (`@click`, `@clickLite`), link support (`href`), and automatic ARIA attributes (`role`, `ariaLabel`, `aria-disabled`) when `dynamic` is enabled
- **Decorative Default:** Renders with `aria-hidden="true"` and zero extraneous ARIA attributes when `dynamic` is not enabled
- **Visual Transformations:** Built-in 180-degree rotation (`turn`), automatic RTL mirroring (`dir`), background substrate (`overlay`), and color palette inheritance (`asPalette`)
- **Layout & Stacking Control:** Flex layout ordering (`start`, `end`) and elevated stacking context (`high`)
- **Visibility & Disabled States:** Granular control via `hide` and `disabled` modifiers propagated to child `Image` elements
- **Lifecycle & Programmatic API:** Forwarding of child image `@load` events and exposed inspection methods (`isActive()`, `getValue()`, `getDetail()`)
- **Skeleton & Composite Integration:** Built-in placeholder support (`isSkeleton`) and seamless composition in parent components via `IconLiteInclude`, `IconInclude`, and `IconTrailingInclude`

**Common use cases:**

- Leading and trailing icons inside buttons, chips, inputs, and list items
- Interactive toggle buttons such as password visibility switches, bookmark/favorite toggles, and expand/collapse chevrons
- Directional navigation indicators with automatic adaptation for RTL languages (`dir`)
- Standalone accessible icon actions with custom `value` and `detail` payloads (`dynamic`)
- Status indicators and decorative interface symbols with palette inheritance (`asPalette`) and overlay substrates (`overlay`)

<script setup>
import { ref } from 'vue'
import { Icon } from '@dxtmisha/constructor'

const isFavorite = ref(false)
const isVisible = ref(false)
const isExpanded = ref(false)

const onIconLoad = (event) => {
  console.log('Icon loaded:', event)

</script>

  <!-- Decorative static icon (renders with aria-hidden="true") -->
  <Icon icon="home" />

  <!-- State-driven icon switching (displays "favorite" when active is true) -->
  <Icon
    icon="favorite_border"
    icon-active="favorite"
    :active="isFavorite"
  />

  <!-- Interactive accessible toggle icon (dynamic mode enables click, keyboard, and ARIA) -->
  <Icon
    icon="visibility"
    icon-active="visibility_off"
    :active="isVisible"
    dynamic
    aria-label="Toggle password visibility"
    value="toggle-visibility"
    @click="isVisible = !isVisible"
  />

  <!-- Visual transformations: 180° rotation, RTL mirroring, palette inheritance, and load event -->
  <Icon
    icon="expand_more"
    :turn="isExpanded"
    dir
    as-palette
    overlay
    @load="onIconLoad"
  />
</template>
  `}

> The Icon component can be used both as a standalone decorative or interactive element and as an embedded icon primitive within other UI components through the `icon`, `icon-active`, and `icon-trailing` properties.
