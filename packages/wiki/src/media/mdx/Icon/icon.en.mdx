Component for displaying vector icons and graphic symbols with support for active state switching, interactive accessibility, visual transformations, and skeleton integration.

Icon provides a unified orchestrator interface on top of the `Image` component, managing both a primary icon (`icon`) and an alternative active icon (`iconActive`). By default, the component renders as a decorative element (`aria-hidden="true"`). When the `dynamic` mode is enabled, it automatically attaches keyboard navigation (`tabindex`, `Enter`, `Space`), click handlers (`EventClickInclude`), enabled/disabled state tracking (`EnabledInclude`), and semantic ARIA attributes (`role="button"`, `aria-label`, `aria-disabled`). It also integrates with `SkeletonInclude` via `isSkeleton` to display loading placeholders.

**Key features:**

- Dual-icon state management with smooth transition animations (`icon`, `iconActive`, `active`, `animationType`, `animationShow`)
- Interactive mode (`dynamic`) with click events (`@click`, `@clickLite`), keyboard navigation (`tabindex`), and automatic ARIA attributes (`role`, `ariaLabel`, `aria-disabled`)
- Decorative mode by default (`aria-hidden="true"`) without extraneous ARIA attributes
- Visual transformations including 180-degree rotation (`turn`), automatic RTL mirroring (`dir`), background substrate (`overlay`), and color palette inheritance (`asPalette`)
- Flex layout ordering and elevation modifiers (`start`, `end`, `high`)
- Visibility and interaction control via `hide` and `disabled` states
- Forwarding of underlying image `@load` events and programmatic state inspection via `isActive()`, `getValue()`, and `getDetail()`
- Built-in skeleton loading placeholder support (`isSkeleton`) and seamless composition in parent components via `IconLiteInclude`, `IconInclude`, and `IconTrailingInclude`

**Common use cases:**

- Leading and trailing icons inside buttons, chips, inputs, and list items
- Interactive toggle buttons such as password visibility switches, bookmark/favorite toggles, and expand/collapse chevrons
- Directional navigation indicators with automatic adaptation for RTL languages (`dir`)
- Standalone accessible icon actions with custom `value` and `detail` payloads (`dynamic`)
- Status indicators and decorative interface symbols with palette inheritance (`asPalette`) and overlay substrates (`overlay`)

  <Icon

    icon-active="visibility_off"
    :active="isVisible"

    aria-label="Toggle password visibility"
    value="toggle-visibility"
    @click="isVisible = !isVisible"
  />

    dir
    as-palette
    overlay
    @load="onIconLoad"
  />

> The Icon component can be used both as a standalone decorative or interactive element and as an embedded icon primitive within other UI components through the `icon`, `icon-active`, and `icon-trailing` properties.
