The flexbox-based table header cell component representing a flexbox layout header item cell. Used inside flexbox header row structures to display text, labels, descriptions, column sorting controls, and tooltips, and supports flex-basis spanning (`colspan` up to 12).

**Key Features:**

- Flexbox layout header cell structure with `colspan` flex-basis support (up to 12)
- Header alignment options (`align` and `alignVertical`)
- Interactive 3-state column sorting support (`sortColumn`, `sortDir`)
- Integrated tooltip component (`tooltipLabel`, `tooltipDescription`)
- Text clamping for cells with long labels (`labelClamp`)
- Dynamic skeleton states (`isSkeleton`) for loading phases
- Sticky columns and headers support (`stickyLeft`, `stickyTop`)
- Selectable and interactive states (`selected`, `disabled`)
