The `TableFlexHeaderItem` component is a flexbox-based table header cell that renders a semantic `<div role="columnheader">` element. It extends `TableHeaderItem` with flex-basis spanning (`data-colspan`/`data-rowspan`), omitting native HTML `scope`/`colspan`/`rowspan` attributes while preserving interactive 3-state column sorting and contextual tooltip controls.

**Key features:**

- **Flexbox Header Semantics:** Renders `<div role="columnheader">` by default with `data-colspan`, `data-rowspan`, and `data-index` attributes (without invalid HTML `scope`/`colspan` attributes on `<div>`)
- **Interactive 3-State Sorting:** Built-in sorting control (`showSort`, `sortColumn`, `sortDir`) emitting `sort` events (`asc` -> `desc` -> reset) and synchronizing `aria-sort`
- **Integrated Tooltip:** Contextual help trigger (`tooltipLabel`, `tooltipDescription`, `iconTooltip`, `tooltipAttrs`, and `#tooltip` slot)
- **Alignment, Dividers & Clamping:** Supports `align`, `alignVertical`, `dividerX`, `dividerY`, and `labelClamp`
- **Sticky & Interactive States:** Supports `stickyTop`, `stickyLeft`, `selected`, `disabled`, and `isSkeleton`

**Common use cases:**

- Sortable and documented column headers inside `TableFlex` and `TableFlexRecord`
- Multi-column flex header groups using `colspan` (up to 12)
- Footer summary cells rendered via `TableFlexRecord` with `isFoot`
