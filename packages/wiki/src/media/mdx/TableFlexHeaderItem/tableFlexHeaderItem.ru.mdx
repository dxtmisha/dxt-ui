Компонент `TableFlexHeaderItem` представляет собой ячейку заголовка таблицы на основе flexbox, рендерящую семантический элемент `<div role="columnheader">`. Он наследует логику `TableHeaderItem` с распределением ширины через `data-colspan`/`data-rowspan`, не добавляет невалидные для `<div>` HTML-атрибуты `scope`/`colspan`/`rowspan` и поддерживает интерактивную 3-состоятельную сортировку и всплывающие подсказки.

**Основные возможности:**

- **Флекс-семантика заголовка:** Рендерит `<div role="columnheader">` по умолчанию с атрибутами `data-colspan`, `data-rowspan` и `data-index` (без HTML-атрибутов `scope`/`colspan`)
- **Интерактивная 3-состоятельная сортировка:** Встроенный элемент сортировки (`showSort`, `sortColumn`, `sortDir`) с событием `sort` (`asc` -> `desc` -> сброс) и синхронизацией `aria-sort`
- **Интегрированная подсказка:** Встроенный триггер справки (`tooltipLabel`, `tooltipDescription`, `iconTooltip`, `tooltipAttrs` и слот `#tooltip`)
- **Выравнивание, разделители и усечение:** Поддержка `align`, `alignVertical`, `dividerX`, `dividerY` и `labelClamp`
- **Липкие и интерактивные состояния:** Поддержка `stickyTop`, `stickyLeft`, `selected`, `disabled` и `isSkeleton`

**Типовые сценарии использования:**

- Сортируемые заголовки столбцов со справкой внутри `TableFlex` и `TableFlexRecord`
- Группирующие заголовки с пропорциональным объединением колонок через `colspan` (до 12)
- Итоговые ячейки подвала, рендерящиеся через `TableFlexRecord` с флагом `isFoot`

<template>
  <!-- Простая ячейка заголовка -->
  <TableFlexHeaderItem label="Заголовок столбца" index="title" />

  <!-- Интерактивный заголовок с 3-состоятельной сортировкой и подсказкой -->
  <TableFlexHeaderItem
    label="Сортируемый заголовок"
    description="Нажмите для сортировки"
    index="price"
    showSort
    sortColumn="price"
    sortDir="asc"
    tooltipLabel="Справка"
    tooltipDescription="Подробное описание для этого столбца"
    align="center"
    colspan="2"
    labelClamp
    @sort="onSort"
  />
</template>
  `}
    language="html"
/>

> TableFlexHeaderItem объединяет доступную семантику заголовка столбца с флекс-макетом, 3-состоятельной сортировкой и встроенными подсказками для адаптивных таблиц.
