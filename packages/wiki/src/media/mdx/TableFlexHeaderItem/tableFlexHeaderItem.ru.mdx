Компонент ячейки заголовка таблицы на основе flexbox, представляющий элемент заголовка с флекс-макетом. Используется внутри флекс-строк заголовка для отображения текста, меток, описаний, элементов управления сортировкой и всплывающих подсказок, а также поддерживает расширение ширины через `colspan` (до 12).

**Ключевые особенности:**

- Макет ячейки заголовка на основе flexbox с поддержкой `colspan` flex-basis (до 12)
- Выравнивание содержимого заголовка (`align` и `alignVertical`)
- Интерактивная 3-состояниевая сортировка колонок (`sortColumn`, `sortDir`)
- Интегрированный компонент всплывающей подсказки (`tooltipLabel`, `tooltipDescription`)
- Ограничение количества строк для ячеек с длинными метками (`labelClamp`)
- Динамические состояния скелетона (`isSkeleton`) для фаз загрузки
- Поддержка липких (sticky) колонок и заголовков (`stickyLeft`, `stickyTop`)
- Выбор и интерактивные состояния ячейки (`selected`, `disabled`)

> TableFlexHeaderItem предоставляет возможности гибкого флекс-макета и представления для содержимого ячеек заголовков таблиц, обеспечивая последовательное усечение текста, выравнивание, подсказки и логику сортировки.
