The `Snackbar` component orchestrates and displays a queue of temporary notifications in a teleported overlay region (`role="region"`). Snackbars provide concise feedback about application processes without interrupting the user's current workflow.

It manages automatic visibility detection, configurable auto-hide timers with pause-on-hover behavior, high-priority notification separation, and full programmatic queue control through exposed methods.

**Key features:**

- **Flexible Positioning:** Configure screen placement and entrance direction via `vertical`, `horizontal`, and `origin`
- **Adaptive Queue Limits:** Control visible stack capacity and responsive display with `limit`, `all`, and `full`
- **Priority Separation:** Pin urgent alerts separately from standard notifications using `highPriority`
- **Lifecycle & Hover Pause:** Configurable auto-hide `delay` (default 8 seconds), automatic pause on `mouseenter` and resume on `mouseleave`, plus `show` and `hide` events
- **Programmatic API:** Manage notifications dynamically via exposed `add()`, `remove()`, `clear()`, and `isItem()` methods

**Common use cases:**

- Confirming user actions (e.g., "File saved successfully")
- Informing about network errors, retries, or warnings
- Real-time system status notifications across the application

      description: 'Description of the event that occurred in the app.',

}
</script>
