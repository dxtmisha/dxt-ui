Компонент `Snackbar` координирует и отображает очередь временных уведомлений в телепортируемой области (`role="region"`). Снекбары предоставляют краткую обратную связь о процессах приложения, не прерывая текущий сценарий работы пользователя.

Компонент управляет автоматическим определением видимости, настраиваемыми таймерами автозакрытия с паузой при наведении курсора, разделением приоритетных уведомлений и полным программным контролем очереди через экспонируемые методы.

**Основные возможности:**

- **Гибкое позиционирование:** Настройка положения на экране и направления анимации через `vertical`, `horizontal` и `origin`
- **Адаптивные ограничения очереди:** Управление количеством видимых карточек и полноширинным режимом через `limit`, `all` и `full`
- **Разделение по приоритету:** Выделение критических сообщений отдельно от обычного потока с помощью `highPriority`
- **Жизненный цикл и пауза при наведении:** Настраиваемая задержка автозакрытия `delay` (по умолчанию 8 секунд), пауза по `mouseenter` и возобновление по `mouseleave`, а также события `show` и `hide`
- **Программный API:** Динамическое управление уведомлениями через экспонируемые методы `add()`, `remove()`, `clear()` и `isItem()`

**Типовые сценарии использования:**

- Подтверждение действий пользователя (например, «Файл успешно сохранен»)
- Информирование об ошибках сети, повторных попытках или предупреждениях
- Системные уведомления в реальном времени по всему приложению

<Source
    code={`
<script setup>
import { ref } from 'vue'

const snackbar = ref(null)

const addMessage = () => {
  snackbar.value?.add({
    data: {
      label: 'Заголовок уведомления',
      description: 'Описание события, которое произошло в приложении.',
      button: 'Ок'
    }
  })
}
</script>

<template>
  <button @click="addMessage">Показать уведомление</button>

  <Snackbar
    ref="snackbar"
    vertical="bottom"
    horizontal="right"
  />
</template>
  `}
    language="html"
/>

> Рекомендуется размещать единый экземпляр `Snackbar` в корне приложения для согласованного управления очередью уведомлений на всех экранах.
