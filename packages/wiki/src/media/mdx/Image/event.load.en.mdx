### `load`

Event fires after the image is loaded.

**Parameters:**
- `image: ImageEventData` — object with image data

**ImageEventData structure:**
- `type: ImageTypeItem` — image type (`'image'`, `'file'`, `'array'`)
- `image: ImageItem` — resolved image metadata and element

**ImageItem structure:**
- `width: number` — natural width of the image
- `height: number` — natural height of the image
- `image: HTMLImageElement` — image DOM element
- `src: string` — image source URL or blob URI

<Source
    code={`
<script setup>
const handleLoad = (data) => {
  console.log('Image type:', data.type)

  if (typeof data.image === 'object' && data.image) {
    console.log('Width:', data.image.width)
    console.log('Height:', data.image.height)
    console.log('URL:', data.image.src)
  } else {
    console.log('Image URL:', data.image)
  }
}
</script>

<template>
  <Image
    value="/path/to/image.jpg"
    @load="handleLoad"
  />
</template>
  `}
