## Основное значение

Свойство `value` определяет контент изображения. Это универсальное свойство, поддерживающее несколько типов источников для максимальной гибкости.

**Поддерживаемые типы:**

- **Имя иконки** — иконка Material (`home`, `filled-home`, `outlined-home`, `$home`) или зарегистрированная публичная иконка
- **URL или путь к изображению** — прямая ссылка или путь со слэшем `/` (PNG, JPG, SVG, WebP и др.), либо явный префикс `image:filename.png`
- **Объект File** — JavaScript-объект `File`, полученный из `<input type="file">` или Drag and Drop
- **Бинарный буфер** — данные `Uint8Array` или `ArrayBuffer`, отображаемые через временный Object URL
- **PDF-документ** — прямая ссылка на PDF-файл с автоматическим встроенным предпросмотром
- **Флаг страны** — стандартный (`flag-us`) или сжатый (`f-de`) код страны по ISO 3166-1 alpha-2
- **Сплошной цвет** — строка цвета в формате HEX (`#4CAF50`) для заливки поверхности

Компонент автоматически определяет тип источника и выбирает оптимальный способ отображения. При передаче `File` или `Uint8Array` происходит чтение и предпросмотр содержимого. Также компонент принимает опциональное свойство `url` для указания базового пути при асинхронном получении иконок через `Icons.get(name, url)`.

<Source
    code={`
<!-- Иконка по имени -->
<Image value="filled-home" />

<!-- Изображение по URL -->
<Image value="https://example.com/image.png" />

<!-- Явный префикс изображения -->
<Image value="image:photo.jpg" />

<!-- Флаг страны -->
<Image value="flag-us" />

<!-- Файл пользователя или бинарный буфер -->
<Image :value="fileFromInput" />

<!-- Сплошная заливка цветом -->
<Image value="#2196F3" />
  `}
    language="html"
/>
