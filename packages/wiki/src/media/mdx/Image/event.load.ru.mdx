### `load`

Событие срабатывает после загрузки изображения.

**Параметры:**
- `image: ImageEventData` — объект с данными загруженного изображения

**Структура ImageEventData:**
- `type: ImageTypeItem` — тип изображения (`'image'`, `'file'`, `'array'`)
- `image: ImageItem` — объект с метаданными и DOM-элементом загруженного изображения

**Структура ImageItem:**
- `width: number` — натуральная ширина изображения
- `height: number` — натуральная высота изображения
- `image: HTMLImageElement` — DOM-элемент изображения
- `src: string` — URL-источник или blob URI

<Source
    code={`
<script setup>
const handleLoad = (data) => {
  console.log('Тип изображения:', data.type)

  if (typeof data.image === 'object' && data.image) {
    console.log('Ширина:', data.image.width)
    console.log('Высота:', data.image.height)
    console.log('URL:', data.image.src)
    console.log('HTMLImageElement:', data.image.image)
  }
}
</script>

<template>
  <Image
    value="/path/to/image.jpg"
    @load="handleLoad"
  />
</template>
  `}
    language="html"
/>
