## Управление отображением изображения

Свойства `size`, `coordinator`, `x` и `y` позволяют детально управлять масштабированием, областью видимости и позиционированием изображения внутри контейнера.

**Свойства:**

- `size` — режим масштабирования и заполнения изображения (`auto`, `contain`, `cover`)
- `coordinator` — массив координат для обрезки области отображения `[top, right, bottom, left]` в процентах (поддерживает от 1 до 4 значений по аналогии с блочной моделью CSS)
- `x` — смещение изображения по горизонтали (пиксели, проценты, например `'20%'`, `'10px'`)
- `y` — смещение изображения по вертикали (пиксели, проценты, например `'-10%'`, `'5px'`)

Свойства работают совместно или по отдельности. Значение `size` определяет режим масштабирования: `auto` использует исходный размер, `contain` вписывает изображение полностью, `cover` заполняет контейнер с возможной обрезкой. Свойство `coordinator` задаёт видимую область обрезки с помощью нормализованных координат `[top, right, bottom, left]` в процентах (1 значение применяется ко всем сторонам, 2 значения задают `[вертикаль, горизонталь]`, 3 значения — `[верх, горизонталь, низ]`, 4 значения — все четыре стороны). Параметры `x` и `y` смещают изображение относительно контейнера для точного позиционирования.

<Source
    code={`
<!-- Режим масштабирования -->
<Image value="/images/photo.jpg" size="contain" />

<!-- Обрезка по координатам [top, right, bottom, left] -->
<Image value="/images/photo.jpg" :coordinator="[10, 20, 10, 20]" />

<!-- Смещение позиции с CSS-единицами измерения -->
<Image value="/images/photo.jpg" x="15%" y="-10%" />

<!-- Комбинация параметров -->
<Image
  value="/images/photo.jpg"
  size="cover"
  :coordinator="[0, 10, 20, 10]"
  x="10%"
  y="5%"
/>
  `}
    language="html"
/>
