A bar and caption component designed for media cards, collages, and gallery items.

CollageBar provides a structured, responsive bar displaying a title (label), auxiliary text (description), and an optional action button with an icon. It can be placed below media elements as a standard caption (using semantic `figcaption` by default) or positioned directly over images and media with gradient scrim overlays for contrast and readability.

**Key features:**

- Structured content area with title (label) and descriptive text (description)
- Integrated trailing action button with customizable text, icon, and attributes
- Multiple positioning modes: static, top overlay, and bottom overlay
- Automatic gradient scrim backgrounds for top and bottom overlay positions
- Selected status with accent palette styling
- Customizable HTML container tag (`figcaption`, `div`, etc.)
- Slots for custom body and trailing elements
- Click event tracking and bubbling

**Typical usage scenarios:**

- Captions and titles for gallery images and photo collages
- Overlay action and title bars on video players and media thumbnails
- Selection indicators and toolbars for media pickers
- Contextual header or footer bars on cards and visual previews
