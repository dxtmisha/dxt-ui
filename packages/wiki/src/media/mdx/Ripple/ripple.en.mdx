The `Ripple` component provides fluid, interactive visual feedback on user touch and click interactions across design system elements.

It automatically coordinates pointerdown events, calculates relative click coordinates, and animates expanding circular waves that gracefully fade out and clean themselves up from the DOM upon transition completion. The element is purely decorative and automatically tagged with `aria-hidden="true"` to prevent screen reader distractions.

**Key features:**

- **Automatic Click Tracking:** Listens to primary pointer interactions and dynamically places waves at exact touch coordinates
- **Programmatic Control:** Exposes `add()` and `addCenter()` methods for programmatic wave generation
- **State Control:** Cleanly disables wave generation via the `disabled` prop
- **Automatic DOM Cleanup:** Removes wave elements from the DOM after the end transition completes
- **Design Token Adaptability:** Inherits surface contrast and border radius automatically from its parent container

**Common use cases:**

- Interactive button surfaces and action sheet items
- Clickable cards, list items, and table records
- Chip items, segmented controls, and navigation rails
- Custom interactive surfaces and touch areas
