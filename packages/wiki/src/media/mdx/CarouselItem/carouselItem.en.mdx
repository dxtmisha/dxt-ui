The `CarouselItem` component represents an individual slide within carousels, sliders, slideshows, and walkthrough sequences. It provides media presentation, scroll snap alignment, interactive selection handling, and built-in accessibility compliance following the WAI-ARIA Carousel design pattern.

The component encapsulates layout positioning, image cropping and scaling, skeleton loading state, link navigation, and scoped default slots for custom slide contents.

**Key features:**

- Scroll snap alignment modes via `snap`: `start`, `center`, `end`, and `none`
- Integrated media presentation with image cropping, scaling, and positioning (`image`, `coordinator`, `x`, `y`, `size`)
- Active slide state management with `selected`
- Full WAI-ARIA Carousel Pattern compliance: automated `role="group"`, `roledescription="slide"`, `aria-label`, and `aria-hidden` attributes
- Slide indexing and total slides count for screen reader accessibility (`slide`, `total`)
- Built-in skeleton loading support (`isSkeleton`)
- Interactive click handling and navigation routing (`href`, `to`)
- Customizable container HTML tag (`tag`: defaults to `a` when `to`/`href` is provided, or `div`)
- Scoped default slot with reactive `{ selected, slide }` parameters

**Common use cases:**

- Full-width hero banners and promotional carousels
- Card and product showcase slideshows with snap scrolling
- Onboarding walkthrough steps with custom content overlays
- Interactive media galleries and image sliders
