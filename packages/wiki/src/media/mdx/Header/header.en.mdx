The `Header` component renders structured section and card headings with integrated support for leading icons, captions, and trailing actions.

It decouples visual heading hierarchy (`h1`–`h6`) into semantic HTML elements via the `tag` property, automatically provides reactive layout area context (`area`) to descendant components, and lazily initializes icon, label, and caption helpers only when needed.

**Key features:**

- **Semantic Heading Hierarchy:** Configurable heading levels (`h1`–`h6`, defaulting to `h3`) rendered on the label element with optional `labelId`
- **Integrated Leading Icon:** Built-in icon support with directional mirroring (`iconDir`), rotation (`iconTurn`), visibility (`iconHide`), palette adaptation (`iconPalette`), and active state (`selected`)
- **Accessible Captions:** Optional secondary caption with polite live-region announcements by default or `aria-hidden="true"` via `captionDecorative`
- **Trailing Slot & Spacer:** Flexible trailing slot separated by an automatic dynamic spacer
- **Reactive Area Context:** Automatic `area` context injection (defaulting to `'header'`) for adaptive descendant components

**Common use cases:**

- Page, section, and form group headings
- Card headers with status badges or action buttons in the trailing slot
- Categorized navigation headers with icons and item-count captions
