## Methods

### Action

- `update(callback: MotionFlipCallback): Promise<void>` — Performs DOM mutation callback and animates child layout changes using FLIP animation.
- `stop(): void` — Stops active FLIP animation and clears animation state.

## FLIP Animation Updates

The `update` method orchestrates FLIP layout animations during DOM modifications.

1. Records original bounding rectangles for all child elements before DOM modification (when not `disabled`).
2. Executes the `callback` function to update state and DOM elements.
3. Measures new child positions and applies calculated offset CSS variables and freeze/go modifier classes.
4. Cleans up temporary classes and inline variables on `transitionend` or after the fallback timeout.

Calling `stop()` cancels any pending animation frames and timers, immediately removing active modifier classes and system CSS variables.

> Important: When orchestrating updates manually, wrap DOM-modifying state changes inside the `update` callback so initial and final element coordinates are measured accurately.
