Компонент `MotionFlip` выполняет FLIP-анимацию (First, Last, Invert, Play) перестроения дочерних элементов при изменении их положения или размеров.

Он оборачивает контейнер с дочерними элементами и отслеживает изменения макета автоматически через `MutationObserver` (свойство `auto` включено по умолчанию) или явно с помощью публичного метода `update(callback)`, применяя плавные CSS-переходы и очищая временные стили после завершения анимации.

**Основные возможности:**

- **Автоматическое отслеживание мутаций:** По умолчанию наблюдает за изменениями дочерних элементов DOM через свойство `auto`
- **Явная оркестрация обновлений:** Поддерживает ручное измерение до и после изменения состояния через метод `update(callback)`
- **Управление остановкой анимации:** Позволяет немедленно прервать активный переход и очистить состояние через метод `stop()`
- **Условное отключение:** Отключает расчёты и переходы FLIP при сохранении выполнения колбэков через свойство `disabled`
- **Автоматическая очистка стилей:** Удаляет временные классы-модификаторы и системные CSS-переменные после `transitionend` или резервного таймера

**Типовые сценарии использования:**

- Списки и динамические сетки с изменяемым порядком элементов
- Коллекции с динамической фильтрацией и сортировкой
- Интерактивная перестановка карточек и переходы макета

<Source
    code={`
<script setup>
import { nextTick, ref } from 'vue'

const motionFlipElement = ref()
const items = ref([1, 2, 3, 4, 5])

const shuffle = async () => {
  await motionFlipElement.value?.update(async () => {
    items.value = [...items.value].reverse()
    await nextTick()
  })
}
</script>

<template>
  <button @click="shuffle">Изменить порядок</button>

  <MotionFlip ref="motionFlipElement" :auto="false">
    <div v-for="item in items" :key="item">
      <div class="item">
        Элемент {{ item }}
      </div>
    </div>
  </MotionFlip>
</template>
  `}
    language="html"
/>

> MotionFlip объединяет автоматическое наблюдение за DOM и явное управление FLIP-переходами через колбэк для плавной анимации макета при минимальной настройке.
