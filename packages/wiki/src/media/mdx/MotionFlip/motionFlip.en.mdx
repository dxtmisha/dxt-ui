Component for performing FLIP (First, Last, Invert, Play) animations on child elements.

MotionFlip automatically animates positional and dimensional changes of child elements when the layout changes (e.g. reordering, inserting, or removing list items).

**Key Features:**

- Smooth FLIP layout transitions during DOM updates
- Automatic DOM mutation observing via `auto` property
- Asynchronous callback orchestration via `update` method
- Automatic transition cleanup upon animation end
- Ability to disable layout animation via `disabled` property

**Typical Use Cases:**

- Reorderable list and grid layouts
- Dynamic filter and sorting interfaces
- Drag-and-drop item transitions
- Card and gallery item reordering

<Source
    code={`
<script setup>
import { ref } from 'vue'

const flipRef = ref()
const items = ref([1, 2, 3, 4, 5])

const shuffle = async () => {
  await flipRef.value?.update(() => {
    items.value = [...items.value].sort(() => Math.random() - 0.5)
  })
}
</script>

<template>
  <button @click="shuffle">Shuffle</button>

  <MotionFlip ref="flipRef">
    <div v-for="item in items" :key="item">
      <div class="item">
        Item {{ item }}
      </div>
    </div>
  </MotionFlip>
</template>
  `}
    language="html"
/>
