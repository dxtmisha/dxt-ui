The `MotionFlip` component performs FLIP (First, Last, Invert, Play) layout animations on child elements whenever their positions or dimensions change.

It wraps a container of child elements and tracks layout changes automatically via `MutationObserver` (`auto` is enabled by default) or explicitly through the exposed `update(callback)` method, applying hardware-accelerated CSS transitions and cleaning up temporary styles upon completion.

**Key features:**

- **Automatic Mutation Tracking:** Observes child DOM changes automatically by default via the `auto` property
- **Explicit Callback Orchestration:** Supports manual pre- and post-update measurement via the exposed `update(callback)` method
- **Animation Interruption Control:** Allows immediate cancellation and state cleanup via the exposed `stop()` method
- **Conditional Disabling:** Disables FLIP measurements and transitions while still executing state callbacks via `disabled`
- **Automatic Style Cleanup:** Removes temporary modifier classes and system CSS variables after `transitionend` or fallback timeout

**Common use cases:**

- Reorderable lists and dynamic grid layouts
- Filtered and sorted item collections
- Interactive card shuffling and layout transitions

<Source
    code={`
<script setup>
import { nextTick, ref } from 'vue'

const motionFlipElement = ref()
const items = ref([1, 2, 3, 4, 5])

const shuffle = async () => {
  await motionFlipElement.value?.update(async () => {
    items.value = [...items.value].reverse()
    await nextTick()
  })
}
</script>

<template>
  <button @click="shuffle">Reorder</button>

  <MotionFlip ref="motionFlipElement" :auto="false">
    <div v-for="item in items" :key="item">
      <div class="item">
        Item {{ item }}
      </div>
    </div>
  </MotionFlip>
</template>
  `}
    language="html"
/>

> MotionFlip combines automatic DOM observation and explicit callback-driven FLIP orchestration to deliver smooth layout transitions with minimal setup.
