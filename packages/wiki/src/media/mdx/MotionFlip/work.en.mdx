## How to Work with Component

To ensure correct FLIP animation functionality when using **MotionFlip**, follow these guidelines:

### 1. Element Structure Requirements

Every direct child element of `<MotionFlip>` must contain an inner nested element (`>*`).

- **Outer Container (Wrapper):** preserves layout positioning and grid dimensions.
- **Inner Element:** smoothly animates via FLIP technique during reordering, insertion, or removal.

<Source
    code={`
<MotionFlip ref="motionFlipElement">
  <!-- Outer wrapper (positioning container) -->
  <div v-for="item in items" :key="item" class="item-wrapper">
    <!-- Inner element (animated content) -->
    <div class="item">
      {{ item }}
    </div>
  </div>
</MotionFlip>
`}
    language="html"
/>

### 2. Automatic Observation vs. Explicit Update

By default (`auto: true`), `MotionFlip` observes direct child mutations automatically. When using manual mode (`:auto="false"`) or when you need fresh measurements immediately before a change, wrap array or DOM mutations inside `update()` and await `nextTick()` so the updated DOM is ready before the animation starts:

<Source
    code={`
await motionFlipElement.value?.update(async () => {
  // Perform array mutations (reorder, insert, remove)
  await nextTick()
})
`}
    language="javascript"
/>
