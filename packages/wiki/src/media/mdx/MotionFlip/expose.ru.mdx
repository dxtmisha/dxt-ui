## Methods

### Action

- `update(callback: MotionFlipCallback): Promise<void>` — Выполняет функцию обновления DOM и анимирует изменение расположения элементов с помощью FLIP-анимации.
- `stop(): void` — Останавливает активную FLIP-анимацию и сбрасывает её состояние.

## Анимация изменений через FLIP

Метод `update` координирует процесс FLIP-анимации при изменении DOM-дерева.

1. Фиксирует исходные координаты и размеры всех дочерних элементов до вызова колбэка (если анимация не отключена через `disabled`).
2. Выполняет функцию `callback` для обновления состояния и элементов DOM.
3. Измеряет новые позиции элементов, применяет вычисленные CSS-переменные смещения и классы-модификаторы фаз анимации.
4. Очищает временные классы и CSS-переменные по событию `transitionend` или по резервному таймауту.

Вызов метода `stop()` отменяет ожидающие кадры анимации и таймеры, немедленно удаляя активные модификаторы и системные CSS-переменные.

> Important: При ручном управлении оборачивайте изменения состояния, влияющие на DOM-структуру дочерних элементов, в колбэк метода `update`, чтобы компонент мог точно измерить исходные и конечные координаты.
