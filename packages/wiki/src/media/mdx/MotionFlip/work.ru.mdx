## Инструкция по работе с компонентом

Для корректной работы FLIP-анимации в компоненте **MotionFlip** соблюдайте следующие требования:

### 1. Требования к структуре элементов

Каждый прямой дочерний элемент компонента `<MotionFlip>` обязательно должен содержать вложенный элемент (`>*`).

- **Внешний контейнер (обёртка):** удерживает место в сетке или макете и сохраняет размеры.
- **Внутренний элемент:** плавно анимируется по технологии FLIP при изменении порядка, добавлении или удалении.

<Source
    code={`
<MotionFlip ref="motionFlipElement">
  <!-- Внешний элемент (контейнер позиционирования) -->
  <div v-for="item in items" :key="item" class="item-wrapper">
    <!-- Внутренний элемент (анимируемое содержимое) -->
    <div class="item">
      {{ item }}
    </div>
  </div>
</MotionFlip>
`}
    language="html"
/>

### 2. Автоматическое отслеживание и ручной вызов

По умолчанию (`auto: true`) компонент `MotionFlip` автоматически отслеживает изменения дочерних элементов. При работе в ручном режиме (`:auto="false"`) или когда требуется точный замер перед обновлением, оборачивайте изменения массива или DOM в колбэк метода `update()` и ожидайте `nextTick()`:

<Source
    code={`
await motionFlipElement.value?.update(async () => {
  // Выполняем изменения в массиве (сортировка, добавление, удаление)
  await nextTick()
})
`}
    language="javascript"
/>
