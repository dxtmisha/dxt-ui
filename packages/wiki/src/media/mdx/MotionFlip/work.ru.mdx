## Инструкция по работе с компонентом

Для правильной и корректной работы FLIP-анимации с компонентом **MotionFlip** необходимо соблюдать следующие инструкции:

### 1. Требования к структуре элементов

Каждый прямой дочерний элемент компонента `<MotionFlip>` обязательно должен содержать вложенный элемент (`>*`). 

- **Внешний контейнер (обертка):** удерживает место в сетке или макете и сохраняет размеры.
- **Внутренний элемент:** плавно анимируется по технологии FLIP при изменении порядка, добавлении или удалении.

<Source
    code={`
<MotionFlip ref="flipRef">
  <!-- Внешний элемент (контейнер позиционирования) -->
  <div v-for="item in items" :key="item" class="item-wrapper">
    <!-- Внутренний элемент (анимируемое содержимое) -->
    <div class="item">
      {{ item }}
    </div>
  </div>
</MotionFlip>
`}
    language="html"
/>

### 2. Обновление состояния и вызов анимации

По умолчанию компонент работает в ручном режиме. Все изменения массива данных или DOM-структуры должны выполняться внутри колбэка метода `update()`:

<Source
    code={`
await flipRef.value.update(() => {
  // Выполняем изменения в массиве (сортировка, добавление, удаление)
})
`}
    language="javascript"
/>
