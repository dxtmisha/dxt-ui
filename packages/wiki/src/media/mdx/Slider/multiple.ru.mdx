## Режим выбора диапазона (`multiple`)

Включение свойства `multiple` переводит слайдер в режим выбора интервала с двумя ползунками. В этом режиме `v-model` связывается с массивом из двух чисел `[min, max]`.

**Ключевые свойства:**

- `multiple` — включает два ползунка для выбора диапазона
- `minimumDistance` — устанавливает минимально допустимое расстояние между левым и правым ползунками (по умолчанию `1`)

При перемещении ползунков компонент автоматически гарантирует, что минимальный ползунок не сможет приблизиться к максимальному ближе чем на `minimumDistance`, исключая пересечение и некорректные интервалы.

<Source
    code={`
<script setup>
import { ref } from 'vue'

const priceRange = ref([100, 500])
</script>

<template>
  <Slider
    v-model="priceRange"
    multiple
    :min="0"
    :max="1000"
    :step="10"
    :minimumDistance="50"
  />
</template>
  `}
    language="html"
/>
