## Метки, шаги и притягивание (`marks`)

Свойство `marks` позволяет задавать визуальные деления и текстовые подписи на шкале слайдера, а также связывать числовые позиции с пользовательскими значениями любого типа.

### Форматы передачи меток

Свойство `marks` принимает данные в нескольких форматах:

#### Простой массив чисел
Если передать простой массив чисел, слайдер построит деления в указанных точках и использует сами числа в качестве подписей.

<Source
    code={`
<Slider :marks="[0, 20, 50, 80, 100]" />
  `}
    language="html"
/>

#### Массив объектов (расширенная настройка)
Каждый элемент массива может быть объектом со следующими свойствами:

- `mark` *(number)* — числовая позиция метки на шкале (от `min` до `max`).
- `label` *(string)* — текстовая подпись для отображения.
- `value` *(any)* — пользовательские данные или текстовый идентификатор, привязанный к этой метке.

<Source
    code={`
<script setup>
const planMarks = [
  { mark: 0, value: 'free', label: 'Бесплатный' },
  { mark: 50, value: 'pro', label: 'Pro' },
  { mark: 100, value: 'enterprise', label: 'Enterprise' }
]
</script>

<template>
  <Slider :marks="planMarks" magnet />
</template>
  `}
    language="html"
/>

#### Объект-словарь (ключ-значение)
Метки можно передать в виде объекта, где ключами являются позиции или идентификаторы:

<Source
    code={`
<script setup>
const speedMarks = {
  0: '0 км/ч',
  60: '60 км/ч',
  110: '110 км/ч (Макс)'
}
</script>

<template>
  <Slider :marks="speedMarks" />
</template>
  `}
    language="html"
/>

### Кастомные ключи (`keyLabel` и `keyValue`)

Если структура входящих данных отличается от стандартных полей `label` и `value`, можно настроить имена ключей через свойства `keyLabel` и `keyValue`:

- `keyLabel` — имя свойства объекта, содержащего текст подписи (по умолчанию `'label'`).
- `keyValue` — имя свойства объекта, содержащего полезную нагрузку (по умолчанию `'value'`).

<Source
    code={`
<script setup>
import { ref } from 'vue'

const selectedCategory = ref(2)
const categories = [
  { id: 1, title: 'Эконом', position: 0 },
  { id: 2, title: 'Стандарт', position: 50 },
  { id: 3, title: 'Премиум', position: 100 }
]
</script>

<template>
  <Slider
    v-model="selectedCategory"
    :marks="categories"
    keyLabel="title"
    keyValue="id"
    magnet
  />
</template>
  `}
    language="html"
/>

### Режим притягивания (`magnet`) и шаг (`step`)

- `step` — определяет дискретный шаг изменения значения при перетаскивании или нажатии клавиш стрелок (по умолчанию `1`).
- `magnet` — включается логическим флагом. В режиме `magnet` ползунок автоматически «прилипает» к ближайшей метке из списка `marks`, не позволяя выбрать промежуточные значения вне меток.

<Source
    code={`
<!-- Ползунок передвигается строго по меткам -->
<Slider
  v-model="volume"
  :marks="[0, 25, 50, 75, 100]"
  magnet
/>
  `}
    language="html"
/>

### Данные в событиях (`@input` и `@change`)

При изменении значения события `@input` и `@change` передают детальный объект `detail` со следующей структурой:

- `detail.mark` — числовое значение позиционирования (или массив `[min, max]` для `multiple`).
- `detail.item` — скомпилированный объект метки (`{ mark, value, label, style }`).
- `detail.value` — пользовательская полезная нагрузка из свойства `value` метки.

Также доступны упрощенные события `@inputLite` и `@changeLite`, передающие только чистое значение `v-model`.

### Кастомизация рендеринга меток через слот `#mark`

Вы можете настроить внешний вид меток с помощью слота `#mark`, принимающего объект `{ item }`:

<Source
    code={`
<template>
  <Slider :marks="[0, 50, 100]">
    <template #mark="{ item }">
      <span class="custom-mark">
        <strong>{{ item.label }}</strong>
      </span>
    </template>
  </Slider>
</template>
  `}
    language="html"
/>
