Компонент `InputFileDropzone` представляет собой элемент формы, объединяющий интерактивную зону загрузки файлов методом Drag and Drop со встроенной меткой поля и блоком сообщений.

Он инкапсулирует полный процесс перетаскивания и выбора файлов в готовое поле формы. Построенный на базе компонентов `Dropzone`, `FieldLabel` и `FieldMessage`, он обеспечивает валидацию форматов файлов через `accept`, фильтрацию по предельному размеру через `maxFileSize` и отправку массива валидных файлов `File` через событие `@add`.

**Основные возможности:**

- **Интерактивная загрузка:** Область сброса файлов (Drag and Drop) с поддержкой открытия системного диалога по клику
- **Одиночный и множественный выбор:** Настраиваемый выбор одного или нескольких файлов с помощью свойства `multiple`
- **Фильтрация типов и размера:** Ограничение по MIME-типам/расширениям (`accept`) и максимальному размеру файла в байтах (`maxFileSize`)
- **Анатомия поля формы:** Полноценная интеграция с заголовком поля (`FieldLabel`), счетчиком, подсказками и сообщениями об ошибках (`FieldMessage`)
- **Обработка событий:** Вызов события `@add` с массивом валидированных файлов
- **Программный API:** Экспорт метода `open()` для программного вызова окна выбора файлов
- **Доступность:** Полное соответствие стандартам ARIA со связыванием `aria-labelledby` и `aria-describedby`
- **Состояния:** Встроенная поддержка состояний `disabled`, `readonly` и скелетона (`isSkeleton`)

**Типовые сценарии использования:**

- Поля прикрепления документов и файлов в формах
- Загрузка резюме, сканов документов и изображений
- Интерактивные панели импорта данных с отображением статуса валидации

<Source
    code={`
<script setup>
const onAdd = (files) => {
  console.log('Загруженные файлы:', files)
}
</script>

<template>
  <InputFileDropzone
    label="Загрузка документов"
    helper-message="PDF, DOCX до 10 МБ"
    accept=".pdf,.docx"
    :max-file-size="10485760"
    @add="onAdd"
  />
</template>
  `}
    language="html"
/>
