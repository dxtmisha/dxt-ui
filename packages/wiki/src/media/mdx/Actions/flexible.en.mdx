## Adaptive layout behavior

The `flexible` property determines automatic switching to block mode when space is limited.

**Possible values:**

- `false` (default) — fixed layout behavior
- `true` — enables automatic transition to block mode when space is constrained

When enabled, it applies block layout behavior when available space becomes smaller than a defined breakpoint, allowing interfaces to display cleanly on both desktop and mobile devices without additional code.

<Source
    code={`
<!-- Automatic transition on narrow viewports/containers -->
<Actions flexible :list="[...]" />

<!-- Explicitly disabled -->
<Actions :flexible="false" :list="[...]" />
  `}
    language="html"
/>
