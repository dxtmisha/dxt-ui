## Adaptive layout behavior

The `flexible` property enables automatic switching from horizontal alignment to `block` layout (`column-reverse` with full-width buttons and hidden secondary/spacer elements) when available space falls below a configured breakpoint.

**Supported breakpoint groups:**

- **Viewport-based (`media-max-group`)** — switches to `block` layout when the browser viewport width falls below the chosen design-system breakpoint.
- **Container-based (`container-max-group`)** — switches to `block` layout when the nearest ancestor with `container-type: inline-size` becomes narrower than the chosen design-system breakpoint.

Available option values are generated by each design system from its breakpoint scale and are listed in the component Controls table.
