Component for grouping and organizing list items with a collapsible structure.

`ListGroup` manages hierarchical content organization with expand/collapse functionality. It integrates with `MotionTransform` for smooth animations, supports nested groups, exposes `getOpen()` state inspection, and provides semantic `role="group"` accessibility.

**Key features:**

- Hierarchical content organization with nested group support
- Expand/collapse transitions via `MotionTransform` (`adaptive="planeAlways"`, `autoClose={false}`)
- State management via the `open` prop or interactive header toggle
- Optional visual separator between consecutive groups via `divider`
- Semantic `role="group"` and `data-open` / `data-divider` root attributes
- Content distribution through `head` and `list` slots

**Common use cases:**

- Grouping list items by categories
- Creating tree-like navigation structures
- Organizing settings and options by sections
- Multi-level menus and expandable lists
