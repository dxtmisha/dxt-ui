Компонент для группировки и организации элементов списка со сворачиваемой структурой.

`ListGroup` управляет иерархической организацией контента с возможностью разворачивания и сворачивания групп. Компонент интегрируется с `MotionTransform` для плавных анимаций, поддерживает вложенные группы, предоставляет метод `getOpen()` и семантический атрибут `role="group"`.

**Основные возможности:**

- Иерархическая организация контента с поддержкой вложенных групп
- Анимации разворачивания/сворачивания через `MotionTransform` (`adaptive="planeAlways"`, `autoClose={false}`)
- Управление состоянием открытия через проп `open` или интерактивный клик по заголовку
- Визуальный разделитель между последовательными группами через проп `divider`
- Семантический `role="group"` и атрибуты состояния `data-open` / `data-divider`
- Гибкая настройка разметки через слоты `head` и `list`

**Типичные сценарии использования:**

- Группировка элементов списка по категориям
- Создание древовидных структур навигации
- Организация настроек и опций по разделам
- Многоуровневые меню и раскрывающиеся списки

<Source
    code={`
<script setup>
import { ref } from 'vue'

const isOpen = ref(true)
</script>

<template>
  <List>
    <ListGroup :open="isOpen" divider>
      <template #head="{ open }">
        <div class="group-header">
          <span>{{ open ? '▼' : '▶' }}</span>
          <span>Группа элементов</span>
        </div>
      </template>

      <template #list>
        <ListItem label="Элемент 1" value="1" />
        <ListItem label="Элемент 2" value="2" />
        <ListItem label="Элемент 3" value="3" />
      </template>
    </ListGroup>
  </List>
</template>
  `}
    language="html"
/>

> ListGroup упрощает создание доступных сворачиваемых групп элементов на базе слотов `head` и `list`.
