Компонент `TableFlexRecord` представляет собой строку флекс-таблицы на основе flexbox, рендерящую контейнер `<div role="row">` и сопоставляющую список колонок `columns` с ячейками (`TableFlexItem` или `TableFlexHeaderItem`). Он расширяет `TableRecord`, добавляя ленивый рендеринг в области видимости (`lazy` и `defaultHeight`) для больших наборов данных.

**Основные возможности:**

- **Флекс-семантика строки:** Рендерит `<div role="row">` с автоматическими атрибутами `data-key`, `aria-selected` и `aria-disabled`
- **Режимы шапки и подвала:** Поддерживает строки заголовка через `isHeader` (слоты `#header-<column>` / `#header-default`) и итоговые строки подвала через `isFoot` (слоты `#foot-<column>` / `#foot-default`)
- **Ленивый рендеринг в области видимости:** Откладывает рендеринг ячеек строк вне viewport через `lazy` (включен по умолчанию) и резервирует минимальную высоту строки через `defaultHeight` (устанавливает CSS-переменную `--[design]-tableFlexRecord-sys-minHeight`); автоматически отключается для строк с `isHeader` или `isFoot`
- **Кастомизация через слоты:** Поддерживает слоты для колонок и резервные слоты (`#<column>`, `#default`, `#header-<column>`, `#header-default`, `#foot-<column>`, `#foot-default`)
- **Проброс состояний и событий:** Передаёт `selected`, `disabled`, `isSkeleton`, `stickyTop`, `stickyLeft`, `tableItemAttrs`, `tableItemColumnAttrs` в ячейки и пробрасывает событие `@sort` из заголовков

**Типовые сценарии использования:**

- Строки шапки, данных и подвала внутри компонента `TableFlex`
- Длинные прокручиваемые флекс-таблицы с оптимизацией через `lazy` и `defaultHeight`
- Самостоятельные строки записей с индивидуальным оформлением колонок через слоты

<Source
    code={`
<template>
  <!-- Строка заголовка -->
  <TableFlexRecord
    :isHeader="true"
    :columns="['id', 'name', 'role', 'status']"
    :item="{ id: 'ID', name: 'Имя', role: 'Должность', status: 'Статус' }"
  />

  <!-- Ленивая строка данных с заданной минимальной высотой -->
  <TableFlexRecord
    :lazy="true"
    :defaultHeight="48"
    :columns="['id', 'name', 'role', 'status']"
    :item="{ id: '1', name: 'Misha', role: 'Разработчик', status: 'Активен' }"
  />

  <!-- Строка подвала с кастомизацией слота #foot-* -->
  <TableFlexRecord
    :isFoot="true"
    :columns="['id', 'name', 'role', 'status']"
    :item="{ id: 'Итого', name: '1 запись', role: '-', status: 'Активен' }"
  >
    <template #foot-name="{ value }">
      <strong>{{ value }}</strong>
    </template>
  </TableFlexRecord>
</template>
  `}
    language="html"
/>

> TableFlexRecord координирует строки флекс-таблицы в режимах шапки, ленивых данных и подвала, обеспечивая гибкую работу со слотами и доступную семантику.
