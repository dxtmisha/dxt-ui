Компонент строки флекс-таблицы на основе flexbox, координирующий рендеринг флекс-ячеек из набора данных и индексов колонок. Используется внутри контейнеров флекс-таблиц для создания гибких строк.

**Ключевые особенности:**

- Флекс-макет строки для динамических наборов данных
- Автоматический рендеринг ячеек путем сопоставления `columns` и свойств объекта `item`
- Поддержка строк заголовков флекс-таблицы (`isHeader`)
- Кастомное переопределение слотов ячеек по индексам колонок
- Динамические состояния скелетона (`isSkeleton`)
- Состояния выбора и отключения на уровне всей строки (`selected`, `disabled`)

</script>

<template>

    />
  </div>
</template>
  `}

> TableFlexRecord предоставляет флекс-макет и координацию для элементов строк таблицы, автоматически рендеря ячейки на основе структуры данных.
