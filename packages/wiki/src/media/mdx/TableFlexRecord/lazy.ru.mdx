## Ленивая загрузка и высота по умолчанию

Свойство `lazy` (включено по умолчанию для строк данных) активирует отложенный рендеринг ячеек через `IntersectionObserver`. Строки вне области видимости не создают дочерние DOM-узлы до приближения к экрану, тогда как строки с `isHeader` и `isFoot` всегда рендерятся сразу.

Свойство `defaultHeight` (число в пикселях, например `48`, или любая валидная CSS-единица, например `'4rem'`) задаёт минимальную высоту ленивой строки через CSS-переменную `--[design]-tableFlexRecord-sys-minHeight` и предотвращает скачки макета при прокрутке.
