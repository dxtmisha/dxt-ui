## Description

A component for managing sticky header positioning, scroll metrics calculations, transformation threshold percentages, and disappears scroll mode updates.

Headroom tracks scrolling activity on a target element or window and dynamically updates its sticky state, dataset attributes, transformation properties, and disappearing offset positioning.

**Key features:**

- Automatic scroll tracking and sticky state evaluation
- Disappears mode that hides the element on scroll down and reveals it on scroll up
- Dynamic transform custom CSS properties and dataset attributes for styling
- Customizable container element or target window
- Configurable HTML tag for rendering

**Common use cases:**

- Sticky site navigation bars and headers
- Auto-hiding headers on mobile and desktop views
- Scroll-linked header animations and visual transformations
- Sticky toolbar containers with dynamic offset calculations
