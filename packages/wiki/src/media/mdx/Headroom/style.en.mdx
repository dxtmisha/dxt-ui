## Custom CSS Properties and Dataset Attributes

**CSS Variables:**

- `--*-sys-top` — top offset position in pixels for `disappears` scroll mode
- `--*-sys-threshold` — transformation threshold value in pixels (`transformThreshold`)
- `--*-sys-value` — current scroll transformation offset in pixels, capped at threshold
- `--*-sys-percent` — transformation percentage ratio from `0` to `1`
- `--*-sys-difference` — difference in pixels between previous and current scroll positions

**Dataset Attributes:**

- `data-headroom` — sticky state indication (`sticky` when scroll > 0, otherwise `none`)
- `data-headroom-direction` — scroll movement direction (`down`, `up`, or `none`)
- `data-headroom-transform` — threshold value representation when `transformThreshold` > 0

Where `*` is the component class name (e.g., `d1-headroom`, `headroom`).
