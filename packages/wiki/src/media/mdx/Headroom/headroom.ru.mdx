Компонент для управления липким положением шапки, вычислениями метрик прокрутки, порога трансформации и смещения в режиме disappears.

Headroom отслеживает активность прокрутки на целевом элементе или окне и динамически обновляет статус прилипания (sticky), стили трансформации и позиционирование смещения в режиме скрытия.

**Ключевые особенности:**

- Автоматическое отслеживание прокрутки и оценка состояния прилипания
- Режим disappears, скрывающий элемент при прокрутке вниз и показывающий при прокрутке вверх
- Динамические пользовательские свойства CSS трансформации (`--headroom-sys-scroll`, `--headroom-sys-percent`, `--headroom-sys-transform`)
- Настраиваемый целевой элемент или окно для прослушивания событий
- Настраиваемый HTML-тег для рендеринга
