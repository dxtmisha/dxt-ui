## Описание

Компонент для управления липким положением шапки (sticky header), вычислениями метрик прокрутки, порогом трансформации и смещением в режиме disappears.

Headroom отслеживает активность прокрутки на целевом элементе или окне и динамически обновляет статус прилипания (`sticky`), дата-атрибуты, свойства трансформации и позиционирование смещения в режиме скрытия.

**Основные возможности:**

- Автоматическое отслеживание прокрутки и оценка состояния прилипания (`isSticky`)
- Режим `disappears`, скрывающий элемент при прокрутке вниз и показывающий при прокрутке вверх
- Динамические свойства CSS трансформации и дата-атрибуты для стилизации
- Настраиваемый целевой элемент или окно для прослушивания событий
- Настраиваемый HTML-тег для рендеринга

**Типичные сценарии использования:**

- Липкие шапки сайта и панели навигации
- Автоматически скрывающиеся панели при прокрутке страницы вниз
- Анимации и визуальные трансформации шапок, привязанные к позиции скролла
- Липкие панели инструментов с динамическим расчетом отступа

> Headroom — компонент для создания фиксированных и скрывающихся шапок с поддержкой анимаций, вычисления метрик прокрутки и динамической кастомизации.
