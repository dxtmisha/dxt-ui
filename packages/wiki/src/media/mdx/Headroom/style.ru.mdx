## Пользовательские CSS свойства и дата-атрибуты

**CSS переменные:**

- `--*-sys-top` — значение верхнего смещения в пикселях для режима скрытия `disappears`
- `--*-sys-threshold` — пороговое значение трансформации в пикселях (`transformThreshold`)
- `--*-sys-value` — текущее смещение трансформации прокрутки в пикселях, ограниченное порогом
- `--*-sys-percent` — процентное соотношение трансформации от `0` до `1`
- `--*-sys-difference` — разница в пикселях между предыдущей и текущей позициями прокрутки

**Дата-атрибуты:**

- `data-headroom` — состояние липкости (`sticky` при прокрутке > 0, иначе `none`)
- `data-headroom-direction` — направление прокрутки страницы (`down`, `up` или `none`)
- `data-headroom-transform` — пороговое значение трансформации при заданном `transformThreshold`

Где `*` — название класса компонента (например, `d1-headroom`, `headroom`).
