The `TextLabel` component is a lightweight text primitive for rendering labels, titles, and semantic headings with dynamic HTML wrapper tag support.

It delegates rendering through `LabelInclude` with lazy instantiation, automatically omitting empty DOM output when neither the `label` prop nor the `default` slot contains content while preserving numeric `0`, custom `labelId`, and merged external attributes such as `for` and `aria-*`.

**Key features:**

- **Dynamic Wrapper Tag:** Configurable semantic HTML tag (`div`, `span`, `p`, `h1`–`h6`, `label`, etc.) via `tag` (defaults to `div`)
- **Zero-Overhead Empty State:** Lazily skips `LabelInclude` allocation and renders nothing for empty or whitespace-only values
- **Slot & Prop Composition:** Supports text/numeric `label` values (including `0`) and rich markup via the `default` slot
- **Accessibility Ready:** Generates deterministic element IDs or applies custom `labelId` for `aria-labelledby` and semantic `<label for="...">` bindings

**Common use cases:**

- Rendering section headings, titles, and compact metadata labels
- Associating semantic `<label>` elements with form inputs
- Presenting unified design-system typography across lightweight UI layouts
