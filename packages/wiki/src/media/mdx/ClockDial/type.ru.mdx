## Типы циферблата (`type`)

Свойство `type` определяет формат шкалы циферблата, количество делений и шаг поворота стрелки:

- `12` *(по умолчанию)* — классический 12-часовой циферблат с делениями от 1 до 12 и шагом поворота 30°. При нулевом значении стрелка выбора скрывается.
- `24` — двухрядный 24-часовой циферблат. Внешний круг содержит дневные часы (1–12), внутренний ряд — ночные часы (13–24 и 0) со сниженной контрастностью. При выборе внутреннего круга компонент активирует модификатор `--section`.
- `minute` — 60-минутный циферблат с шагом 6°. Числовые подписи отображаются с интервалом в 5 минут (00, 05, 10...), а промежуточные деления отображают точку-индикатор при выборе.
- `second` — 60-секундный циферблат с шагом 6°. Числовые метки отображаются каждые 5 секунд, промежуточные деления выводятся точечными индикаторами.

### Ограничения диапазона и шаг (`min`, `max`, `step`)

Компонент позволяет задавать ограничения для допустимых значений:

- `min` — минимальное допустимое значение. Деления меньше `min` становятся неактивными (`disabled`).
- `max` — максимальное допустимое значение. Деления больше `max` становятся неактивными (`disabled`).
- `step` — дискретный шаг делений. Значения, не кратные `step` относительно `min`, блокируются. При перетаскивании стрелка автоматически притягивается к ближайшему активному делению.

<script setup>
import { ref } from 'vue'

const hour = ref(10)
const hour24 = ref(16)

  <!-- Минуты с шагом 5 минут -->
  <ClockDial v-model="minute" type="minute" :step="5" />
