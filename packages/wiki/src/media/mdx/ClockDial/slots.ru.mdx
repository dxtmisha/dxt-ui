- `default?(props: any): any` — Слот по умолчанию для пользовательского контента, отображаемого в центре циферблата (например, цифрового времени или иконки).
- `item?(props: ClockDialMarkSlot): any` — Слот для кастомного рендеринга отдельного элемента деления/метки часов.

> **ClockDialMarkSlot:**
> - `item: ClockDialMarkItem` — объект конфигурации элемента метки циферблата.
