Компонент оповещения (`Alert`), предназначенный для отображения контекстных сообщений, статусных баннеров и закрываемых уведомлений.

Компонент поддерживает ведущую и хвостовую иконки, заголовок (`label`), описание (`description`), слоты содержимого и правой области, хвостовую кнопку действия (`button`), встроенные ссылки (`links`), группы кнопок действий (`actionsList` / `actionsSecondary`) и кнопку закрытия (`closeButton`) с плавным переходом прозрачности.

<Source
    code={`
<template>
  <Alert
    icon="info"
    label="Обновление системы"
    description="Новая версия готова к установке."
    button="Обновить"
    close-button
    @click-lite="onAction"
    @close="onClose"
  />
</template>
  `}
    language="html"
/>

**Основные возможности:**

- Структурированный flex-макет: ведущая иконка, область контекста (`label`, `description`, `#body`, `links`, `actions`), правая кнопка/слот `#trailing` и опциональная кнопка закрытия `closeButton`
- Автоматическая связка WAI-ARIA (`role`, `aria-live`, `aria-labelledby`, `aria-describedby` и локализованный `aria-label` кнопки закрытия через `textClose`)
- Хвостовая кнопка `button` с поддержкой строк, числа `0` и объектных привязок, генерирующая события `click` / `clickLite`
- Встроенные ссылки (`links` / `linksAttrs`) и панель действий (`actionsList` / `actionsSecondary` / `actionsHide`)
- Плавное скрытие с генерацией события `close` после завершения CSS-перехода `opacity`

**Типичные сценарии использования:**

- Встроенные баннеры статуса для информационных, успешных, предупреждающих и критических сообщений
- Закрываемые объявления уровня страницы с быстрыми ссылками или действиями
- Карточки обратной связи с произвольным содержимым в слотах `#body` и `#trailing`

> Для оповещений с многострочным описанием передавайте `:item-center="false"`, чтобы ведущая иконка и кнопка закрытия оставались выровненными по первой строке текста.
