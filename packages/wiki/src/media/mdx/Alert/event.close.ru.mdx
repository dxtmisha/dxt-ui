### `close`

Срабатывает после нажатия на кнопку закрытия (`closeButton`), завершения CSS-перехода скрытия `opacity` и удаления оповещения из DOM.

**Параметры:**

- Нет (`[]`)

<Source
    code={`
<script setup>
const handleClose = () => {
  console.log('Оповещение скрыто')
}
</script>

<template>
  <Alert
    label="Заголовок оповещения"
    close-button
    @close="handleClose"
  />
</template>
  `}
    language="html"
/>
