### `close`

Fires after the user clicks the close button (`closeButton`) and the alert finishes its opacity exit transition and is removed from render.

**Parameters:**

- None (`[]`)

<Source
    code={`
<script setup>
const handleClose = () => {
  console.log('Alert dismissed')
}
</script>

<template>
  <Alert
    label="Alert Title"
    close-button
    @close="handleClose"
  />
</template>
  `}
    language="html"
/>
