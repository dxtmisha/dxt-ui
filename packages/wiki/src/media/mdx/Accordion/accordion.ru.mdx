Раскрывающийся контейнер для организации контента с плавными анимациями открытия и закрытия, упрощающий структурирование информации в интерфейсе.

Accordion объединяет интерактивный заголовок на базе Cell и анимируемую область содержимого на базе MotionTransform. Компонент поддерживает двустороннее связывание состояния (`v-model:open`), визуальные разделители, настройку атрибутов заголовка и трансформации (`cellAttrs`, `motionTransformAttrs`) и гибкую кастомизацию через слоты.

**Основные возможности:**

- Плавные анимации раскрытия и сворачивания
- Заголовок с `label`, `description`, иконкой (`icon`) и настраиваемой стрелкой (`iconArrowDown`)
- Контролируемое (`v-model:open`, `v-model:modelOpen`) и неконтролируемое (`open`, `clickOpen`, `autoClose`) управление состоянием
- Программное управление (`toggle`, `toOpen`, `toClose`, `setOpen`, `getOpen`, `isShow`)
- Визуальный разделитель между секциями (`divider`)
- Настройка атрибутов заголовка и анимации (`cellAttrs`, `motionTransformAttrs`)
- Кастомизация через слоты `#label`, `#description`, `#caption`, `#trailing`, `#body` и `#default`

**Типичные сценарии использования:**

- FAQ секции
- Панели настроек
- Фильтры товаров
- Информационные блоки
- Меню с подразделами

<script setup>
import { ref } from 'vue'

const isOpen = ref(false)
</script>

<template>
  <!-- Базовый аккордеон -->
  <Accordion label="Вопрос 1" description="Нажмите, чтобы увидеть ответ">
    <p>Ответ на вопрос.</p>
  </Accordion>

  <!-- Управляемый аккордеон с иконкой -->
  <Accordion
    v-model:open="isOpen"
    label="Настройки"
    icon="settings"
  >
    <p>Содержимое настроек.</p>
  </Accordion>

  <!-- С кастомными слотами заголовка -->
  <Accordion :divider="false">
    <template #label>Свой заголовок</template>
    <template #trailing>Метка</template>
    <template #default>
      <p>Содержимое секции.</p>
    </template>
  </Accordion>
</template>
  `}
