Expandable container for organizing content with smooth opening and closing animations, simplifying information structuring in the interface.

Accordion provides an interactive header built on Cell and animated collapsible body powered by MotionTransform. The component supports two-way state binding (`v-model:open`), visual dividers, header/cell attribute customization (`cellAttrs`, `motionTransformAttrs`), and flexible slot overrides.

**Key features:**

- Smooth expand and collapse animations
- Header with `label`, `description`, `icon`, and customizable expand arrow (`iconArrowDown`)
- Controlled (`v-model:open`, `v-model:modelOpen`) and uncontrolled (`open`, `clickOpen`, `autoClose`) state management
- Programmatic control (`toggle`, `toOpen`, `toClose`, `setOpen`, `getOpen`, `isShow`)
- Visual divider between sections (`divider`)
- Header and Cell attribute customization (`cellAttrs`, `motionTransformAttrs`)
- Content customization via `#label`, `#description`, `#caption`, `#trailing`, `#body`, and `#default` slots

**Common use cases:**

- FAQ sections
- Settings panels
- Product filters
- Information blocks
- Menus with subsections
