- `getSelected(): number` — Returns the currently active slide index (1-based).
- `getCount(): number` — Returns the total count of slides.
- `set(selected: number): void` — Programmatically sets the active slide index.
- `next(): void` — Advances to the next slide, cycling back to the first slide when the end is reached.
- `previous(): void` — Moves to the previous slide, cycling to the last slide when at the beginning.
