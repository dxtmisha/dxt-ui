The `CarouselPagination` component provides navigation and progress indicators for carousels, sliders, and multi-step viewports. It supports various visual presentation modes including bullets (dots), lines, fractional counters, and linear progress bars.

The component handles slide indexing, dynamic scaling of indicators for long lists, two-way state synchronization, and customizable templates and slots for bespoke designs.

**Key features:**

- Multiple display types: classic dots (`bullets`), line segments (`lines`), fraction counter (`fraction`), and continuous progress bar (`progressbar`)
- Dynamic scaling mode (`dynamic`) that smoothly scales edge indicators for large slide counts
- Bidirectional state binding via `v-model:selected`
- Customizable visible items count in dynamic mode (`visible`)
- Horizontal and vertical layout orientation support (`vertical`)
- Configurable interactive bullet clicks (`clickable`)
- Automatic concealment when only a single slide exists (`hideIfOne`)
- Template-driven fraction formatting (`template`, e.g. `[active] / [total]`)
- Comprehensive scoped slots for custom bullet items, fraction displays, and progress bars with pre-computed `binds`

**Common use cases:**

- Indicating active slides and navigation in media carousels and banners
- Multi-step wizards, onboarding flows, and walkthrough sequences
- Image galleries with large numbers of slides requiring compact dynamic pagination
- Story-like cards and mobile viewport progress indicators
