Компонент `CarouselPagination` предназначен для отображения индикаторов навигации и прогресса в каруселях, слайдерах и многошаговых сценариях. Он поддерживает различные визуальные режимы представления: буллеты (точки), линии, дробные счетчики и линейные полосы прогресса.

Компонент обеспечивает управление индексацией слайдов, динамическое масштабирование индикаторов для длинных списков, двустороннюю синхронизацию состояния, а также гибкую кастомизацию через шаблоны и слоты.

**Основные возможности:**

- Различные типы отображения: классические точки (`bullets`), линии (`lines`), дробный счетчик (`fraction`) и непрерывная полоса прогресса (`progressbar`)
- Динамический режим (`dynamic`), плавно уменьшающий крайние буллеты при большом количестве слайдов
- Двусторонняя синхронизация выбранного слайда через `v-model:selected`
- Настройка количества видимых буллетов в динамическом режиме (`visible`)
- Поддержка горизонтальной и вертикальной ориентации (`vertical`)
- Настройка интерактивности кликов по буллетам (`clickable`)
- Автоматическое скрытие пагинации, если слайд всего один (`hideIfOne`)
- Форматирование дробного счетчика через шаблон (`template`, например `[active] / [total]`)
- Слоты с готовыми объектами привязок (`binds`) для кастомизации элементов, дроби и прогресса

**Типичные сценарии использования:**

- Индикация активного слайда и навигация в медиа-каруселях и промо-баннерах
- Многошаговые формы, мастера настройки и обучающие экраны (onboarding)
- Галереи изображений с большим числом слайдов, требующие компактной динамической пагинации
- Истории (stories) и мобильные экраны с полосой прогресса

<script setup>
import { ref } from 'vue'

const currentSlide = ref(1)
</script>

<template>
  <div class="carousel-pagination-demo">
    <!-- Классические буллеты -->
    <CarouselPagination
      v-model:selected="currentSlide"
      :count="5"
    />

    <!-- Динамические буллеты для больших коллекций -->
    <CarouselPagination
      v-model:selected="currentSlide"
      :count="10"
      dynamic
      :visible="5"
    />

    <!-- Дробный счетчик -->
    <CarouselPagination
      v-model:selected="currentSlide"
      :count="5"
      type="fraction"
    />

    <!-- Полоса прогресса -->
    <CarouselPagination
      v-model:selected="currentSlide"
      :count="5"
      type="progressbar"
    />
  </div>
</template>
  `}
    language="html"

> CarouselPagination представляет собой универсальный компонент пагинации, обеспечивающий удобную визуальную обратную связь и управление слайдами с высокой степенью доступности.
