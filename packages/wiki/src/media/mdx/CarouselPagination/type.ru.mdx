## Типы отображения

Свойство `type` определяет визуальный формат и способ отображения индикаторов пагинации:

- **`bullets`** (по умолчанию) — Классические круглые точки (буллеты). Каждая точка соответствует одному слайду; активный слайд выделяется цветом.
- **`lines`** — Вытянутые сегменты-линии. Обеспечивают современный минималистичный вид индикаторов вместо стандартных точек.
- **`fraction`** — Текстовый дробный счетчик, отображающий текущий номер слайда относительно общего количества (например, `1 / 5`). Формат настраивается через свойство `template`.
- **`progressbar`** — Непрерывная полоса прогресса, заполняющаяся пропорционально положению активного слайда от `0%` до `100%`.
