Container component for grouping multiple buttons into a single accessible action block.

`ButtonGroup` organizes related buttons into a logical group (`role="group"` by default) with shared layout context (`area`), orientation, wrapping, skeleton state, and delegated click events.

**Key Features:**

- Horizontal and vertical orientations (`orientation`)
- Automatic multi-line wrapping (`wrap`) when horizontal space is constrained
- Forwarding shared attributes to all buttons via `buttonAttrs`
- Flexible composition via the `list` array or the `#default` slot
- Accessible `role="group"` semantics with customizable `role` and `ariaLabel`
- Zero-duplication skeleton loading state (`isSkeleton`) forwarded automatically to child buttons

**Typical Usage Scenarios:**

- Formatting and editor toolbars
- Grouped form or dialog actions
- Segmented filter, view-switcher, or pagination controls
- Action bars inside cards, headers, or list items
