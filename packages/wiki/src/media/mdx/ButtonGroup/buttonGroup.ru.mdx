Компонент-контейнер для группировки нескольких кнопок в единый семантический блок действий.

`ButtonGroup` объединяет связанные кнопки в логическую группу (`role="group"` по умолчанию) с общим контекстом области (`area`), ориентацией, переносом строк, состоянием скелетона и делегированной обработкой кликов.

**Основные возможности:**

- Горизонтальная и вертикальная ориентация (`orientation`)
- Автоматический многострочный перенос кнопок (`wrap`) при нехватке места
- Передача общих атрибутов всем кнопкам через `buttonAttrs`
- Гибкое управление набором кнопок через массив `list` или слот `#default`
- Доступная семантика `role="group"` с поддержкой настраиваемых `role` и `ariaLabel`
- Состояние загрузки скелетона без дублирования разметки (`isSkeleton`), автоматически пробрасываемое дочерним кнопкам

**Типичные сценарии использования:**

- Панели инструментов и форматирования (toolbars)
- Группы действий в формах и диалоговых окнах
- Переключатели режимов отображения, фильтров или сортировки
- Компактные блоки управления в карточках, заголовках и списках

<template>
  <!-- Базовое использование через список с доступной меткой -->

      { label: 'Назад', icon: 'arrow_back', value: 'back' },
      { label: 'Главная', icon: 'home', value: 'home' },

    ]"
  />

  <!-- Вертикальная ориентация с общими атрибутами кнопок -->
  <ButtonGroup
    orientation="vertical"
    :buttonAttrs="{ inverse: true }"
    :list="[
      { label: 'Сохранить', icon: 'save', value: 'save' },
      { label: 'Удалить', icon: 'delete', value: 'delete' }
    ]"
  />
</template>
