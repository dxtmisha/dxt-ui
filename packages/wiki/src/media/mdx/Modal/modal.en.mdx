A simplified wrapper over the Window component for creating modal dialogs with preconfigured centered positioning settings.

Modal is a specialized component that uses Window with a fixed `adaptive: 'modal'` mode. It is designed to display content that requires immediate user attention, blocking interaction with the main interface. The component automatically centers content, adds a semi-transparent backdrop (overlay), and manages focus.

**Key features:**

- **Centered Modal Presentation:** Pre-configured `Window` wrapper with fixed `adaptive: 'modal'` mode and semi-transparent overlay
- **Two-Way State Control:** Synchronized open state via `v-model:open`, `v-model:modelOpen`, or exposed methods
- **Integrated Bars & Actions:** Built-in `Bars` header (`barsLabel`, `barsDescription`, `barsList`, `barsBackHide`) and `Actions` footer (`actionsList`, `actionsSecondary`) with automatic ARIA linkage
- **Image Banner Support:** Optional banner image with `image` and `imagePosition` (`'top' | 'left'`)
- **Flexible Slots:** Dedicated `#control`, `#title`, `#header`, `#default`, and `#footer` slots
- **Window Configuration & Accessibility:** Full `windowAttrs` forwarding (`persistent`, `closeButton`, `beforeClosing`), focus trapping, `disableFocusReturn`, and ESC/backdrop dismissal

**Differences from Window:**

Modal is a `Window` wrapper with preset `adaptive: 'modal'` plus integrated `Bars` and `Actions` slots, simplifying standard dialog composition without configuring positioning and adaptive modes manually.

**Common use cases:**

- Action confirmation dialogs
- Create/edit forms
- Warnings and informational messages
- Viewing detailed information
- Multi-step wizards
