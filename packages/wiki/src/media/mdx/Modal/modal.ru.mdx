Упрощенная обертка над компонентом Window для создания модальных диалогов с предустановленными настройками центрированного позиционирования.

Modal является специализированным компонентом, который использует Window с фиксированным режимом `adaptive: 'modal'`. Он предназначен для отображения контента, требующего немедленного внимания пользователя, с блокировкой взаимодействия с основным интерфейсом. Компонент автоматически центрирует содержимое, добавляет полупрозрачный фон (overlay) и управляет фокусом.

**Основные возможности:**

- **Центрированное отображение:** Предустановленная обертка над `Window` с фиксированным режимом `adaptive: 'modal'` и полупрозрачным оверлеем
- **Двустороннее управление:** Синхронизация открытия через `v-model:open`, `v-model:modelOpen` или методы `expose`
- **Интеграция Bars и Actions:** Встроенная шапка `Bars` (`barsLabel`, `barsDescription`, `barsList`, `barsBackHide`) и футер `Actions` (`actionsList`, `actionsSecondary`) с автоматической связью ARIA
- **Поддержка баннера изображения:** Настраиваемое изображение через `image` и `imagePosition` (`'top' | 'left'`)
- **Гибкие слоты:** Слоты `#control`, `#title`, `#header`, `#default` и `#footer`
- **Настройка Window и доступность:** Проброс `windowAttrs` (`persistent`, `closeButton`, `beforeClosing`), захват фокуса, `disableFocusReturn` и закрытие по `ESC`/оверлею

**Отличия от Window:**

Modal — это обертка над `Window` с предустановленным `adaptive: 'modal'` и встроенными секциями `Bars` и `Actions`, что упрощает создание стандартных диалоговых окон без ручной настройки позиционирования.

**Типичные сценарии использования:**

- Диалоги подтверждения действий
- Формы создания/редактирования
- Предупреждения и информационные сообщения
- Просмотр детальной информации
- Многошаговые мастера (wizards)

<script setup>
import { ref } from 'vue'

const isModalOpen = ref(false)

const handleBeforeClosing = async () => {
  // Проверка перед закрытием
  return confirm('Закрыть модальное окно?')
}
</script>

<template>
  <button @click="isModalOpen = true">Открыть модальное окно</button>

  <Modal
    v-model:open="isModalOpen"
    :windowAttrs="{ beforeClosing: handleBeforeClosing, closeButton: true }"
  >
    <template #title>
      <h2>Подтверждение действия</h2>
    </template>

    <template #default>
      <p>Вы уверены, что хотите выполнить это действие?</p>
      <p>Это действие нельзя будет отменить.</p>
    </template>

    <template #footer="{ classesWindow }">
      <button :class="classesWindow.close">Отмена</button>
      <button @click="performAction">Подтвердить</button>
    </template>
  </Modal>
</template>
  `}
    language="html"
/>

> Modal объединяет оверлей, управление фокусом и жизненный цикл Window со встроенными панелями Bars и кнопками Actions для типовых диалоговых сценариев.
