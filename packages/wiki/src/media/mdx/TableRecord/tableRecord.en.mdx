The table row component representing a `<tr>` tag. It coordinates the rendering of a set of column cells (`TableHeaderItem` for `isHeader`, `isFoot`, or per-cell `isHeader`, or `TableItem` for data cells) based on a data record (`item` prop) and a list of column indexes (`columns` prop).

**Key Features:**

- Standard table row container (`tr` tag) with automatic `data-key` resolution
- Dynamic cell generation based on `columns` keys and `item` values
- Header row mode (`isHeader`, setting `scope="col"`), footer row mode (`isFoot`, omitting `scope="col"` and resolving `#foot-*` slots), and per-cell row headers (`isHeader: true` on an individual cell object, setting `scope="row"`)
- Selectable and disabled states applied row-wide (`selected`, `disabled`) with ARIA synchronization
- Dynamic custom slots per column (`#<column>`, `#default`, `#header-<column>`, `#header-default`, `#foot-<column>`, `#foot-default`)

> TableRecord simplifies table generation by automating cell rendering from key-value data structures, with full support for custom slot overrides per column.
