Компонент строки таблицы, представляющий тег `<tr>`. Он координирует рендеринг набора ячеек столбцов (`TableHeaderItem` для `isHeader`, `isFoot` или отдельной ячейки с `isHeader`, либо `TableItem` для обычных ячеек данных) на основе записи данных (свойство `item`) и списка индексов столбцов (свойство `columns`).

**Ключевые особенности:**

- Стандартный контейнер строки таблицы (тег `tr`) с автоматическим определением `data-key`
- Динамическая генерация ячеек на основе ключей `columns` и значений `item`
- Режим строки заголовка (`isHeader` с `scope="col"`), режим строки подвала (`isFoot` без `scope="col"` и со слотами `#foot-*`), а также заголовки отдельных ячеек строки (`isHeader: true` в объекте ячейки с `scope="row"`)
- Состояния выбора и отключения, применяемые ко всей строке (`selected`, `disabled`) с синхронизацией ARIA
- Динамические пользовательские слоты для каждой колонки (`#<column>`, `#default`, `#header-<column>`, `#header-default`, `#foot-<column>`, `#foot-default`)

<Source
    code={`
<script setup>
</script>

<template>
  <table>
    <thead>
      <!-- Строка заголовка -->
      <TableRecord
        :isHeader="true"
        :columns="['name', 'role']"
        :item="{ name: 'Имя', role: 'Роль' }"
      />
    </thead>

    <tbody>
      <!-- Строка данных -->
      <TableRecord
        :columns="['name', 'role']"
        :item="{ name: 'Алиса', role: 'Разработчик' }"
      />
    </tbody>

    <tfoot>
      <!-- Строка подвала -->
      <TableRecord
        :isFoot="true"
        :columns="['name', 'role']"
        :item="{ name: 'Итого', role: '1 пользователь' }"
      />
    </tfoot>
  </table>
</template>
  `}
    language="html"
/>

> TableRecord упрощает создание таблиц путем автоматизации рендеринга ячеек на основе структур данных «ключ-значение» с полной поддержкой переопределения через пользовательские слоты для каждой колонки.
