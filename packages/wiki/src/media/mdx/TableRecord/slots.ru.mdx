- `[column: string](props: TableRecordItemSlotProps): any` — Динамический слот для рендеринга пользовательской ячейки данных для указанного индекса колонки.
- `default(props: TableRecordItemSlotProps): any` — Резервный слот для ячеек данных без отдельного слота колонки.
- `header-[column: string](props: TableRecordItemSlotProps): any` — Динамический слот для рендеринга пользовательской ячейки заголовка при активном `isHeader`.

- `foot-[column: string](props: TableRecordItemSlotProps): any` — Динамический слот для рендеринга пользовательской ячейки подвала при активном `isFoot`.
- `foot-default(props: TableRecordItemSlotProps): any` — Резервный слот для ячеек подвала без отдельного слота `foot-<column>`.

> **TableRecordItemSlotProps:**
> - `item: any` — Объект данных строки.
> - `value: any` — Текущее значение ячейки.
> - `classes: { label: string, description: string }` — Вспомогательные имена классов элементов ячейки.

> - `index: string` — Индекс колонки.
> - `slotsName: string` — Имя слота.
