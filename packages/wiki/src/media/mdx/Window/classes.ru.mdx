## CSS классы для управления поведением

Рекомендуется брать классы из параметров слота (`#default="{ classesWindow }"`, `#footer="{ classesWindow }"` и т.д.):

- `classesWindow.static` (`*--static`) — отменяет срабатывание `autoClose` и клик-действий при клике на элемент **внутри** окна (используйте этот класс, чтобы меню или окно с `autoClose` не закрывалось при клике по элементу)
- `classesWindow.close` (`*--close`) — явно закрывает текущее окно при клике
- `classesWindow.block` (`*--block`) — применяется к **контролу или обёртке контрола дочернего окна**, блокируя закрытие родительского окна при взаимодействии
- `classesWindow.blockChildren` (`*--blockChildren`) — помещается внутрь тела окна и запрещает закрытие окна по клику на фон (backdrop)
- `classesWindow.blockOther` (`*--blockOther`) — запрещает закрытие нижележащих открытых окон, пока активно текущее окно
- `classesWindow.controlOpenOnly` (`*--controlOpenOnly`) — применяется к контролу, чтобы он только открывал окно (не закрывая при повторном клике)
- `classesWindow.controlStatic` (`*--controlStatic`) — отключает открытие окна при клике по контролу

Где `*` — название класса компонента (например, `d1-window`, `m3-window`).
