## CSS Classes for Behavior Control

Expose `classesWindow` from slot props (`#default="{ classesWindow }"`, `#footer="{ classesWindow }"`, etc.) instead of hardcoding class names:

- `classesWindow.static` (`*--static`) — prevents `autoClose` dismissal and click actions when clicking an element **inside** the window (use this to keep an `autoClose` menu/window open on click)
- `classesWindow.close` (`*--close`) — explicitly closes the current window when clicked
- `classesWindow.block` (`*--block`) — placed on a **child window control/wrapper** to prevent closing the parent/current window on click
- `classesWindow.blockChildren` (`*--blockChildren`) — placed inside a window body to prevent closing that window on backdrop click
- `classesWindow.blockOther` (`*--blockOther`) — prevents underlying open windows from closing while this window is active
- `classesWindow.controlOpenOnly` (`*--controlOpenOnly`) — placed on a control so clicking it only opens the window (never closes)
- `classesWindow.controlStatic` (`*--controlStatic`) — placed on a control to disable opening the window on click

Where `*` is the component class name (e.g., `d1-window`, `m3-window`).
