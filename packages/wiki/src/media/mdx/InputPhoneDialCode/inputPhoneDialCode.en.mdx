Trigger button component for selecting a country phone dial code via a country menu popup.

InputPhoneDialCode is a compact trigger button that opens a **MenuCountry** popup, allowing users to select a country and its associated phone dial code. It automatically detects the user's current country via `Geo.getCountry()` as the default value and reactively binds the selection via `v-model:model-selected` or `value` + `@update:selected`.

**Key features:**

- **Automatic Country Detection:** Detects the default country via `Geo.getCountry()`
- **Country Popup Selection:** Opens a `MenuCountry` popup displaying country flags, names, grouped alternative dial prefixes (`DO`, `VA`), and phone dial codes (`showPhoneCode: true`)
- **Direct Filtering & Search:** Supports direct `countryList`, `showSearch`, `filterMode`, and `highlightLengthStart` props for filtering and highlighting countries and dial codes
- **Configurable Label Modes:** Supports `code` (e.g. `+1`), `name` (country name), or `none` via `labelType`
- **Trailing Arrow Indicator:** Reflects the popup open/close state via `iconTurn` and supports custom `iconArrowDown` icons
- **Readonly & Single-Country Lock:** Locks menu interaction via `readonly` (or automatically when `countryList` / `menuCountryAttrs.list` contains only one single-code country, while keeping multi-code countries like `DO` interactive) and preserves the flag and dial code display
- **Focus Management:** Defaults `disableFocusReturn` to `true` (overridable via `:disable-focus-return="false"`) and forwards `window` events so host phone inputs can manage focus on close
- **Inherited Capabilities:** Inherits `Button` and `MenuCountry` configuration via `buttonAttrs`, `menuCountryAttrs`, `readonly`, and `disabled`

**Common use cases:**

- Phone number input field prefix for selecting the country dial code
- Country or region picker in registration, profile, and checkout forms
