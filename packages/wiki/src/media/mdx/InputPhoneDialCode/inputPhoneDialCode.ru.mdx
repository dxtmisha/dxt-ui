Кнопка-триггер для выбора кода страны телефонного номера через всплывающее меню стран.

InputPhoneDialCode — это компактная кнопка-триггер, которая открывает всплывающее меню **MenuCountry**, позволяя пользователю выбрать страну и соответствующий телефонный код. Компонент автоматически определяет текущую страну пользователя через `Geo.getCountry()` в качестве значения по умолчанию и реактивно связывает выбор через `v-model:model-selected` или `value` + `@update:selected`.

**Основные возможности:**

- **Автоматическое определение страны:** Определение страны по умолчанию через `Geo.getCountry()`
- **Всплывающее меню стран:** Выбор страны через `MenuCountry` с флагами, названиями и телефонными кодами (`showPhoneCode: true`)
- **Настраиваемая метка:** Поддержка режимов `code` (например, `+7`), `name` (название страны) и `none` через `labelType`
- **Индикатор открытия:** Поворот иконки-стрелки (`iconTurn`) и настройка стрелки через `iconArrowDown`
- **Режим блокировки выбора:** Поддерживает `readonly` (и автоматически блокирует переключение, если `menuCountryAttrs.list` ограничивает выбор одной страной), сохраняя отображение флага и телефонного кода
- **Управление фокусом:** Отключает автоматический возврат фокуса при закрытии окна (`disableFocusReturn: true`) и пробрасывает событие `window` родительскому полю ввода
- **Наследуемые настройки:** Поддерживает конфигурацию `Button` и `MenuCountry` через `buttonAttrs`, `menuCountryAttrs`, `readonly` и `disabled`

**Типовые сценарии использования:**

- Префикс поля ввода телефонного номера для выбора кода страны
- Компактный переключатель страны или региона в формах регистрации и оформления заказа
