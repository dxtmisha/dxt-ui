The `Avatar` component visually represents users, entities, or brands with profile images, automatically reduced initials, status badges, skeleton placeholders, and interactive navigation.

When an `image` prop is supplied, `Avatar` delegates rendering to the integrated `Image` sub-component; otherwise it displays initials generated from `label` (respecting `reduction` and multi-byte Unicode graphemes) or custom `default` slot content. Interactive link props (`href`, `to`) switch the root element to a native `<a>` tag without conflicting `role="button"` attributes.

**Key features:**

- **Unicode-Safe Initials Reduction:** Automatically condenses multi-word labels to up to two uppercase graphemes (controlled by `reduction`)
- **Integrated Media & Badges:** Lazy-instantiated `Image` and circular `Badge` inclusions (`image`, `badge`, `badgeDot`)
- **Zero-Duplication Skeleton Mode:** Applies background skeleton classes via `isSkeleton` inside a `Skeleton` container
- **Accessible Interactive & Link Modes:** Resolves `role` (`button`, `img`, or native anchor link), `aria-label`, `tabindex`, and click events

**Common use cases:**

- User profile avatars in navigation bars and account menus
- Chat participant and team member lists with online indicator badges
- Clickable profile links and interactive account triggers
