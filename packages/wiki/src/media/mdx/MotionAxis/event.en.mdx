### `start`

Event triggered when the slide transition animation starts.

**Parameters:**
- `selected: string | undefined` — identifier of the slide to which the transition starts

### `end`

Event triggered after the slide transition animation completes.

**Parameters:**
- `selected: string | undefined` — identifier of the slide on which the transition ended

### `motionAxis`

Event triggered at both the start and end phases of the transition animation.

**Parameters:**
- `options: MotionAxisEmitOptions` — object with transition phase parameters

**`MotionAxisEmitOptions` structure:**
- `type: 'start' | 'end'` — transition phase type
- `selected?: string` — identifier of the target selected slide
- `previous?: string` — identifier of the outgoing slide (cleared on `'end'`)
- `preparation?: string` — identifier of the incoming slide being prepared (cleared on `'end'`)
- `active?: string` — identifier of the currently active slide

### `update:selected` & `update:modelSelected`

Events triggered whenever the internal selected slide identifier changes (supporting `v-model:selected` and `v-model:modelSelected`).

**Parameters:**
- `value: string | undefined` — new selected slide identifier

<script setup>
const handleStart = (selected) => {

  </MotionAxis>
