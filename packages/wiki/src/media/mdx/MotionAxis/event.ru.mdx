### `start`

Событие срабатывает в начале анимации перехода слайда.

**Параметры:**
- `selected: string | undefined` — идентификатор слайда, к которому начинается переход

### `end`

Событие срабатывает после завершения анимации перехода слайда.

**Параметры:**
- `selected: string | undefined` — идентификатор слайда, на котором завершился переход

### `motionAxis`

Событие срабатывает на этапах начала и завершения анимации перехода.

**Параметры:**
- `options: MotionAxisEmitOptions` — объект с параметрами фазы перехода

**Структура `MotionAxisEmitOptions`:**
- `type: 'start' | 'end'` — тип фазы перехода
- `selected?: string` — идентификатор выбранного целевого слайда
- `previous?: string` — идентификатор уходящего слайда (очищается на этапе `'end'`)
- `preparation?: string` — идентификатор подготавливаемого входящего слайда (очищается на этапе `'end'`)
- `active?: string` — идентификатор текущего активного слайда

### `update:selected` и `update:modelSelected`

События срабатывают при изменении внутреннего идентификатора выбранного слайда (поддержка `v-model:selected` и `v-model:modelSelected`).

**Параметры:**
- `value: string | undefined` — новый идентификатор выбранного слайда
