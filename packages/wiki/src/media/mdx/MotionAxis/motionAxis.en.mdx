The `MotionAxis` component orchestrates animated transitions between content views (slides) along the `X`, `Y`, and `Z` axes.

It supports automatic direction detection based on slide order as well as explicit directional overrides, optional container height animation (`animationHeight`), scroll-jump prevention during transitions, and fine-grained DOM lifecycle control (`inDom`, `inDomSlide`).

**Key features:**

- **3D Axis Transitions:** Slide animations along horizontal (`x`), vertical (`y`), and depth (`z`) axes
- **Direction Control:** Automatic direction detection (`auto`) or explicit `next` and `back` modes
- **Height Animation:** Smooth container height transitions between slides of different sizes (`animationHeight`)
- **DOM Lifecycle Management:** Lazy slide mounting by default with full (`inDom`) or selective (`inDomSlide`) DOM retention
- **Rich Navigation API:** Reactive `v-model:selected` binding and programmatic navigation via exposed directional methods

**Common use cases:**

- Multi-step forms and onboarding wizards
- Animated tab content panels and carousels
- Hierarchical drill-down views and image galleries
