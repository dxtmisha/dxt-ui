## Управление скроллом при анимации

Компонент автоматически управляет видимостью скролла во время анимации перехода, чтобы предотвратить скачки контента.

### Использование

Для активации этой функции добавьте класс `*__scroll` родительскому контейнеру с прокруткой (где `*` — имя класса компонента, например `design-motion-axis__scroll`).

1. Оберните компонент в контейнер с прокруткой.
2. Добавьте этому контейнеру класс `*__scroll`.

<Source
    code={`
<div class="design-motion-axis__scroll">
  <MotionAxis :selected="selected">
    <!-- Слайды -->
  </MotionAxis>
</div>
  `}
    language="html"
/>

Во время анимации перехода компонент автоматически добавляет класс `*__scroll--hidden` (применяющий `overflow-x: hidden`) к ближайшему контейнеру прокрутки и удаляет его после завершения анимации.
