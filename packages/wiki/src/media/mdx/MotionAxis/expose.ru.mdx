- `back(): void` — Переход к предыдущему слайду (`direction = 'back'`).
- `next(): void` — Переход к следующему слайду (`direction = 'next'`).
- `to(selected?: string): void` — Переход к указанному слайду с автоматическим определением направления по порядку слайдов.
- `top(selected?: string): void` — Переход к указанному слайду по оси `Y` в направлении `back`.
- `right(selected?: string): void` — Переход к указанному слайду по оси `X` в направлении `next`.
- `bottom(selected?: string): void` — Переход к указанному слайду по оси `Y` в направлении `next`.
- `left(selected?: string): void` — Переход к указанному слайду по оси `X` в направлении `back`.
- `down(selected?: string): void` — Переход к указанному слайду по оси `Z` в направлении `back`.
- `up(selected?: string): void` — Переход к указанному слайду по оси `Z` в направлении `next`.
