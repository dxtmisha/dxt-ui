## Scroll Management during Animation

The component automatically manages scroll visibility during transition animations to prevent content jumps.

### Usage

To enable this feature, add the `*__scroll` class to the scrollable parent container (where `*` is the component class name, e.g., `design-motion-axis__scroll`).

1. Wrap the component in a scrollable container.
2. Add the `*__scroll` class to this container.

<Source
    code={`
<div class="design-motion-axis__scroll">
  <MotionAxis :selected="selected">
    <!-- Slides -->
  </MotionAxis>
</div>
  `}
    language="html"
/>

During the transition animation, the component automatically adds the `*__scroll--hidden` class (applying `overflow-x: hidden`) to the closest scrollable ancestor and removes it once the animation ends.
