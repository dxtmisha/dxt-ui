Component for creating popup menus, dropdown lists, and context menus with navigation and action support.

`Menu` combines the functionality of `Window` (positioning and visibility management), `Bars` (action and tool panel), and `List` (displaying items, groups, and nested submenus). The component provides keyboard navigation, nested structure support, asynchronous data loading, optimized rendering mode for large lists, and full control over selection and window state.

**Key Features:**

- Integration of `Window`, `Bars`, and `List` components
- Keyboard navigation and programmatic step movement (`previous` / `next`)
- Nested submenus with unlimited depth
- Asynchronous data loading via `ajax`, `request`, and `cache`
- Lite rendering mode for large lists (`liteThreshold`)
- Lazy item rendering with viewport observation and height caching (`lazy`, `lazyMargin`, `lazyCacheHeight`)
- Built-in search, filtering (`showSearch`, `filterMode`), and text highlighting (`highlight`)
- Selection state management (`selected`, `isSelectedByValue`, `selectionStyle`, `max`)
- Custom field mapping (`keyLabel`, `keyValue`) and attribute forwarding (`listAttrs`, `itemAttrs`, `barsAttrs`, `windowAttrs`)

**Typical Use Cases:**

- Navigation dropdown menus and action panels
- Context menus and toolbars with headers
- Searchable selectors and multi-select lists
- Menus with dynamic asynchronous data loading

const handleClick = (_event: MouseEvent, value: EventClickValue) => {
  console.log('Selected item:', value.value)
}
</script>

<template>
  <Menu
    v-model:selected="selected"
    :list="menuItems"
    is-selected-by-value
    @click="handleClick"
  >
    <template #control="{ binds }">
      <button type="button" v-bind="binds">Actions</button>
    </template>
  </Menu>
