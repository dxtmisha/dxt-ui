### `updateValue`

Событие срабатывает при программном изменении выбранного значения (например, через методы навигации `previous()` / `next()`) при включённом `isSelectedByValue`.

**Параметры:**
- `value?: NumberOrStringOrBoolean` — новое выбранное значение

<Source
    code={`
<script setup lang="ts">
import { ref } from 'vue'
import type { NumberOrStringOrBoolean } from '@dxtmisha/functional'

const selected = ref('item1')
const menuItems = [
  { label: 'Пункт меню 1', value: 'item1' },
  { label: 'Пункт меню 2', value: 'item2' },
  { label: 'Пункт меню 3', value: 'item3' }
]

const handleUpdateValue = (value?: NumberOrStringOrBoolean) => {
  console.log('Новое значение:', value)
}
</script>

<template>
  <Menu
    v-model:selected="selected"
    :list="menuItems"
    is-selected-by-value
    @update-value="handleUpdateValue"
  >
    <template #control="{ next }">
      <button type="button" @click="next">Следующий пункт</button>
    </template>
  </Menu>
</template>
  `}
    language="html"
/>
