Компонент для создания всплывающих меню, выпадающих списков и контекстных меню с поддержкой навигации и действий.

`Menu` объединяет функциональность `Window` (позиционирование и управление видимостью), `Bars` (панель действий и заголовка) и `List` (отображение пунктов, групп и вложенных подменю). Компонент обеспечивает клавиатурную навигацию, поддержку вложенной структуры, асинхронную загрузку данных, оптимизированный режим рендеринга для больших списков и полный контроль над состоянием выбора и окна.

**Основные возможности:**

- Интеграция компонентов `Window`, `Bars` и `List`
- Клавиатурная навигация и программное переключение по шагу (`previous` / `next`)
- Вложенные подменю с неограниченной глубиной
- Асинхронная загрузка данных через `ajax`, `request` и `cache`
- Облегчённый режим рендеринга для больших списков (`liteThreshold`)
- Ленивый рендеринг элементов с отслеживанием видимости и кэшированием высоты (`lazy`, `lazyMargin`, `lazyCacheHeight`)
- Встроенный поиск, фильтрация (`showSearch`, `filterMode`) и подсветка текста (`highlight`)
- Управление выбранными элементами (`selected`, `isSelectedByValue`, `selectionStyle`, `max`)
- Пользовательские ключи полей (`keyLabel`, `keyValue`) и проброс атрибутов (`listAttrs`, `itemAttrs`, `barsAttrs`, `windowAttrs`)

**Типичные сценарии использования:**

- Выпадающие меню навигации и панели действий
- Контекстные меню с заголовком и подвалом
- Селекторы с поиском и множественным выбором
- Меню с динамической асинхронной загрузкой данных

<script setup lang="ts">
import { ref } from 'vue'
import type { EventClickValue } from '@dxtmisha/constructor'

const selected = ref('edit')
const menuItems = ref([
  { label: 'Создать', value: 'create', icon: 'add' },
  { label: 'Редактировать', value: 'edit', icon: 'edit' },
  { label: 'Удалить', value: 'delete', icon: 'delete' },
  {
    label: 'Экспорт',
    value: 'export',
    children: [
      { label: 'PDF', value: 'pdf' },
      { label: 'Excel', value: 'excel' },
      { label: 'CSV', value: 'csv' }
    ]
  }
])

const handleClick = (_event: MouseEvent, value: EventClickValue) => {
  console.log('Выбран пункт:', value.value)
}
</script>

<template>
  <Menu
    v-model:selected="selected"
    :list="menuItems"
    is-selected-by-value
    @click="handleClick"
  >
    <template #control="{ binds }">
      <button type="button" v-bind="binds">Действия</button>
    </template>
  </Menu>
</template>
  `}
    language="html"
/>

> `Menu` предоставляет единую и доступную основу для выпадающих меню, списков команд и вложенной навигации.
