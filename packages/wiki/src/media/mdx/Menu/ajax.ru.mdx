## AJAX загрузка меню

Свойства `ajax`, `request` и `cache` предназначены для управления асинхронной загрузкой и кэшированием данных меню.

**Свойства:**

- `ajax` — строка URL или функция загрузки, возвращающая `ListRecord` (или `Promise<ListRecord>`)
- `request` — объект типа `ApiFetch` с настройками HTTP-запроса
- `cache` — включает кэширование загруженных элементов меню после первого запроса

Когда задано `ajax` или `request`, `Menu` запускает загрузку данных на этапе подготовки окна перед открытием и передаёт реактивный флаг `loading` в слоты и `expose`. При включённом `cache` повторные открытия меню используют сохранённые данные без повторных запросов.

<Source
    code={`
<script setup lang="ts">
const loadMenu = async () => [
  { label: 'Панель', value: 'dashboard' },
  { label: 'Настройки', value: 'settings' }
]
</script>

<template>
  <!-- Загрузка по URL с кэшированием -->
  <Menu
    ajax="/api/menu-items"
    cache
  >
    <template #control="{ binds, loading }">
      <button type="button" v-bind="binds">
        {{ loading.value ? 'Загрузка...' : 'Открыть меню по URL' }}
      </button>
    </template>
  </Menu>

  <!-- С настройками запроса -->
  <Menu
    ajax="/api/menu"
    :request="{
      method: 'POST',
      headers: { 'X-Custom': 'value' }
    }"
    cache
  >
    <template #control="{ binds }">
      <button type="button" v-bind="binds">Меню с request</button>
    </template>
  </Menu>

  <!-- Асинхронная функция загрузки -->
  <Menu :ajax="loadMenu">
    <template #control="{ binds }">
      <button type="button" v-bind="binds">Меню из функции</button>
    </template>
  </Menu>
</template>
  `}
    language="html"
/>
