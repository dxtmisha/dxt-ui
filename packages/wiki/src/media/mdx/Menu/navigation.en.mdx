## Menu item navigation

Methods `previous()` and `next()` provide programmatic movement through menu items based on the current selection and the `step` property.

**Methods:**

- `previous()` — moves selection backward by `step` positions and returns the selected item value (or `undefined`)
- `next()` — moves selection forward by `step` positions and returns the selected item value (or `undefined`)
- `step` — number of items to advance on each call (default: `1`)

When `isSelectedByValue` is enabled, calling `previous()` or `next()` updates the internal selected state, emits `update:selected`, `update:modelSelected`, and `updateValue`, and stops at list boundaries without overflowing.

<Source
    code={`
<script setup lang="ts">
import { ref } from 'vue'
import type { MenuExpose } from '@dxtmisha/constructor/Menu'

const menuRef = ref<MenuExpose>()
const selected = ref('item2')
const items = [
  { label: 'Item 1', value: 'item1' },
  { label: 'Item 2', value: 'item2' },
  { label: 'Item 3', value: 'item3' }
]
</script>

<template>
  <!-- Call via ref -->
  <button type="button" @click="menuRef?.previous()">Previous</button>
  <button type="button" @click="menuRef?.next()">Next</button>

  <Menu
    ref="menuRef"
    v-model:selected="selected"
    :list="items"
    :step="1"
    is-selected-by-value
  />

  <!-- Navigation in control slot -->
  <Menu v-model:selected="selected" :list="items" is-selected-by-value>
    <template #control="{ previous, next, selectedNames }">
      <button type="button" @click="previous">◀</button>
      <span>{{ selectedNames.value[0] }}</span>
      <button type="button" @click="next">▶</button>
    </template>
  </Menu>
</template>
  `}
    language="html"
/>
