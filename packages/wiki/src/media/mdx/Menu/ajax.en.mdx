## AJAX Menu Loading

The `ajax`, `request`, and `cache` properties manage asynchronous loading and caching of menu data.

**Properties:**

- `ajax` — remote URL string or loader function returning `ListRecord` (or `Promise<ListRecord>`)
- `request` — `ApiFetch` configuration object with HTTP request parameters
- `cache` — caches loaded menu items after the first request

When `ajax` or `request` is provided, `Menu` triggers data loading during window preparation before opening and exposes the reactive `loading` state in slot props and `expose`. With `cache` enabled, subsequent openings reuse the buffered items without repeating network requests.

<Source
    code={`
<script setup lang="ts">
const loadMenu = async () => [
  { label: 'Dashboard', value: 'dashboard' },
  { label: 'Settings', value: 'settings' }
]
</script>

<template>
  <!-- Loading with URL and cache -->
  <Menu
    ajax="/api/menu-items"
    cache
  >
    <template #control="{ binds, loading }">
      <button type="button" v-bind="binds">
        {{ loading.value ? 'Loading...' : 'Open URL Menu' }}
      </button>
    </template>
  </Menu>

  <!-- With request settings -->
  <Menu
    ajax="/api/menu"
    :request="{
      method: 'POST',
      headers: { 'X-Custom': 'value' }
    }"
    cache
  >
    <template #control="{ binds }">
      <button type="button" v-bind="binds">Open Request Menu</button>
    </template>
  </Menu>

  <!-- Async function -->
  <Menu :ajax="loadMenu">
    <template #control="{ binds }">
      <button type="button" v-bind="binds">Open Function Menu</button>
    </template>
  </Menu>
</template>
  `}
    language="html"
/>
