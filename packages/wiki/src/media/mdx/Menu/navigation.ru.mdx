## Навигация по элементам меню

Методы `previous()` и `next()` предназначены для программного перемещения по элементам меню на основе текущего выбора и свойства `step`.

**Методы:**

- `previous()` — перемещает выбор назад на `step` позиций и возвращает значение выбранного элемента (или `undefined`)
- `next()` — перемещает выбор вперёд на `step` позиций и возвращает значение выбранного элемента (или `undefined`)
- `step` — количество позиций для шага навигации (по умолчанию: `1`)

При включённом `isSelectedByValue` вызов `previous()` или `next()` обновляет внутреннее состояние выбора, генерирует события `update:selected`, `update:modelSelected` и `updateValue`, а также останавливается на границах списка без выхода за его пределы.

<Source
    code={`
<script setup lang="ts">
import { ref } from 'vue'
import type { MenuExpose } from '@dxtmisha/constructor/Menu'

const menuRef = ref<MenuExpose>()
const selected = ref('item2')
const items = [
  { label: 'Элемент 1', value: 'item1' },
  { label: 'Элемент 2', value: 'item2' },
  { label: 'Элемент 3', value: 'item3' }
]
</script>

<template>
  <!-- Вызов через ref -->
  <button type="button" @click="menuRef?.previous()">Назад</button>
  <button type="button" @click="menuRef?.next()">Вперёд</button>

  <Menu
    ref="menuRef"
    v-model:selected="selected"
    :list="items"
    :step="1"
    is-selected-by-value
  />

  <!-- Навигация в слоте control -->
  <Menu v-model:selected="selected" :list="items" is-selected-by-value>
    <template #control="{ previous, next, selectedNames }">
      <button type="button" @click="previous">◀</button>
      <span>{{ selectedNames.value[0] }}</span>
      <button type="button" @click="next">▶</button>
    </template>
  </Menu>
</template>
  `}
    language="html"
/>
