Component for displaying helper text, validation messages, and an optional character counter beneath form fields.

`FieldMessage` centralizes the presentation of field hints and validation errors. It automatically toggles the validation state (`--validation`) when `validationMessage` or the `#validation` slot is active, attaches `role="alert"` to error messages, hides output when `disabled` unless `forceShow` is enabled, supports explicit `hasHtmlCode` rendering, and integrates `FieldCounter` and `Skeleton` styling.

**Key features:**

- **Helper & Validation Modes:** Separate `helperMessage` and `validationMessage` regions with automatic validation priority
- **Accessible Semantics:** `role="alert"` on error nodes and configurable `helperId`, `validationId`, and `counterId` for `aria-describedby`
- **Visibility Control:** Automatic unmounting when empty or `disabled`, overridden via `forceShow`
- **Safe HTML & Slots:** Escaped text by default, opt-in `hasHtmlCode` markup, and `#helper` / `#validation` scoped slots
- **Counter & Skeleton Integration:** Built-in character counter support (`counterShow`, `counter`, `maxlength`, `counterTemplate`) and `isSkeleton` state

**Common use cases:**

- Helper hints and validation errors beneath inputs, textareas, and selects
- Accessible form feedback bound to controls via `aria-describedby`
- Complex fields combining validation messages with character counters

<Source
    code={`
<template>
  <!-- Helper message -->
  <FieldMessage helper-message="Enter your email address" />

  <!-- Validation message with counter -->
  <FieldMessage
    validation-message="Minimum 3 characters required"
    counter-show
    :counter="2"
    :maxlength="50"
  />

  <!-- Slots -->
  <FieldMessage>
    <template #helper>Hint content</template>
    <template #validation>Error content</template>
  </FieldMessage>
</template>
  `}
    language="html"
/>

> `FieldMessage` coordinates accessible validation feedback, helper hints, and character counters while unmounting from the DOM when inactive.
