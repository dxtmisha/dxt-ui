Component for creating nested dropdown menus and organizing hierarchical navigation elements.

`ListMenu` is an auxiliary component for `List` that manages submenu open/close state and integrates with `Window` for floating or embedded positioning, multi-level nesting, and accessible trigger bindings.

**Key features:**

- Hierarchical submenu organization with nested `ListMenu` instances
- Automatic open/close state management via `ListGroupOpen` and `Window`
- Horizontal (`axis="x"`) and vertical (`axis="y"`) positioning axes
- Safe nested menu behavior (`inert: false`, `autoTabIndex: false`, `closeOnEsc: false`)
- Full slot customization via `#head` (with `WindowControlItem` bindings) and `#list`
- Programmatic control via exposed `Window` API (`toOpen`, `toClose`, `toggle`, `getOpen`)

**Common use cases:**

- Dropdown submenus inside navigation lists and rails
- Multi-level category and action menus
- Nested context menus with independent open states
