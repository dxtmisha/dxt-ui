### `head`

Слот для рендеринга элемента-триггера меню. Получает свойства `WindowControlItem` (`class`, `open`, `binds`, `classesWindow`, `onClick`, `onKeydown`, `onContextmenu`). Привяжите `binds` к элементу управления для автоматической обработки кликов, клавиатуры и ARIA-атрибутов.

### `list`

Слот для рендеринга содержимого тела меню, отображаемого внутри `Window` при открытии подменю.
