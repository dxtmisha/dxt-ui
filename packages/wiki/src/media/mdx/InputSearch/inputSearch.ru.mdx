Компонент поля ввода для поисковых запросов с поддержкой задержки debounce, минимальной длины ввода и быстрой очистки.

InputSearch — это специализированный компонент ввода, оптимизированный для сценариев поиска. Он включает в себя встроенную задержку (debounce), фильтрацию по минимальной длине поискового запроса, отображение индикатора загрузки во время ожидания задержки, а также кнопку быстрой очистки поля и запуск поиска по нажатию клавиши Enter.

**Основные возможности:**

- Встроенная задержка debounce перед отправкой поискового запроса (`delay`)
- Настройка минимальной длины запроса для запуска поиска (`minQuery`)
- Автоматическая иконка поиска и кнопка быстрой очистки по умолчанию
- Немедленная отправка запроса по нажатию клавиши `Enter`
- Динамический статус загрузки во время ожидания задержки (`loading`)
- Оптимизированный UX для поиска (отключены автокоррекция, автозаполнение, проверка орфографии)
- Поддержка двусторонней привязки данных (`v-model:value`)
- Полная интеграция с Field: плавающие метки, сообщения валидации, счетчики и префиксы/суффиксы

**Типичные сценарии использования:**

- Панели поиска по каталогу товаров или услуг
- Поиск пользователей, документов и записей в таблицах
- Фильтры данных и выпадающие списки с автопоиском
