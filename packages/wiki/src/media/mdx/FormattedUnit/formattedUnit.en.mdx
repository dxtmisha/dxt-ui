The `FormattedUnit` component is an inline formatted text component for displaying and automatically converting units of measurement according to localized standard settings (e.g. converting Celsius to Fahrenheit, grams to ounces, meters to feet).

`FormattedUnit` provides a simple, clean interface for presenting measurement data cleanly in any part of the UI. It supports automatic conversion of units based on the country's default customary unit settings, localized formatting via `GeoUnit`, and the ability to selectively disable formatting.

**Key features:**

- **Automatic Conversion:** Unit translation and conversion math based on locale customary settings (`en-US`, `ru-RU`, `de-DE`, etc.)
- **Standard Unit Support:** Supports `millimeter`, `centimeter`, `meter`, `kilometer`, `square-meter`, `hectare`, `gram`, `kilogram`, `tonne`, `milliliter`, `liter`, `celsius`, and `kilometer-per-hour`
- **Formatting Bypass:** When `formatting` is `false`, outputs the raw value converted to a string without conversion
- **Locale Override:** Custom language/locale configuration via the `language` prop with reactive fallback to the global locale
- **Lightweight Rendering:** Renders inline as a native `<span>` element

**Common use cases:**

- Displaying weather and temperature values automatically adjusted to Celsius or Fahrenheit
- Showing weights, distances, volumes, and areas in metric or customary units depending on user locale
- Formatting vehicle or wind speed values (`km/h` vs `mph`) cleanly and reactively
