The `TextareaAutosize` component is a multi-line text field engine that automatically adjusts its height based on content.

It combines CSS `field-sizing: content` with a hidden `aria-hidden="true"` clone fallback to measure scroll-free container height accurately while respecting padding and typography of the underlying `<textarea>` element.

**Key features:**

- **Automatic Height Adjustment:** Expands and shrinks dynamically with entered text when `autosize` is enabled (default `true`)
- **Hidden Clone Measurement:** Uses an `aria-hidden="true"` clone synchronized via `requestAnimationFrame` when CSS `field-sizing` is unavailable
- **Fixed Height Toggle:** Set `:autosize="false"` to disable dynamic height calculation and use native `rows`
- **Native Attribute Forwarding:** Forwards standard `<textarea>` attributes (`rows`, `cols`, `maxlength`, `placeholder`, `disabled`, `readonly`, `aria-label`) through `inputAttrs` or fallthrough attributes
- **Reactive Value & Expose API:** Synchronizes with the `value` prop, emits native `input` events, and exposes `getValue()`

**Common use cases:**

- Foundational textarea engine inside higher-level field components such as `Textarea`
- Auto-expanding comment, note, and chat message inputs
- Dynamic multi-line forms where scrollbars inside textareas are undesirable
