Компонент `TextareaAutosize` — это базовый движок многострочного текстового поля с автоматической подстройкой высоты под содержимое.

Он сочетает CSS `field-sizing: content` со скрытым элементом-клоном (`aria-hidden="true"`) в качестве резервного механизма расчёта высоты без прокрутки с учётом отступов и типографики исходного `<textarea>`.

**Основные возможности:**

- **Автоматическая подстройка высоты:** Динамически изменяет высоту при изменении текста, когда включён `autosize` (по умолчанию `true`)
- **Скрытый элемент-клон:** Использует элемент-клон с `aria-hidden="true"`, синхронизируемый через `requestAnimationFrame`, если браузер не поддерживает CSS `field-sizing`
- **Отключение авторазмера:** Передайте `:autosize="false"`, чтобы зафиксировать высоту через нативный атрибут `rows`
- **Передача нативных атрибутов:** Пробрасывает стандартные атрибуты `<textarea>` (`rows`, `cols`, `maxlength`, `placeholder`, `disabled`, `readonly`, `aria-label`) через `inputAttrs` или сквозные атрибуты
- **Реактивное значение и Expose API:** Синхронизируется со свойством `value`, генерирует событие `input` и экспонирует метод `getValue()`

**Типовые сценарии использования:**

- Базовый движок многострочного ввода внутри составных компонентов полей, таких как `Textarea`
- Автоматически расширяемые поля для комментариев, заметок и сообщений в чатах
- Динамические многострочные формы без внутренних полос прокрутки

<Source
    code={`
<script setup>
import { ref } from 'vue'

const message = ref('')

const handleInput = (event) => {
  message.value = event.target.value
}
</script>

<template>
  <TextareaAutosize
    :value="message"
    :input-attrs="{
      placeholder: 'Введите ваше сообщение...',
      maxlength: 500
    }"
    @input="handleInput"
  />

  <TextareaAutosize
    value="Текстовое поле с фиксированной высотой"
    :autosize="false"
    :input-attrs="{
      placeholder: 'Высота не изменяется',
      rows: 3
    }"
  />
</template>
  `}
    language="html"
/>

> TextareaAutosize предоставляет лёгкий и доступный примитив автоматически расширяемого textarea с надёжным резервным расчётом высоты.
