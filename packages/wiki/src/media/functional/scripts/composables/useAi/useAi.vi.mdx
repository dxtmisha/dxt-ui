# `useAi`

Composable để nhận phiên bản adapter AI dựa trên cấu hình hiện tại của dự án.

**Trả về:**
`AiAbstract | undefined` — Một phiên bản của lớp nhà cung cấp AI (như `AiGoogle`, `AiGoogleCli`, `AiClaude`, `AiClaudeAgent`, `AiClaudeCli`, `AiOpenAi`, `AiZAi`) tùy thuộc vào loại AI được cấu hình, hoặc `undefined` nếu loại không được nhận dạng hoặc chưa được cấu hình.

## Cách hoạt động

Composable đọc loại AI từ `PropertiesConfig.getAiType()` và khởi tạo lớp tương ứng:
- `'claude'` — trả về `AiClaude` (Anthropic Claude API).
- `'claude-agent'` — trả về `AiClaudeAgent` (Anthropic Claude Agent SDK).
- `'claude-cli'` — trả về `AiClaudeCli` (Giao diện dòng lệnh Claude CLI).
- `'gemini'` — trả về `AiGoogle` (Google Gemini API).
- `'gemini-cli'` — trả về `AiGoogleCli` (Giao diện dòng lệnh Google Gemini CLI).
- `'openai'` — trả về `AiOpenAi` (OpenAI GPT API).
- `'zai'` — trả về `AiZAi` (xAI / Grok API).
- Các loại khác trả về `undefined`.

## Ví dụ

```typescript
import { useAi } from '@dxtmisha/scripts'

const ai = useAi()

if (ai) {
  const response = await ai.generate('Xin chào, AI!')
  console.log(response)
}
```
