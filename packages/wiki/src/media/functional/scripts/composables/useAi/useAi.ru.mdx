# `useAi`

Композабл для получения экземпляра AI-адаптера на основе текущей конфигурации проекта.

**Возвращает:**
`AiAbstract | undefined` — экземпляр класса AI-провайдера (например, `AiGoogle`, `AiGoogleCli`, `AiClaude`, `AiClaudeAgent`, `AiClaudeCli`, `AiOpenAi`, `AiZAi`) в зависимости от настроенного типа AI, или `undefined`, если тип не распознан или не настроен.

## Как это работает

Композабл считывает тип AI из `PropertiesConfig.getAiType()` и возвращает новый экземпляр соответствующего класса:
- `'claude'` — возвращает `AiClaude` (интеграция с Anthropic Claude API).
- `'claude-agent'` — возвращает `AiClaudeAgent` (Anthropic Claude Agent SDK).
- `'claude-cli'` — возвращает `AiClaudeCli` (CLI-интерфейс Claude).
- `'gemini'` — возвращает `AiGoogle` (Google Gemini API).
- `'gemini-cli'` — возвращает `AiGoogleCli` (CLI-интерфейс Google Gemini).
- `'openai'` — возвращает `AiOpenAi` (OpenAI GPT API).
- `'zai'` — возвращает `AiZAi` (xAI / Grok API).
- Другие типы возвращают `undefined`.

## Пример

```typescript
import { useAi } from '@dxtmisha/scripts'

const ai = useAi()

if (ai) {
  const response = await ai.generate('Привет, AI!')
  console.log(response)
}
```
