# `sortList`

Một tiện ích sắp xếp một mảng các đối tượng hoặc phần tử theo một hoặc nhiều đường dẫn thuộc tính cột, hướng sắp xếp (`'asc'` hoặc `'desc'`), hoặc một hàm so sánh tùy chỉnh. Tiện ích thực hiện so sánh chuỗi theo ngữ cảnh địa phương bằng `Intl.Collator` với tùy chọn so sánh số và không phân biệt chữ hoa chữ thường, đồng thời đưa các giá trị `null` hoặc `undefined` về cuối danh sách đã sắp xếp.

**Tham số:**
- `list: T[]` — Mảng các phần tử đầu vào cần sắp xếp.
- `sortColumns: SortColumnItem[]` — Mảng các chỉ định sắp xếp cột `{ column: string, dir: SortDir }`.
- `customSort?: SortFunction<T>` — Hàm so sánh tùy chỉnh (không bắt buộc).

**Trả về:**
`T[]` — Mảng các phần tử mới đã được sắp xếp (hoặc mảng ban đầu nếu `sortColumns` rỗng hoặc độ dài danh sách nhỏ hơn 2).

```typescript
import { sortList } from '@dxtmisha/functional-basic'

const users = [
  { id: 3, category: 'A', name: 'Charlie', age: 30 },
  { id: 1, category: 'B', name: 'Alice', age: 25 },
  { id: 4, category: 'A', name: 'Alice', age: 20 },
  { id: 2, category: 'B', name: 'Bob', age: 35 }
]

// Sắp xếp theo danh mục tăng dần, sau đó theo tuổi giảm dần
const sorted = sortList(users, [
  { column: 'category', dir: 'asc' },
  { column: 'age', dir: 'desc' }
])

console.log(sorted.map(user => user.id)) // [3, 4, 2, 1]
```
