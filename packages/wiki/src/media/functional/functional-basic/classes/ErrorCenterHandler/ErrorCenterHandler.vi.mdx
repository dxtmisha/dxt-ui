# Lớp ErrorCenterHandler

`ErrorCenterHandler` là trình quản lý để quản lý các hàm callback (trình xử lý). Nó cho phép bạn liên kết logic với các nhóm lỗi cụ thể và thực thi nó khi có sự kiện tương ứng xảy ra.

## Các tính năng chính

- **Đăng ký trình xử lý** — thêm thuận tiện các hàm callback vào các nhóm cụ thể.
- **Trình xử lý toàn cục** — hỗ trợ nhóm `undefined`, nhóm này bắt bất kỳ lỗi nào không có trình xử lý cụ thể.
- **Thực thi tuần tự** — kích hoạt tất cả các hàm đã đăng ký theo thứ tự chúng được thêm vào.
- **Ghi log có thể cấu hình** — xuất chi tiết lỗi ra console với hỗ trợ hàm lọc tùy chỉnh hoặc tắt hoàn toàn.

## Khởi tạo

Để tạo một thực thể, sử dụng constructor `ErrorCenterHandler(handlers, isConsole)`.

**Tham số:**
- `handlers?: ErrorCenterHandlerList` — danh sách trình xử lý ban đầu.
- `isConsole?: ErrorCenterHandlerIsConsole` — cờ hoặc hàm lọc cho console (mặc định là `true`).

```typescript
import { ErrorCenterHandler } from '@dxtmisha/functional-basic'

const handlers = new ErrorCenterHandler(
  [
    {
      group: 'api',
      handlers: [(cause) => console.log('Lỗi API:', cause.code)]
    }
  ],
  false // Tắt ghi log ra console
);
```

## Các phương thức

### Hành động
- `on(cause: ErrorCenterCauseItem): this` — Kích hoạt chuỗi trình xử lý và ghi log ra console nếu được bật.

### Xác minh
- `has(group: ErrorCenterGroup): boolean` — Kiểm tra xem có trình xử lý cho một nhóm không.
- `get(group: ErrorCenterGroup): ErrorCenterHandlerItem | undefined` — Trả về danh sách các hàm cho một nhóm.

### Cấu hình
- `add(group: ErrorCenterGroup, handler: ErrorCenterHandlerCallback): this` — Thêm một hàm vào một nhóm.
- `addList(handlers: ErrorCenterHandlerList): this` — Đăng ký hàng loạt các trình xử lý.
- `setIsConsole(isConsole: ErrorCenterHandlerIsConsole): this` — Thiết lập cờ hoặc hàm lọc xuất console.

## Các kiểu dữ liệu

#### `ErrorCenterGroup`
Tên nhóm (`string`) hoặc `undefined` để chặn toàn cục.

#### `ErrorCenterHandlerCallback`
Hàm callback: `(cause: ErrorCenterCauseItem) => void`.

#### `ErrorCenterHandlerIsConsole`
Tùy chọn cấu hình ghi log console: `boolean | ((cause: ErrorCenterCauseItem) => boolean)`.

#### `ErrorCenterHandlerIsConsoleCallback`
Hàm callback để kiểm tra xem có ghi log lỗi ra console hay không: `(cause: ErrorCenterCauseItem) => boolean`.

#### `ErrorCenterHandlerItem`
Liên kết giữa một nhóm và một mảng các hàm của nó.
- `group?: ErrorCenterGroup` — nhóm mục tiêu.
- `handlers: ErrorCenterHandlerCallback[]` — danh sách các hàm.

## Ví dụ

### Trình quản lý cô lập với bộ lọc console
```typescript
const uploadHandlers = new ErrorCenterHandler();

// Lọc xuất console: chỉ ghi log lỗi có nhóm 'upload'
uploadHandlers.setIsConsole((cause) => cause.group === 'upload');

uploadHandlers.add('upload', (cause) => {
  if (cause.code === 'retry') {
    restartUpload();
  }
});

uploadHandlers.on({ group: 'upload', code: 'retry' });
```
