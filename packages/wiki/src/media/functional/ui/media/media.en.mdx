# Global Tokens and Media (src/media)

The `src/media` directory is intended for storing global design tokens and media assets (such as icons) for your design system. The directory structure and set of tokens are flexible and customized for each project based on design requirements.

## 1. Directory Structure

Example of a basic layout:

```
src/media/
├── icons/                   # Project SVG icons
│   └── *.svg
├── tokens/                  # JSON token files (colors, grids, spacing, etc.)
│   └── *.json
└── properties.json          # Main global token configuration manifest
```

## 2. Token Configuration (properties.json)

The `src/media/properties.json` file links your project tokens together, organizes them by category, and controls how they are compiled:

```json
{
  "ref": {
    "value": {
      "file|ref": "tokens/ref.json"
    },
    "_type": "var",
    "_category": "root"
  },
  "sys": {
    "value": {
      "file|sys": "tokens/sys.json"
    },
    "_type": "var",
    "_category": "root"
  },
  "color": {
    "value": {
      "file|color": "tokens/color.json"
    },
    "_category": "class"
  },
  "dark": {
    "value": {
      "file|dark": "tokens/dark.json"
    },
    "_category": "theme"
  }
}
```

- `"file|<name>": "path.json"` — imports an external JSON token file.
- `"_type": "var"` — exports tokens as CSS variables.
- `"_category": "root"` — root system variables.
- `"_category": "class"` — reusable style presets for components.
- `"_category": "theme"` — theme override tokens (e.g., dark mode).

## 3. Adding Icons (icons)

To add new icons:
1. Place `.svg` files into the `src/media/icons/` folder.
2. Run code generation:
   ```bash
   npm run ui
   ```

The script will automatically discover all icons, generate asynchronous imports, and register them via `Icons`. The icon will then be available by file name in all components:

```html
<d1-button icon="my-icon">Button</d1-button>
```

## 4. Synchronization

After modifying tokens or adding new icons, run:

```bash
npm run ui
```

This command recompiles SCSS mixins, updates `ui-properties.scss`, registers icons, and synchronizes TypeScript types.
