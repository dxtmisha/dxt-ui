# Token toàn cầu và Media (src/media)

Thư mục `src/media` dùng để lưu trữ các design token toàn cầu và tài nguyên phương tiện (như biểu tượng) cho hệ thống thiết kế của bạn. Cấu trúc thư mục và danh sách token là linh hoạt và tùy biến cho từng dự án dựa trên yêu cầu thiết kế.

## 1. Cấu trúc thư mục

Ví dụ về cấu trúc cơ bản:

```
src/media/
├── icons/                   # Các biểu tượng SVG của dự án
│   └── *.svg
├── tokens/                  # Các tệp JSON chứa design token (màu sắc, lưới, khoảng cách, v.v.)
│   └── *.json
└── properties.json          # Tệp cấu hình chính cho toàn bộ token toàn cầu
```

## 2. Cấu hình Token (properties.json)

Tệp `src/media/properties.json` liên kết các token của dự án lại với nhau, phân loại theo danh mục và điều khiển cách biên dịch chúng:

```json
{
  "ref": {
    "value": {
      "file|ref": "tokens/ref.json"
    },
    "_type": "var",
    "_category": "root"
  },
  "sys": {
    "value": {
      "file|sys": "tokens/sys.json"
    },
    "_type": "var",
    "_category": "root"
  },
  "color": {
    "value": {
      "file|color": "tokens/color.json"
    },
    "_category": "class"
  },
  "dark": {
    "value": {
      "file|dark": "tokens/dark.json"
    },
    "_category": "theme"
  }
}
```

- `"file|<tên>": "duong_dan.json"` — nhập tệp JSON token bên ngoài.
- `"_type": "var"` — xuất các token thành biến CSS.
- `"_category": "root"` — các biến hệ thống gốc.
- `"_category": "class"` — các nhóm kiểu dáng có thể tái sử dụng cho các thành phần.
- `"_category": "theme"` — các token ghi đè chủ đề (ví dụ: chế độ tối).

## 3. Thêm biểu tượng (icons)

Để thêm biểu tượng mới:
1. Đặt các tệp `.svg` vào thư mục `src/media/icons/`.
2. Khởi chạy trình tạo mã:
   ```bash
   npm run ui
   ```

Tệp lệnh sẽ tự động tìm kiếm tất cả biểu tượng, tạo import bất đồng bộ và đăng ký qua `Icons`. Sau đó biểu tượng có thể được sử dụng theo tên tệp trong mọi thành phần:

```html
<d1-button icon="my-icon">Nút bấm</d1-button>
```

## 4. Đồng bộ hóa

Sau khi chỉnh sửa token hoặc thêm biểu tượng mới, hãy chạy:

```bash
npm run ui
```

Lệnh này sẽ biên dịch lại các mixin SCSS, cập nhật `ui-properties.scss`, kết nối biểu tượng và đồng bộ hóa các kiểu TypeScript.
