## 2. Детальные тест-кейсы

### 2.1. Визуальные проверки (VIS)

#### TC-VIS-001: Первичный рендер форматирования меток, иконок и вариантов на десктопе (1440×900)
- **Приоритет**: P0
- **Категория**: `VIS`
- **Предусловия**: Открыт маршрут `/component-menu-button` при разрешении `1440×900`.
- **Шаги**: Проверить рендер всех 8 групп, 23 кнопок `.d1-menuButton__button` и 23 скрытых `<input type="hidden">`, отсутствие горизонтального скролла.
- **Ожидаемый результат**: Все режимы (`Hide Label`, `Show Label`, `Custom Separator`, `hideValueIcon`, `Multiple`, `buttonAttrs`, `States`, `#default`) отображаются без переполнения (`scrollWidth === 1440`).
- **Тип доказательства**: Скриншот + DOM-метрики.

#### TC-VIS-002: Видимость отключенной кнопки (`disabled: true`) без иконки
- **Приоритет**: P0
- **Категория**: `VIS`
- **Предусловия**: Загружена страница `/component-menu-button`.
- **Шаги**: Проверить, что отключенный `D1MenuButton` без пропса `icon` (где `iconTrailing` равен `undefined`) присутствует в DOM и имеет ненулевые размеры.
- **Ожидаемый результат**: Кнопка видима (`disabledButtonsVisible === 1`), имеет приглушенный стиль `disabled` и не скрывает текст.
- **Тип доказательства**: Скриншот + DOM-проверка.

### 2.2. Интерактивные сценарии (INT)

#### TC-INT-001: Открытие выпадающего списка и поворот стрелки (`iconTurn`)
- **Приоритет**: P0
- **Категория**: `INT`
- **Предусловия**: Страница открыта в `1440×900`.
- **Шаги**: Кликнуть по первой активной кнопке `.d1-menuButton__button:not(:disabled)`, дождаться завершения анимации.
- **Ожидаемый результат**: Меню открывается, отображаются 8 опций (`JavaScript`..`PHP`) с иконками, стрелка на кнопке повернута вверх.
- **Тип доказательства**: Скриншот раскрытого меню + DOM-проверка.

#### TC-INT-002: Выбор опции, обновление триггера и автозакрытие
- **Приоритет**: P0
- **Категория**: `INT`
- **Предусловия**: Меню из `TC-INT-001` открыто.
- **Шаги**: Кликнуть по второй опции (`TypeScript`), дождаться закрытия меню.
- **Ожидаемый результат**: Значение обновилось на `ts`, связанный `Event Tracker` получил payload `{"value":"ts"}`, меню закрыто (`visibleOptionsAfterClick === 0`).
- **Тип доказательства**: DOM-проверка.

#### TC-INT-003: Программное управление через Expose и переключение `v-if`
- **Приоритет**: P1
- **Категория**: `INT`
- **Предусловия**: Страница открыта в `1440×900`.
- **Шаги**: Выполнить клики `setValue('option1')` → `Read Expose` → `clear()` → `Read Expose` → `Unmount (v-if)` → `Mount (v-if)`.
- **Ожидаемый результат**: Состояние expose переходит `value="option1"` → `value=undefined`; размонтирование и повторное монтирование проходят чисто.
