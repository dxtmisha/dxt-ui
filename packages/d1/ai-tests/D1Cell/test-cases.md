# Спецификация тест-кейсов: D1Cell

- **Сущность**: `D1Cell` (`Cell`, `CellDesign`)

## 1. Обзор матрицы покрытия

| Категория | Код | Количество | Распределение приоритетов | Область фокуса |
| :--- | :--- | :--- | :--- | :--- |
| **Визуальное отображение и токены** | `VIS` | 8 | P0, P1 | Разметка ячейки, метки, подписи, описания, теги (`div`, `section`, `button`, `a`), состояния (`focus`, `selected`, `readonly`, `disabled`), загрузка/скелетон, иконки, разделители, отступы, слоты |
| **Интерактивность и функциональный контракт** | `INT` | 3 | P0, P1 | Динамические состояния (`dynamic`, `dynamicHover`), обработка кликов (`@click`, `@click-lite`), методы контроллера (`getValue`, `getDetail`) |
| **Граничные значения и крайние случаи** | `BND` | 2 | P1, P2 | Числовые форматы пропсов, переполнение длинным текстом, режим `dir="rtl"` |
| **Адаптивность и вьюпорты** | `RSP` | 1 | P1, P2 | Адаптивность Desktop (`1440×900`), Tablet (`768×1024`), Mobile (`375×812`), адаптивный разделитель `dividerLabel="adaptiveSm"` |
| **Доступность (A11y)** | `A11Y` | 2 | P1, P2 | ARIA-роли (`listitem`, `menuitem`, `option`, `button`), доступность с клавиатуры (`Tab`, `Enter`, `Space`, кольцо `:focus-visible`) |
| **Консоль и здоровье среды выполнения** | `LOG` | 1 | P0 | Отсутствие `console.error`, необработанных исключений и предупреждений `[Vue warn]` при работе с компонентом |
