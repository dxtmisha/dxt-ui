## Сообщение 2

**Пользователь**

import { D1Button, D1Modal } from '@dxtmisha/d1' - не правильно подключено

**Ассистент**

В библиотеке `@dxtmisha/d1` компоненты не экспортируются именованным экспортом из корневого пакета `'@dxtmisha/d1'`.

Есть два правильных способа подключения:

### 1. Автоматический импорт через плагин (рекомендуемый способ)
В проекте уже настроен плагин `uiD1VitePlugin()` в `vite.config.ts`. Он автоматически подключает и регистрирует все компоненты `D1...` в шаблонах без необходимости ручного импорта в `<script setup>`:

```vue
<script setup lang="ts">
import { ref } from 'vue'

const isOpen = ref(false)

const handleOpen = () => {
  isOpen.value = true
}
</script>

<template>
  <div class="app">
    <D1Button
      label="Открыть"
      primary
      @click="handleOpen"
    />

    <D1Modal
      v-model:open="isOpen"
      bars-label="Привет"
    >
      Привет
    </D1Modal>
  </div>
</template>
```

---

### 2. Прямой импорт из подпутей каждого компонента
Если требуется импортировать компоненты явно, импорт выполняется из отдельных модулей:

```ts
import { D1Button } from '@dxtmisha/d1/D1Button'
import { D1Modal } from '@dxtmisha/d1/D1Modal'
```

Файл `App.vue` обновлен.
