# Поддерживаемые AI-провайдеры

Справочник параметров подключения и поддерживаемых провайдеров искусственного интеллекта для настройки в `design.config.json` или `design.config.local.json`.

## Параметры конфигурации

- **`aiType`** — тип провайдера или CLI-раннера.
- **`aiModel`** — идентификатор модели.
- **`aiKey`** — API-ключ для авторизации (не требуется для CLI-инструментов, если они уже авторизованы в системе).
- **`aiConfig`** — дополнительные параметры генерации (температура, токены, заголовки).

## Список провайдеров (aiType)

- **`gemini` (Google Gemini API)**:
  - **Класс**: `AiGoogle`
  - **Пакет**: `@google/genai`
  - **Модели**: `gemini-3.7-flash`, `gemini-2.5-pro`, `gemini-2.5-flash`
  - **Требуется**: API-ключ Google AI в `aiKey`.

- **`gemini-cli` (Google Gemini CLI)**:
  - **Класс**: `AiGoogleCli`
  - **Требуется**: Установленная в системе утилита `gemini` в PATH.
  - **Модели**: `gemini-3.7-flash`, `gemini-2.5-flash`

- **`antigravity-cli` (Google Antigravity CLI)**:
  - **Класс**: `AiAntigravityCli`
  - **Требуется**: Установленная в системе утилита `agy` в PATH.
  - **Модели**: `gemini-3.7-flash`, `gemini-2.5-flash`

- **`claude` (Anthropic Claude API)**:
  - **Класс**: `AiClaude`
  - **Пакет**: `@anthropic-ai/sdk`
  - **Модели**: `claude-3-7-sonnet-20250219`, `claude-3-5-sonnet-20241022`, `claude-3-5-haiku-20241022`
  - **Требуется**: API-ключ Anthropic в `aiKey`.

- **`claude-cli` (Anthropic Claude CLI)**:
  - **Класс**: `AiClaudeCli`
  - **Требуется**: Установленная в системе утилита `claude` в PATH.
  - **Модели**: `claude-3-7-sonnet`, `claude-3-5-sonnet`

- **`claude-agent` (Anthropic Claude Agent SDK)**:
  - **Класс**: `AiClaudeAgent`
  - **Пакет**: `@anthropic-ai/claude-agent-sdk`
  - **Требуется**: API-ключ Anthropic в `aiKey`.

- **`openai` (OpenAI API)**:
  - **Класс**: `AiOpenAi`
  - **Пакет**: `openai`
  - **Модели**: `gpt-4o`, `gpt-4o-mini`, `o3-mini`, `o1`
  - **Требуется**: API-ключ OpenAI в `aiKey`. Поддерживает совместимые эндпоинты через `aiConfig.baseURL`.

- **`zai` (xAI Grok)**:
  - **Класс**: `AiZAi`
  - **Пакеты**: `@ai-sdk/xai`, `ai`
  - **Модели**: `grok-4.5`, `grok-2`
  - **Требуется**: API-ключ xAI в `aiKey`.

## Пример настройки в design.config.json

```json
{
  "aiType": "gemini",
  "aiModel": "gemini-3.7-flash",
  "aiKey": "AIzaSy...",
  "aiConfig": {
    "temperature": 0.2
  }
}
```

Для локальной разработки без коммита ключей в Git создайте `design.config.local.json`:

```json
{
  "aiType": "gemini",
  "aiModel": "gemini-3.7-flash",
  "aiKey": "AIzaSy..."
}
```
