# Конфигурация design.config.json для AI и генерации типов

Файл `design.config.json` является единым центром управления параметрами генерации AI-документации, компиляции типов TypeScript (`.d.ts`), сканирования исходников и подключения языковых моделей.

Конфигурационный файл размещается в корне монорепозитория или в корне отдельного пакета библиотеки. Пакеты могут переопределять базовые настройки и наследовать их через механизм `"extends"`.

## Пример минимального конфига для AI

Для работы ИИ-генератора `dxt-types` и сборщика системного промпта `dxt-prompt` достаточно указать параметры выбранного провайдера:

```json
{
  "aiType": "gemini",
  "aiModel": "gemini-3.7-flash",
  "aiKey": "AIzaSy...",
  "aiConfig": {
    "temperature": 0.2
  }
}
```

## Полный пример конфигурации для генерации .d.ts и AI-типов

Ниже приведен пример конфига со всеми параметрами, регулирующими компиляцию деклараций и сборку AI-контекста:

```json
{
  "extends": "../../design.config.json",
  "packagePrefix": "@dxtmisha",
  "typesPaths": [
    "src"
  ],
  "typesMatch": [
    "Button",
    "Input"
  ],
  "typesExclude": [
    "\\.wiki\\.(d\\.)?ts$",
    "wiki/",
    "library/"
  ],
  "typesWithoutVue": false,
  "typesDir": "ai-types-temp",
  "distDir": "dist",
  "aiResourcesDir": "ai-resources",
  "promptScanDepth": 6,
  "aiType": "gemini",
  "aiModel": "gemini-3.7-flash",
  "aiKey": "AIzaSy...",
  "aiConfig": {
    "temperature": 0.2
  },
  "aiTypesConcurrency": 8
}
```

## Описание параметров для AI и генерации типов

### 1. Настройки подключения к ИИ-провайдеру
- **`aiType`** (`string`, по умолчанию: `'gemini'`) — провайдер искусственного интеллекта для оптимизации JSDoc и генерации описаний. Поддерживаются:
  - `gemini` — официальный Google Gemini API (через `@google/genai`).
  - `gemini-cli` — вызовы через локальный интерфейс Gemini CLI.
  - `openai` — модели OpenAI (GPT-4o, GPT-4o-mini и совместимые эндпоинты).
  - `claude` — Anthropic Claude API.
  - `claude-cli` / `claude-agent` — вызовы через CLI/Agent Anthropic.
  - `zai` — Zhipu AI (GLM модели).
- **`aiModel`** (`string`) — точный идентификатор модели нейросети (например: `gemini-3.7-flash`, `gpt-4o`, `claude-3-7-sonnet`).
- **`aiKey`** (`string`) — API-ключ для авторизации в сервисе выбранного провайдера.
- **`aiConfig`** (`object`) — объект тонких настроек генерации (например, температура генерации `temperature: 0.2`, лимиты токенов и кастомные заголовки).
- **`aiTypesConcurrency`** (`number`, по умолчанию: `8`) — максимальное количество файлов типов, обрабатываемых моделью параллельно во время работы команды `dxt-types`.

### 2. Параметры сканирования и компиляции .d.ts
- **`typesPaths`** (`string[]`, по умолчанию: `['src']`) — массив путей к директориям с исходным кодом, которые сканируются для извлечения TypeScript-деклараций.
- **`typesMatch`** (`string | string[]`) — строковые шаблоны или регулярные выражения для включения в сборку только определенных файлов/компонентов.
- **`typesExclude`** (`string | string[]`) — массив регулярных выражений или путей для исключения вспомогательных файлов, тестовых утилит и внутренней wiki из анализа типов (например: `["\\.wiki\\.(d\\.)?ts$", "wiki/", "library/"]`).
- **`typesWithoutVue`** (`boolean`, по умолчанию: `false`) — флаг режима компиляции. Установите `true` для чисто TypeScript/JavaScript пакетов без `.vue` компонентов: скрипт отключит вызовы `vue-tsc` и применит стандартный компилятор `tsc`.
- **`typesDir`** (`string`, по умолчанию: `'ai-types-temp'`) — имя временной директории, в которую `dxt-types` извлекает сырые `.d.ts` файлы перед очисткой и удалением приватных сущностей.
- **`distDir`** (`string`, по умолчанию: `'dist'`) — директория со скомпилированным бандлом пакета, используемая генератором для сопоставления экспортов.

### 3. Интеграция в системный промпт
- **`aiResourcesDir`** (`string`, по умолчанию: `'ai-resources'`) — папка с узкопрофильными руководствами и стандартами. `dxt-types` сканирует её и формирует блок `## Mandatory Rules` в `ai-description.md`.
- **`promptScanDepth`** (`number`, по умолчанию: `6`) — максимальная глубина рекурсивного обхода каталогов при поиске пакетов и сборе сводного `ai-prompt.md`.
- **`packagePrefix`** (`string`) — префикс пакетов монорепозитория (например, `@dxtmisha` или `@my-org`), используемый для корректного формирования путей импорта в промптах.

## Наследование и безопасность API-ключей (.local)

- **Наследование (`extends`):**
  В монорепозиториях базовый конфиг размещается в корне, а пакеты внутри `packages/*` наследуют его через `"extends": "../../design.config.json"`, переопределяя только специфичные для себя параметры (`typesWithoutVue`, `typesPaths`).
- **Локальные ключи (`design.config.local.json`):**
  Чтобы не коммитить персональные API-ключи (`aiKey`) в Git, создайте файл `design.config.local.json` рядом с основным конфигом. Скрипты автоматически подхватят локальные параметры поверх базовых. Сам файл `*.local.json` должен быть внесен в `.gitignore`.
