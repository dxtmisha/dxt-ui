# AI Documentation File Ecosystem

The `dxt-ui` ecosystem implements a multi-layered structure of machine-readable files to govern the behavior of AI assistants. The central mechanism relies on distributed documentation within individual packages, which is automatically aggregated into a unified global context.

Below is the complete registry of the ecosystem files and their areas of responsibility.

## Global System Files

- **`ai-prompt.md` (Main Aggregated System Prompt)**
  - **Location:** Monorepo root.
  - **Purpose:** Automatically generated by `dxt-prompt`. It consolidates engineering principles (AI Code Promise, Vue Style Guide) and scans all packages (including `node_modules` dependencies), extracting their descriptions (`ai-description.md`), guides (`ai-doc.md`), type links (`ai-types.md`), screenshots (`ai-screenshot/`), and developer guides (`ai-developer.md`).
  - **Usage:** Read by the agent at the beginning of each session; acts as the primary source of truth.

- **`ai-instruction.md` (Global High-Priority Directives)**
  - **Location:** Monorepo root.
  - **Purpose:** Maintained manually by developers for urgent or project-wide overriding rules. When running `dxt-prompt`, its contents are embedded at the end of `ai-prompt.md` in the `High-Priority Directives` section, superseding any base rules.

- **`ai-mcp-all-resources.json` (Consolidated MCP Resource Registry)**
  - **Location:** Monorepo root.
  - **Purpose:** An aggregated registry of all available resources (docs, types, screenshots, prompts) for Model Context Protocol (MCP) server integration.

## Internal Package Development

Files regulating work on the internal source code of a specific package. The AI accesses these files when requested to modify or extend the package itself.

- **`ai-developer.md` (Internal Standards & Patterns)**
  - **Location:** Package root (e.g., `packages/d1/ai-developer.md`).
  - **Purpose:** Fundamental guidelines on extending functionality or building new components within the library.
  - **Maintenance:** Maintained manually by developers. A relative path is embedded into `ai-prompt.md` requiring the AI to study it before altering code.

- **`ai-memory.md` (Local Workspace Memory)**
  - **Location:** Package root (e.g., `packages/scripts/ai-memory.md`).
  - **Purpose:** Dynamic architectural constraints, prohibitions, and established package conventions.
  - **Maintenance:** Updated by the agent during conversations via the **"Remember"** trigger. Holds the highest priority when making decisions inside the package.

- **`materials/` (Working Specs & Inbox)**
  - **Location:** Package or component root.
  - **Purpose:** Storage directory for specifications, design briefs, UI references, and primary task requirements.

## Public Library Interface

The public package surface utilized by the aggregation engine and consumer applications.

- **`ai-description.md` (Package Purpose & Rule Triggers)**
  - **Location:** Package root.
  - **Purpose:** Automatically generated during documentation builds (`npm run types` / `dxt-types`). Contains `Core Purpose`, `Key Capabilities`, `Triggers for Studying ai-types.md`, and the `## Mandatory Rules` block linking domain rules from `ai-resources/`.

- **`ai-doc.md` (Specialized Developer Guidelines)**
  - **Location:** Package root.
  - **Purpose:** Created manually to detail unique domain nuances, integration patterns, or styling standards. Fully embedded into `ai-prompt.md`.

- **`ai-resources/` (Domain-Specific Standards Directory)**
  - **Location:** Package root (e.g., `packages/d1/ai-resources/`, `packages/styles/ai-resources/`).
  - **Purpose:** Contains focused topic regulations structured as "Anti-Pattern vs Recommended Pattern" (e.g., `colors-and-palettes.md`, `skeleton.md`, `storage-state.md`).
  - **Example Rule (Zero-Duplication Skeleton):**
    - ❌ *Anti-Pattern:* Duplicating markup using `v-if="isLoading"` with custom placeholder boxes.
    - ✅ *Design System Pattern:* Wrapping the exact same template markup inside `<MySkeleton :active="isLoading">` with skeleton modifier classes.
  - **Usage:** Scanned by `dxt-types` during documentation builds to automatically populate triggers in the `## Mandatory Rules` section of `ai-description.md`. The AI loads a specific guide only when the assigned task explicitly touches that domain.


- **`ai-types.md` (Optimized TypeScript API Specification)**
  - **Location:** Package root.
  - **Purpose:** Automatically generated by `dxt-types`. Contains cleaned type declarations, interfaces, classes, and functions with JSDoc comments and search tags (`@keywords`), stripped of private members and implementation noise.

- **`ai-screenshot/` (Visual Context Directory)**
  - **Location:** Package root.
  - **Purpose:** Contains visual screenshots (`.webp`), rendered DOM (`screenshot-code.html`), and computed CSS (`screenshot-styles.css`) captured by `dxt-screenshot`.

- **`ai-mcp-resources.json` (Package MCP Resource Definition)**
  - **Location:** Package root.
  - **Purpose:** Map of package resource URIs exported for the Model Context Protocol.
