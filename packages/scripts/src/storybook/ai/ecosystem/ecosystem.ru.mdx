# Экосистема AI-документации

В экосистеме `dxt-ui` реализована многоуровневая структура машиночитаемых файлов для управления поведением AI-ассистентов. Центральным механизмом выступает распределенное ведение документации в пакетах с последующей автоматической агрегацией в единый глобальный контекст.

Ниже представлен полный реестр файлов экосистемы и их зоны ответственности.

## Глобальные системные файлы

- **`ai-prompt.md` (Главный агрегированный системный промпт)**
  - **Расположение:** корень монорепозитория.
  - **Суть:** файл генерируется автоматически скриптом `dxt-prompt`. Объединяет базовые стандарты разработки (AI Code Promise, Vue Style Guide) и обходит все пакеты репозитория (включая зависимости в `node_modules`), извлекая их описания (`ai-description.md`), инструкции (`ai-doc.md`), ссылки на типы (`ai-types.md`), скриншоты (`ai-screenshot/`) и стандарты разработчика (`ai-developer.md`).
  - **Использование:** читается агентом в начале каждой сессии, является главным источником правил проекта.

- **`ai-instruction.md` (Глобальные высокоприоритетные директивы)**
  - **Расположение:** корень монорепозитория.
  - **Суть:** пишется разработчиком вручную при необходимости ввести срочные или временные правила. При выполнении `dxt-prompt` содержимое файла встраивается в конец `ai-prompt.md` в секцию `High-Priority Directives` и переопределяет любые базовые правила.

- **`ai-mcp-all-resources.json` (Консолидированный реестр ресурсов MCP)**
  - **Расположение:** корень монорепозитория.
  - **Суть:** агрегированный список всех доступных ресурсов (документация, типы, скриншоты, промпты) для подключения к MCP-серверу (Model Context Protocol).

## Внутреннее использование (Разработка самого пакета)

Файлы, регламентирующие правила работы с исходным кодом конкретного пакета. Агент обращается к ним, когда разработчик просит изменить или расширить код внутри данного пакета.

- **`ai-developer.md` (Внутренние стандарты и паттерны разработки)**
  - **Расположение:** корень пакета (например, `packages/d1/ai-developer.md`).
  - **Суть:** фундаментальные правила о том, как правильно расширять функционал или создавать новые компоненты внутри библиотеки.
  - **Ведение:** поддерживается разработчиком вручную. В `ai-prompt.md` встраивается путь к файлу с требованием изучить его перед изменением кода пакета.

- **`ai-memory.md` (Локальная память пакета / Workspace Memory)**
  - **Расположение:** корень пакета (например, `packages/scripts/ai-memory.md`).
  - **Суть:** динамические архитектурные ограничения, запреты и паттерны пакета.
  - **Ведение:** обновляется агентом в процессе диалога по команде **«Запомни»** / **«Remember»**. Имеет высший приоритет при принятии решений внутри пакета.

- **`materials/` (Папка рабочих материалов и ТЗ)**
  - **Расположение:** корень пакета или конкретного компонента.
  - **Суть:** хранилище первичных материалов, макетов, спецификаций и технических заданий для решения крупных задач.

## Внешнее использование (Пакет как библиотека)

Публичный интерфейс пакета, используемый скриптом-агрегатором и пакетами-потребителями.

- **`ai-description.md` (Техническое описание пакета и триггеры правил)**
  - **Расположение:** корень пакета.
  - **Суть:** автоматически формируется при генерации документации (`npm run types` / `dxt-types`). Содержит секции `Core Purpose`, `Key Capabilities`, `Triggers for Studying ai-types.md` и раздел `## Mandatory Rules` с триггерами правил из `ai-resources/`. Текст файла полностью встраивается в `ai-prompt.md`.

- **`ai-doc.md` (Специализированные руководства разработчика)**
  - **Расположение:** корень пакета.
  - **Суть:** создается вручную для описания уникальных нюансов логики, интеграций или стилей. Полностью встраивается в `ai-prompt.md`.

- **`ai-resources/` (Папка узкопрофильных стандартов и правил)**
  - **Расположение:** корень пакета (например, `packages/d1/ai-resources/`, `packages/styles/ai-resources/`).
  - **Суть:** содержит предметные регламенты (например, `colors-and-palettes.md`, `border.md`, `elevation.md`, `spacing.md`, `skeleton.md`, `api-reference.md`, `storage-state.md`).
  - **Использование:** анализируется при сборке документации для формирования триггеров в блоке `## Mandatory Rules` файла `ai-description.md`.

- **`ai-types.md` (Оптимизированная TypeScript-спецификация API)**
  - **Расположение:** корень пакета.
  - **Суть:** автоматически создается командой `dxt-types`. Содержит очищенные декларации типов, интерфейсов, классов и функций с JSDoc-описаниями и поисковыми тегами (`@keywords`), избавленные от приватных полей и деталей реализации.

- **`ai-screenshot/` (Визуальный контекст пакета)**
  - **Расположение:** корень пакета.
  - **Суть:** содержит снимки экрана интерфейса (`.webp`), отрендеренный DOM (`screenshot-code.html`) и примененные CSS-стили (`screenshot-styles.css`), сгенерированные утилитой `dxt-screenshot`.

- **`ai-mcp-resources.json` (Ресурсная спецификация MCP пакета)**
  - **Расположение:** корень пакета.
  - **Суть:** карта URI-ресурсов пакета для экспорта в протокол Model Context Protocol.
