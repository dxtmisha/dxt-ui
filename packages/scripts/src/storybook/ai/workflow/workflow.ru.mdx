# Полный процесс работы (AIDD Workflow)

Для поддержания экосистемы AI-Driven Development (AIDD) в актуальном состоянии при разработке и модификации пакетов библиотеки `dxt-ui` необходимо следовать стандартному инженерному циклу.

## Шаг 1: Разработка исходного кода

Стандартный процесс реализации логики и интерфейсов внутри монорепозитория:
- Создание Vue 3 компонентов строго с `<script setup lang="ts">`.
- Вынос бизнес-логики и управления состоянием в Composables (`executeUseGlobal`, `executeUseLocal`, `executeUseProvide`).
- Использование SCSS-миксинов и токенов из `@dxtmisha/styles` без инлайновых стилей и кастомных медиа-запросов.

## Шаг 2: Документирование кода (TSDoc / JSDoc)

Подготовка публичного API пакета для последующего машинного анализа и генерации AI-метаданных:
- **JSDoc-описания** — документируйте классы, методы, функции, свойства и интерфейсы в соответствии с двуязычным стандартом (English / Russian).
- **Специальные теги** — активно используйте теги, которые генератор гарантированно переносит в `ai-types.md`:
  - `@example` — канонические примеры вызова методов или компонентов.
  - `@note` — архитектурные нюансы, правила инициализации и сайд-эффекты.
  - `@warning` — критические ограничения среды исполнения (например, SSR-безопасность или DOM-only).
  - `@keywords` — ключевые слова и синонимы для быстрого поиска по файлу агентом.

## Шаг 3: Генерация типов и описаний пакета

После завершения кодирования запустите генератор определений типов и метаданных в директории пакета:

```bash
npm run types
```

Команда автоматически:
- Скомпилирует `.d.ts` декларации во временную директорию.
- Удалит приватные и защищенные поля.
- Сгенерирует компактный файл `ai-types.md` с оптимизированными сигнатурами и тегами `@keywords`.
- Сформирует файл `ai-description.md` с назначением пакета, триггерами изучения и блоком `## Mandatory Rules` из папки `ai-resources/`.
- Обновит спецификацию ресурсов MCP в `ai-mcp-resources.json`.

## Шаг 4: Снятие визуального контекста (Опционально для UI)

Для пакетов компонентов (`@dxtmisha/d1`) или визуальных модулей зафиксируйте визуальное состояние:

```bash
npm run screenshot
```

Утилита автоматически запустит локальный dev-сервер, перейдет по локальному URL в headless-браузере, сделает снимок страницы (`ai-screenshot/*.webp`), экспортирует DOM-дерево (`screenshot-code.html`) и примененные стили (`screenshot-styles.css`).

## Шаг 5: Агрегация глобального промпта

Для синхронизации всех изменений в корневом файле контекста выполните в корне монорепозитория:

```bash
npm run prompt
```

Скрипт `dxt-prompt` соберет метаданные всех обновленных пакетов и зависимостей, перезаписав `ai-prompt.md` и `ai-mcp-all-resources.json`.

## Шаг 6: Постановка задач AI и сохранение опыта

При взаимодействии с AI-ассистентом:
- Агент читает обновленный `ai-prompt.md` и `ai-types.md`, формируя безошибочный код.
- При выявлении специфических нюансов разработки используйте триггер **«Запомни»**, чтобы агент зафиксировал правило в `ai-memory.md` пакета на будущее.
