# Визуальный контекст (ai-screenshot)

Одной из самых мощных возможностей инфраструктуры AIDD в `dxt-ui` является передача искусственному интеллекту не только текстовых TypeScript-контрактов, но и **визуального контекста** реального интерфейса. Это позволяет мультимодальным AI-моделям «видеть» внешний вид компонентов, проверять верстку, отступы и визуальные токены.

За эту функциональность отвечает директория `ai-screenshot/`, артефакты которой генерируются утилитой `dxt-screenshot` (класс `DesignScreenshot`).

## Как это работает под капотом

Генератор визуального контекста работает полностью автономно по следующему алгоритму:

- **1. Запуск сервера разработки:** Скрипт программно запускает локальный сервер пакета (`npm run dev`) через дочерний процесс.
- **2. Перехват локального URL:** Скрипт в реальном времени анализирует вывод консоли (stdout) запущенного сервера и считывает адрес хоста (например, `http://localhost:5173`).
- **3. Запуск Headless-браузера:** После получения адреса поднимается headless-браузер (без графической оболочки) и выполняет навигацию на целевую страницу.
- **4. Захват состояния интерфейса:** Браузер выполняет полный снимок экрана страницы в высоком разрешении, сохраняя оптимизированные изображения в формате `.webp`, а также извлекает отрендеренное DOM-дерево и примененные CSS-стили.
- **5. Завершение процесса:** Скрипт корректно завершает работу dev-сервера и сохраняет все полученные файлы в папку `ai-screenshot/`.

## Содержимое директории ai-screenshot/

После генерации в корне пакета создается набор артефактов:

- **`screenshot-*.webp`** — серия графических снимков интерфейса в формате WebP с минимальным весом и высокой детализацией.
- **`screenshot-code.html`** — полный отрендеренный HTML (DOM-дерево) со всеми атрибутами и классами.
- **`screenshot-styles.css`** — скомпилированные CSS-стили, реально примененные к элементам страницы.

## Интеграция в системный промпт и MCP

При запуске `dxt-prompt` пути ко всем файлам из папки `ai-screenshot/` автоматически встраиваются в реестр пакетов файла `ai-prompt.md`:

```markdown
## Component Visual References (Screenshots)
- 'node_modules/@dxtmisha/d1/ai-screenshot/screenshot-8_1.webp'
- 'node_modules/@dxtmisha/d1/ai-screenshot/screenshot-code.html'
- 'node_modules/@dxtmisha/d1/ai-screenshot/screenshot-styles.css'
```

Кроме того, генератор ресурсов `DesignTypesMcp` преобразует скриншоты в мультимедийные ресурсы протокола MCP с MIME-типами `image/webp`, `text/html` и `text/css`, позволяя современным AI-агентам запрашивать визуальные данные напрямую через инструменты модели.

## Запуск генерации

- **Через npm-скрипт в директории пакета:**
  ```bash
  npm run screenshot
  ```
- **Через npx CLI:**
  ```bash
  npx dxt-screenshot
  ```
