# `useAi`

Composable to obtain an AI adapter instance based on the current project configuration.

**Returns:**
`AiAbstract | undefined` — An instance of the configured AI provider class (such as `AiGoogle`, `AiGoogleCli`, `AiClaude`, `AiClaudeAgent`, `AiClaudeCli`, `AiOpenAi`, `AiZAi`) depending on the configured AI type, or `undefined` if the type is unrecognized or unconfigured.

## How it works

The composable reads the AI type from `PropertiesConfig.getAiType()` and instantiates the corresponding class:
- `'claude'` — returns `AiClaude` (Anthropic Claude API).
- `'claude-agent'` — returns `AiClaudeAgent` (Anthropic Claude Agent SDK).
- `'claude-cli'` — returns `AiClaudeCli` (Claude CLI interface).
- `'gemini'` — returns `AiGoogle` (Google Gemini API).
- `'gemini-cli'` — returns `AiGoogleCli` (Google Gemini CLI interface).
- `'openai'` — returns `AiOpenAi` (OpenAI GPT API).
- `'zai'` — returns `AiZAi` (xAI / Grok API).
- Other types return `undefined`.

## Example

```typescript
import { useAi } from '@dxtmisha/scripts'

const ai = useAi()

if (ai) {
  const response = await ai.generate('Hello, AI!')
  console.log(response)
}
```
