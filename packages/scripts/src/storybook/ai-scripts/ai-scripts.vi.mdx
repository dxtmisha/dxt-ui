# Tạo định nghĩa kiểu và lời nhắc AI

Trong hệ sinh thái **DXT UI**, quá trình chuẩn bị ngữ cảnh máy có thể đọc được và đào tạo các trợ lý AI lập trình được tự động hóa hoàn toàn thông qua hai lệnh CLI bổ trợ lẫn nhau: `dxt-types` (`design-types.ts`) và `dxt-prompt` (`design-prompt.ts`).

Các công cụ này giúp giải phóng lập trình viên khỏi gánh nặng sao chép tài liệu thủ công, tạo ra các hợp đồng mã nguồn có kiểu chặt chẽ, tối ưu hóa token và hợp nhất các quy tắc hệ thống.

## Ưu điểm vượt trội của tự động hóa

### 1. Không ảo giác nhờ hợp đồng kiểu chuẩn xác (Zero Hallucinations)
Lệnh `dxt-types` trích xuất các tệp khai báo TypeScript (`.d.ts`), loại bỏ hoàn toàn các thuộc tính private và chi tiết cài đặt bên trong, chỉ giữ lại API công khai. Trợ lý AI chỉ dựa vào các export thực tế của thư viện.

### 2. Nguồn chân lý duy nhất (Single Source of Truth)
Lệnh `dxt-prompt` quét đệ quy các package nội bộ và dependency trong `node_modules`, tổng hợp metadata và tạo tệp `ai-prompt.md` tại thư mục gốc monorepo, tự động khởi tạo ngữ cảnh ngay khi bắt đầu bất kỳ phiên làm việc AI nào.

### 3. Hỗ trợ gốc giao thức Model Context Protocol (MCP)
Cả hai script đều tự động tạo các bản kê tài nguyên `ai-mcp-resources.json` và `ai-mcp-all-resources.json`, cho phép các trợ lý AI hiện đại kết nối trực tiếp qua giao thức MCP.

## Hướng dẫn từng bước (Những việc cần làm)

### Phần 1. Tạo kiểu dữ liệu và hồ sơ Package (`dxt-types`)

#### Bước 1.1. Chạy lệnh tạo kiểu trong thư mục Package
Sau khi thêm hoặc chỉnh sửa hàm, component hoặc interface, hãy thực hiện trong thư mục package:

```bash
npx dxt-types
```

Script sẽ tự động thực hiện các thao tác sau:
- Biên dịch các khai báo TypeScript vào một thư mục tạm thời riêng biệt.
- Loại bỏ chi tiết cài đặt, các thuộc tính `private` và `protected`.
- Tối ưu hóa chú thích JSDoc bằng AI, giữ lại các thẻ kiến trúc quan trọng (`@example`, `@note`, `@warning`, `@remarks`, `@keywords`).
- Tạo tệp `ai-types.md` chứa đặc tả kiểu đã nén gọn.
- Tạo hồ sơ thư viện `ai-description.md` kèm khối `## Mandatory Rules` từ thư mục `ai-resources/`.
- Ghi tệp tài nguyên `ai-mcp-resources.json`.

```text
DesignTypes: making AI types...
DesignTypes: AI types saved.
```

#### Bước 1.2. Lưu nhanh ngoại tuyến không dùng AI (`dxt-types-save`)
Nếu cần tạo lại tệp kiểu từ bộ nhớ đệm có sẵn mà không cần gọi API AI:

```bash
npx dxt-types-save
```

#### Các tùy chọn của lệnh `dxt-types`:
```bash
npx dxt-types [--prompts DIR] [--dir DIR] [--dist DIR]
```
- **`--prompts` (`-p`)**: Đường dẫn tới thư mục quy tắc cục bộ (mặc định là `ai-resources`).
- **`--dir` (`-d`)**: Thư mục tạm thời chứa các khai báo trung gian (mặc định là `ai-types-temp`).
- **`--dist`**: Thư mục chứa các tệp JS/DTS đã biên dịch (mặc định là `dist`).

### Phần 2. Hợp nhất lời nhắc toàn cục (`dxt-prompt`)

#### Bước 2.1. Chạy lệnh tạo lời nhắc hệ thống
Tại thư mục gốc monorepo, hãy chạy `dxt-prompt`:

```bash
npx dxt-prompt
```

Script sẽ tiến hành xây dựng ngữ cảnh toàn cục:
- Quét đệ quy các thư mục module đã cấu hình (`packages/*`, `node_modules/@dxtmisha/*`).
- Thu thập mô tả package (`ai-description.md`), hướng dẫn (`ai-doc.md`), liên kết kiểu (`ai-types.md`) và ảnh chụp (`ai-screenshot/`).
- Kết hợp vai trò hệ thống, nguyên tắc AI Code Promise (`aiCodeGlobalPrompt`) và tiêu chuẩn Vue Style Guide (`aiCodeVuePrompt`).
- Nhúng các chỉ thị ưu tiên cao từ `ai-instruction.md` (nếu có).
- Thêm danh sách kiểm tra tự đánh giá bắt buộc (`Self-Audit`).
- Lưu tệp kết quả `ai-prompt.md` tại thư mục gốc dự án.

```text
Generating AI prompt...
end
```

#### Bước 2.2. Tạo kèm danh mục tài nguyên MCP hợp nhất
Để tự động tạo bản kê tài nguyên `ai-mcp-all-resources.json`, thêm tùy chọn `--mcp` (`-m`):

```bash
npx dxt-prompt --mcp
```

## Cấu trúc bên trong của các công cụ

- **Bộ sinh kiểu dữ liệu (`DesignTypes`)**:
  - `DesignTypesBuild` — Quản lý biên dịch tạm thời các khai báo TypeScript.
  - `DesignTypesMake` — Làm sạch AST khai báo và loại bỏ thực thể private.
  - `DesignTypesAi` — Tương tác với mô hình ngôn ngữ để chuẩn hóa JSDoc.
  - `DesignTypesPrompts` — Lưu bộ nhớ đệm và phân tích quy tắc từ `ai-resources/`.
  - `DesignTypesDescription` — Tổng hợp mô tả kỹ thuật trong `ai-description.md`.
  - `DesignTypesMcp` — Đăng ký tài nguyên có kiểu MIME trong `ai-mcp-resources.json`.

- **Bộ tổng hợp lời nhắc (`LibraryAiPrompt`)**:
  - `LibraryAiPromptItem` — Quét từng package riêng lẻ và thu thập metadata.
  - `LibraryAiMcp` — Tổng hợp danh mục tài nguyên toàn cục `ai-mcp-all-resources.json`.
  - `LibraryAiWiki` — Đồng bộ hóa cấu trúc tài liệu MDX.

## Ưu điểm so với quản lý ngữ cảnh thủ công

- **Đồng bộ tự động**: Ngữ cảnh AI luôn khớp chính xác 100% với mã nguồn thực tế.
- **Tiết kiệm tới 80% token**: Việc làm sạch kiểu và tải lười theo trigger ngăn ngừa tràn bộ nhớ ngữ cảnh.
- **Độc lập với công cụ**: Tệp `ai-prompt.md` hoạt động đồng nhất trên Antigravity, Cursor, Windsurf, Claude Code và GitHub Copilot.
