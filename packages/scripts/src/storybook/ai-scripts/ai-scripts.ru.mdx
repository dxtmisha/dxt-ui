# Генерация AI-типов и системного промпта

В экосистеме **DXT UI** процессы подготовки машиночитаемого контекста и обучения AI-ассистентов полностью автоматизированы с помощью двух взаимосвязанных CLI-команд: `dxt-types` (`design-types.ts`) и `dxt-prompt` (`design-prompt.ts`).

Эти инструменты избавляют разработчика от ручного копирования документации и формируют строгие, оптимизированные по токенам кодовые контракты и консолидированные файлы системных правил.

## Преимущества автоматизации

### 1. Нулевая толерантность к галлюцинациям (Zero Hallucinations)
Команда `dxt-types` извлекает TypeScript-декларации (`.d.ts`), очищает их от приватных полей и внутренней реализации, сохраняя только публичный интерфейс. ИИ-ассистент опирается исключительно на реальные экспорты библиотеки.

### 2. Единый источник истины (Single Source of Truth)
Команда `dxt-prompt` рекурсивно обходит локальные пакеты и установленные зависимости `node_modules`, собирает метаданные и формирует в корне монорепозитория файл `ai-prompt.md`, который автоматически инициализирует контекст при старте любой AI-сессии.

### 3. Нативная поддержка Model Context Protocol (MCP)
Оба скрипта автоматически генерируют ресурсные манифесты `ai-mcp-resources.json` и `ai-mcp-all-resources.json`, позволяя современным AI-агентам подключаться к кодовой базе через протокол MCP.

## Пошаговое руководство (Что нужно делать)

### Часть 1. Генерация типов и профиля пакета (`dxt-types`)

#### Шаг 1.1. Запустите генерацию типов в директории пакета
После добавления или изменения функций, компонентов или интерфейсов выполните в папке пакета:

```bash
npx dxt-types
```

Скрипт автоматически выполнит следующие действия:
- Скомпилирует декларации TypeScript во временную изолированную директорию.
- Удалит внутренние детали реализации, приватные (`private`) и защищенные (`protected`) свойства.
- Оптимизирует JSDoc-описания с помощью ИИ, сохранив критические архитектурные теги (`@example`, `@note`, `@warning`, `@remarks`, `@keywords`).
- Создаст файл `ai-types.md` со сжатыми спецификациями типов.
- Сформирует профиль библиотеки `ai-description.md` с блоком `## Mandatory Rules` из папки `ai-resources/`.
- Запишет ресурсный файл `ai-mcp-resources.json`.

```text
DesignTypes: making AI types...
DesignTypes: AI types saved.
```

#### Шаг 1.2. Быстрое сохранение без вызова ИИ (`dxt-types-save`)
Если требуется пересобрать типы из существующего кэша без сетевых обращений к API ИИ:

```bash
npx dxt-types-save
```

#### Опции команды `dxt-types`:
```bash
npx dxt-types [--prompts DIR] [--dir DIR] [--dist DIR]
```
- **`--prompts` (`-p`)**: Путь к папке локальных промптов и регламентов (по умолчанию `ai-resources`).
- **`--dir` (`-d`)**: Временная директория для промежуточных деклараций (по умолчанию `ai-types-temp`).
- **`--dist`**: Папка скомпилированных JS/DTS файлов пакета (по умолчанию `dist`).

### Часть 2. Консолидация глобального промпта (`dxt-prompt`)

#### Шаг 2.1. Запустите генерацию системного промпта
В корне монорепозитория выполните команду `dxt-prompt`:

```bash
npx dxt-prompt
```

Скрипт выполнит сборку глобального контекста:
- Рекурсивно просканирует настроенные директории модулей (`packages/*`, `node_modules/@dxtmisha/*`).
- Соберет описания библиотек (`ai-description.md`), инструкции (`ai-doc.md`), ссылки на типы (`ai-types.md`) и скриншоты (`ai-screenshot/`).
- Объединит системную роль, правила AI Code Promise (`aiCodeGlobalPrompt`) и стандарты Vue Style Guide (`aiCodeVuePrompt`).
- Встроит высокоприоритетные директивы из `ai-instruction.md` (при наличии).
- Добавит чек-лист обязательного финального самоаудита (`Self-Audit`).
- Запишет итоговый файл `ai-prompt.md` в корень проекта.

```text
Generating AI prompt...
end
```

#### Шаг 2.2. Генерация с реестром MCP-ресурсов
Для автоматической сборки единого файла `ai-mcp-all-resources.json` добавьте опцию `--mcp` (`-m`):

```bash
npx dxt-prompt --mcp
```

## Внутреннее устройство инструментов

- **Движок генерации типов (`DesignTypes`)**:
  - `DesignTypesBuild` — управление временной компиляцией TypeScript-деклараций.
  - `DesignTypesMake` — очистка AST-деклараций и удаление приватных сущностей.
  - `DesignTypesAi` — взаимодействие с языковой моделью для нормализации JSDoc.
  - `DesignTypesPrompts` — кэширование и парсинг локальных правил `ai-resources/`.
  - `DesignTypesDescription` — синтез технического описания `ai-description.md`.
  - `DesignTypesMcp` — регистрация ресурсов с MIME-типами в `ai-mcp-resources.json`.

- **Движок агрегации промптов (`LibraryAiPrompt`)**:
  - `LibraryAiPromptItem` — сканер отдельного пакета и сборщик метаданных.
  - `LibraryAiMcp` — агрегатор реестра ресурсов `ai-mcp-all-resources.json`.
  - `LibraryAiWiki` — синхронизация MDX-документации.

## Преимущества перед ручным ведением контекста

- **Автоматическая актуализация**: Контекст ИИ всегда точно соответствует реальному исходному коду проекта.
- **Экономия токенов до 80%**: Очистка типов и ленивая подгрузка по триггерам предотвращают переполнение контекстного окна.
- **Инструментальная независимость**: Сгенерированный `ai-prompt.md` работает одинаково эффективно в Antigravity, Cursor, Windsurf, Claude Code и GitHub Copilot.
