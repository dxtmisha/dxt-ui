# Архитектура и преимущества дизайн-системы

Пакет `@dxtmisha/scripts` — это инфраструктурное ядро и кодогенератор дизайн-системы **DXT UI**. Он реализует передовую архитектуру разделения абстрактной поведенческой логики и визуального представления, автоматизируя создание, связывание, типизацию и документирование всех компонентов библиотеки.

Главная цель системы — предоставить разработчикам полностью автоматизированный конвейер, исключающий рутинный шаблонный код (boilerplate), предотвращающий ошибки человеческого фактора и обеспечивающий сквозную согласованность между дизайном, стилями, логикой и типами TypeScript.

## Ключевые преимущества реализации

### 1. Строгая изоляция логики от визуального слоя (Headless + Design System)
Поведенческая логика (обработка клавиатуры, фокус-ловушки, расчет позиционирования, доступность ARIA, синхронизация состояний) полностью вынесена в `@dxtmisha/constructor`. 
- **Легкость создания новых UI-китов:** Для создания альтернативной темы оформления (например, `d2` или кастомной темы бренда) не нужно переписывать ни строчки сложной логики компонентов — достаточно определить новые `properties.json` и файлы стилей.
- **Гарантированная надежность:** Исправление бага в логике конструктора автоматически чинит поведение во всех дизайн-системах, использующих этот конструктор.

### 2. Нулевой бойлерплейт и колоссальная скорость разработки (Zero-Boilerplate)
В классическом подходе добавление каждого нового пропса требует правок в 5–7 местах (типы, пропсы Vue, валидаторы, шаблон классов, SCSS-селекторы, документация).
- В DXT UI разработчик добавляет **одну строку** в `properties.json`.
- Команда `dxt-ui` за секунду автоматически генерирует обновленный `props.ts`, BEM-маппинг в `.vue` файле, SCSS-переменные в `styleToken.scss` и метаданные для автодополнения в IDE.

### 3. Единый источник правды и сквозная типизация (100% Type Safety)
Файл `properties.json` выступает абсолютным источником правды для всей инфраструктуры:
- **TypeScript**: строго типизирует все возможные значения свойств (`size: 'sm' | 'md' | 'lg'`).
- **Runtime-проверки**: генерирует массивы допустимых значений (`propsValues`) для мгновенной валидации через хелперы `inArray`.
- **IDE подсказки**: автоматически обновляет `web-types.json`, обеспечивая полноценный IntelliSense в WebStorm и VS Code.
- Полностью исключены человеческие ошибки: опечатки в названиях классов, расхождения типов и CSS-селекторов, забытые экспорты.

### 4. Мгновенный глобальный рефакторинг всей дизайн-системы
Если требуется изменить префикс BEM-классов, скорректировать правила формирования CSS-переменных или поддержать новые стандарты браузеров во всех 100+ компонентах:
- Достаточно внести изменение в один генератор в `@dxtmisha/scripts`.
- Запуск сборки мгновенно пересобирает все компоненты монорепозитория в соответствии с новыми правилами за считанные секунды.

### 5. Декларативное управление палитрами и темами без раздувания CSS
Парсер дизайн-токенов поддерживает сложные паттерны оформления:
- **`flag-theme` и палитры**: динамическое переключение темной/светлой темы и цветовых схем без дублирования CSS-кода через CSS-переменные палитр.
- **Разделение цвета и прозрачности**: использование токенов с независимой прозрачностью (`backgroundOpacity`, `colorOpacity`).
- **Умные BEM-модификаторы (`flag-subclass`, `flag-replace`)**: классы-модификаторы добавляются в DOM только тогда, когда активны соответствующие флаги.

### 6. Автоматическая композиция и Dependency Injection подкомпонентов
Сгенерированный `.vue` компонент автоматически связывает и передает вспомогательные элементы (иконки `D1Icon`, индикаторы загрузки `D1Progress`, эффекты нажатия `D1Ripple`) напрямую в класс `Design`. Шаблон компонента остается предельно чистым:
```html
<script setup lang="ts">
// Вся связка сгенерирована автоматически
const design = new ButtonDesign('d1.button', props, {
  emits,
  classes: classesToken,
  styles: stylesToken,
  components: { icon: D1Icon, progress: D1Progress, ripple: D1Ripple }
})
const render = design.render()
</script>

<template>
  <render/>
</template>
```

### 7. AI-Native экосистема и автоматизация документации
- **Генерация `ai-types.md`**: пакет компилирует сжатые справочники типов, позволяющие LLM-моделям мгновенно понимать API библиотек без чтения гигантских файлов исходников.
- **AI-генерация справочников и Storybook MDX**: автоматическое наполнение документации описаниями и интерактивными примерами.
- **Figma API синхронизация**: прямой импорт фреймов, токенов и стилей из макетов Figma в кодовую базу.

## Как это устроено под капотом

### 1. Описание визуального контракта (`properties.json`)
Разработчик описывает дизайн-свойства компонента в декларативном формате:
```json
{
  "size": {
    "type": "type-var",
    "value": ["sm", "md", "lg"],
    "default": "md"
  },
  "palette": {
    "type": "flag-theme",
    "value": ["primary", "secondary", "tertiary", "error"]
  },
  "outline": {
    "type": "flag-subclass"
  }
}
```

### 2. Автоматическая генерация файлов
Инструмент `dxt-ui` компилирует JSON-конфигурацию в набор взаимосвязанных файлов:
1. **`props.ts`**: объединяет базовые свойства логического конструктора и визуальные дизайн-токены с дефолтными значениями.
2. **`styleToken.scss`**: генерирует SCSS-миксины и CSS-переменные для каждого значения токенов.
3. **`D1[Component].vue`**: формирует реактивную BEM-карту классов (`classesToken`) и инициирует экземпляр `Design`.
4. **`index.ts`**: собирает и экспортирует компонент и все связанные типы.

## Основные CLI-команды экосистемы

- **`dxt-ui [ComponentName]`** — главный оркестратор сборки UI. Сканирует `properties.json`, генерирует шаблоны, BEM-карты, типизированные пропсы и связывает их с классами Конструктора.
- **`dxt-constructor`** — компилирует глобальные классы и интерфейсы конструктора логики, актуализируя типы компонентов.
- **`dxt-library`** — сканирует структуру проекта и автоматически обновляет индексные файлы экспорта во всех пакетах монорепозитория.
- **`dxt-screenshot`** — автоматизированная среда регрессионного визуального аудита на базе Puppeteer.
- **`dxt-types-save`** — генерирует AI-оптимизированные справочники типов `ai-types.md` для интеграции с языковыми моделями.
