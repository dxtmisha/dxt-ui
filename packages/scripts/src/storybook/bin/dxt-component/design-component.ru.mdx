# dxt-component

Команда `dxt-component` обеспечивает автоматическую генерацию базовой структуры (скаффолдинг) новых компонентов дизайн-системы. Инструмент использует классы `ComponentCreator` и `ComponentItem` для автоматического обнаружения пустых папок внутри `src/components/` и создания полного набора шаблонных файлов для каждого нового компонента.

## Ключевые возможности

- **Автоматическое сканирование директорий**: Рекурсивно сканирует `src/components/` и находит все пустые папки компонентов.
- **Полная генерация шаблонов**: Разворачивает 8 обязательных файлов компонента, включая код Vue SFC, TypeScript-типы, входные точки, Storybook MDX/Stories и промпты для ИИ.
- **Динамическая замена плейсхолдеров**: Автоматически подставляет имя компонента (в PascalCase и kebab-case), имя текущего проекта из `package.json` и относительный путь.
- **Управление правами файлов**: Автоматически устанавливает корректные права доступа для созданных файлов через `PropertiesFile.chmod`.

## Как это работает?

1. **Поиск пустых директорий**: Класс `ComponentCreator` сканирует директорию `src/components/` через `PropertiesFile.readDirOnlyRecursive` и фильтрует папки, в которых нет файлов.
2. **Инициализация генератора**: Для каждой пустой папки создается экземпляр `ComponentItem`, который загружает набор встроенных шаблонов (`componentDocTemplates`).
3. **Подстановка контекстных данных**: Выполняется строковая замена плейсхолдеров:
   - `ComponentDoc` -> имя компонента в PascalCase (например, `Button`)
   - `component-doc` -> имя компонента в kebab-case (например, `button`)
   - `[project]` -> имя пакета из `package.json` (например, `@dxtmisha/d1`)
   - `[path]` -> относительный путь к компоненту (например, `src/components/Button`)
   - `_.gitignore.txt` -> `.gitignore`
4. **Запись файлов**: Сгенерированные файлы записываются в целевую папку компонента с установкой прав доступа.

## Использование

Создайте пустую папку для нового компонента в `src/components/` (например, `src/components/Badge`) и выполните команду:

```bash
npx dxt-component
```

Либо добавьте вызов в скрипты `package.json` пакета:

```json
{
  "scripts": {
    "component": "dxt-component"
  }
}
```

## Структура генерируемых файлов

Для каждого обнаруженного компонента создаются 8 файлов:

- `[ComponentName].vue` — Базовый Vue 3 SFC шаблон с `<script setup lang="ts">`, типизацией и базовым `<style lang="scss">`.
- `index.ts` — Точка входа компонента с именованным экспортом (`export const [ComponentName]`).
- `types.ts` — Интерфейсы TypeScript для `Props`, `Emits`, `Slots` и свойств по умолчанию.
- `materials/prompt.md` — Системные инструкции и промпт для ИИ по материалам компонента.
- `subcomponents/.gitignore` — Файл исключений для директории вложенных подкомпонентов.
- `wiki/[ComponentName].mdx` — Готовый файл документации Storybook в формате MDX.
- `wiki/[ComponentName].stories.ts` — Конфигурация историй Storybook Vue 3 с превью компонента.
- `wiki/prompt.md` — Системные инструкции и промпт для документирования компонента в Wiki.
