# dxt-types-save

Команда `dxt-types-save` собирает и сохраняет оптимизированные для ИИ определения типов TypeScript из предварительно обработанных файлов списка без повторного вызова моделей ИИ. Она обеспечивает быструю генерацию справочника типов, проверяет наличие руководства разработчика и компилирует ресурсы для MCP-сервера.

## Ключевые возможности

- **Быстрое локальное сохранение**: Объединяет обработанные декларации из директории `ai-types-list` без расхода токенов и сетевых запросов к API ИИ.
- **Автоматическая проверка описания**: Проверяет наличие файла `ai-developer.md` и генерирует его только при отсутствии.
- **Компиляция MCP-ресурсов**: Формирует ресурсы и метаданные протокола MCP (Model Context Protocol).

## Как это работает?

1. **Чтение готового списка**: Считывает подготовленные определения типов из директории `ai-types-list`.
2. **Сборка `ai-types.md`**: Объединяет и сохраняет итоговый оптимизированный справочник типов TypeScript для ИИ.
3. **Проверка руководства**: Проверяет наличие технического резюме в `ai-developer.md` и генерирует его при необходимости.
4. **Сборка конфигурации MCP**: Вызывает `DesignTypesMcp` для формирования ресурсов MCP.

## Использование

Запустите сохранение типов через `npx`:
```bash
npx dxt-types-save [build_dir] [resources_dir]
```
- `build_dir` (Необязательно): Директория сборки. По умолчанию `dist`.
- `resources_dir` (Необязательно): Директория с файлами промптов и ресурсов. По умолчанию `ai-resources`.
