# Класс AiAntigravityCli

Высокоуровневая реализация для взаимодействия с Google Antigravity AI через интерфейс командной строки (`agy`). Класс `AiAntigravityCli` расширяет `AiAntigravityCliLite` и упрощает работу, автоматически загружая API-ключ и идентификатор модели из настроек конфигурации проекта (`getConfigAi()`).

> Для работы этой реализации требуется установленная утилита `agy` CLI, доступная в переменной PATH вашей системы.

## Ключевые особенности

- **Автоматическая настройка** — не требует ручной инициализации ключей или моделей; параметры считываются из окружения проекта (`design.config.json` / `design.config.local.json`).
- **Выполнение через CLI** — использует прямой вызов `agy` без системной оболочки для надежного выполнения запросов.
- **Управление временными файлами** — автоматически обрабатывает создание и удаление временных файлов промптов (`ApiTmp`).
- **Строгий вывод ответов** — использует флаг `--yolo` и специализированные инструкции, чтобы ассистент возвращал чистый результат без лишних вступлений.

## Инициализация

Класс `AiAntigravityCli` готов к использованию без каких-либо аргументов конструктора.

```typescript
import { AiAntigravityCli } from '@dxtmisha/scripts'

const ai = new AiAntigravityCli()

// Генерация ответа с использованием настроек проекта
const response = await ai.generate('Сгенерируй TypeScript интерфейс для компонента.')
```

## Методы

### Генерация

- `generate(contents: string): Promise<string>` — (Унаследовано) Анализирует ввод, управляет временными файлами и выполняет команду `agy` CLI для получения ответа.

### Конфигурация

- `setKey(key: string): this` — (Унаследовано) Позволяет вручную переопределить API-ключ при необходимости.
- `setModel(model: string): this` — (Унаследовано) Переключает идентификатор активной модели.

### Сбор контекста

- `addPrompt(prompt: string): void` — (Унаследовано) Устанавливает постоянный текстовый префикс (системные инструкции).
- `addContent(content: string): this` — (Унаследовано) Добавляет текстовую часть к совокупному запросу.
- `resetPrompt(): void` — (Унаследовано) Очищает постоянный префикс.
- `resetContents(): this` — (Унаследовано) Очищает все накопленные части текста.

## Ограничения

- **Мультимодальность** — как и базовый CLI-класс, эта реализация в настоящее время не поддерживает ввод изображений.
- **Системные зависимости** — требуется наличие инструмента `agy` CLI в переменной PATH.
