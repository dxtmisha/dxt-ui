# Class DesignTypesBuildAbstract

The `DesignTypesBuildAbstract` abstract base class defines the interface and foundational architecture for compiling TypeScript and Vue source files into declaration files (`.d.ts`) inside a temporary directory prior to AI optimization and documentation processing.

## Constructor

**Parameters:**
- `temporaryDirectory: string` — directory path for storing temporary declaration files. Defaults to `PropertiesConfig.getTypesTemporaryDirectory()`.

```typescript
import { DesignTypesBuildAbstract } from '@dxtmisha/scripts'

class CustomTypesBuild extends DesignTypesBuildAbstract {
  is(): boolean {
    // Check directory existence
    return false
  }

  clean(): this {
    // Clean temporary directory
    return this
  }

  build(): this {
    // Compile type declarations
    return this
  }
}
```

## Methods

### `abstract is(): boolean`
Checks if the temporary compilation directory exists on disk.

### `abstract clean(): this`
Cleans or deletes the temporary compilation directory and all emitted declarations.

### `abstract build(): this`
Compiles TypeScript declarations from source files into the temporary directory.
