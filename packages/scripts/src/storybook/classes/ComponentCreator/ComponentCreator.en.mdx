# ComponentCreator Class

The `ComponentCreator` class is an automation utility designed to discover empty directories inside `src/components/` and scaffold their initial component structure. It scans configured component paths and bootstraps a full set of boilerplate files using `ComponentItem`.

## Key Features

- **Automated Discovery**: Recursively scans `src/components/` using `PropertiesFile.readDirOnlyRecursive`.
- **Empty Folder Filtering**: Filters for folders that contain zero files.
- **Batch Scaffolding**: Instantiates `ComponentItem` for each detected empty folder to generate all essential component files.
- **Design System Consistency**: Enforces a unified baseline architecture for all newly created components.

## Initialization

Initialize an instance of `ComponentCreator`. It automatically targets the standard components directory `src/components/`:

```typescript
import { ComponentCreator } from '@dxtmisha/scripts'

const creator = new ComponentCreator()
creator.make()
```

## Methods

- `make(): void` — Primary orchestration method:
  1. Calls `getDirs()` to obtain a list of empty directory paths.
  2. For each detected path, creates a `ComponentItem(path)` instance and invokes `.make()`.
- `protected getDirs(): string[]` — Scans `UI_DIRS_COMPONENTS` (`src/components/`) via `PropertiesFile.readDirOnlyRecursive` and returns an array of folder paths where `PropertiesFile.readDir(getComponentPaths(path)).length === 0`.

## Example Usage

```typescript
import { ComponentCreator } from '@dxtmisha/scripts'

// Scan and bootstrap all empty component directories
new ComponentCreator().make()
```
