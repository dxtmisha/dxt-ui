# Класс ComponentCreator

Класс `ComponentCreator` — это утилита автоматизации для обнаружения пустых папок внутри директории компонентов (`src/components/`) и создания их начальной структуры (скаффолдинга). Он сканирует настроенные пути компонентов и инициирует создание полного набора файлов шаблонов через `ComponentItem`.

## Ключевые возможности

- **Автоматическое обнаружение**: Рекурсивно сканирует директорию `src/components/` с помощью `PropertiesFile.readDirOnlyRecursive`.
- **Фильтрация пустых папок**: Выбирает только те директории, в которых полностью отсутствуют файлы.
- **Пакетная генерация**: Инициирует `ComponentItem` для каждой найденной пустой папки, разворачивая полноценный набор файлов компонента.
- **Согласованность архитектуры**: Гарантирует единообразие структуры всех новых компонентов в дизайн-системе.

## Инициализация

Создайте новый экземпляр `ComponentCreator`. Он автоматически использует стандартную директорию компонентов `src/components/`:

```typescript
import { ComponentCreator } from '@dxtmisha/scripts'

const creator = new ComponentCreator()
creator.make()
```

## Методы

- `make(): void` — основной метод оркестрации:
  1. Вызывает `getDirs()` для получения списка пустых директорий.
  2. Для каждого найденного пути создает экземпляр `ComponentItem(path)` и вызывает метод `.make()`.
- `protected getDirs(): string[]` — сканирует `UI_DIRS_COMPONENTS` (`src/components/`) через `PropertiesFile.readDirOnlyRecursive` и возвращает массив путей к папкам, для которых `PropertiesFile.readDir(getComponentPaths(path)).length === 0`.

## Пример использования

```typescript
import { ComponentCreator } from '@dxtmisha/scripts'

// Сканирование и создание шаблонов во всех пустых папках компонентов
new ComponentCreator().make()
```
