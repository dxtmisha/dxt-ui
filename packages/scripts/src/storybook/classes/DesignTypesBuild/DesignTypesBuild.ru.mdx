# Класс DesignTypesBuild

Класс `DesignTypesBuild` отвечает за предварительную компиляцию исходных файлов TypeScript и компонентов Vue (`.vue`) в файлы деклараций типов (`.d.ts`) во временную директорию перед последующей генерацией файлов документации и справочников типов для ИИ.

## Ключевые особенности

- **Поддержка TypeScript и Vue**: Автоматически определяет наличие файлов `.vue` и использует `vue-tsc` для извлечения деклараций компонентов либо TypeScript Compiler API для чистого TypeScript.
- **Интеллектуальная фильтрация**: Учитывает конфигурации путей (`typesPaths`), шаблонов включения (`typesMatch`) и исключения (`typesExclude`) из `design-ui.json`.
- **Автоматическая очистка**: Удаляет временную директорию перед сборкой и отсекает избыточные файлы (тесты, истории Storybook, внутренние входные точки).

## Конструктор

**Параметры:**
- `temporaryDirectory: string` — путь к временной директории компиляции. По умолчанию используется значение из `PropertiesConfig.getTypesTemporaryDirectory()`.

```typescript
import { DesignTypesBuild } from '@dxtmisha/scripts'

const builder = new DesignTypesBuild()
builder.build()
```

## Методы

### `is(): boolean`
Проверяет, существует ли временная директория компиляции.

### `isVue(): boolean`
Проверяет, содержит ли проект компоненты Vue (`.vue`), требующие запуска компилятора `vue-tsc`.

### `build(): this`
Запускает полный цикл компиляции деклараций. Автоматически выбирает сборку через `vue-tsc` при наличии Vue-файлов или встроенный TypeScript-компилятор для остальных файлов.

### `clean(): this`
Удаляет временную директорию компиляции со всеми созданными файлами.
