# Класс AiAntigravityCliLite

Специализированная легковесная реализация класса `AiAbstract`, которая взаимодействует с Google Antigravity AI через интерфейс командной строки (`agy`).

> Для работы этой реализации требуется установленная утилита `agy` CLI, доступная в переменной PATH вашей системы.

## Ключевые особенности

- **Работа через CLI** — выполняет запросы прямым запуском CLI `agy` с массивом аргументов через `execFile` (`node:child_process`) без использования системной оболочки.
- **Обработка длинных промптов** — автоматически создает временные файлы для передачи объемного контекста в CLI через `ApiTmp`, обходя ограничения операционной системы на длину командной строки.
- **Чистое выполнение** — управляет созданием временных файлов и гарантирует их удаление после каждого запроса или ошибки.
- **Режим YOLO** — автоматически применяет флаг `--yolo` и директиву чистого вывода ответа без рассуждений.

## Инициализация

Инициализируйте `AiAntigravityCliLite`, передав API-ключ и идентификатор модели через конструктор.

**Параметры:**
- `key: string` — API-ключ (передается через переменные окружения).
- `model: string` — идентификатор модели для Antigravity CLI.
- `config?: Record<string, any>` — дополнительные параметры конфигурации.

```typescript
import { AiAntigravityCliLite } from '@dxtmisha/scripts'

const ai = new AiAntigravityCliLite('ВАШ_API_КЛЮЧ', 'gemini-3.7-flash')

// Генерация ответа
const response = await ai.generate('Проанализируй архитектуру пакета.')
```

## Методы

### Генерация

- `generate(contents: string): Promise<string>` — Основной метод взаимодействия. Компилирует контекст во временные файлы, выполняет команду CLI `agy` и возвращает результат.

### Конфигурация

- `setKey(key: string): this` — Обновляет API-ключ.
- `setModel(model: string): this` — Переключает идентификатор активной модели.

### Сбор контекста

- `addPrompt(prompt: string): void` — Устанавливает постоянный текстовый префикс (системный промпт).
- `addContent(content: string): this` — Добавляет текстовую часть к накопительному контексту.
- `resetPrompt(): void` — Очищает постоянный префикс.
- `resetContents(): this` — Очищает все накопленные части текста.

## Ограничения

- **Изображения** — реализация CLI в настоящее время не поддерживает передачу изображений.
- **Окружение** — требует наличия утилиты `agy` в переменной PATH.
