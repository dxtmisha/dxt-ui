# Lớp DesignTypesMake

Lớp `DesignTypesMake` là một động cơ hiệu suất cao dùng để quét các tệp khai báo TypeScript (`.d.ts`), theo dõi thay đổi bằng mã băm MD5, loại bỏ mã mẫu thừa và tạo ra tệp kiểu hợp nhất `ai-types.md`.

## Các tính năng chính

- **Bộ nhớ đệm theo MD5** — Tính toán mã băm của tệp khai báo và lưu kết quả tối ưu hóa của AI vào thư mục `ai-types-list/`, tránh các cuộc gọi API tốn kém và lặp lại.
- **Làm sạch khai báo thông minh** — Loại bỏ các import nội bộ, tham chiếu vòng và chú thích thừa, chuẩn hóa thành các hợp đồng kiểu rõ ràng.
- **Bổ sung ngữ cảnh mã JS** — Quét và kết hợp các tệp mã nguồn JavaScript tương ứng để cung cấp ngữ cảnh thực thi cho mô hình AI.
- **Hợp nhất thành một tệp duy nhất** — Gộp hàng chục tệp `.d.ts` phân mảnh thành một tài liệu `ai-types.md` gọn gàng, dễ điều hướng.

## Khởi tạo

**Tham số khởi tạo:**
- `ai: DesignTypesAi` — thực thể AI client để tối ưu hóa khai báo.
- `dir: string` — đường dẫn thư mục khai báo đầu vào (mặc định `PropertiesConfig.getTypesTemporaryDirectory()`).
- `dirDist: string` — đường dẫn thư mục JavaScript đã biên dịch (mặc định `PropertiesConfig.getDistDir()`).

```typescript
import { DesignTypesAi, DesignTypesMake } from '@dxtmisha/scripts'

const ai = new DesignTypesAi('dist')
const makeTypes = new DesignTypesMake(ai)
```

## Phương thức

### `getFullContent(): string`
Trả về nội dung định nghĩa kiểu đã được kết hợp và tối ưu hóa trên toàn bộ dự án.

### `getFullJsContent(): string`
Trả về nội dung JavaScript kết hợp từ tất cả các tệp nguồn được lọc.

### `make(): Promise<this>`
Thực thi toàn bộ quy trình sinh mã bao gồm kiểm tra bộ nhớ đệm, xử lý qua AI và lưu tệp `ai-types.md`.

### `makeSave(): this`
Tổng hợp các định nghĩa kiểu cuối cùng và lưu trực tiếp vào tệp `ai-types.md`.

## Ví dụ sử dụng

```typescript
import { DesignTypesAi, DesignTypesMake } from '@dxtmisha/scripts'

const ai = new DesignTypesAi('dist')
const makeTypes = new DesignTypesMake(ai)

await makeTypes.make()
```
