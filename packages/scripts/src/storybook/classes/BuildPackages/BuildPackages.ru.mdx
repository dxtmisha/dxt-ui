# Класс BuildPackages

Класс `BuildPackages` — это оркестратор для сканирования, фильтрации, сортировки по приоритетам и инкрементальной сборки npm-пакетов в монорепозитории. Он отслеживает изменения версий пакетов с помощью локального файла кэша логов (`./logs/ui-build.log.json` или пользовательского файла лога) и компилирует только те модули, версии которых изменились или еще не были собраны.

## Ключевые возможности

- **Автоматическое сканирование монорепозитория**: Сканирует директорию пакетов (`packages/`) и находит все активные модули, содержащие валидный файл `package.json`.
- **Сортировка по приоритету сборки (`ui-priority`)**: Упорядочивает пакеты по свойству `ui-priority` из `package.json` (по умолчанию `500`, сортировка по возрастанию), гарантируя сборку низкоуровневых библиотек перед зависимыми пакетами.
- **Инкрементальное кэширование по версиям**: Сравнивает версию пакета с кэшем лога для предотвращения повторной сборки неизмененного кода.
- **Пользовательский лог-файл и интеграция с `.gitignore`**: Позволяет задавать имя файла лога и автоматически добавляет путь к файлу в `.gitignore`.
- **Интеллектуальный выбор скрипта сборки**: Поддерживает пользовательские команды/скрипты сборки (`code`) либо автоматически выбирает команду из `package.json` в строгом порядке приоритета:
  1. `prepublishOnly` (приоритет 1)
  2. `build-recovery` (приоритет 2)
  3. `build` (приоритет 3)
- **Фильтрация тестовых пакетов**: Игнорирует пакеты, отмеченные свойством `"ui-test": true`.
- **Автоматическое сохранение лога**: Записывает обновленные версии собранных пакетов в файл лога только при наличии успешно собранных пакетов (`changed > 0`).

## Конструктор

Конструктор принимает путь к директории с пакетами (по умолчанию константа `UI_DIR_PACKAGES` = `'packages'`), опциональную команду сборки (`code`), опциональное имя или путь к файлу лога (`logFile`) и загружает существующий кэш версий:

```typescript
import { BuildPackages } from '@dxtmisha/scripts'

// Создание с директорией по умолчанию ('packages')
const builder = new BuildPackages()

// Или с указанием пользовательского пути к пакетам, команды сборки и лог-файла
const customBuilder = new BuildPackages('custom-packages', 'npm run types', 'ui-types')
await customBuilder.make()
```

### Свойства класса

- `protected readonly path: string` — путь к корневой директории пакетов монорепозитория (по умолчанию `'packages'`).
- `protected readonly code?: string` — пользовательская команда сборки или имя npm-скрипта (например, `'types'` или `'npm run types'`).
- `protected readonly logFile?: string` — пользовательское имя или путь к файлу лога сборки (например, `'ui-types'` или `'logs/ui-types.log.json'`).
- `protected readonly log: Record<string, string>` — оперативная карта кэшированных версий пакетов вида `{ [packageName]: version }`.

## Методы

- `make(): Promise<void>` — основной метод оркестрации:
  1. Получает отсортированный список валидных пакетов через `getList()`.
  2. Выводит в консоль общее количество найденных пакетов (`Build packages(N)...`).
  3. Для каждого пакета проверяет необходимость обновления (`isUpdate`).
  4. При необходимости запускает сборку (`build`).
  5. При успешной сборке обновляет запись версии в оперативной памяти (`updateLog`) и увеличивает счетчик `changed`.
  6. Если `changed > 0`, сохраняет файл лога на диск (`saveLog`) и логирует `Build packages changed: N`.
  7. Добавляет файл лога в `.gitignore` (`initGitIgnore`).
  8. Если изменений не было, выводит `Build packages - no changes`.
- `protected isUpdate(packageFile: PackageFile): boolean` — проверяет необходимость сборки пакета путем вызова `!packageFile.isVersionConsistency(this.getVersionLog(packageFile.getName()))`.
- `protected getCode(packageFile: PackageFile): string | undefined` — возвращает команду сборки: использует переданный `this.code` (при необходимости преобразуя имя скрипта в `npm run <script>`) либо стандартный скрипт через `packageFile.getCodeBuildOrRecovery()`.
- `protected getLogPath(): string[]` — возвращает сегменты пути к файлу лога сборки на основе `this.logFile` (по умолчанию `['.', 'logs', 'ui-build.log.json']`).
- `protected getVersionLog(name: string): string` — возвращает зафиксированную версию пакета из лога (возвращает `'0.0.0'`, если пакет ранее не кэшировался).
- `protected updateLog(packageFile: PackageFile): void` — обновляет запись версии в оперативной карте `this.log[packageFile.getName()] = packageFile.getVersion()`.
- `protected build(packageFile: PackageFile): Promise<boolean>` — выполняет команду сборки для пакета:
  - Определяет скрипт через `this.getCode(packageFile)`.
  - Выполняет команду сборки в директории пакета с помощью утилиты `run`.
  - Возвращает `true` при успешном завершении или `false` в случае ошибки / отсутствия скрипта сборки.
- `protected initGitIgnore(): void` — добавляет путь к файлу лога сборки в `.gitignore` под секцией `# Logs`.
- `protected saveLog(): void` — сохраняет текущую карту версий `this.log` в файл лога через `PropertiesFile.writeByPath`.
- `private getList(): PackageFile[]` — сканирует директорию `this.path`, фильтрует папки (проверяет наличие `package.json` и отсутствие `"ui-test": true`) и сортирует пакеты по числовому значению `ui-priority` (по умолчанию `500`).
