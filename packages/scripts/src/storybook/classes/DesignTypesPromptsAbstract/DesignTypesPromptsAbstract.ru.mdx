# Класс DesignTypesPromptsAbstract

Абстрактный класс `DesignTypesPromptsAbstract` предоставляет базовую архитектуру для сканирования, анализа, кэширования и компиляции файлов правил и промптов (`ai-resources/`) в обязательные инструкции для ИИ-ассистентов.

## Ключевые особенности

- **Поиск промптов**: Рекурсивный поиск файлов промптов и инструкций.
- **Инкрементальный MD5 кэш**: Создание и ведение отдельных JSON файлов метаданных в `ai-types-list/ai-resources/`.
- **Генерация метаданных через ИИ**: Использование LLM для извлечения кратких названий и описаний правил.
- **Формирование обязательных правил**: Компиляция форматированных директив для включения в `ai-description.md`.

## Параметры конструктора

- `promptsDir: string` — относительный путь к директории с промптами (по умолчанию `'ai-resources'`).
- `ai: DesignTypesAi` — экземпляр `DesignTypesAi` для выполнения запросов к ИИ и получения имени проекта.

## Методы

### `abstract getCacheList(): DesignTypesPromptCacheList`
Возвращает список метаданных промптов из кэша.

### `abstract make(): Promise<this>`
Обрабатывает файлы промптов и обновляет кэш метаданных.

### `abstract toAiPrompts(): Promise<string>`
Формирует строку обязательных правил для ИИ на основе промптов.
