# Класс LibraryExport

Класс `LibraryExport` отвечает за агрегацию и генерацию файлов экспорта для библиотеки. Он сканирует назначенные подпапки на наличие файлов TypeScript и Vue, автоматически компилируя все экспорты в единый публичный интерфейс для упрощения последующих импортов. Также класс поддерживает создание облегченной подбиблиотеки без компонентов и стилей.

## Ключевые особенности

- **Генерация единого экспорта** — Создает комплексную публичную точку входа для всех компонентов, composables, функций и классов.
- **Умное обнаружение модулей** — Автоматически применяет стандартные экспорты со звездочкой (`export *`) для TypeScript-утилит и создает именованные экспорты для Vue SFC компонентов.
- **Интеграция стилей** — Автоматически проверяет наличие и интегрирует глобальные таблицы стилей CSS или SCSS с возможностью их отключения.
- **Поддержка подбиблиотеки** — Генерирует дополнительную точку входа без компонентов и стилей (`src/library/_library.ts`) для использования логики в headless-режиме.
- **Интеллектуальная фильтрация** — Исключает файлы юнит-тестов (`.test.`) и модули, помеченные специальной директивой `// export:none`.

## Инициализация

Инициализируйте и запустите генератор экспорта с помощью метода `make`. В конструктор можно передать флаги включения стилей и создания подбиблиотеки:

```typescript
import { LibraryExport } from '@dxtmisha/scripts'

// Стандартный экспорт (со стилями, только основная библиотека)
const generator = new LibraryExport()
generator.make()

// Экспорт без подключения стилей
const noStyleGenerator = new LibraryExport(false)
noStyleGenerator.make()

// Экспорт основной библиотеки и дополнительной подбиблиотеки
const fullGenerator = new LibraryExport(true, true)
fullGenerator.make()
```

### Параметры конструктора

- `style: boolean = true` — Подключать ли глобальные таблицы стилей в сгенерированный экспорт.
- `sub: boolean = false` — Генерировать ли дополнительный файл подбиблиотеки (`src/library/_library.ts`) без компонентов и стилей.

## Методы

### Основное выполнение

#### `make`
Запускает компиляцию библиотеки и генерацию точки входа. Метод сканирует все настроенные поддиректории, собирает подходящие файлы, отфильтровывает тесты и файлы с признаком `export:none`, а затем записывает сгенерированные инструкции импорта и экспорта в файл `UI_DIRS_FILE_EXPORT` (`src/library.ts`). Если включена генерация подбиблиотеки (`isSub() === true`), метод дополнительно компилирует и записывает `UI_DIRS_FILE_EXPORT_SUB` (`src/library/_library.ts`).

**Параметры:**
- Параметры отсутствуют.

**Возвращает:** `void` — Модифицирует целевые файлы в файловой системе и выводит логи в консоль.

```typescript
import { LibraryExport } from '@dxtmisha/scripts'

new LibraryExport(true, true).make()
```

### Вспомогательные методы

- `getPath(directory: string): string[]` — Возвращает компоненты пути к директории на основе `UI_DIR_IN` и указанного имени директории.
- `isExport(path: string | string[]): boolean` — Проверяет, подходит ли путь к файлу для экспорта, убеждаясь, что это не файл теста и он не совпадает с шаблоном `UI_FLAG_NOT_EXPORT`.
- `isStyle(): boolean` — Проверяет, нужно ли подключать стили в экспорт.
- `isSub(): boolean` — Проверяет, нужно ли генерировать файл подбиблиотеки.
- `getDirectory(): LibraryFiles` — Рекурсивно собирает все индексируемые файлы внутри настроенных папок экспорта и агрегирует их.
- `getName(name: string): string` — Преобразует первый символ имени директории в верхний регистр для стандартизации комментариев в сгенерированном файле.
- `getFile(path: string | string[]): string` — Считывает содержимое файла по указанному пути из файловой системы.
- `initFile(isSub?: boolean): string` — Формирует необработанное содержимое выходного файла библиотеки, включая импорты, настройку стилей, а также wildcard и именованные экспорты. При `isSub = true` компоненты и стили исключаются, а относительные пути корректируются.
- `initStyles(): string` — Генерирует импорты для глобальных таблиц стилей (`style.scss` или `style.css`), если они присутствуют в корне исходной директории и `isStyle()` возвращает `true`.

## Зависимости и конфигурации

Класс `LibraryExport` взаимодействует с несколькими глобальными конфигурациями для выполнения генерации:

- `UI_DIRS_LIST_EXPORT` — Указывает активные папки, которые рекурсивно сканируются на наличие экспортов (`classes`, `components`, `composables`, `functions`, `global`, `types`).
- `UI_DIRS_FILE_EXPORT` — Задает путь назначения скомпилированного файла библиотеки (`src/library.ts`).
- `UI_DIRS_FILE_EXPORT_SUB` — Задает путь назначения файла подбиблиотеки без компонентов и стилей (`src/library/_library.ts`).
- `UI_DIRS_LIBRARY` — Путь к директории хранения сгенерированных файлов библиотеки (`src/library`).
- `UI_DIR_IN` — Идентифицирует корневую директорию исходного кода, содержащую модули (`src`).
- `UI_FLAG_NOT_EXPORT` — Содержит регулярное выражение, соответствующее директиве исключения экспорта (`/\/\/ *export:none/`).
