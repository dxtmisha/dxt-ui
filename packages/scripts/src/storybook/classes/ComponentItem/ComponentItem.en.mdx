# ComponentItem Class

The `ComponentItem` class is responsible for generating and writing a complete set of boilerplate files for a specific component. It loads built-in templates (`componentDocTemplates`), performs contextual placeholder replacements, and saves files with proper system permissions.

## Key Features

- **Generates 8 template files**: Creates Vue 3 SFC (`.vue`), entry point `index.ts`, types `types.ts`, materials prompt (`materials/prompt.md`), subcomponents (`subcomponents/.gitignore`), and Storybook documentation (`wiki/ComponentDoc.mdx`, `wiki/ComponentDoc.stories.ts`, `wiki/prompt.md`).
- **Dynamic Placeholder Replacements**:
  - `ComponentDoc` -> PascalCase component name (`this.getName()`)
  - `component-doc` -> kebab-case component name (`toKebabCase(this.getName())`)
  - `[project]` -> package name from `package.json` (`this.getProjectName()`)
  - `[path]` -> relative component directory path (`src/components/ComponentName`)
  - `_.gitignore.txt` -> `.gitignore`
- **Permission Management**: Automatically invokes `PropertiesFile.chmod` for all written files.

## Constructor

Accepts the target component directory path:

```typescript
import { ComponentItem } from '@dxtmisha/scripts'

const component = new ComponentItem('Button')
component.make()
```

### Class Properties

- `protected readonly path: string` — Relative component directory path.
- `protected sample: Record<string, string>` — Map of template file paths and raw contents (`componentDocTemplates`).

## Methods

- `make(): void` — Primary generation method:
  1. Logs component name and path (`Component create: <Name>`, `path: <path>`).
  2. Iterates over all template keys from `getFilesSample()`.
  3. Reads raw template content (`readSample`), executes data replacement (`replacement`), and writes output file (`writeFile`).
  4. Logs `end`.
- `protected getFilePath(path: string): string[]` — Builds destination file path segments using `getComponentPaths(this.path)` with filename replacement.
- `protected getFilesSample(): string[]` — Returns the list of all template file keys (`Object.keys(this.sample)`).
- `protected getName(): string` — Extracts the component name from the last segment of `this.path`.
- `protected getProjectName(): string` — Retrieves the project package name from `package.json` or defaults to `'Project'`.
- `protected readPackage(): Record<string, any>` — Reads `package.json` from the current workspace.
- `protected readSample(path: string): string` — Reads template file content from the in-memory sample cache.
- `protected replacement(contentOrPath: string): string` — Performs string substitutions across file paths and template contents.
- `protected writeFile(path: string, content: string): void` — Writes generated file to disk via `PropertiesFile.writeByPath` and applies `PropertiesFile.chmod`.
