# Класс ComponentItem

Класс `ComponentItem` отвечает за создание и запись полного набора шаблонных файлов для конкретного компонента. Он загружает встроенные шаблоны (`componentDocTemplates`), выполняет контекстную замену плейсхолдеров и сохраняет файлы с корректными правами доступа.

## Ключевые возможности

- **Генерация 8 шаблонных файлов**: Создает Vue 3 SFC (`.vue`), входную точку `index.ts`, типы `types.ts`, промпт материалов (`materials/prompt.md`), подкомпоненты (`subcomponents/.gitignore`) и документацию Storybook (`wiki/ComponentDoc.mdx`, `wiki/ComponentDoc.stories.ts`, `wiki/prompt.md`).
- **Динамическая замена плейсхолдеров**:
  - `ComponentDoc` -> имя компонента в PascalCase (`this.getName()`)
  - `component-doc` -> имя компонента в kebab-case (`toKebabCase(this.getName())`)
  - `[project]` -> имя пакета из `package.json` (`this.getProjectName()`)
  - `[path]` -> относительный путь компонента (`src/components/ComponentName`)
  - `_.gitignore.txt` -> `.gitignore`
- **Управление правами доступа**: Вызывает `PropertiesFile.chmod` для всех записанных файлов.

## Конструктор

Принимает путь к директории компонента:

```typescript
import { ComponentItem } from '@dxtmisha/scripts'

const component = new ComponentItem('Button')
component.make()
```

### Свойства класса

- `protected readonly path: string` — относительный путь к директории компонента.
- `protected sample: Record<string, string>` — карта файлов шаблонов (`componentDocTemplates`).

## Методы

- `make(): void` — основной метод генерации:
  1. Выводит в консоль имя компонента и путь (`Component create: <Name>`, `path: <path>`).
  2. Итерирует по всем шаблонам из `getFilesSample()`.
  3. Читает содержимое шаблона (`readSample`), выполняет подстановку данных (`replacement`) и записывает файл (`writeFile`).
  4. Выводит в консоль `end`.
- `protected getFilePath(path: string): string[]` — формирует путь назначения для выходного файла через `getComponentPaths(this.path)` с заменой имени файла.
- `protected getFilesSample(): string[]` — возвращает список путей всех файлов шаблонов (`Object.keys(this.sample)`).
- `protected getName(): string` — извлекает имя компонента из последнего сегмента пути `this.path`.
- `protected getProjectName(): string` — возвращает имя проекта из `package.json` или `'Project'`.
- `protected readPackage(): Record<string, any>` — считывает `package.json` текущего пакета.
- `protected readSample(path: string): string` — возвращает исходный текст шаблона по его ключу.
- `protected replacement(contentOrPath: string): string` — выполняет строковые подстановки плейсхолдеров в путях и содержимом файлов.
- `protected writeFile(path: string, content: string): void` — записывает сгенерированный файл на диск через `PropertiesFile.writeByPath` и применяет `PropertiesFile.chmod`.
