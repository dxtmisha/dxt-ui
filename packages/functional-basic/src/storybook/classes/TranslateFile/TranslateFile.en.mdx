# TranslateFile Class

A class for managing translation data from external files. It supports lazy loading of translation packs, automatic locale matching, and internal caching to optimize performance and reduce redundant file processing.

Unlike static utilities, `TranslateFile` is an instantiable class, allowing for multiple translation sets with independent locale and location settings.

## Key Features

- **Lazy Loading** — Supports asynchronous loading of translation files only when they are needed for the current locale.
- **Smart Caching** — Automatically caches the content of loaded files, preventing repetitive file reads or network requests.
- **Request Deduplication** — Concurrent requests for the same locale share a single in-flight promise tracked by a unique identifier.
- **Locale Prioritization** — Intelligently selects the best-matching file based on location (Location > Language > Global).
- **Flexible Context** — Supports custom location and language providers, defaulting to the global `Geo` settings.

## Initialization

To initialize the object, call the `TranslateFile(data, location, language)` constructor.

**Parameters:**
- `data?: TranslateDataFile` — initial mapping of locales to file loaders.
- `location: string | (() => string) = () => Geo.getLocation()` — current location or a function returning it.
- `language: string | (() => string) = () => Geo.getLanguage()` — current language or a function returning it.

```javascript
import { TranslateFile, Geo } from '@dxtmisha/functional-basic'

// 1. Simple initialization
const files = new TranslateFile({
  'en-US': () => import('./locales/en-US.json'),
  'en': () => import('./locales/en.json'),
  'global': () => import('./locales/global.json')
})

// 2. Custom context providers
const customFiles = new TranslateFile(
  {}, 
  () => 'fr-FR', 
  () => 'fr'
)
```

## Methods

### Data Retrieval

- `async getList(location?: string, language?: string): Promise<TranslateDataFileList | undefined>` — Returns translations for the specified location and language. Omitted arguments use the current providers. It checks the internal cache before loading the file.
- `isFile(location?: string, language?: string): boolean` — Checks for a file matching the specified location and language; omitted arguments use the current values.
- `getLocation(): string` — Returns the current location string (executes the provider if it's a function).
- `getLanguage(): string` — Returns the current language string (executes the provider if it's a function).

### Data Management

- `add(data: TranslateDataFile): void` — Adds a mapping of locales to their respective translation file loaders (functions returning a Promise).
- `reset(): this` — Resets the cache of loaded translation data and active promises.

## Types

### `TranslateDataFile`
A collection of asynchronous loader functions indexed by locale/region strings:
- **Key**: Locale code (e.g., `'en-US'`, `'ru'`, `'global'`).
- **Value**: Function returning a `Promise` of `TranslateDataFileList`.

### `TranslateDataFileList`
A simple key-value record of translations: `Record<string, string>`.

### `TranslatePromiseItem`
An item for tracking active translation loading promises:
- `id: number` — Unique numeric request identifier.
- `promise: Promise<TranslateDataFileList | undefined>` — Active loading promise.

## Examples

### Integration with TranslateInstance

`TranslateInstance` captures the language and location when a request is queued. Locale placeholders in the API path are also resolved at that point. Different locales use separate batches; file selection and cache keys retain the original locale after asynchronous loading. A late response for a previous language stays in that language's cache.

```javascript
import { TranslateFile, TranslateInstance } from '@dxtmisha/functional-basic'

const translationFiles = new TranslateFile({
  'en-US': () => Promise.resolve({ hello: 'Hello US' }),
  'en': () => Promise.resolve({ hello: 'Hello' })
})

const translate = new TranslateInstance(
  '/api/translate',
  'list',
  translationFiles
)

const message = await translate.get('hello')
```
