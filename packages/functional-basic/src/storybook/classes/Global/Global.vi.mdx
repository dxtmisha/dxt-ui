# Lớp Global

Một lớp tiện ích tĩnh để lưu trữ và truy xuất dữ liệu toàn cục của ứng dụng. Cấu hình không rỗng đầu tiên xác định các khóa cấp cao nhất. Dùng `get()` để đọc từng giá trị. Các đối tượng lồng nhau được trả về theo tham chiếu.

## Tính năng chính

- **Khởi tạo một lần** — `add()` lưu tập thuộc tính an toàn không rỗng đầu tiên.
- **Cô lập SSR** — Dữ liệu được lưu trữ qua `ServerStorage`, đảm bảo cô lập giữa các yêu cầu trên máy chủ.
- **Không quản lý trạng thái** — Chỉ dành cho cấu hình tĩnh.
- **Truy cập tĩnh** — tất cả các phương thức đều là tĩnh, loại bỏ nhu cầu khởi tạo (`new Global()`).

## Cách sử dụng cơ bản

Vì lớp này là tĩnh, các phương thức của nó có thể được gọi trực tiếp.

```javascript
import { Global } from '@dxtmisha/functional-basic'

// Thiết lập một lần (ví dụ: khi ứng dụng tải)
Global.add({
  apiUrl: 'https://api.myapp.com',
  appName: 'My Application'
})

// Lấy giá trị theo khóa
console.log(Global.get('apiUrl')) // 'https://api.myapp.com'
```

## Phương thức

- `get<R = unknown>(name: string): R | undefined` — Trả về giá trị thuộc tính riêng theo khóa hoặc `undefined` nếu không tìm thấy khóa.
- `add(data: Record<string, unknown>): void` — Lưu tập thuộc tính riêng có thể liệt kê không rỗng đầu tiên, bỏ qua `__proto__`, `constructor` và `prototype`.

## Ví dụ

### Truy xuất dữ liệu
```typescript
import { Global } from '@dxtmisha/functional-basic'

const apiUrl = Global.get<string>('apiUrl')
console.log(apiUrl) // 'https://api.myapp.com'

const flags = Global.get<Record<string, boolean>>('featureFlags')
console.log(flags?.darkMode ?? false)
```

### Khởi tạo khi ứng dụng bắt đầu
```javascript
// main.ts (chạy một lần trước khi mount ứng dụng)
Global.add(window.__SERVER_DATA__ ?? {})

// Ở bất kỳ đâu trong code
const serverId = Global.get('serverId')
```
