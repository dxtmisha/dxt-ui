# Global Class

A static utility class for storing and retrieving application-wide global data. Data is written **once** during initialization and is thereafter available as read-only. Used to pass server-side configuration or data to the client-side application.

## Key Features

- **One-time initialization** — The `add` method only works on the first call; subsequent calls are ignored.
- **SSR isolation** — Data is stored via `ServerStorage`, ensuring per-request isolation on the server.
- **No state management** — Intended purely for static configuration.
- **Static Access** — all methods are static, eliminating the need for instantiation (`new Global()`).

## Basic Usage

Since the class is static, its methods can be called directly.

```javascript
import { Global } from '@dxtmisha/functional-basic'

// Set once (e.g., on application load)
Global.add({
  apiUrl: 'https://api.myapp.com',
  appName: 'My Application'
})

// Retrieve value by key
console.log(Global.get('apiUrl')) // 'https://api.myapp.com'
```

## Methods

- `get<R = unknown>(name: string): R` — Returns the own property value for a given key from the stored global data.
- `getItem(): Record<string, unknown>` — Returns the global data storage object for the current context.
- `add(data: Record<string, unknown>): void` — Saves the global data. Only works **on the first call** (while storage is empty). Subsequent calls are silently ignored.

## Examples

### Retrieving Data
```javascript
import { Global } from '@dxtmisha/functional-basic'

const apiUrl = Global.get<string>('apiUrl')
console.log(apiUrl) // 'https://api.myapp.com'

const flags = Global.get<Record<string, boolean>>('featureFlags')
console.log(flags.darkMode) // true
```

### Initialization on App Start
```javascript
// main.ts (executed once before mounting the app)
Global.add(window.__SERVER_DATA__ ?? {})

// Anywhere else in the code
const serverId = Global.get('serverId')
```
