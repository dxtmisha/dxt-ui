# Класс GeoTimezone

Специализированный класс для управления, нормализации и форматирования смещений часовых поясов как в рамках географического контекста (`GeoInstance`), так и в качестве самостоятельного объекта значений. Класс хранит смещение в минутах по семантике `Date.prototype.getTimezoneOffset()` (отрицательное для зон восточнее UTC, положительное для зон западнее UTC) и преобразует его в формат ISO 8601.

## Основные возможности

- **Стандартная семантика** — полное соответствие правилам ECMAScript `Date.prototype.getTimezoneOffset()`.
- **Надежная нормализация** — автоматическое приведение входных данных к конечным целым числам, безопасная обработка чисел с плавающей точкой, отрицательного нуля (`-0`) и некорректных значений (`NaN`, `Infinity`).
- **Форматирование по ISO 8601** — преобразование смещения в минутах в стандартизированную строку вида `'+03:00'`, `'-05:00'`, `'+00:00'`.
- **Текучий интерфейс (Fluent API)** — поддержка цепочки вызовов через метод `set()`.
- **Изоморфизм и безопасность SSR** — отсутствие обращения к глобальным объектам браузера, полная безопасность для серверного рендеринга.

## Базовое использование

```javascript
import { GeoTimezone } from '@dxtmisha/functional-basic'

// Инициализация смещением системного часового пояса
const tz = new GeoTimezone()
console.log(tz.get()) // например, -180 (для UTC+3)
console.log(tz.getFormat()) // '+03:00'

// Установка смещения для UTC-5 (300 минут западнее UTC)
tz.set(300)
console.log(tz.getFormat()) // '-05:00'

// Поддержка дробных часовых поясов, например UTC+5:30 (Индия)
tz.set(-330)
console.log(tz.getFormat()) // '+05:30'
```

## Методы

- `get(): number` — Возвращает текущее смещение часового пояса в минутах.
- `set(timezone: number): this` — Обновляет и нормализует смещение часового пояса в минутах, возвращая текущий экземпляр для цепочки вызовов.
- `getFormat(): string` — Возвращает текущее смещение часового пояса в виде отформатированной строки стандарта ISO 8601 (например, `'+03:00'`, `'-05:00'`).
