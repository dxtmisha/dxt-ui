# Класс GeoLocation

Класс для управления, валидации и сохранения текущего кода географической локации (например, `'en-GB'`, `'ru-RU'`) внутри `Geo` или как самостоятельный объект. Обеспечивает эшелонированный поиск локали через куки, локальное хранилище браузера, атрибуты HTML-документа и свойства браузера `navigator` с поддержкой SSR и санитизацией по стандарту BCP-47.

## Основные возможности

- **Эшелонированное разрешение локали** — строгий детерминированный поиск в порядке приоритета: Cookie -> DataStorage -> атрибут `lang` тега HTML -> `navigator.language` / `navigator.languages` -> провайдер по умолчанию -> `'en-GB'`.
- **Двухуровневое сохранение** — опциональная синхронизация локации одновременно в `localStorage` (через `DataStorage`) и куки (через `Cookie`), гарантирующая доступность данных между сессиями и запросами.
- **Санитизация по BCP-47** — валидация и нормализация строк через `sanitizeLocation` с заменой подчеркиваний на дефисы и защитой от инъекций.
- **Динамические дефолты** — поддержка статических строк или динамических коллбэк-функций через `setValueDefault()`.
- **SSR-изоляция** — изоморфный доступ к окружению через `isDomRuntime()` и безопасная гидратация куки через `ServerStorage`.

## Базовое использование

```javascript
import { GeoLocation } from '@dxtmisha/functional-basic'

// Инициализация менеджера с автоматическим разрешением
const location = new GeoLocation()
console.log(location.get()) // например, 'en-GB' или значение из Cookie/DOM

// Обновление локации с сохранением в хранилище и куки
location.set('ru-RU', true)
console.log(location.get()) // 'ru-RU'

// Установка динамического провайдера по умолчанию
location.setValueDefault(() => 'vi-VN')
```

## Методы

- `get(): string` — Возвращает строку текущего кода локации.
- `set(code?: string, save?: boolean): this` — Обновляет текущий код локации и опционально сохраняет его в хранилище и куки, возвращая инстанс для цепочечных вызовов.
- `setValueDefault(code?: string | (() => string | undefined)): this` — Устанавливает значение по умолчанию или функцию его вычисления и заново разрешает локацию.
