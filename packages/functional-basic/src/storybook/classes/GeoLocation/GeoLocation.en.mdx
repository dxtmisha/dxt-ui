# GeoLocation Class

A dedicated class for managing, validating, and persisting the current geographic location code (e.g., `'en-GB'`, `'ru-RU'`) within `Geo` and standalone applications. It provides a robust, tiered fallback resolution hierarchy across cookies, local browser storage, DOM document attributes, and browser navigator properties, with full SSR compatibility and BCP-47 sanitization.

## Key Features

- **Tiered Resolution Hierarchy** — resolves location code deterministically in order: Cookie -> DataStorage -> HTML `lang` attribute -> `navigator.language` / `navigator.languages` -> Default fallback provider -> `'en-GB'`.
- **Dual-Tier Persistence** — optionally synchronizes location across both browser `localStorage` (via `DataStorage`) and cookies (via `Cookie`), ensuring cross-session and cross-request persistence.
- **BCP-47 Sanitization** — normalizes and validates external strings via `sanitizeLocation`, converting underscores to hyphens and discarding invalid or dangerous inputs.
- **Dynamic Defaults** — supports static string values or dynamic callback resolvers via `setValueDefault()`.
- **SSR Safe** — guards all DOM interactions with `isDomRuntime()` and integrates with request-isolated `ServerStorage` for cookie access in server runtimes.

## Basic Usage

```javascript
import { GeoLocation } from '@dxtmisha/functional-basic'

// Initialize location instance with automatic resolution
const location = new GeoLocation()
console.log(location.get()) // e.g., 'en-GB' or resolved from Cookie/DOM

// Update current location with storage persistence
location.set('ru-RU', true)
console.log(location.get()) // 'ru-RU'

// Provide a dynamic fallback resolver
location.setValueDefault(() => 'vi-VN')
```

## Methods

- `get(): string` — Returns the current location code string.
- `set(code?: string, save?: boolean): this` — Updates the current location code and optionally persists it in storage and cookie, returning the instance for chaining.
- `setValueDefault(code?: string | (() => string | undefined)): this` — Sets the default value or resolver for the location code and re-evaluates current location.
