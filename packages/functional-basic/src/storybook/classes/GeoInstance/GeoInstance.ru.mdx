# Класс GeoInstance

Класс для работы с географическими данными на уровне экземпляра. Он отвечает за обработку кодов языков (ISO 639-1), стран (ISO 3166-1 alpha-2), временных зон и локализации. В отличие от статического класса `Geo`, `GeoInstance` позволяет создавать независимые объекты со своим состоянием, что особенно важно для изоляции запросов в SSR или в приложениях с несколькими контекстами локализации.

## Ключевые особенности

- **Объектно-ориентированность** — позволяет создавать несколько экземпляров с разными конфигурациями.
- **Автоматическое определение** — интеллектуально определяет локаль через хранилище или настройки окружения при инициализации.
- **Интеграция с медиа-базой** — предоставляет доступ к полной базе данных стран и языков из библиотеки `@dxtmisha/media`.
- **Динамическое управление временем** — установка и получение смещения часового пояса на уровне конкретного экземпляра.

## Базовое использование

Вы можете создать новый экземпляр класса для управления специфическим географическим контекстом.

```javascript
import { GeoInstance } from '@dxtmisha/functional-basic'

const geo = new GeoInstance()

// Получаем текущий код языка
console.log(geo.getLanguage()) // например, 'ru'

// Устанавливаем новую локаль для этого экземпляра
geo.set('en-US')

// Получаем форматированную временную зону
console.log(geo.getTimezoneFormat()) // например, '+03:00'
```

## Методы

### Информация

- `get(): GeoItemFull` — Возвращает полный объект данных о текущей стране и языке.
- `getItem(): GeoItemFull` — *(Устарело: используйте `get()`)* Возвращает текущий объект данных `GeoItemFull`.
- `getCountry(): string` — Возвращает нормализованный 2-буквенный код текущей страны (в верхнем регистре).
- `getLanguage(): string` — Возвращает нормализованный код текущего языка (в нижнем регистре).
- `getStandard(): string` — Возвращает каноническую строку локали на основе текущих настроек (например, `'en-VN'`, `'ru-BY'`).
- `getLocation(): string` — Возвращает текущую установленную локацию в виде «сырой» строки (например, `'ru-BY_BY'`, `'us-US'`).
- `getLocationCountry(): string` — Возвращает сырой код страны, извлеченный напрямую из строки локации (например, `'BY_BY'`, `'QQ'` или `''`).
- `getLocationLanguage(): string` — Возвращает сырой код языка, извлеченный напрямую из строки локации (например, `'us'`, `'qq'` или `''`).
- `getFirstDay(): string` — Возвращает код первого дня недели для текущей локали (например, `'Mo'`, `'Su'`).
- `getTimezone(): number` — Возвращает смещение часового пояса в минутах.
- `getTimezoneFormat(configuredOnly?: boolean): string` — Возвращает смещение часового пояса в строковом формате (например, `'+03:00'`). При `configuredOnly = true` возвращает `''`, если смещение не задано явно.

### Выбор

- `getList(): GeoItem[]` — Возвращает полный список доступных стран и языков.
- `getByCode(code?: string): GeoItemFull` — Находит полные гео-данные по коду (приоритет: полное совпадение `язык-страна` -> страна -> язык -> первый элемент `GeoList`).
- `getByCodeFull(code?: string): GeoItem | undefined` — Ищет точное совпадение по полному коду локали (например, `'ru-RU'`, `'RU-ru'`).
- `getByCountry(country?: string): GeoItem | undefined` — Ищет данные страны по основному или альтернативному коду страны.
- `getByLanguage(language?: string): GeoItem | undefined` — Ищет данные страны по основному или альтернативному коду языка.
- `find(code?: string): GeoItemFull` — *(Устарело: используйте `getByCode()`)* Алиас для метода `getByCode`.

### Конфигурация

- `set(code?: string, save?: boolean): this` — Устанавливает локацию для текущего экземпляра, опционально сохраняет ее в хранилище и куки и возвращает текущий экземпляр.
- `setTimezone(timezone: number): this` — Устанавливает смещение часового пояса в минутах и возвращает текущий экземпляр.
- `setValueDefault(code?: string | (() => string | undefined)): this` — Устанавливает значение или функцию вычисления кода локации по умолчанию и возвращает текущий экземпляр.
- `add(country: string, item?: Partial<GeoItem>): this` — Добавляет новую страну или объединяет данные с существующей страной в `GeoList`.
- `addList(list?: Record<string, Partial<GeoItem>>): this` — Добавляет или обновляет несколько стран в `GeoList`.

### Вспомогательные методы

- `toStandard(item?: GeoItem, language?: string, raw?: boolean): string` — Формирует стандартную строку `'язык-страна'` из объекта `GeoItem`.

## Примеры

### Изолированные контексты
```javascript
import { GeoInstance } from '@dxtmisha/functional-basic'

const geoRU = new GeoInstance()
geoRU.set('ru-RU')

const geoEN = new GeoInstance()
geoEN.set('en-US')

console.log(geoRU.getLanguage()) // 'ru'
console.log(geoEN.getLanguage()) // 'en'
```
