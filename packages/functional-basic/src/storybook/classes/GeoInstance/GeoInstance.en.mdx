# GeoInstance Class

An instance-based class for managing geographical data. It handles language codes (ISO 639-1), country codes (ISO 3166-1 alpha-2), time zones, and localization. Unlike the static `Geo` class, `GeoInstance` allows creating independent objects with their own state, which is particularly useful for request isolation in SSR or multi-context environments.

## Key Features

- **Object-Oriented** — allows creating multiple instances with different configurations.
- **Auto-Detection** — intelligently identifies the locale via storage or environment defaults during initialization.
- **Media Database Integration** — provides access to a comprehensive database of countries and languages from the `@dxtmisha/media` library.
- **Dynamic Time Management** — instance-level setting and retrieval of time zone offsets.

## Basic Usage

You can create a new instance of the class to manage a specific geographic context.

```javascript
import { GeoInstance } from '@dxtmisha/functional-basic'

const geo = new GeoInstance()

// Get the current language code
console.log(geo.getLanguage()) // e.g., 'en'

// Set a new locale for this instance
geo.set('fr-FR')

// Get the formatted time zone
console.log(geo.getTimezoneFormat()) // e.g., '+00:00'
```

## Methods

### Information

- `get(): GeoItemFull` — Returns the full data object for the current country and language.
- `getItem(): GeoItemFull` — *(Deprecated: use `get()`)* Returns the current `GeoItemFull` data object.
- `getCountry(): string` — Returns the normalized 2-letter ISO code of the current country (uppercase).
- `getLanguage(): string` — Returns the normalized ISO code of the current language (lowercase).
- `getStandard(): string` — Returns the combined canonical locale string based on current settings (e.g., `'en-VN'`, `'ru-BY'`).
- `getLocation(): string` — Returns the currently set raw location string (e.g., `'ru-BY_BY'`, `'us-US'`).
- `getLocationCountry(): string` — Returns the raw country code extracted directly from the location string (e.g., `'BY_BY'`, `'QQ'`, or `''`).
- `getLocationLanguage(): string` — Returns the raw language code extracted directly from the location string (e.g., `'us'`, `'qq'`, or `''`).
- `getFirstDay(): string` — Returns the code for the first day of the week (e.g., `'Mo'`, `'Su'`).
- `getTimezone(): number` — Returns the time zone offset in minutes.
- `getTimezoneFormat(): string` — Returns the time zone offset in string format (e.g., `'+03:00'`).

### Selection

- `getList(): GeoItem[]` — Returns the full list of available countries and languages.
- `getByCode(code?: string): GeoItemFull` — Resolves full geographic data by code (priority: full `language-country` match -> country -> language -> first item in `GeoList`).
- `getByCodeFull(code?: string): GeoItem | undefined` — Searches for an exact match by full locale code (e.g., `'ru-RU'`, `'RU-ru'`).
- `getByCountry(country?: string): GeoItem | undefined` — Searches for country data by primary or alternative country code.
- `getByLanguage(language?: string): GeoItem | undefined` — Searches for country data by primary or alternative language code.
- `find(code?: string): GeoItemFull` — *(Deprecated: use `getByCode()`)* Alias for `getByCode`.

### Configuration

- `set(code?: string, save?: boolean): this` — Sets the location for the current instance, optionally persists it in storage and cookie, and returns the current instance.
- `setTimezone(timezone: number): this` — Sets a custom time zone offset in minutes and returns the current instance.
- `setValueDefault(code?: string | (() => string | undefined)): this` — Sets the default fallback location code or resolver function and returns the current instance.
- `add(country: string, item?: Partial<GeoItem>): this` — Adds a new country or merges data into an existing country in `GeoList`.
- `addList(list?: Record<string, Partial<GeoItem>>): this` — Adds or updates multiple countries in `GeoList`.

### Auxiliary

- `toStandard(item?: GeoItem, language?: string, raw?: boolean): string` — Generates a standard `'language-country'` string from a `GeoItem` object.

## Examples

### Isolated Contexts
```javascript
import { GeoInstance } from '@dxtmisha/functional-basic'

const geoEN = new GeoInstance()
geoEN.set('en-US')

const geoRU = new GeoInstance()
geoRU.set('ru-RU')

console.log(geoEN.getLanguage()) // 'en'
console.log(geoRU.getLanguage()) // 'ru'
```
