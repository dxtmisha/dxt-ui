# Класс GeoList

Статический класс для хранения, управления и запроса глобального репозитория стран и локалей. Поддерживает абсолютную глубокую копию географической базы данных `@dxtmisha/media`, разделяемую между всеми запросами в SSR, предотвращая мутации исходных объектов и предоставляя высокопроизводительные методы поиска.

## Основные возможности

- **Абсолютная глубокая копия** — при первом обращении создается полностью изолированный глубокий клон через `copyObject(geo)`, защищающий исходные данные медиа-библиотеки от нежелательных мутаций.
- **Общее статическое хранилище** — единый список для всех запросов в SSR и всех экземпляров `GeoInstance`, исключающий дублирование памяти.
- **Быстрый поиск** — оптимизированные методы поиска по коду страны (`getByCountry`), коду языка (`getByLanguage`) и полному коду локали (`getByCodeFull`).
- **Динамическое расширение** — добавление новых стран или переопределение существующих параметров с автоматическим глубоким слиянием конфигураций единиц измерения (`unit`) через `add()` и `addList()`.
- **Сброс окружения** — метод `reset()` для сброса состояния и кэша при тестировании или перезапуске окружения.

## Базовое использование

```javascript
import { GeoList } from '@dxtmisha/functional-basic'

// Получение глобального списка стран
const countries = GeoList.get()

// Поиск страны по основному коду или альтернативным псевдонимам
const us = GeoList.getByCountry('US')
const uk = GeoList.getByCountry('UK') // возвращает GB

// Поиск страны по языку
const french = GeoList.getByLanguage('fr')

// Глобальное добавление или обновление параметров страны
GeoList.add('VN', {
  phoneCode: '84',
  firstDay: 'Mo'
})
```

## Методы

- `get(): GeoItem[]` — Возвращает глобальный список стран, создавая абсолютную глубокую копию при первом обращении.
- `getByCodeFull(code?: string): GeoItem | undefined` — Находит данные страны по комбинированному коду локали (например, `'en-US'` или `'RU-ru'`).
- `getByCountry(country?: string): GeoItem | undefined` — Находит данные страны по коду ISO 3166-1 или альтернативным псевдонимам.
- `getByLanguage(language?: string): GeoItem | undefined` — Находит данные страны по коду языка ISO 639-1 или альтернативным псевдонимам.
- `add(country: string, item?: Partial<GeoItem>): GeoItem` — Добавляет или обновляет данные страны в глобальном списке, возвращая результирующий объект.
- `addList(list?: Record<string, Partial<GeoItem>>): void` — Добавляет или обновляет конфигурации нескольких стран.
- `reset(): void` — Сбрасывает кэшированный список, возвращая его к исходному состоянию при следующем доступе.
