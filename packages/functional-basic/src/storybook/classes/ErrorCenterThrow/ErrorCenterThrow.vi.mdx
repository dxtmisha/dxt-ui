# Lớp ErrorCenterThrow

`ErrorCenterThrow` là **lớp facade tĩnh** bọc quanh `ErrorCenterThrowInstance`, kết hợp việc ghi nhận lỗi tập trung và ném ngoại lệ trong một thao tác duy nhất. Khi gọi `ErrorCenterThrow.on()`, lớp sẽ gửi lỗi qua `ErrorCenterInstance` đang hoạt động (kích hoạt trình xử lý, callback toàn cục và xuất console), sau đó lập tức ném ra `ErrorCenterError` chứa siêu dữ liệu nguyên nhân đã được hợp nhất.

Facade tĩnh sử dụng `ServerStorage` để tái sử dụng một `ErrorCenterThrowInstance` cho mỗi yêu cầu SSR. Trên trình duyệt và trong Node.js ngoài yêu cầu, lớp sử dụng bộ nhớ trong runtime hiện tại.

## Các tính năng chính

- **Giao diện tĩnh** — ghi nhận và ném lỗi mà không cần khởi tạo thủ công.
- **Cô lập SSR** — quản lý một `ErrorCenterThrowInstance` riêng cho từng ngữ cảnh yêu cầu thông qua `ServerStorage`.
- **Hợp nhất dữ liệu từ sổ đăng ký** — tạo `ErrorCenterError` thông qua `errorCenter.assign(cause)`, tự động áp dụng `label`, `message` và quy tắc `priority` đã đăng ký.
- **Hợp đồng kiểu `never` chặt chẽ trong TypeScript** — các phương thức `on<D = unknown>(...)` và `handle<D = unknown>(...)` đảm bảo không trả về bình thường và giữ nguyên kiểu dữ liệu `details` trên `ErrorCenterError<D>`.
- **Ngăn chặn ghi nhận trùng lặp** — phương thức `handle()` ném lại trực tiếp thực thể `ErrorCenterError` đã tồn tại mà không kích hoạt lại các trình xử lý của `ErrorCenterInstance`.

## Các phương thức

### `getItem`
Trả về `ErrorCenterThrowInstance` cho ngữ cảnh lưu trữ đang hoạt động.

**Trả về:** `ErrorCenterThrowInstance` — thực thể đang hoạt động được cô lập theo yêu cầu.

```typescript
import { ErrorCenterThrow } from '@dxtmisha/functional-basic'

const instance = ErrorCenterThrow.getItem()
```

### `on`
Gửi nguyên nhân lỗi tới `ErrorCenterInstance` đang hoạt động và ném ra ngoại lệ `ErrorCenterError<D>` với dữ liệu nguyên nhân đã được hợp nhất.

**Tham số:**
- `cause: ErrorCenterCauseItem<D>` — dữ liệu nguyên nhân lỗi có cấu trúc (`group`, `code`, `priority`, `label`, `message`, `details`).
- `options?: ErrorOptions` — các tùy chọn chuẩn của `Error` (ví dụ `{ cause: originalError }`).

**Trả về:** `never` — không bao giờ trả về bình thường; luôn ném ra `ErrorCenterError<D>`.

```typescript
ErrorCenterThrow.on<{ resourceId: number }>({
  group: 'api',
  code: 'notFound',
  details: { resourceId: 42 }
})
```

### `handle`
Xử lý lỗi đã bắt được mà không ghi nhận trùng lặp các thực thể `ErrorCenterError`. Nếu `error` là một `ErrorCenterError`, ném lại trực tiếp lỗi đó; ngược lại sẽ ủy quyền cho `on(cause, resolvedOptions)`, tự động lưu `error` vào `Error.cause` khi `error` được xác định và `options.cause` không được truyền tường minh.

**Tham số:**
- `cause: ErrorCenterCauseItem<D>` — dữ liệu nguyên nhân lỗi có cấu trúc (`group`, `code`, `priority`, `label`, `message`, `details`).
- `error?: unknown` — thực thể hoặc giá trị lỗi đã bắt được để kiểm tra (tự động chuyển vào `Error.cause` khi có giá trị và không truyền `options.cause`).
- `options?: ErrorOptions` — các tùy chọn chuẩn của `Error` (ví dụ `{ cause: originalError }`).

**Trả về:** `never` — không bao giờ trả về bình thường; ném lại `error` (nếu là `ErrorCenterError`) hoặc ném ra `ErrorCenterError<D>`.

```typescript
try {
  // Thao tác có thể ném ra ErrorCenterError hoặc một lỗi bất ngờ khác
} catch (error) {
  ErrorCenterThrow.handle(
    { group: 'api', code: 'server' },
    error
  )
}
```

## Ví dụ

### Sử dụng facade tĩnh
```typescript
import { ErrorCenterError, ErrorCenterThrow } from '@dxtmisha/functional-basic'

try {
  ErrorCenterThrow.on({
    group: 'api',
    code: 'unauthorized',
    details: { endpoint: '/profile' }
  })
} catch (error) {
  if (error instanceof ErrorCenterError) {
    console.log(error.getCode())    // 'unauthorized'
    console.log(error.getMessage()) // Thông báo mặc định từ sổ đăng ký
    console.log(error.getDetails()) // { endpoint: '/profile' }
  }
}
```

### Sử dụng với ErrorCenterInstance tùy chỉnh
Đối với các thực thể `ErrorCenterInstance` cô lập tùy chỉnh, hãy khởi tạo trực tiếp `ErrorCenterThrowInstance`:

```typescript
import {
  ErrorCenterHandler,
  ErrorCenterInstance,
  ErrorCenterThrowInstance
} from '@dxtmisha/functional-basic'

const localInstance = new ErrorCenterInstance(
  [{ group: 'storage', code: 'readFailed', message: 'Không thể đọc cấu hình.' }],
  new ErrorCenterHandler([], false)
)

const localThrow = new ErrorCenterThrowInstance(localInstance)

try {
  throw new SyntaxError('Unexpected token')
} catch (originalError) {
  localThrow.on(
    { group: 'storage', code: 'readFailed', details: { key: 'settings' } },
    { cause: originalError }
  )
}
```
