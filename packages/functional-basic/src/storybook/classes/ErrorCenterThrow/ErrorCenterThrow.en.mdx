# ErrorCenterThrow Class

`ErrorCenterThrow` is a **static facade** around `ErrorCenterThrowInstance` that combines centralized error reporting and exception throwing into a single operation. Calling `ErrorCenterThrow.on()` first dispatches the error through the active `ErrorCenterInstance` (triggering handlers, callbacks, and console logging) and immediately throws an `ErrorCenterError` populated with the merged cause metadata.

The static facade uses `ServerStorage` to reuse one `ErrorCenterThrowInstance` per SSR request. In the browser and in Node.js outside a request, it uses the current runtime's in-memory storage.

## Key Features

- **Static Interface** — dispatch and throw errors without manual instantiation.
- **SSR Isolation** — manages one `ErrorCenterThrowInstance` per request context via `ServerStorage`.
- **Registry Metadata Merging** — resolves the thrown `ErrorCenterError` via `errorCenter.assign(cause)` so registered `label`, `message`, and `priority` rules apply consistently.
- **Strong TypeScript `never` Contract** — `on<D = unknown>(...)` and `handle<D = unknown>(...)` guarantee non-returning control flow and preserve typed `details` on the thrown `ErrorCenterError<D>`.
- **Double-Report Prevention** — `handle()` rethrows existing `ErrorCenterError` instances directly without triggering `ErrorCenterInstance` handlers again.

## Methods

### `getItem`
Returns the `ErrorCenterThrowInstance` for the active storage context.

**Returns:** `ErrorCenterThrowInstance` — the active request-isolated instance.

```typescript
import { ErrorCenterThrow } from '@dxtmisha/functional-basic'

const instance = ErrorCenterThrow.getItem()
```

### `on`
Dispatches the error cause through the active `ErrorCenterInstance` and throws an `ErrorCenterError<D>` containing the merged cause data.

**Parameters:**
- `cause: ErrorCenterCauseItem<D>` — structured error cause details (`group`, `code`, `priority`, `label`, `message`, `details`).
- `options?: ErrorOptions` — standard `Error` options (such as `{ cause: originalError }`).

**Returns:** `never` — never returns normally; always throws `ErrorCenterError<D>`.

```typescript
ErrorCenterThrow.on<{ resourceId: number }>({
  group: 'api',
  code: 'notFound',
  details: { resourceId: 42 }
})
```

### `handle`
Handles a caught error without double-reporting `ErrorCenterError` instances. If `error` is an `ErrorCenterError`, rethrows it directly; otherwise delegates to `on(cause, options)`.

**Parameters:**
- `cause: ErrorCenterCauseItem<D>` — structured error cause details (`group`, `code`, `priority`, `label`, `message`, `details`).
- `error?: unknown` — caught error instance or value to inspect.
- `options?: ErrorOptions` — standard `Error` options (such as `{ cause: originalError }`).

**Returns:** `never` — never returns normally; rethrows `error` (when it is `ErrorCenterError`) or throws `ErrorCenterError<D>`.

```typescript
try {
  // Operation that may throw either ErrorCenterError or an unexpected Error
} catch (error) {
  ErrorCenterThrow.handle(
    { group: 'api', code: 'server' },
    error,
    error instanceof Error ? { cause: error } : undefined
  )
}
```

## Examples

### Using the Static Facade
```typescript
import { ErrorCenterError, ErrorCenterThrow } from '@dxtmisha/functional-basic'

try {
  ErrorCenterThrow.on({
    group: 'api',
    code: 'unauthorized',
    details: { endpoint: '/profile' }
  })
} catch (error) {
  if (error instanceof ErrorCenterError) {
    console.log(error.getCode())    // 'unauthorized'
    console.log(error.getMessage()) // Default message from registry
    console.log(error.getDetails()) // { endpoint: '/profile' }
  }
}
```

### Using a Custom ErrorCenterInstance
For isolated custom `ErrorCenterInstance` instances, instantiate `ErrorCenterThrowInstance` directly:

```typescript
import {
  ErrorCenterHandler,
  ErrorCenterInstance,
  ErrorCenterThrowInstance
} from '@dxtmisha/functional-basic'

const localInstance = new ErrorCenterInstance(
  [{ group: 'storage', code: 'readFailed', message: 'Failed to read configuration.' }],
  new ErrorCenterHandler([], false)
)

const localThrow = new ErrorCenterThrowInstance(localInstance)

try {
  throw new SyntaxError('Unexpected token')
} catch (originalError) {
  localThrow.on(
    { group: 'storage', code: 'readFailed', details: { key: 'settings' } },
    { cause: originalError }
  )
}
```
