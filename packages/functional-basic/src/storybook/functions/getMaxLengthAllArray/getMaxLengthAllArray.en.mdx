# `getMaxLengthAllArray`

A utility that finds the longest string in the provided array or object and returns its length (as a number). The function uses `Math.max` combined with `getLengthOfAllArray` (falling back to `.reduce()` for collections larger than 10,000 elements to prevent call stack overflow).

**Parameters:**
- `data: ObjectOrArray<string>` — The input array or object of strings.

**Returns:**
`number` — The length of the longest string in the collection. If an empty array or object is passed, it returns `0`.

```typescript
import { getMaxLengthAllArray } from '@dxtmisha/functional-basic'

const phrases = ['Hello', 'Good morning', 'Greetings']
const maxLength = getMaxLengthAllArray(phrases)

console.log(maxLength) // 12 ("Good morning")
```
