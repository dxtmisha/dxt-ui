# `getMaxLengthAllArray`

Утилита, которая находит самую длинную строку в предоставленном массиве или объекте и возвращает её длину (число). Функция использует `Math.max` в сочетании с `getLengthOfAllArray` (переключаясь на `.reduce()` для коллекций размером более 10 000 элементов для предотвращения переполнения стека вызовов).

**Параметры:**
- `data: ObjectOrArray<string>` — Входной массив или объект строк.

**Возвращает:**
`number` — Длина самой длинной строки коллекции. Если передан пустой массив или объект, возвращается `0`.

```typescript
import { getMaxLengthAllArray } from '@dxtmisha/functional-basic'

const phrases = ['Привет', 'Доброе утро', 'Здравствуйте']
const maxLength = getMaxLengthAllArray(phrases)

console.log(maxLength) // 12 ("Здравствуйте")
```
