# `getMaxLengthAllArray`

Một tiện ích tìm chuỗi dài nhất trong mảng hoặc đối tượng đã cung cấp và trả về độ dài của nó (dưới dạng một số). Hàm sử dụng `Math.max` kết hợp với `getLengthOfAllArray` (tự động chuyển sang `.reduce()` đối với tập hợp lớn hơn 10.000 phần tử để tránh tràn ngăn xếp lệnh gọi).

**Tham số:**
- `data: ObjectOrArray<string>` — Mảng hoặc đối tượng chuỗi đầu vào.

**Trả về:**
`number` — Độ dài của chuỗi dài nhất trong tập hợp. Nếu truyền vào mảng hoặc đối tượng rỗng, hàm sẽ trả về `0`.

```typescript
import { getMaxLengthAllArray } from '@dxtmisha/functional-basic'

const phrases = ['Xin chào', 'Chào buổi sáng', 'Chào']
const maxLength = getMaxLengthAllArray(phrases)

console.log(maxLength) // 14 ("Chào buổi sáng")
```
