# `forEach`

The function performs the specified function once for each element in the collection (`Array`, `Object`, `Map`, `Set`) and returns an array with the results of executing the function (omitting `undefined` values unless `saveUndefined` is `true`).

**Parameters:**
- `data: D` — Object or collection for iteration (`D extends ForEachData<T> = readonly T[] | Record<string, T> | Map<unknown, T> | Set<T>`).
- `callback: (item: T, key: K, collection: D) => R` — A callback function executed for each element (`key` is of type `number` for arrays, `string` for objects, `K` for `Map`, and `S` for `Set`).
- `saveUndefined?: S` — If `true`, preserves `undefined` return values in the resulting array (filtered out by default).

**Returns:**
`ForEachReturn<R, S>` (`(S extends true ? R : Exclude<R, undefined>)[]`) — an array with the results of executing the function. When `saveUndefined: false` (or omitted), the type automatically excludes `undefined` (`Exclude<R, undefined>[]`). When `saveUndefined: true`, the return type preserves `undefined` (`(R | undefined)[]`).

## How it works

The function is a universal utility for iterating, transforming, and filtering diverse data structures simultaneously in a single O(N) pass.

**Features:**
- **Collection Support** — natively works with `Array`, `Map`, `Set`, and dictionary objects (`Record<string, T>`).
- **Result Collection (filterMap / compactMap)** — unlike standard `Array.prototype.forEach`, this function collects returned values into a new array similarly to `map`, but without allocating intermediate arrays.
- **Smart Undefined Filtering** — by default, all `undefined` values (e.g., when the callback returns nothing or explicit `undefined`) are filtered out of the resulting array, and the return type narrows to `Exclude<R, undefined>[]`.
- **saveUndefined Parameter** — passing `true` as the third argument retains all values, including `undefined`.
- **Unified Argument Contract** — all callbacks receive `(item, key, collection)`. For `Set`, the item itself is supplied as the key (`item`), matching ECMAScript standard behavior.
- **Length Mutation Guard** — array length is cached prior to the loop, preventing infinite cycles if elements are pushed during iteration.
- **Object Integrity** — object property traversal utilizes `for...in` with native `Object.hasOwn` guards, skipping prototype properties and avoiding temporary key array allocations.

## Examples

```typescript
import { forEach } from '@dxtmisha/functional-basic'

// 1. Array
const numbers = [1, 2, 3, 4]
const evens = forEach(numbers, item => (item % 2 === 0 ? item * 10 : undefined))
// [20, 40]

// 2. Object / Record
const user = { name: 'Alice', role: 'admin', age: 25 }
const pairs = forEach(user, (value, key) => `${key}=${value}`)
// ['name=Alice', 'role=admin', 'age=25']

// 3. Map
const map = new Map([['first', 10], ['second', 20]])
const mapResults = forEach(map, (value, key) => `${key}:${value}`)
// ['first:10', 'second:20']

// 4. Set
const set = new Set(['apple', 'banana'])
const setUpper = forEach(set, item => item.toUpperCase())
// ['APPLE', 'BANANA']

// 5. Preserving undefined (saveUndefined: true)
const withUndefined = forEach([1, 2, 3], item => (item % 2 === 0 ? item : undefined), true)
// [undefined, 2, undefined]
```
