# `isFunction`

Hàm bảo vệ kiểu nhận diện các đối tượng hàm, gồm hàm thông thường, hàm tạo của lớp và hàm từ ngữ cảnh JavaScript khác.

## Tính năng chính

- **Kiểm tra giá trị** — Dùng `typeof callback === 'function'` mà không cần duyệt chuỗi prototype.
- **Hỗ trợ Cross-Realm & Iframe** — Xác định chính xác các hàm đến từ các cửa sổ riêng biệt, iframe hoặc ngữ cảnh Node.js VM, nơi `instanceof Function` thường thất bại do cây prototype không đồng nhất.
- **Hỗ trợ toàn diện các cấu trúc thực thi** — Nhận diện tất cả các loại hàm: khai báo thông thường, hàm mũi tên, hàm `async`, hàm generator (`function*`), lớp ES6, hàm tạo tích hợp (`Date`, `Array`, `Function`), hàm đã liên kết (`bind`) và hàm được bọc bằng `Proxy`.
- **Thu hẹp kiểu trong TypeScript** — Giữ nguyên chữ ký gọi hàm hoặc chữ ký hàm tạo đã biết khi thu hẹp kiểu hợp. Giá trị kiểu `unknown` được thu hẹp thành `CallableFunction | NewableFunction`.
- **An toàn trước các giá trị falsy và không thể gọi** — Trả về `false` một cách an toàn cho `null`, `undefined`, `0`, `false`, `NaN`, chuỗi rỗng, mảng, regex và các đối tượng giả lập phương thức `call`/`apply`.
- **Đẳng hình & Sẵn sàng cho SSR** — Hàm thuần túy không có tác dụng phụ, không phụ thuộc vào DOM hoặc môi trường trình duyệt.

**Tham số:**
- `callback: unknown` — Giá trị cần kiểm tra.

**Trả về:**
`callback is CallableFunction | NewableFunction` — Trả về `true` cho đối tượng hàm và `false` cho các giá trị khác. Để gọi giá trị được thu hẹp từ `unknown`, trước tiên hãy xác định chữ ký gọi hàm.

## Ví dụ

<Source
  language='typescript'
  code={`
import { isFunction } from '@dxtmisha/functional-basic'

// 1. Hàm thông thường, hàm mũi tên và hàm bất đồng bộ
isFunction(function regular() {})        // true
isFunction(() => 'arrow')                // true
isFunction(async () => 'async')          // true
isFunction(function* generator() {})     // true

// 2. Lớp ES6 và các hàm tạo tích hợp
class MyService {}
isFunction(MyService)                    // true
isFunction(Date)                         // true
isFunction(Array)                        // true
isFunction(Math.max)                     // true

// 3. Hàm đã liên kết và bộ bọc Proxy
const greet = (name: string) => \`Xin chào, \${name}!\`
const boundGreet = greet.bind(null, 'Alice')
const proxiedGreet = new Proxy(greet, {})

isFunction(boundGreet)                   // true
isFunction(proxiedGreet)                 // true

// 4. Đối tượng không thể gọi, mảng và thể hiện của lớp
isFunction({})                           // false
isFunction(new MyService())              // false
isFunction([() => {}])                   // false
isFunction(/regex/)                      // false
isFunction({ call: () => {} })           // false

// 5. Kiểu nguyên thủy và giá trị falsy
isFunction(null)                         // false
isFunction(undefined)                    // false
isFunction(0)                            // false
isFunction(false)                        // false
isFunction('function() {}')              // false

// 6. Thu hẹp kiểu trong TypeScript
function execute(handler: string | (() => number)): number {
  if (isFunction(handler)) {
    // TypeScript thu hẹp handler thành () => number
    return handler()
  }

  return Number(handler)
}
  `}
