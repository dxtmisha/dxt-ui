# `isFunction`

A type guard that recognizes function objects, including ordinary functions, class constructors, and functions from other realms.

## Key Features

- **Runtime Check** — Uses `typeof callback === 'function'` without traversing the prototype chain.
- **Cross-Realm & Iframe Support** — Accurately identifies functions originating from separate window realms, iframes, and VM contexts where `instanceof Function` would otherwise fail due to distinct prototype trees.
- **Comprehensive Callable Support** — Recognizes all executable constructs: standard functions, arrow functions, async functions, generator functions, ES6 classes, built-in constructors (`Date`, `Array`, `Function`), bound functions, and Proxy-wrapped callables.
- **TypeScript Type Guard** — Preserves known call or constructor signatures when narrowing a union, and narrows `unknown` or `any` to `FunctionAnyType`.
- **Safe Against Falsy & Non-Callable Inputs** — Gracefully returns `false` for `null`, `undefined`, `0`, `false`, `NaN`, empty strings, arrays, regexes, plain objects, and objects with callable mimics.
- **Pure & Isomorphic** — Stateless, side-effect-free, and safe for server-side rendering (SSR/SSG).

**Parameters:**
- `callback: T` — The value to check.

**Returns:**
`boolean` — Returns `true` for function objects (narrowing `callback` to its callable/constructor type or `FunctionAnyType`) and `false` for other values.

## Examples

<Source
  language='typescript'
  code={`
import { isFunction } from '@dxtmisha/functional-basic'

// 1. Standard, arrow, and async functions
isFunction(function regular() {})        // true
isFunction(() => 'arrow')                // true
isFunction(async () => 'async')          // true
isFunction(function* generator() {})     // true

// 2. ES6 classes and built-in constructors
class MyService {}
isFunction(MyService)                    // true
isFunction(Date)                         // true
isFunction(Array)                        // true
isFunction(Math.max)                     // true

// 3. Bound functions and Proxy wrappers
const greet = (name: string) => \`Hello, \${name}!\`
const boundGreet = greet.bind(null, 'Alice')
const proxiedGreet = new Proxy(greet, {})

isFunction(boundGreet)                   // true
isFunction(proxiedGreet)                 // true

// 4. Non-callable objects, arrays, and class instances
isFunction({})                           // false
isFunction(new MyService())              // false
isFunction([() => {}])                   // false
isFunction(/regex/)                      // false
isFunction({ call: () => {} })           // false

// 5. Primitives and falsy values
isFunction(null)                         // false
isFunction(undefined)                    // false
isFunction(0)                            // false
isFunction(false)                        // false
isFunction('function() {}')              // false

// 6. TypeScript type narrowing
function execute(handler: string | (() => number)): number {
  if (isFunction(handler)) {
    // TypeScript narrows handler to () => number
    return handler()
  }

  return Number(handler)
}
  `}
/>
