# `uniqueArray`

Creates a new array containing only unique elements from the original array while preserving the order of their first appearance.

**Parameters:**
- `value?: readonly T[] | null` — The input array or readonly collection to deduplicate.
- `<T = unknown>` — Element type of the array.

**Returns:**
`T[]` — A new array without duplicate elements. If the input is not an array or is empty, returns `[]`.

```typescript
import { uniqueArray } from '@dxtmisha/functional-basic'

const list = [1, 2, 2, 3, 1]
console.log(uniqueArray(list)) // [1, 2, 3]

// Works with readonly arrays and tuples
const readonlyList = ['a', 'b', 'a'] as const
console.log(uniqueArray(readonlyList)) // ['a', 'b']
```
