# `getExp`

Tiện ích này tạo ra một đối tượng `RegExp` từ một chuỗi mẫu bằng cách thực hiện "thoát" (escape) tất cả các ký tự đặc biệt của biểu thức chính quy bên trong giá trị đầu vào (chẳng hạn như `-` `.` `*` `+` `?` `^` `$` `{` `}` `(` `)` `|` `[` `]` `\` `/`).

Điều này rất cần thiết khi chuỗi tìm kiếm đến từ người dùng hoặc chứa các ký tự có thể phá vỡ một biểu thức chính quy. Hàm cho phép bạn chỉ định các cờ (flags) cho `RegExp` cũng như một chuỗi mẫu nơi đoạn văn bản đã "escape" sẽ thay thế token `:value`.

Chỉ `value` được escape; `pattern` vẫn là mẫu biểu thức chính quy. Cờ hoặc mẫu không hợp lệ gây ra `SyntaxError` chuẩn từ constructor `RegExp`. Mỗi lần gọi tạo một instance riêng.

**Tham số:**
- `value?: unknown` — (tuỳ chọn) Giá trị đích cần chuyển thành chuỗi và escape.
- `flags?: string` — (tuỳ chọn) Các cờ cấu hình (ví dụ: `'ig'`). Mặc định là `'ig'` (không phân biệt chữ hoa/thường và tìm toàn cục).
- `pattern?: string` — (tuỳ chọn) Chuỗi mẫu biểu thức chính quy. Mặc định chỉ là `':value'`.

**Trả về:**
`RegExp` — Đối tượng biểu thức chính quy.

```typescript
import { getExp } from '@dxtmisha/functional-basic'

// Tìm kiếm cơ bản
const basicExpression = getExp('user.name')
console.log(basicExpression) // /user\.name/gi  (dấu chấm đã được escape)

// Tìm kiếm với cờ và chuỗi mẫu tuỳ chỉnh (ví dụ: "bắt đầu bằng")
const prefixExpression = getExp('query[1]', 'i', '^:value.*')
console.log(prefixExpression) // /^query\[1\].*/i
```
