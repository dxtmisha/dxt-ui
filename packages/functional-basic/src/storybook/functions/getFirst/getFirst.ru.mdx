# `getFirst`

Возвращает первый элемент массива или первое собственное перечисляемое значение объекта со строковым ключом. Необъектные значения возвращаются без изменений.

**Параметры:**
- `value?: T | readonly T[] | Record<PropertyKey, T>` — входное значение.

**Возвращает:**
`T` — объявленный тип результата: первый элемент или исходное необъектное значение. Во время выполнения пустые массивы и объекты, а также отсутствующий аргумент дают `undefined`.

```typescript
import { getFirst } from '@dxtmisha/functional-basic'

console.log(getFirst([1, 2, 3])) // 1
console.log(getFirst({ a: 1, b: 2 })) // 1
console.log(getFirst('string')) // 'string'
console.log(getFirst([])) // undefined
console.log(getFirst({})) // undefined
```
