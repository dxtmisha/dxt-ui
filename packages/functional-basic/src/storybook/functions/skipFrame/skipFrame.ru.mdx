# `skipFrame`

Асинхронная утилита, которая пропускает указанное количество кадров анимации (`requestAnimationFrame`) или выполняет функцию обратного вызова внутри них.

Она полезна для ожидания обновления DOM, завершения перерисовки браузера перед выполнением следующей операции (например, перед чтением размеров элементов или обработкой рендеринга), а также для выполнения кода на определенном кадре анимации.

**SSR поведение:**
В средах без DOM (например, SSR) `requestAnimationFrame` не используется. Функция разрешается немедленно без вызова `requestAnimationFrame`, предотвращая блокировку потока на сервере.

**Параметры:**
- `callback?: () => T | Promise<T>` — Опциональная функция обратного вызова, которая будет выполнена на целевом кадре анимации.
- `count = 1` — Количество кадров анимации для пропуска (по умолчанию `1`).

**Возвращает:**
`Promise<T | void>` — Промис, разрешающийся на кадре анимации с результатом выполнения коллбэка (или `undefined`, если коллбэк не передан).

```typescript
import { skipFrame } from '@dxtmisha/functional-basic'

// Ожидание следующего кадра (1 кадр по умолчанию)
await skipFrame()

// Пропуск нескольких кадров (например, 2 кадра)
await skipFrame(undefined, 2)

// Выполнение коллбэка после пропуска кадров
const result = await skipFrame(() => {
  return document.getElementById('box')?.getBoundingClientRect()
}, 2)
```
