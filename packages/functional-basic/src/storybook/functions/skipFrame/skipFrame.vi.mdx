# `skipFrame`

Tiện ích bất đồng bộ giúp bỏ qua số lượng khung hình hoạt ảnh đã chỉ định (`requestAnimationFrame`) hoặc thực thi hàm callback trong khung hình đó.

Tiện ích này hữu ích cho việc chờ DOM cập nhật và trình duyệt vẽ lại (repaint) trước khi thực hiện thao tác tiếp theo (ví dụ: đo kích thước phần tử hoặc xử lý hiển thị), cũng như thực thi mã tại một khung hình cụ thể.

**Hành vi trong SSR:**
Trong các môi trường không có DOM (chẳng hạn như SSR), `requestAnimationFrame` sẽ không được sử dụng. Hàm sẽ giải quyết ngay lập tức mà không cần gọi `requestAnimationFrame` để ngăn chặn chặn luồng trên máy chủ.

**Tham số:**
- `callback?: () => T | Promise<T>` — Hàm callback tùy chọn để thực thi tại khung hình hoạt ảnh đích.
- `count = 1` — Số lượng khung hình hoạt ảnh cần bỏ qua (mặc định là `1`).

**Trả về:**
`Promise<T | void>` — Một promise giải quyết tại khung hình hoạt ảnh với kết quả của callback (hoặc `undefined` nếu không cung cấp callback).

```typescript
import { skipFrame } from '@dxtmisha/functional-basic'

// Chờ khung hình hoạt ảnh tiếp theo (mặc định 1 khung hình)
await skipFrame()

// Bỏ qua nhiều khung hình (ví dụ: 2 khung hình)
await skipFrame(undefined, 2)

// Thực thi callback sau khi bỏ qua khung hình
const result = await skipFrame(() => {
  return document.getElementById('box')?.getBoundingClientRect()
}, 2)
```
