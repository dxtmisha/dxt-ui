# `goScroll`

Quickly adjusts the container's vertical scroll position to bring a target element into view (scroll-into-view) if it is outside the visible boundary, or centers it relative to a reference element. Scrolling is confined strictly to the container and does not affect outer window scrolling.

SSR calls, missing target or container elements, unmatched container selectors, and containers without vertical overflow are ignored. `indent` applies to boundary scrolling when `elementCenter` is not provided; centering uses the reference element without this additional spacing.

**Parameters:**
- `target?: string | HTMLElement | null` — CSS selector to resolve the nearest ancestor container or the scrollable container element itself.
- `elementTo?: HTMLElement | null` — The target element to scroll into view.
- `elementCenter?: HTMLElement | null` — (Optional) Reference element to center the target element against.
- `indent?: number` — (Optional) Additional padding indent in pixels from the boundary. Defaults to `0`.

**Returns:**
`void` — Performs the scroll side-effect and returns nothing.

```typescript
import { goScroll } from '@dxtmisha/functional-basic'

const container = document.querySelector<HTMLElement>('.container')
const target = document.querySelector<HTMLElement>('.target')

// Option 1: Find container via selector through closest
goScroll('.container', target)

// Option 2: Pass container element directly with optional indent
if (container && target) {
  goScroll(container, target, null, 16)
}
```
