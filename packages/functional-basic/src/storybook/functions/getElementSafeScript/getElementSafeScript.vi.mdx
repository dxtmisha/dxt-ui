# `getElementSafeScript`

Tạo chuỗi phần tử HTML `<script type="application/json">` an toàn chống chèn mã độc (injection-safe), được tối ưu hóa cho quá trình truyền dữ liệu từ máy chủ sang máy khách (SSR-to-client hydration), đồng bộ hóa trạng thái và nhúng dữ liệu được tuần tự hóa.

## Tính năng chính

- **Ngăn chặn XSS & Đóng thẻ script sớm** — Vô hiệu hóa các cuộc tấn công phá vỡ ngữ cảnh script HTML bằng cách thoát toàn bộ các biến thể của thẻ đóng `</script>` thành `<\\/script>` (bao gồm chữ hoa/thường `</Script>`, khoảng trắng cuối `</script >`, dấu gạch chéo cuối `</script/>` và thẻ có thuộc tính `</script attr="...">`), ngăn parser HTML của trình duyệt đóng script trước thời hạn.
- **Thoát ký tự thuộc tính `id` mạnh mẽ** — Tận dụng tiện ích `encodeAttribute` để thoát toàn diện các ký tự đặc biệt (`"`, `<`, `>`, `&`, `'`) trong thuộc tính định danh, loại bỏ hoàn toàn nguy cơ thoát thuộc tính và tiêm thẻ HTML.
- **Tuần tự hóa JSON an toàn** — Chuyển đổi an toàn các giá trị `undefined`, hàm, symbol và `null` thành chuỗi `'null'`, đảm bảo đầu ra JSON luôn hợp lệ.
- **Bảo toàn Unicode & Ký tự đa ngôn ngữ** — Giữ nguyên vẹn văn bản tiếng Việt có dấu, chữ Cyrillic, ký tự CJK và các biểu tượng cảm xúc emoji đa byte (thuộc bình diện mở rộng astral plane) mà không bị lỗi font hay hỏng mã hóa.
- **Tích hợp đồng bộ với `getHydrationData`** — Được thiết kế để làm việc đối xứng với tiện ích `getHydrationData` phía client, bảo đảm khôi phục dữ liệu nguyên vẹn không mất mát.
- **Thuần túy & Đẳng hình (Isomorphic)** — Hàm thuần túy không có tác dụng phụ, không phụ thuộc vào DOM, thực thi với hiệu năng $O(n)$ trên Node.js, Nitro, Bun, Cloudflare Workers và trình duyệt.

**Tham số:**
- `id: string | number` — Định danh DOM duy nhất cho thẻ script. Các ký tự HTML đặc biệt được tự động mã hóa an toàn.
- `data?: T` — Dữ liệu cần tuần tự hóa sang JSON (`<T = unknown>`). Nếu bỏ trống hoặc là `undefined`, `'null'` sẽ được lưu trữ.

**Trả về:**
`string` — Chuỗi thẻ HTML `<script>` an toàn, sẵn sàng để nhúng vào mã nguồn SSR.

## Ví dụ

<Source
  language='typescript'
  code={`
import { getElementSafeScript, getHydrationData } from '@dxtmisha/functional-basic'

// 1. Hydration trạng thái ứng dụng SSR cơ bản
const appState = {
  theme: 'dark',
  user: { id: 42, role: 'admin' },
  counts: [10, 20, 30]
}
const htmlScript = getElementSafeScript('app-state', appState)
console.log(htmlScript)
// <script id="app-state" type="application/json">{"theme":"dark","user":{"id":42,"role":"admin"},"counts":[10,20,30]}</script>

// 2. Vô hiệu hóa XSS (thoát thẻ đóng script)
const untrustedPayload = {
  comment: '</script><script>alert("XSS")</script>'
}
console.log(getElementSafeScript('safe-comment', untrustedPayload))
// <script id="safe-comment" type="application/json">{"comment":"<\\/script><script>alert(\\"XSS\\")<\\/script>"}</script>

// 3. Thoát thuộc tính ID an toàn
console.log(getElementSafeScript('user" onfocus="alert(1)', { ok: true }))
// <script id="user&quot; onfocus=&quot;alert(1)" type="application/json">{"ok":true}</script>

// 4. Khôi phục dữ liệu hoàn chỉnh phía máy khách
document.body.innerHTML = getElementSafeScript('sync-data', { counter: 100 })
const restored = getHydrationData<{ counter: number }>('sync-data', { counter: 0 })
console.log(restored.counter) // 100
  `}
/>
