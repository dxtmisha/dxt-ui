# `getElementSafeScript`

Generates an injection-safe `<script type="application/json">` HTML element string engineered for SSR-to-client data hydration, state synchronization, and serialized payload embedding.

## Key Features

- **XSS & Script Termination Defense** — Neutralizes HTML script breakout attacks by escaping all variations of closing `</script>` tags into `<\\/script>` (including mixed-case `</Script>`, trailing whitespace `</script >`, trailing slashes `</script/>`, and attribute variants `</script attr="...">`), ensuring the browser HTML parser cannot prematurely terminate the script element.
- **Robust Attribute Sanitization** — Leverages `encodeAttribute` to comprehensively escape special characters (`"`, `<`, `>`, `&`, `'`) in the `id` attribute, preventing attribute breakout and tag injection vulnerabilities.
- **Fail-Safe JSON Serialization** — Converts undefined, function, symbol, and null values safely into `'null'`, ensuring valid JSON output even for unsupported primitives.
- **Full Unicode & Multilingual Support** — Transparently preserves Cyrillic, Vietnamese diacritics, CJK glyphs, and astral plane Unicode characters (multibyte emojis and surrogate pairs) without encoding corruption.
- **Seamless Pair Integration** — Designed to pair symmetrically with `getHydrationData`, ensuring zero-loss deserialization round-trips for complex state structures.
- **Pure & Isomorphic** — Executes cleanly with $O(n)$ string serialization performance and zero DOM dependencies across Node.js, Nitro, Bun, Cloudflare Workers, and browser runtimes.

**Parameters:**
- `id: string | number` — The unique DOM identifier for the script tag. Special HTML characters are safely encoded.
- `data?: T` — The data payload to serialize into JSON (`<T = unknown>`). If omitted or undefined, `'null'` is stored.

**Returns:**
`string` — Complete, safe HTML `<script>` tag string ready for SSR embedding.

## Examples

<Source
  language='typescript'
  code={`
import { getElementSafeScript, getHydrationData } from '@dxtmisha/functional-basic'

// 1. Basic SSR state hydration
const appState = {
  theme: 'dark',
  user: { id: 42, role: 'admin' },
  counts: [10, 20, 30]
}
const htmlScript = getElementSafeScript('app-state', appState)
console.log(htmlScript)
// <script id="app-state" type="application/json">{"theme":"dark","user":{"id":42,"role":"admin"},"counts":[10,20,30]}</script>

// 2. XSS injection neutralization (closing script tag escaping)
const untrustedPayload = {
  comment: '</script><script>alert("XSS")</script>'
}
console.log(getElementSafeScript('safe-comment', untrustedPayload))
// <script id="safe-comment" type="application/json">{"comment":"<\\/script><script>alert(\\"XSS\\")<\\/script>"}</script>

// 3. ID attribute escaping
console.log(getElementSafeScript('user" onfocus="alert(1)', { ok: true }))
// <script id="user&quot; onfocus=&quot;alert(1)" type="application/json">{"ok":true}</script>

// 4. Client-side hydration round-trip
document.body.innerHTML = getElementSafeScript('sync-data', { counter: 100 })
const restored = getHydrationData<{ counter: number }>('sync-data', { counter: 0 })
console.log(restored.counter) // 100
  `}
