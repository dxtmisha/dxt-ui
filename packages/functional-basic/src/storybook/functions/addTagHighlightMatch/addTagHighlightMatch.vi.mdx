# `addTagHighlightMatch`

Tiện ích để làm nổi bật các kết quả khớp trong một chuỗi bằng cách bọc chúng trong thẻ HTML `<span>` với một class được chỉ định. Nó sử dụng `getSeparatingSearchExp` để hỗ trợ tìm kiếm nhiều từ (phân tách bằng dấu cách).

**Tham số:**
- `value?: string | number | null` — Giá trị ban đầu để xử lý.
- `search?: string | RegExp` — Chuỗi tìm kiếm (một hoặc nhiều từ phân tách bằng dấu cách) hoặc biểu thức chính quy.
- `options: AddTagHighlightMatchOptions = {}` — Tùy chọn cấu hình:
  - `className?: string` — Class CSS sẽ được thêm vào thẻ `<span>` (mặc định: `'sys-highlight-match'`).
  - `shouldEscape?: boolean` — Có nên thoát chuỗi trước khi thêm làm nổi bật hay không (mặc định: `false`).
  - `shouldRemoveTag?: boolean` — Có nên xóa các thẻ HTML hiện có khỏi chuỗi hay không (mặc định: `true`).

**Trả về:**
`string` — Chuỗi với các thẻ HTML được thêm vào để làm nổi bật.

<Source
  language='typescript'
  code={`
import { addTagHighlightMatch } from '@dxtmisha/functional-basic'

// Làm nổi bật một từ đơn
addTagHighlightMatch('Hello world', 'hello')
// '<span class="sys-highlight-match">Hello</span> world'

// Làm nổi bật nhiều từ (logic OR)
addTagHighlightMatch('Apple and Banana', 'apple banana')
// '<span class="sys-highlight-match">Apple</span> and <span class="sys-highlight-match">Banana</span>'

// Class tùy chỉnh
addTagHighlightMatch('Test', 'test', { className: 'text-red' })
// '<span class="text-red">Test</span>'

// Xóa thẻ (hành vi mặc định)
addTagHighlightMatch('<p>Hello <b>world</b></p>', 'world')
// 'Hello <span class="sys-highlight-match">world</span>'

// Giữ lại các thẻ HTML hiện có
addTagHighlightMatch('<p>Hello <b>world</b></p>', 'world', { shouldRemoveTag: false })
// '<p>Hello <b><span class="sys-highlight-match">world</span></b></p>'

// Với thoát chuỗi và giữ thẻ HTML dưới dạng văn bản
addTagHighlightMatch('<b>bold</b>', 'bold', { shouldEscape: true, shouldRemoveTag: false })
// '&lt;b&gt;<span class="sys-highlight-match">bold</span>&lt;/b&gt;'
  `}
/>
