# `addTagHighlightMatch`

A utility for highlighting matches in a string by wrapping them in a `<span>` HTML tag with a specified class. It uses `getSeparatingSearchExp` to support multi-word search (space-separated).

**Parameters:**
- `value?: string | number | null` — The initial value to process.
- `search?: string | RegExp` — The search string (one or more words separated by spaces) or a regular expression.
- `options: AddTagHighlightMatchOptions = {}` — Configuration options:
  - `className?: string` — The CSS class to be added to the `<span>` tag (default: `'sys-highlight-match'`).
  - `shouldEscape?: boolean` — Whether to escape the string before adding highlighting (default: `false`).
  - `shouldRemoveTag?: boolean` — Whether to strip existing HTML tags from the string (default: `true`).

**Returns:**
`string` — The string with HTML tags added for highlighting.

<Source
  language='typescript'
  code={`
import { addTagHighlightMatch } from '@dxtmisha/functional-basic'

// Highlight a single word
addTagHighlightMatch('Hello world', 'hello')
// '<span class="sys-highlight-match">Hello</span> world'

// Highlight multiple words (OR logic)
addTagHighlightMatch('Apple and Banana', 'apple banana')
// '<span class="sys-highlight-match">Apple</span> and <span class="sys-highlight-match">Banana</span>'

// Custom class
addTagHighlightMatch('Test', 'test', { className: 'text-red' })
// '<span class="text-red">Test</span>'

// Tag removal (default behavior)
addTagHighlightMatch('<p>Hello <b>world</b></p>', 'world')
// 'Hello <span class="sys-highlight-match">world</span>'

// Preserving existing HTML tags
addTagHighlightMatch('<p>Hello <b>world</b></p>', 'world', { shouldRemoveTag: false })
// '<p>Hello <b><span class="sys-highlight-match">world</span></b></p>'

// With escaping while preserving raw HTML tags as text
addTagHighlightMatch('<b>bold</b>', 'bold', { shouldEscape: true, shouldRemoveTag: false })
// '&lt;b&gt;<span class="sys-highlight-match">bold</span>&lt;/b&gt;'
  `}
/>
