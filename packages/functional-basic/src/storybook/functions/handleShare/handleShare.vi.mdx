# `handleShare`

Triệu hồi cơ chế chia sẻ tự nhiên của thiết bị thông qua Web Share API (`navigator.share`).
Bên trong hàm tự động kiểm tra hỗ trợ bằng `isShare()` và `navigator.canShare(data)` trước khi gọi `navigator.share(data)`. Nếu xảy ra lỗi trong quá trình chia sẻ, lỗi sẽ được chuyển tiếp tới `ErrorCenter` (`group: 'share'`, `code: 'error'`).

**Tham số:**
- `data: ShareData` — Một đối tượng chứa dữ liệu để chia sẻ (`title`, `text`, `url`, `files`).

**Trả về:**
`Promise<boolean>` — `true` nếu dữ liệu được chia sẻ thành công, ngược lại là `false` (nếu không được hỗ trợ, dữ liệu không hợp lệ hoặc bị hủy/lỗi).

```typescript
import { handleShare, isShare } from '@dxtmisha/functional-basic'

const shareData = {
  title: 'Hãy xem trang web này!',
  text: 'Tôi đã tìm thấy điều gì đó thú vị ở đây.',
  url: 'https://example.com'
}

if (isShare()) {
  const success = await handleShare(shareData)
  
  if (success) {
    console.log('Đã chia sẻ thành công!')
  }
}
```
