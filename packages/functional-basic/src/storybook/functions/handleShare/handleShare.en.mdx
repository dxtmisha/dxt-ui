# `handleShare`

Invokes the native sharing mechanism of the device via the Web Share API (`navigator.share`).
Internally verifies support using `isShare()` and `navigator.canShare(data)` before invoking `navigator.share(data)`. Any error thrown during sharing is routed through `ErrorCenter` (`group: 'share'`, `code: 'error'`).

Both `share` and `canShare` must be available. Missing data, unsupported APIs, or a payload rejected by `canShare` return `false` without invoking `share`. A rejection from `share`, including user cancellation, is reported to `ErrorCenter` and returns `false`.

**Parameters:**
- `data?: ShareData | null` — An object containing data to share (`title`, `text`, `url`, `files`). Safely handles `null` and `undefined`.

**Returns:**
`Promise<boolean>` — `true` if the data was shared successfully, otherwise `false` (if unsupported, invalid, or cancelled/failed).

```typescript
import { handleShare, isShare } from '@dxtmisha/functional-basic'

const shareData = {
  title: 'Check out this website!',
  text: 'I found something interesting here.',
  url: 'https://example.com'
}

if (isShare()) {
  const success = await handleShare(shareData)
  
  if (success) {
    console.log('Shared successfully!')
  }
}
```
