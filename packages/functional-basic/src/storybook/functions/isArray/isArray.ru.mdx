# `isArray`

Проверяет, являются ли значения массивами.

**Параметры:**
- `value: unknown` — проверяемое входное значение любого типа.
- `<T = unknown>` — опциональный дженерик для указания типа элементов результирующего массива `T[]`.

**Возвращает:**
`value is T[]` (`boolean`) — `true`, если значение является массивом (`Array.isArray(value)`), иначе `false`. Выступает в качестве защитника типа (type guard) TypeScript, сужая тип проверяемого значения до `T[]`.

```typescript
import { isArray } from '@dxtmisha/functional-basic'

console.log(isArray([1, 2, 3])) // true
console.log(isArray({})) // false
```
