# `isArray`

Checks if the values are arrays.

**Parameters:**
- `value: unknown` — input target value of any type.
- `<T = unknown>` — optional generic specifying the item type of the resultant array `T[]`.

**Returns:**
`value is T[]` (`boolean`) — `true` if the value is an array (`Array.isArray(value)`), otherwise `false`. Acts as a TypeScript type guard narrowing the checked value to `T[]`.

```typescript
import { isArray } from '@dxtmisha/functional-basic'

console.log(isArray([1, 2, 3])) // true
console.log(isArray({})) // false
```
