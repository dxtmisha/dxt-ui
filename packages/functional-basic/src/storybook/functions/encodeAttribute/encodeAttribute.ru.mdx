# `encodeAttribute`

Кодирует специальные символы в строке (`&`, `<`, `>`, `"`, `'`) в соответствующие HTML-сущности (`&amp;`, `&lt;`, `&gt;`, `&quot;`, `&#39;`). Это необходимо для безопасной вставки динамических значений или пользовательского ввода в HTML-атрибуты для предотвращения XSS-атак и инъекций с выходом из контекста кавычек (attribute breakout).

> **Совет:** Если требуется экранировать только базовые символы HTML (`<`, `>`, `&`), сохраняя кавычки без изменений (например, внутри тегов `<title>` или текстового содержимого элементов), используйте `encodeLiteAttribute`.

### Ключевые возможности:
- **Полная защита атрибутов**: Экранирует как двойные (`"`), так и одинарные (`'`) кавычки, амперсанд (`&`) и угловые скобки (`<`, `>`).
- **Высокая производительность (Fast-Path)**: Использует моментальную предварительную проверку перед заменой подстрок, возвращая исходную строку без лишних аллокаций памяти, если спецсимволы отсутствуют.
- **Безопасное приведение типов**: Корректно обрабатывает строки, числа (включая `0` и отрицательные числа), `null` и `undefined` без выброса исключений в рантайме.
- **Сохранение пробелов**: Не выполняет принудительный trimming, полностью сохраняя пробелы, табуляции и переносы строк.

**Параметры:**
- `text?: string | number | null` — Значение для кодирования (строка, число или nullish-значение).

**Возвращает:**
`string` — Закодированная строка, либо пустая строка `''` для `null` или `undefined`.

```typescript
import { encodeAttribute } from '@dxtmisha/functional-basic'

// 1. Предотвращение XSS и инъекций с выходом из кавычек
const unsafeInput = '<script>alert("XSS")</script>'
const safeAttr = encodeAttribute(unsafeInput)
console.log(safeAttr)
// '&lt;script&gt;alert(&quot;XSS&quot;)&lt;/script&gt;'

// Безопасная интерполяция в HTML-атрибуты
const userInput = '"><img src=x onerror=alert(1)>'
const html = `<input type="text" name="query" value="${encodeAttribute(userInput)}">`
// '<input type="text" name="query" value="&quot;&gt;&lt;img src=x onerror=alert(1)&gt;">'

// 2. Безопасная обработка чисел и nullish-значений
encodeAttribute(0)         // '0'
encodeAttribute(123)       // '123'
encodeAttribute(null)      // ''
encodeAttribute(undefined) // ''
```
