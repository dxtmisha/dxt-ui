# `encodeAttribute`

Mã hóa các ký tự đặc biệt trong chuỗi (`&`, `<`, `>`, `"`, `'`) thành các thực thể HTML tương ứng (`&amp;`, `&lt;`, `&gt;`, `&quot;`, `&#39;`). Điều này là cần thiết để chèn giá trị động hoặc dữ liệu người dùng vào các thuộc tính HTML một cách an toàn nhằm ngăn chặn các cuộc tấn công XSS và chèn thuộc tính (attribute breakout).

> **Mẹo:** Nếu bạn chỉ cần mã hóa các ký tự HTML cơ bản (`<`, `>`, `&`) mà không muốn thay đổi dấu ngoặc kép (ví dụ: bên trong thẻ `<title>` hoặc nội dung văn bản), hãy sử dụng `encodeLiteAttribute`.

### Tính năng chính:
- **Bảo vệ toàn diện cho thuộc tính**: Mã hóa cả dấu ngoặc kép (`"`), dấu ngoặc đơn (`'`), dấu và (`&`) và dấu ngoặc nhọn (`<`, `>`).
- **Hiệu năng cao (Fast-Path)**: Sử dụng kiểm tra nhanh trước khi thay thế chuỗi, trả về chuỗi gốc ngay lập tức nếu không tìm thấy ký tự đặc biệt, tránh cấp phát bộ nhớ dư thừa.
- **Ép kiểu an toàn & Hỗ trợ Nullish**: Xử lý an toàn chuỗi, số (bao gồm `0` và số âm), `null` và `undefined` mà không gây ra lỗi ngoại lệ runtime.
- **Giữ nguyên khoảng trắng**: Không tự động cắt tỉa (trim), giữ nguyên hoàn toàn các khoảng trắng, tab và xuống dòng.

**Tham số:**
- `text?: string | number | null` — Giá trị cần mã hóa (chuỗi, số hoặc giá trị nullish).

**Trả về:**
`string` — Chuỗi đã được mã hóa, hoặc chuỗi rỗng `''` nếu giá trị là `null` hoặc `undefined`.

```typescript
import { encodeAttribute } from '@dxtmisha/functional-basic'

// 1. Ngăn chặn tấn công XSS và thoát thuộc tính
const unsafeInput = '<script>alert("XSS")</script>'
const safeAttr = encodeAttribute(unsafeInput)
console.log(safeAttr)
// '&lt;script&gt;alert(&quot;XSS&quot;)&lt;/script&gt;'

// Nội suy an toàn vào các thuộc tính HTML
const userInput = '"><img src=x onerror=alert(1)>'
const html = `<input type="text" name="query" value="${encodeAttribute(userInput)}">`
// '<input type="text" name="query" value="&quot;&gt;&lt;img src=x onerror=alert(1)&gt;">'

// 2. Xử lý an toàn số và các giá trị nullish
encodeAttribute(0)         // '0'
encodeAttribute(123)       // '123'
encodeAttribute(null)      // ''
encodeAttribute(undefined) // ''
```
