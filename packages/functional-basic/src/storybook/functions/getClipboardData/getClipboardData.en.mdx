# `getClipboardData`

Asynchronously extracts text from the clipboard.

This function primarily attempts to retrieve text data from the provided `ClipboardEvent` (e.g., when handling a `paste` event). It falls back to reading directly from the system clipboard using `navigator.clipboard.readText()` only when the event text result is `null` or `undefined`, including when the event or its `clipboardData` is missing. An empty string returned by `getData('text')` is preserved without reading the system clipboard.

If an error occurs while reading the clipboard, it is reported via `ErrorCenter` (`group: 'clipboard'`, `code: 'error'`) and the function safely resolves to an empty string `''`. In non-DOM environments (e.g., SSR), it immediately returns `''`.

> Note: Using `navigator.clipboard.readText()` requires a secure context (HTTPS) and may require the user to explicitly grant clipboard reading permissions in some browsers.

**Parameters:**
- `event?: ClipboardEvent | null` — The optional clipboard event or `null` that fires during cut, copy, or paste actions.

**Returns:**
`Promise<string>` — A promise that resolves to the string content of the clipboard, or an empty string if retrieval fails.

```typescript
import { getClipboardData } from '@dxtmisha/functional-basic'

// Direct usage
document.querySelector('#paste-btn')?.addEventListener('click', async () => {
  const text = await getClipboardData()
  console.log('Clipboard text:', text)
})

// Usage inside a 'paste' event handler
document.addEventListener('paste', async (event) => {
  const text = await getClipboardData(event)
  console.log('Pasted text:', text)
})
```
