# `replaceTemplate`

Упрощенный вариант шаблонизации для одного типа замены — маркеров вида `[pattern]`. В отличие от комплексной функции `applyTemplate`, которая поддерживает позиционные списки (`%d`..`%v`) и блочные теги (`[tag]контент[/tag]`), `replaceTemplate` сфокусирован на быстрой прямой подстановке значений и результатов функций по словарю ключей.

Если значением маркера является функция, она автоматически вызывается, и в строку безопасно подставляется результат ее выполнения.

**Параметры:**
- `value: string` — Строка шаблона с маркерами (например, `[name]`).
- `replaces: Record<string, FunctionOr<string | number | boolean>>` — Объект с данными для замены, где ключ — имя маркера внутри скобок, а значение — строка, число, логическое значение или функция, возвращающая значение.

**Возвращает:**
`string` — Новая строка с подставленными значениями.

```typescript
import { replaceTemplate } from '@dxtmisha/functional-basic'

const template = 'Привет, [name]! Страница: [page]. Твой баланс: [balance].'
const data = {
  name: 'Иван',
  page: 1,
  balance: () => '$100' // Функция вычисляется при подстановке, спецсимволы $ сохраняются буквально
}

console.log(replaceTemplate(template, data)) 
// 'Привет, Иван! Страница: 1. Твой баланс: $100.'
```
