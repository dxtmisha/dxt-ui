# `getRequestString`

Transforms an object or array into a URL-style formatted string (by default, a query string for GET parameters) where keys and values are joined by designated delimiters. Keys are trimmed and URL-encoded via `encodeURIComponent`, values are converted to strings and URL-encoded, nested objects and arrays are recursively serialized using bracket notation (`key[subKey]` or `key[]`), and resulting entries are sorted alphabetically.

**Parameters:**
- `request: Record<string, unknown> | readonly unknown[]` — The data object or array to convert.
- `sign?: string` — (Optional) The character linking a key to its value. Defaults to `'='`.
- `separator?: string` — (Optional) The character separating key-value pairs. Defaults to `'&'`.
- `subKey?: string` — (Optional) Parent key prefix used for formatting nested object properties or array elements.

**Returns:**
`string` — A formatted and sorted query string (or `''` if `request` is not an object or array).

```typescript
import { getRequestString } from '@dxtmisha/functional-basic'

const params = {
  sort: 'desc',
  page: 2,
  search: 'comfortable chair'
}

console.log(getRequestString(params)) 
// 'page=2&search=comfortable%20chair&sort=desc'
```
