# `getRequestString`

Преобразует объект или массив в URL-формат (по умолчанию строку запроса для GET-параметров), где ключи и значения объединяются заданными разделителями. Ключи очищаются от пробелов по краям и кодируются через `encodeURIComponent`, значения приводятся к строке и кодируются через `encodeURIComponent`, вложенные объекты и массивы рекурсивно сериализуются с использованием скобочной нотации (`key[subKey]` или `key[]`), а итоговые пары сортируются в алфавитном порядке.

**Параметры:**
- `request: Record<string, unknown> | readonly unknown[]` — Объект или массив с данными для преобразования.
- `sign?: string` — (Необязательно) Символ соединения между ключом и значением. По умолчанию `'='`.
- `separator?: string` — (Необязательно) Разделитель между парами. По умолчанию `'&'`.
- `subKey?: string` — (Необязательно) Родительский ключ для форматирования вложенных объектов или элементов массива.

**Возвращает:**
`string` — Отформатированная и отсортированная строка запроса (или `''`, если `request` не является объектом или массивом).

```typescript
import { getRequestString } from '@dxtmisha/functional-basic'

const params = {
  sort: 'desc',
  page: 2,
  search: 'удобный стул'
}

console.log(getRequestString(params)) 
// 'page=2&search=%D1%83%D0%B4%D0%BE%D0%B1%D0%BD%D1%8B%D0%B9%20%D1%81%D1%82%D1%83%D0%BB&sort=desc'
```
