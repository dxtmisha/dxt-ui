# `capitalize`

Преобразует первую букву переданной строки в верхний регистр, сохраняя регистр всех последующих символов без изменений. Полностью изоморфна, учитывает локаль и корректно работает с символами астральной плоскости Юникода.

## Ключевые возможности

- **Поддержка астральной плоскости Юникода и эмодзи** — Корректно обрабатывает символы за пределами базовой многоязычной плоскости (BMP, кодовые точки > `0xFFFF`, включая суррогатные пары, алфавиты SMP и эмодзи), предотвращая разрыв 16-битных суррогатов и повреждение текста.
- **Капитализация с учетом языковой локали** — Поддерживает языковые особенности регистра (например, турецкая точка над `'i'` -> `'İ'` вместо `'I'`) как через явный код локали BCP 47 (например, `'tr-TR'`), так и через текущую глобальную локаль приложения, получаемую из `Geo.getLocation()`.
- **Сохранение литеральных типов TypeScript** — Поддерживает встроенный тип `Capitalize<T>` для строковых литералов (`'user'` -> `'User'`), обеспечивая строгую типизацию и автодополнение для имен событий, CSS-классов и ключей объектов на этапе компиляции.
- **Безопасное приведение входных данных** — Использует `toString()` для безопасного преобразования не-строковых примитивов, чисел (`0`, `-42`), логических значений (`false`, `true`), `null` и `undefined` без падений и исключений во время выполнения.
- **Чистота, детерминированность и безопасность для SSR** — Чистая функция без побочных эффектов и зависимостей от DOM-дерева, выполняющаяся с вычислительной сложностью $O(1)$ в среде Node.js, Nitro, Bun и браузере.

**Параметры:**
- `value?: T | unknown` — Исходная строка или значение для капитализации. Если значение опущено или равно nullish, возвращается пустая строка.
- `locale: boolean | string = false` — Если `true`, используется глобальная локаль приложения из `Geo.getLocation()`; если передана строка, она используется как явный тег локали BCP 47 (например, `'tr-TR'`).

**Возвращает:**
`Capitalize<T> | string` — Строка с первой заглавной буквой.

## Примеры

<Source
  language='typescript'
  code={`
import { capitalize, Geo } from '@dxtmisha/functional-basic'

// 1. Базовая капитализация
console.log(capitalize('hello'))     // 'Hello'
console.log(capitalize('helloWorld')) // 'HelloWorld' (регистр последующих символов сохраняется)
console.log(capitalize('A'))          // 'A'
console.log(capitalize(''))           // ''

// 2. Капитализация с учетом локали (турецкая 'i' с точкой)
console.log(capitalize('istanbul', false))     // 'Istanbul'
console.log(capitalize('istanbul', 'tr-TR'))   // 'İstanbul'

// Использование глобальной локали через Geo
Geo.set('tr-TR')
console.log(capitalize('i', true))             // 'İ'

// 3. Символы астральной плоскости Юникода и суррогатные пары (> 0xFFFF)
console.log(capitalize('𐐨abc'))                // '𐐀abc' (буква Deseret 'ee' -> 'Ee')
console.log(capitalize('🚀rocket'))             // '🚀rocket' (эмодзи сохраняется без повреждения)

// 4. Безопасное приведение не-строковых типов
console.log(capitalize(0))                     // '0'
console.log(capitalize(false))                 // 'False'
console.log(capitalize(null))                  // ''
console.log(capitalize(undefined))             // ''

// 5. Вывод литерального типа TypeScript
const status = capitalize('active' as const)
// Тип переменной status строго 'Active'
  `}
/>
