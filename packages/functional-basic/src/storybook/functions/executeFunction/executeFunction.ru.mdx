# `executeFunction`

Базовая изоморфная утилита, которая вызывает переданное значение, если оно является функцией, либо возвращает его без изменений, если передан статический литерал или объект.

## Ключевые возможности

- **Разрешение полиморфных значений** — Позволяет единообразно работать со значениями, которые могут быть заданы как статически, так и динамически через функцию (`T | (() => T)`), избавляя от ручных проверок `typeof value === 'function'`.
- **Проброс произвольных аргументов** — Поддерживает передачу любого количества типизированных аргументов (`...args: Args`) в функцию обратного вызова со строгим выводом типов TypeScript без явных приведений.
- **Сохранение невызываемых типов** — Гарантированно возвращает примитивы (включая `0`, `false`, `""`, `null`, `undefined`), объекты, массивы, Map, Set и экземпляры классов по исходной ссылке, если они не являются вызываемыми функциями.
- **Одноуровневое выполнение** — Если функция возвращает другую функцию, выполняется только внешняя функция, что гарантирует детерминированное поведение без неконтролируемой рекурсии.
- **Изоморфность и безопасность для SSR** — Чистая функция с накладными расходами $O(1)$, не имеющая внешних зависимостей и работающая одинаково стабильно в Node.js, Nitro, Bun, Cloudflare Workers и браузере.

**Параметры:**
- `callback: T | FunctionArgs<never, T> | ((...args: Args) => T)` — Значение для обработки. Может быть литералом, объектом или вызываемой функцией, возвращающей тип `T`.
- `...args: Args` — Аргументы, передаваемые в функцию, если переданный `callback` является функцией.

**Возвращает:**
`T` — Результат выполнения функции или само исходное значение.

## Примеры

<Source
  language='typescript'
  code={`
import { executeFunction } from '@dxtmisha/functional-basic'

// 1. Статические значения и примитивы
console.log(executeFunction('Привет')) // 'Привет'
console.log(executeFunction(42))       // 42
console.log(executeFunction(false))    // false

const config = { theme: 'dark' }
console.log(executeFunction(config) === config) // true (та же ссылка)

// 2. Функция без аргументов (ленивое вычисление)
const computeExpensiveDefault = () => 100 * 2
console.log(executeFunction(computeExpensiveDefault)) // 200

// 3. Функция с пробросом параметров
const formatGreeting = (name: string, role: string) => \`\${role} \${name}\`
console.log(executeFunction(formatGreeting, 'Алиса', 'Инженер')) // 'Инженер Алиса'

// 4. Унификация полиморфных пропсов компонентов (значение или геттер)
function resolveProp<T>(prop: T | (() => T)): T {
  return executeFunction(prop)
}
console.log(resolveProp('статический заголовок')) // 'статический заголовок'
console.log(resolveProp(() => 'динамический заголовок')) // 'динамический заголовок'
  `}
/>
