# `toLanguage`

Extracts and validates a canonical lowercase language code from location strings, locale identifiers, or language codes via `GeoList`.

## Key Features

- **BCP-47 Subtag Support** — Accurately extracts the primary 2- or 3-letter language code from standard and complex BCP-47 locale tags (e.g., `'zh-Hans-CN'` -> `'zh'`, `'cmn-SG'` -> `'cmn'`).
- **Flexible Locale Tag Formats** — Supports classic (`'en-US'`), underscore-separated (`'en_US'`), case-insensitive (`'ru-ru'` -> `'ru'`, `'EN-GB'` -> `'en'`), and reversed (`'RU-ru'` -> `'ru'`, `'VN_vi'` -> `'vi'`) locale tags.
- **Alternative Language Code Resolution** — Automatically maps historical or non-standard language codes registered in `GeoList` to their canonical forms (e.g., `'us'` -> `'en'`, `'ua'` -> `'uk'`, `'cz'` -> `'cs'`, `'il'` -> `'he'`).
- **Strict Verification via `GeoList`** — Distinguishes language codes from uppercase country codes (`'US'` -> `''`, `'RU'` -> `''`) and validates that extracted language tags exist in the supported geo database.
- **Isomorphic & Safe Coercion** — Pure, side-effect-free function utilizing `isString()` to safely reject non-string, `null`, and `undefined` inputs in $O(1)$ without runtime exceptions.

**Parameters:**
- `code?: unknown` — Candidate location or language string to parse and validate.

**Returns:**
- `string` — Canonical lowercase language code (e.g., `'en'`, `'ru'`, `'vi'`) or an empty string if not found.

## Examples

<Source
  language='typescript'
  code={`
import { toLanguage } from '@dxtmisha/functional-basic'

// 1. Direct language codes
toLanguage('en')  // 'en'
toLanguage('ru')  // 'ru'
toLanguage('cmn') // 'cmn'

// 2. Standard and reversed locale tags
toLanguage('en-US') // 'en'
toLanguage('en_US') // 'en'
toLanguage('RU-ru') // 'ru'
toLanguage('VN_vi') // 'vi'

// 3. Complex BCP-47 tags
toLanguage('zh-Hans-CN')         // 'zh'
toLanguage('en-US-u-ca-gregory') // 'en'
toLanguage('cmn-SG')             // 'cmn'

// 4. Alternative language codes (via GeoList)
toLanguage('ua')    // 'uk'
toLanguage('ua-UA') // 'uk'
toLanguage('cz')    // 'cs'
toLanguage('il')    // 'he'

// 5. Country-only, empty, or invalid values
toLanguage('US')      // '' (country only, not a language)
toLanguage('')        // ''
toLanguage(undefined) // ''
  `}
/>
