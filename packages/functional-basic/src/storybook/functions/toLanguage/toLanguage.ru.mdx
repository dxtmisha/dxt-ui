# `toLanguage`

Извлекает и валидирует канонический строчный код языка из строк локаций, тегов локалей или кодов языков через реестр `GeoList`.

## Основные возможности

- **Поддержка субтегов BCP-47** — Точно извлекает первичный 2- или 3-буквенный языковой субтег из стандартных и расширенных BCP-47 тегов (например, `'zh-Hans-CN'` -> `'zh'`, `'cmn-SG'` -> `'cmn'`).
- **Гибкие форматы тегов локали** — Поддерживает классические (`'en-US'`), с разделителем подчеркивания (`'en_US'`), регистронезависимые (`'ru-ru'` -> `'ru'`, `'EN-GB'` -> `'en'`) и инвертированные (`'RU-ru'` -> `'ru'`, `'VN_vi'` -> `'vi'`) форматы.
- **Разрешение альтернативных кодов языков** — Автоматически сопоставляет нестандартные или альтернативные коды, зарегистрированные в `GeoList`, с их каноническими формами (например, `'us'` -> `'en'`, `'ua'` -> `'uk'`, `'cz'` -> `'cs'`, `'il'` -> `'he'`).
- **Строгая верификация через `GeoList`** — Отличает коды языков от заглавных кодов стран (`'US'` -> `''`, `'RU'` -> `''`) и проверяет наличие извлеченного языка в базе поддерживаемых локалей.
- **Изоморфность и безопасная валидация** — Чистая функция без побочных эффектов, использующая `isString()` для мгновенного отсечения нестроковых значений, `null` и `undefined` за $O(1)$ без риска runtime-ошибок.

**Параметры:**
- `code?: unknown` — Проверяемая строка локации или код языка.

**Возвращает:**
- `string` — Канонический код языка в нижнем регистре (например, `'en'`, `'ru'`, `'vi'`) или пустая строка, если язык не найден.

## Примеры

<Source
  language='typescript'
  code={`
import { toLanguage } from '@dxtmisha/functional-basic'

// 1. Прямые коды языков
toLanguage('en')  // 'en'
toLanguage('ru')  // 'ru'
toLanguage('cmn') // 'cmn'

// 2. Стандартные и обратные теги локалей
toLanguage('en-US') // 'en'
toLanguage('en_US') // 'en'
toLanguage('RU-ru') // 'ru'
toLanguage('VN_vi') // 'vi'

// 3. Расширенные субтеги BCP-47
toLanguage('zh-Hans-CN')         // 'zh'
toLanguage('en-US-u-ca-gregory') // 'en'
toLanguage('cmn-SG')             // 'cmn'

// 4. Альтернативные коды языков (через GeoList)
toLanguage('ua')    // 'uk'
toLanguage('ua-UA') // 'uk'
toLanguage('cz')    // 'cs'
toLanguage('il')    // 'he'

// 5. Одиночные коды стран и невалидные значения
toLanguage('US')      // '' (код страны, не языка)
toLanguage('')        // ''
toLanguage(undefined) // ''
  `}
/>
