# `getMinLengthAllArray`

Утилита, которая находит самую короткую строку в предоставленном массиве или объекте и возвращает её длину (число). Функция использует `Math.min` в сочетании с `getLengthOfAllArray` (переключаясь на `.reduce()` для коллекций размером более 10 000 элементов для предотвращения переполнения стека вызовов).

**Параметры:**
- `data: ObjectOrArray<string>` — Входной массив или объект строк.

**Возвращает:**
`number` — Длина самой короткой строки коллекции. Если передан пустой массив или объект, возвращается `0`.

```typescript
import { getMinLengthAllArray } from '@dxtmisha/functional-basic'

const words = ['компьютер', 'код', 'программирование']
const minLength = getMinLengthAllArray(words)

console.log(minLength) // 3 ("код")
```
