# `isDifferent`

Выполняет поверхностное сравнение двух объектов на наличие различий. 

Сначала выполняется быстрая проверка на равенство ссылок $O(1)$. Если ссылки разные, сравнивается количество собственных ключей объектов. Если количество ключей совпадает, функция проверяет наличие каждого ключа во втором объекте и сравнивает значения свойств по семантике `Object.is` (с корректной обработкой `NaN` и различием между отсутствующими ключами и `undefined`).

**Параметры:**
- `value: ObjectItem<T>` — Текущий (новый) объект или элемент данных.
- `old: ObjectItem<T>` — Старый (предыдущий) объект для сравнения.

**Возвращает:**
`boolean` — Вернет `true`, если объекты отличаются (по количеству свойств, наличию ключей или значению хотя бы одного свойства), и `false`, если они идентичны.

```typescript
import { isDifferent } from '@dxtmisha/functional-basic'

const oldState = { id: 1, active: false }
const newState = { id: 1, active: true }

// Объекты отличаются в поле `active`
console.log(isDifferent(newState, oldState)) // true

const sameState = { id: 1, active: false }

// Объекты полностью идентичны
console.log(isDifferent(sameState, oldState)) // false
```
