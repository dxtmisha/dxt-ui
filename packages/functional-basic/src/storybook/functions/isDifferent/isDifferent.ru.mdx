# `isDifferent`

Выполняет поверхностное сравнение объектов или изменяемых/readonly-массивов.

Сначала выполняется быстрая проверка на равенство ссылок $O(1)$. Если ссылки разные, сравниваются собственные перечисляемые строковые ключи. Символы и неперечисляемые свойства игнорируются. Значения совпадающих ключей проверяются через `Object.is`: `NaN` равен `NaN`, а `+0` отличается от `-0`. Вложенные объекты и функции сравниваются по ссылке. Отсутствующий ключ отличается от присутствующего ключа со значением `undefined`.

Одинаковые nullish-аргументы дают `false`; `null` и `undefined` отличаются друг от друга, объектов и массивов.

**Параметры:**
- `value?: ObjectItem<T> | readonly T[] | null` — Текущий объект или массив.
- `old?: ObjectItem<T> | readonly T[] | null` — Предыдущий объект или массив.

**Возвращает:**
`boolean` — Вернет `true`, если объекты отличаются (по количеству свойств, наличию ключей или значению хотя бы одного свойства), и `false`, если они идентичны.

```typescript
import { isDifferent } from '@dxtmisha/functional-basic'

const oldState = { id: 1, active: false }
const newState = { id: 1, active: true }

// Объекты отличаются в поле `active`
console.log(isDifferent(newState, oldState)) // true

const sameState = { id: 1, active: false }

// Собственные перечисляемые ключи и их значения совпадают
console.log(isDifferent(sameState, oldState)) // false
```
