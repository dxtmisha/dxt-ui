# `isDifferent`

So sánh nông các đối tượng hoặc mảng có thể thay đổi/readonly.

Hàm kiểm tra nhanh tính đồng nhất tham chiếu $O(1)$ trước. Nếu các tham chiếu khác nhau, hàm so sánh các khóa chuỗi riêng có thể liệt kê. Symbol và thuộc tính không thể liệt kê bị bỏ qua. Giá trị của các khóa khớp nhau được so sánh bằng `Object.is`: `NaN` bằng `NaN`, còn `+0` khác `-0`. Đối tượng lồng nhau và hàm được so sánh theo tham chiếu. Khóa bị thiếu khác với khóa tồn tại có giá trị `undefined`.

Hai đầu vào nullish giống nhau trả về `false`; `null` khác `undefined`, đối tượng và mảng.

**Tham số:**
- `value?: ObjectItem<T> | readonly T[] | null` — Đối tượng hoặc mảng hiện tại.
- `old?: ObjectItem<T> | readonly T[] | null` — Đối tượng hoặc mảng trước đó.

**Trả về:**
`boolean` — Trả về `true` nếu tìm thấy sự khác biệt giữa hai đối tượng (về số lượng khóa, sự hiện diện của khóa hoặc giá trị của thuộc tính), hoặc `false` nếu chúng giống nhau.

```typescript
import { isDifferent } from '@dxtmisha/functional-basic'

const oldState = { id: 1, active: false }
const newState = { id: 1, active: true }

// Đối tượng khác biệt tại trường phân tích `active`
console.log(isDifferent(newState, oldState)) // true

const sameState = { id: 1, active: false }

// Các khóa riêng có thể liệt kê và giá trị tương ứng khớp nhau
console.log(isDifferent(sameState, oldState)) // false
```
