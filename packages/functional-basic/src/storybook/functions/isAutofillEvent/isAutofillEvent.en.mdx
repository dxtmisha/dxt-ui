# `isAutofillEvent`

Checks whether an `input` event was triggered by browser autofill (`inputType === 'insertReplacementText'`, missing/empty `inputType`, or the target element matching `isAutofillElement`).

**Parameters:**
- `event?: Event | null` — the DOM event to inspect.
- `elementSelectors?: ElementOrString<E> | null` — optional target element or CSS selector (defaults to `event.target`).

**Returns:**
`boolean` — `true` if the event corresponds to browser autofill, otherwise `false`.

```typescript
import { isAutofillEvent } from '@dxtmisha/functional-basic'

input.addEventListener('input', (event) => {
  if (isAutofillEvent(event)) {
    console.log('Input updated by browser autofill')
  }
})
```
