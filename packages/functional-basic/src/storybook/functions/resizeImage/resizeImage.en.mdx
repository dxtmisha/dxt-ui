# `resizeImage`

Asynchronously loads and resizes an image if its width or height exceeds the specified `maxSize`. Returns a Promise with a Data URL string of the scaled image, or the original source if no scaling is needed.

**Parameters:**
- `image: HTMLImageElement | string` — The image element or string source (URL, Data URL).
- `maxSize: number` — The maximum allowed size in pixels (defaults to `1280`).
- `typeData?: string` — Optional MIME type for the resulting Data URL (e.g., `'image/jpeg'`).

**Returns:**
`Promise<string>` — A promise resolving with the resized Data URL string or the original source.

```typescript
import { resizeImage } from '@dxtmisha/functional-basic'

// Resize from Data URL or URL
const resizedDataUrl = await resizeImage('data:image/png;base64,...', 1280)
console.log(resizedDataUrl)

// Usage with an <img> element
const img = document.querySelector('img')
const result = await resizeImage(img, 800, 'image/jpeg')
```
