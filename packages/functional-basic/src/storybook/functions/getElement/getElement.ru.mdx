# `getElement`

Возвращает `Element` (HTML-узел) документа. Утилита принимает на вход строку-селектор, объект `Window` или готовый `Element` и возвращает соответствующий DOM-узел, если выполнение происходит в браузере.

### Особенности работы в SSR и граничные случаи:
- **Строковые селекторы в SSR**: В средах без DOM (серверный рендеринг Node.js / Nitro) поиск элементов невозможен, поэтому для любых строковых селекторов функция безопасно возвращает `undefined`.
- **Готовые элементы (Unwrapper)**: Если в функцию передан уже существующий объект `Element` (HTML, SVG, виртуальный узел или mock в тестах), функция возвращает его как есть без изменений, работая как прозрачная обёртка.
- **Объект `Window`**: При передаче `Window` в браузере возвращается `document.body`.
- **Значения `null` и `undefined`**: При передаче `null` или `undefined` функция сразу возвращает `undefined`.

**Параметры:**
- `element?: ElementOrString<E> | null` — CSS-селектор (например, `'.btn'`), объект `Window` или уже существующий узел `Element` (HTML, SVG).

**Возвращает:**
`R | undefined` — найденный или переданный DOM-узел, либо `document.body`, если был передан `Window`. Возвращает `undefined`, если элемент не найден или DOM недоступен.

```typescript
import { getElement } from '@dxtmisha/functional-basic'

// Поиск по селектору
const btn = getElement('.submit-btn')

// Передача существующего элемента (в DOM и SSR возвращает сам элемент)
const sameBtn = getElement(btn)

// Передача Window вернет document.body
const body = getElement(window)
```
