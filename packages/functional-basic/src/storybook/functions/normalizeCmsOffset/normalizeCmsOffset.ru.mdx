# `normalizeCmsOffset`

Нормализует параметр смещения выборки CMS к неотрицательному целому числу. Если `offset` не задан, не является конечным числом (`NaN`, `Infinity`, `-Infinity`) или меньше нуля, возвращает `0`. Положительные дробные числа усекаются до целого.

**Параметры:**
- `offset?: number` — Запрошенное смещение.

**Возвращает:**
`number` — Неотрицательное целочисленное смещение.

```typescript
import { normalizeCmsOffset } from '@dxtmisha/functional-basic'

console.log(normalizeCmsOffset()) // 0
console.log(normalizeCmsOffset(-10)) // 0
console.log(normalizeCmsOffset(12.9)) // 12
console.log(normalizeCmsOffset(40)) // 40
```
