# `normalizeCmsOffset`

Normalizes the CMS list offset parameter to a non-negative integer. If `offset` is omitted, non-finite (`NaN`, `Infinity`, `-Infinity`), or negative, it returns `0`. Positive floats are truncated toward zero.

**Parameters:**
- `offset?: number` — Requested offset.

**Returns:**
`number` — Non-negative integer offset.

```typescript
import { normalizeCmsOffset } from '@dxtmisha/functional-basic'

console.log(normalizeCmsOffset()) // 0
console.log(normalizeCmsOffset(-10)) // 0
console.log(normalizeCmsOffset(12.9)) // 12
console.log(normalizeCmsOffset(40)) // 40
```
