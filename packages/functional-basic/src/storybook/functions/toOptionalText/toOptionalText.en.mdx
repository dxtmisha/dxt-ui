# `toOptionalText`

Converts an optional value to a trimmed string, converting empty, whitespace-only, `null`, or non-string values to `null` while preserving `undefined`.

**Parameters:**
- `value?: unknown` — Raw optional value.

**Returns:**
`string | null | undefined` — Trimmed string, `null`, or `undefined`.

```typescript
import { toOptionalText } from '@dxtmisha/functional-basic'

console.log(toOptionalText()) // undefined
console.log(toOptionalText(null)) // null
console.log(toOptionalText('   ')) // null
console.log(toOptionalText(123)) // null
console.log(toOptionalText('  hello world  ')) // 'hello world'
```
