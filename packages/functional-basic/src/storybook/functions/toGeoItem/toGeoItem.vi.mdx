# `toGeoItem`

Tìm dữ liệu địa lý quốc gia và ngôn ngữ (`GeoItem`) theo mã kết hợp ngôn ngữ-quốc gia, mã quốc gia hoặc mã ngôn ngữ thông qua `GeoList`.

## Tính năng chính

- **Tìm kiếm theo thẻ ngôn ngữ đầy đủ** — Khớp các chuỗi định dạng kết hợp ngôn ngữ-quốc gia hoặc quốc gia-ngôn ngữ (ví dụ: `'en-US'`, `'RU-ru'`).
- **Dự phòng theo mã quốc gia** — Tìm dữ liệu quốc gia theo mã ISO 2 chữ cái hoặc các bí danh thay thế (ví dụ: `'US'`, `'VN'`, `'UK'`).
- **Dự phòng theo mã ngôn ngữ** — Tìm dữ liệu quốc gia mặc định theo mã ngôn ngữ (ví dụ: `'ru'`, `'vi'`).
- **Xử lý dữ liệu đầu vào an toàn** — Hàm thuần túy không có tác dụng phụ, trả về `undefined` một cách an toàn cho các đầu vào không hợp lệ, chuỗi rỗng hoặc không phải chuỗi.

**Tham số:**
- `code?: unknown` — Mã định danh kết hợp, mã quốc gia hoặc mã ngôn ngữ để tìm kiếm.

**Trả về:**
- `GeoItem | undefined` — Đối tượng dữ liệu địa lý hoặc `undefined` nếu không tìm thấy.

## Ví dụ sử dụng

<Source
  language='typescript'
  code={`
import { toGeoItem } from '@dxtmisha/functional-basic'

// 1. Mã định danh đầy đủ (hỗ trợ dấu gạch dưới, chữ hoa/thường và BCP-47)
toGeoItem('en-US') // { country: 'US', language: 'en', ... }
toGeoItem('en_US') // { country: 'US', language: 'en', ... }
toGeoItem('RU-ru') // { country: 'RU', language: 'ru', ... }
toGeoItem('en-gb') // { country: 'GB', language: 'en', ... }
toGeoItem('zh-Hans-CN') // { country: 'CN', language: 'zh', ... }

// 2. Mã quốc gia
toGeoItem('VN')    // { country: 'VN', language: 'vi', ... }
toGeoItem('UK')    // { country: 'GB', language: 'en', ... }

// 3. Mã ngôn ngữ
toGeoItem('ru')    // { country: 'RU', language: 'ru', ... }

// 4. Mã không hợp lệ hoặc không khớp
toGeoItem('XYZ')   // undefined
toGeoItem(null)    // undefined
`}
/>
