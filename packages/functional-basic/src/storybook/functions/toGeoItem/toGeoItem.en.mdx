# `toGeoItem`

Resolves geographic country and locale data (`GeoItem`) from a language-country code, country code, or language code via `GeoList`.

## Key Features

- **Full Locale Tag Resolution** — Matches combined locale strings in language-country or country-language format (e.g., `'en-US'`, `'RU-ru'`).
- **Country Code Fallback** — Resolves country data by 2-letter ISO country code or alternative aliases (e.g., `'US'`, `'VN'`, `'UK'`).
- **Language Code Fallback** — Resolves default country data for language codes (e.g., `'ru'`, `'vi'`).
- **Safe Input Handling** — Pure, side-effect-free function that gracefully returns `undefined` for invalid, empty, or non-string inputs.

**Parameters:**
- `code?: unknown` — Language-country code, country code, or language code to resolve.

**Returns:**
- `GeoItem | undefined` — The matched geographic data object, or `undefined` if not found.

## Examples

<Source
  language='typescript'
  code={`
import { toGeoItem } from '@dxtmisha/functional-basic'

// 1. Full locale code (including underscores, case variations, and BCP-47)
toGeoItem('en-US') // { country: 'US', language: 'en', ... }
toGeoItem('en_US') // { country: 'US', language: 'en', ... }
toGeoItem('RU-ru') // { country: 'RU', language: 'ru', ... }
toGeoItem('en-gb') // { country: 'GB', language: 'en', ... }
toGeoItem('zh-Hans-CN') // { country: 'CN', language: 'zh', ... }

// 2. Country code
toGeoItem('VN')    // { country: 'VN', language: 'vi', ... }
toGeoItem('UK')    // { country: 'GB', language: 'en', ... }

// 3. Language code
toGeoItem('ru')    // { country: 'RU', language: 'ru', ... }

// 4. Invalid or non-matching code
toGeoItem('XYZ')   // undefined
toGeoItem(null)    // undefined
`}
/>
