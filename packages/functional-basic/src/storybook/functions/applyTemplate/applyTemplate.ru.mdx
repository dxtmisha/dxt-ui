# `applyTemplate`

Высокопроизводительная утилита для применения шаблонов к тексту, заменяющая позиционные маркеры (`%d`..`%v`), парные блочные теги (`[tag]контент[/tag]`, `{tag}контент{/tag}`) и именованные плейсхолдеры (`[key]`, `{key}`) значениями из объекта или массива.

## Ключевые возможности

- **Двойной синтаксис скобок** — Взаимозаменяемо поддерживает как квадратные скобки `[key]`, так и фигурные скобки `{key}` в пределах одной шаблонной строки.
- **Блочные теги и подстановка контента** — Поддерживает парные теги (`[tag]контент[/tag]` или `{tag}контент{/tag}`) с автоматической вставкой внутреннего контента через макрос `[content]` или `{content}`.
- **Позиционные маркеры списка $O(1)$** — Моментально сопоставляет элементы массива с позиционными макросами от `%d` до `%v` (до 19 позиционных аргументов) через константное арифметическое смещение по кодам символов без обхода массивов.
- **Защита от Prototype Pollution** — Использует `hasKey` для строгой проверки собственных свойств объекта, полностью игнорируя унаследованные свойства прототипа (`toString`, `valueOf`, `constructor`, `__proto__`).
- **Безопасность спецсимволов замены** — Воспринимает знаки доллара (`$`) в значениях и заменяемом контенте буквально, предотвращая искажения подстановки захваченных групп в регулярных выражениях.
- **Быстрый ранний выход (Fast-Path)** — Пропускает выполнение регулярных выражений, если шаблонная строка не содержит символа `%`, скобок `[`/`{` или слэша тегов `/`.
- **Гибкое и безопасное приведение типов** — Корректно обрабатывает любые типы входного текста (`unknown`) и примитивы значений (`0`, `false`, отрицательные числа, пользовательский `toString`) без исключений в рантайме.
- **Изоморфность и безопасность для SSR** — Чистая функция без побочных эффектов и зависимостей от глобальных объектов браузера или DOM API.

**Параметры:**
- `text: unknown` — Исходный текст или значение с шаблоном. Автоматически приводится к строке.
- `replacement?: Record<string, unknown> | readonly unknown[]` — (Опционально) Объект или массив, содержащий пары ключ-значение или элементы для замены. По умолчанию `{}`.

**Форматы замены (`replacement`):**
- **Массив (`readonly unknown[]`)**: Используется для позиционных маркеров от `%d` (индекс 0) до `%v` (индекс 18). Отсутствующие элементы заменяются пустой строкой `''`. Буквы вне диапазона (например, `%a`, `%w`, `%D`) и одиночные знаки `%` сохраняются без изменений.
- **Объект (`Record<string, unknown>`)**: Используется для именованных меток в скобках `[key]` или `{key}`, а также для парных тегов `[tag]текст[/tag]` или `{tag}текст{/tag}`.
  - **Блочные теги**: Если строка замены содержит `[content]` или `{content}`, макрос заменяется внутренним содержимым тега. Если макрос отсутствует, тег и его содержимое целиком заменяются на указанное значение.
  - **Отсутствующие ключи**: Метки, отсутствующие в объекте замены, сохраняются в шаблоне без изменений.
  - **Ложные значения (Falsy)**: Числовой `0` и булево `false` сохраняются как `'0'` и `'false'`, а `null` и `undefined` превращаются в пустую строку `''`.

**Возвращает:**
`string` — Текст с подставленными значениями шаблона.

## Примеры

<Source
  language='typescript'
  code={`
import { applyTemplate } from '@dxtmisha/functional-basic'

// 1. Позиционные маркеры с использованием массива (%d..%v)
applyTemplate('Привет, %d %e!', ['Иван', 'Иванов'])
// => 'Привет, Иван Иванов!'

applyTemplate('Координаты: %d, %e, %f', [10, 20, 30])
// => 'Координаты: 10, 20, 30'

// 2. Именованные маркеры с объектом ([key] и {key})
applyTemplate('Цена: [price] {currency}', { price: 100, currency: 'USD' })
// => 'Цена: 100 USD'

applyTemplate('Пользователь: [name] <{email}>', { name: 'Алексей', email: 'alex@example.com' })
// => 'Пользователь: Алексей <alex@example.com>'

// 3. Парные блочные теги со вставкой контента через [content] / {content}
const tags = {
  link: '<a href="https://example.com">[content]</a>',
  bold: '<b>{content}</b>'
}
applyTemplate('Нажмите [link]здесь[/link] или {bold}подробнее{/bold}.', tags)
// => 'Нажмите <a href="https://example.com">здесь</a> или <b>подробнее</b>.'

// 4. Блочные теги без [content] полностью заменяют тег и его содержимое
const badges = { badge: '<span class="badge" />' }
applyTemplate('Товар [badge]новинка[/badge]', badges)
// => 'Товар <span class="badge" />'

// 5. Сохранение значимых ложных значений (0 и false)
applyTemplate('Количество: [count], Активен: [active]', { count: 0, active: false })
// => 'Количество: 0, Активен: false'

applyTemplate('Смещение: %d, Включено: %e', [0, false])
// => 'Смещение: 0, Включено: false'

// 6. Обработка nullish значений и отсутствующих ключей
applyTemplate('Отсутствует: [none], Пусто: [empty]', { empty: null })
// => 'Отсутствует: [none], Пусто: '

// 7. Выход за границы массива и несовпадающие маркеры
applyTemplate('Список: %d, %e, %f, %g', ['первый', 'второй'])
// => 'Список: первый, второй, , '

applyTemplate('Символы: %a %b %D 100%', ['val'])
// => 'Символы: %a %b %D 100%'

// 8. Безопасность знака доллара ($) в значениях и контенте
applyTemplate('Итого: [price]', { price: '$500 USD' })
// => 'Итого: $500 USD'

applyTemplate('Стоимость: [highlight]$100 + $20[/highlight]', {
  highlight: '<span class="price">[content]</span>'
})
// => 'Стоимость: <span class="price">$100 + $20</span>'

// 9. Поддержка мультиязычности и Unicode
applyTemplate('Привет, [имя]! %d новых уведомлений 🚀', { имя: 'Алексей' })
// => 'Привет, Алексей! %d новых уведомлений 🚀'

applyTemplate('Xin chào %d, bạn có %e thông báo.', ['Nguyễn', 3])
// => 'Xin chào Nguyễn, bạn có 3 thông báo.'
  `}
