# `getSearchExp`

Утилита, строящая регистронезависимое регулярное выражение `RegExp` для поиска строк, содержащих **все** слова из поискового запроса (в любом порядке).

Каждое слово в строке поиска разделяется пробелами, дедуплицируется, экранируется от спецсимволов RegExp и оборачивается в positive lookahead-условие `(?=.*?слово)`. Это идеально подходит для живого поиска, фильтрации списков и таблиц по нескольким колонкам одновременно.

### Ключевые возможности:
- **Поиск «И» независимо от порядка слов (AND Logic)**: Строка совпадает, если содержит каждое из введенных слов, независимо от их расположения в тексте (например, запрос `"красная машина"` находит как `"красная быстрая машина"`, так и `"машина ярко красная"`).
- **Поиск подстрок внутри токенов**: Находит слова в любой позиции (например, запрос `"cat dog"` найдет строку `"caterpillar hotdog"`).
- **Многострочный поиск без учета регистра (флаги `is`)**: Использует флаги `i` (регистронезависимость) и `s` (dotAll — точка совпадает с переносом строки `\n`), благодаря чему слова могут находиться в разных абзацах.
- **Дедупликация слов**: Автоматически удаляет повторяющиеся слова в запросе через `Set`, исключая избыточные lookahead-группы.
- **Автоматическое экранирование спецсимволов**: Безопасно экранирует метасимволы через `escapeExp` (`.`, `*`, `+`, `?`, `$`, `^`, `[`, `]`, `(`, `)`, `|`, `\`, `/`), предотвращая синтаксические ошибки и ReDoS-уязвимости при вводе пользовательских данных.
- **Детерминированный фоллбэк `/^/`**: При пустом запросе, строке только из пробелов, нестроковых типах или превышении лимита длины возвращает выражение `/^/` (совпадает с началом любой строки). Это позволяет при пустом поле поиска отображать полный список элементов без дополнительных проверок `if (!search)`.
- **Изоморфность и безопасность для SSR**: Чистая функция без обращений к глобальным объектам браузера.

**Параметры:**
- `search?: unknown` — (Необязательно) Строка поиска из одного или нескольких слов через пробел, либо любое входное значение запроса.
- `limit?: number` — (Необязательно) Максимально допустимая длина строки поиска. По умолчанию `128`.

**Возвращает:**
`RegExp` — Регулярное выражение с флагами `is`. Если строка `search` пустая, не является строкой или превышает `limit`, возвращается `/^/` (совпадает с любой строкой).

```typescript
import { getSearchExp } from '@dxtmisha/functional-basic'

// 1. Базовый поиск "И" по нескольким словам (порядок не имеет значения)
const regex = getSearchExp('foo bar')

console.log(regex.test('foo bar baz'))  // true  — содержит оба слова
console.log(regex.test('bar foo'))      // true  — порядок не важен
console.log(regex.test('foo only'))     // false — слово "bar" отсутствует

// 2. Многострочный поиск через флаг s (dotAll)
const multilineRegex = getSearchExp('заголовок описание')
const targetText = 'Заголовок: Карточка товара\nОписание: Высокое качество'
console.log(multilineRegex.test(targetText)) // true

// 3. Автоматическое экранирование спецсимволов RegExp
const priceRegex = getSearchExp('цена $10.00')
console.log(priceRegex.test('Итоговая цена $10.00 за штуку')) // true
console.log(priceRegex.test('Итоговая цена X10Y00 за штуку')) // false

// 4. Дедупликация слов в запросе
const deduplicatedRegex = getSearchExp('яблоко яблоко яблоко')
console.log(deduplicatedRegex.source) // '^(?=.*?яблоко)'

// 5. Безопасная обработка пустых строк, нестроковых значений и лимитов
getSearchExp('').source             // '^' (совпадает со всеми элементами)
getSearchExp('   ').source          // '^'
getSearchExp(null).source           // '^'
getSearchExp(undefined).source      // '^'
getSearchExp('длинный текст', 4).source // '^' (превышен лимит 4)

// 6. Практический пример: фильтрация массива данных
const searchInput = 'разработчик senior'
const searchPattern = getSearchExp(searchInput)

const employees = [
  { name: 'Алексей Смирнов', position: 'Senior Frontend разработчик' },
  { name: 'Борис Иванов', position: 'Junior разработчик' },
  { name: 'Сергей Петров', position: 'Senior Product Manager' }
]

const matchedEmployees = employees.filter(employee =>
  searchPattern.test(`${employee.name} ${employee.position}`)
)
// Результат: [ { name: 'Алексей Смирнов', position: 'Senior Frontend разработчик' } ]
```
