# `isDomRuntime`

A fast and reliable isomorphic runtime guard that determines whether code is currently executing in an active browser DOM environment where both `window` and `document` are available.

## Key Features

- **Dual-Verification Guard** — Validates both `typeof window !== 'undefined'` and `Boolean(window.document)`, preventing false positives in environments where a partial global `window` object is defined without an actual DOM.
- **SSR & SSG Safety** — Protects against runtime crashes during Server-Side Rendering (Nuxt, Next.js, Nitro, Node.js) and static site generation by guarding DOM-dependent APIs like `document.querySelector`, `window.localStorage`, `IntersectionObserver`, and event listeners.
- **Fast-Path $O(1)$ Evaluation** — Executes in negligible CPU cycles without memory allocation or prototype traversal, making it safe for high-frequency calls in lifecycle hooks and state guards.
- **Web Worker & Edge Worker Resilience** — Correctly returns `false` in Web Workers, Service Workers, and Cloudflare Edge Workers where `self` is defined but DOM tree operations are unavailable.
- **Pure & Side-Effect-Free** — Pure inspection utility that never mutates global state or creates memory retention.

**Parameters:**
This function does not accept any parameters.

**Returns:**
`boolean` — Returns `true` if executing within a DOM-enabled browser environment; otherwise `false` (in Node.js, SSR, or Web Workers).

## Examples

<Source
  language='typescript'
  code={`
import { isDomRuntime } from '@dxtmisha/functional-basic'

// 1. Guarding DOM manipulation and browser APIs
if (isDomRuntime()) {
  document.body.classList.add('hydrated')
  window.scrollTo({ top: 0, behavior: 'smooth' })
} else {
  // Safe fallback for SSR rendering
  console.log('Executing in Server-Side Rendering (SSR) context')
}

// 2. Safe client-side storage access
function getStoredTheme(): string {
  if (isDomRuntime()) {
    return window.localStorage.getItem('theme') ?? 'light'
  }
  return 'light'
}

// 3. Conditional event listener attachment
export function setupWindowResize(handler: () => void): () => void {
  if (isDomRuntime()) {
    window.addEventListener('resize', handler)
    return () => window.removeEventListener('resize', handler)
  }
  return () => {}
}
  `}
