# `isDomRuntime`

Быстрая и надежная изоморфная утилита-защитник среды выполнения, определяющая, выполняется ли код в активном браузерном DOM-окружении, где доступны глобальные объекты `window` и `document`.

## Ключевые возможности

- **Двойная проверка окружения** — Проверяет как `typeof window !== 'undefined'`, так и `Boolean(window.document)`, исключая ложные срабатывания в средах, где объявлен фиктивный объект `window` без реального дерева DOM.
- **Безопасность SSR и SSG** — Предотвращает фатальные сбои при серверном рендеринге (Nuxt, Next.js, Nitro, Node.js) и статической генерации, защищая вызовы `document.querySelector`, `window.localStorage`, `IntersectionObserver` и обработчиков событий.
- **Мгновенное выполнение $O(1)$** — Работает на уровне базовых опкодов движка без выделения памяти и обхода прототипов, что делает проверку безопасной для высокочастотного вызова в хуках жизненного цикла и гвардах состояний.
- **Корректность в Web Workers** — Возвращает `false` в контексте Web Worker, Service Worker и Cloudflare Workers, где доступен глобальный контекст `self`, но отсутствует дерево DOM.
- **Изоморфность и отсутствие побочных эффектов** — Чистая функция, не изменяющая глобальное состояние и не приводящая к утечкам памяти.

**Параметры:**
Функция не принимает аргументов.

**Возвращает:**
`boolean` — Возвращает `true`, если код выполняется в среде браузера с активным DOM; иначе `false` (в среде Node.js, SSR или Web Workers).

## Примеры

<Source
  language='typescript'
  code={`
import { isDomRuntime } from '@dxtmisha/functional-basic'

// 1. Безопасная работа с DOM и API браузера
if (isDomRuntime()) {
  document.body.classList.add('hydrated')
  window.scrollTo({ top: 0, behavior: 'smooth' })
} else {
  // Безопасный сценарий для сервера
  console.log('Выполнение на стороне сервера (SSR)')
}

// 2. Безопасный доступ к хранилищу браузера
function getStoredTheme(): string {
  if (isDomRuntime()) {
    return window.localStorage.getItem('theme') ?? 'light'
  }
  return 'light'
}

// 3. Условная подписка на события окна
export function setupWindowResize(handler: () => void): () => void {
  if (isDomRuntime()) {
    window.addEventListener('resize', handler)
    return () => window.removeEventListener('resize', handler)
  }
  return () => {}
}
  `}
/>
