# `strFill`

Возвращает строковое представление `value`, повторённое `count` раз. `count` задаёт число повторений, поэтому `strFill('ab', 3)` возвращает `'ababab'` длиной 6.

Nullish-значения дают пустую строку; остальные преобразуются через `String()`. Число повторений по умолчанию — `0`. Дробные значения count усекаются к нулю, а `NaN` действует как `0`. Как и в нативном `String.prototype.repeat`, отрицательное после усечения или бесконечное число повторений вызывает `RangeError`.

**Параметры:**
- `value?: unknown` — значение для преобразования в строку и повторения; nullish-значения дают `''`.
- `count?: number` — число повторений; по умолчанию `0`.

**Возвращает:**
`string` — строка, заполненная указанным значением.

```typescript
import { strFill } from '@dxtmisha/functional-basic'

const string = strFill('a', 3)
console.log(string) // 'aaa'
```
