# `isFloat`

Accepts finite JavaScript numbers (including integers) and decimal strings after trimming outer whitespace. A string may have a leading `+` or `-`, must contain digits before the decimal point, and must contain digits after it when present.

Strings such as `'1e3'`, `'0x10'`, `'.5'`, and `'1.'` are rejected, as are `NaN`, infinities, and bigint values. String validation checks the decimal syntax without converting it to a number.

**Parameters:**
- `value?: unknown` — values for checking.

**Returns:**
`boolean` — `true` for a finite number or a decimal string matching the grammar above; otherwise `false`.

```typescript
import { isFloat } from '@dxtmisha/functional-basic'

console.log(isFloat(123)) // true
console.log(isFloat('123.45')) // true
console.log(isFloat('abc')) // false
```
