# `isFloat`

Принимает конечные числа JavaScript (включая целые) и десятичные строки после удаления внешних пробелов. В строке допустим начальный знак `+` или `-`; цифры до точки обязательны, а при наличии точки обязательны и цифры после неё.

Строки `'1e3'`, `'0x10'`, `'.5'` и `'1.'` отклоняются, как и `NaN`, бесконечности и bigint. Для строк проверяется десятичный синтаксис без преобразования в число.

**Параметры:**
- `value?: unknown` — значения для проверки.

**Возвращает:**
`boolean` — `true` для конечного числа или десятичной строки указанного формата, иначе `false`.

```typescript
import { isFloat } from '@dxtmisha/functional-basic'

console.log(isFloat(123)) // true
console.log(isFloat('123.45')) // true
console.log(isFloat('abc')) // false
```
