# `getObjectNoUndefined`

Создаёт и возвращает новый объект с собственными перечисляемыми строковыми свойствами, значения которых не совпадают со значением-исключением. По умолчанию исключается `undefined`. `NaN` совпадает с `NaN`; положительный и отрицательный ноль считаются равными.

Функция полезна для очистки данных перед отправкой на сервер или для нормализации объектов. При передаче массива индексы будут преобразованы в строковые ключи результирующего объекта.

Зарезервированные ключи `__proto__`, `constructor` и `prototype` всегда исключаются для защиты прототипа результата. Пропущенное, nullish-значение или значение не объектного типа даёт пустой обычный объект. Фильтрация поверхностная и сохраняет вложенные ссылки.

**Параметры:**
- `data?: T` — Исходное значение; поддерживаются объекты и readonly-массивы.
- `exception?: unknown` — (Необязательно) Значение, свойства с которым будут исключены (сравнивается через `Object.is` и строгое неравенство). По умолчанию равно `undefined`.

**Возвращает:**
`R` — Новый объект без зарезервированных ключей и совпадающих значений. По умолчанию для массивов выводится `Record<number, V>`, для входных записей сохраняется `T`, для остальных значений выводится `Record<PropertyKey, unknown>`. Результат всегда объект, в том числе при передаче массива.

```typescript
import { getObjectNoUndefined } from '@dxtmisha/functional-basic'

const user = {
  name: 'John',
  age: 25,
  description: undefined, // Будет удалено (по умолчанию)
  status: 'guest'
}

console.log(getObjectNoUndefined(user)) 
// { name: 'John', age: 25, status: 'guest' }

// Удалить свойства со значением 'guest'
console.log(getObjectNoUndefined(user, 'guest'))
// { name: 'John', age: 25, description: undefined }
```
