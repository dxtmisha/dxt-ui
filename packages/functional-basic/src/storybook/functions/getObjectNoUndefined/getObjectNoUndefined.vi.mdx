# `getObjectNoUndefined`

Tạo và trả về một đối tượng mới gồm các thuộc tính riêng có thể liệt kê với khóa chuỗi và giá trị không khớp với giá trị ngoại lệ. Mặc định, giá trị ngoại lệ là `undefined`. `NaN` khớp với `NaN`; số không dương và số không âm được xem là bằng nhau.

Hàm này thường được dùng để dọn dẹp dữ liệu trước khi gửi tới máy chủ hoặc để chuẩn hóa các đối tượng. Khi bạn truyền vào một mảng, các chỉ số của mảng sẽ được chuyển dạng thành khóa (key) kiểu chuỗi trong kết quả trả về.

Các khóa dành riêng `__proto__`, `constructor` và `prototype` luôn bị loại bỏ để bảo vệ prototype của kết quả. Đầu vào bị bỏ qua, nullish hoặc không phải đối tượng trả về một đối tượng thông thường rỗng. Hàm lọc nông và giữ nguyên tham chiếu lồng nhau.

**Tham số:**
- `data?: T` — Giá trị nguồn; hỗ trợ đối tượng và mảng readonly.
- `exception?: unknown` — (Tùy chọn) Giá trị sẽ khiến thuộc tính mang nó bị loại bỏ (so sánh qua `Object.is` và so sánh khác nghiêm ngặt). Mặc định là `undefined`.

**Trả về:**
`R` — Đối tượng mới không có khóa dành riêng hoặc giá trị khớp. Theo mặc định, mảng suy ra `Record<number, V>`, đối tượng record giữ kiểu `T`, các giá trị khác suy ra `Record<PropertyKey, unknown>`. Kết quả luôn là đối tượng, kể cả khi đầu vào là mảng.

```typescript
import { getObjectNoUndefined } from '@dxtmisha/functional-basic'

const user = {
  name: 'John',
  age: 25,
  description: undefined, // Sẽ tự động bị xóa (mặc định)
  status: 'guest'
}

console.log(getObjectNoUndefined(user)) 
// { name: 'John', age: 25, status: 'guest' }

// Xóa tất cả các thuộc tính có giá trị bằng 'guest'
console.log(getObjectNoUndefined(user, 'guest'))
// { name: 'John', age: 25, description: undefined }
```
