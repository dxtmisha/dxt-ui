# `getLengthOfAllArray`

Создает и возвращает новый массив, состоящий из длин (свойство `.length`) всех элементов переданного массива или объекта строк.

**Параметры:**
- `value: ObjectOrArray<string>` — Входной массив или объект строк.

**Возвращает:**
`number[]` — Массив чисел, где каждое число соответствует длине строки исходной коллекции (или `0`, если элемент не определен или пуст).

```typescript
import { getLengthOfAllArray } from '@dxtmisha/functional-basic'

const data = ['красный', 'синий', 'зеленый']
const lengths = getLengthOfAllArray(data)

console.log(lengths) // [7, 5, 7]
```
