# `getObjectOrNone`

Утилита возвращает объект, не являющийся массивом, без изменений с сохранением ссылки. Принимаются пустые объекты, объекты с null-прототипом и экземпляры классов, например `Date`. Для массивов, функций, примитивов, null, undefined и пропущенного аргумента каждый вызов создаёт новый пустой объект `{}`.

**Параметры:**
- `value?: T` — Любое значение, которое предполагается быть объектом.

**Возвращает:**
`ObjectOrNoneReturn<T>` — Сохраняет `T & Record<string, unknown>` для входного объекта, не являющегося массивом. Для массивов, функций, примитивов, nullish-значений и пропущенного аргумента используется `Record<string, unknown>`, поэтому методы отклонённого значения не объявляются вызываемыми методами результата. Для union-входа сохраняются оба варианта: исходный объект и пустой объект. Во время выполнения возвращается исходный объект, не являющийся массивом, или новый пустой объект `{}`.

```typescript
import { getObjectOrNone } from '@dxtmisha/functional-basic'

// Успешный возврат объекта
console.log(getObjectOrNone({ name: 'Admin' })) // { name: 'Admin' }

// Массив — не подходящий тип объекта, вернется {}
console.log(getObjectOrNone([1, 2, 3])) // {}

// Примитивы и null возвращают {}
console.log(getObjectOrNone(null)) // {}
console.log(getObjectOrNone('строка')) // {}
```
