# `getObjectOrNone`

Tiện ích trả về nguyên đối tượng không phải mảng và giữ nguyên tham chiếu. Hàm chấp nhận đối tượng rỗng, đối tượng có prototype null và thể hiện của lớp như `Date`. Với mảng, hàm, kiểu nguyên thủy, null, undefined hoặc đối số bị bỏ qua, mỗi lần gọi tạo một đối tượng rỗng `{}` mới.

**Tham số:**
- `value?: T` — Bất kỳ giá trị nào, thường mong đợi đây là một đối tượng.

**Trả về:**
`ObjectOrNoneReturn<T>` — Giữ `T & Record<string, unknown>` cho đối tượng đầu vào không phải mảng. Mảng, hàm, kiểu nguyên thủy, giá trị nullish và đối số bị bỏ qua dùng `Record<string, unknown>`, nên phương thức của giá trị bị loại không được xem là phương thức có thể gọi trên kết quả. Đầu vào union giữ cả khả năng trả về đối tượng gốc và đối tượng rỗng. Khi chạy, hàm trả về nguyên đối tượng không phải mảng hoặc một đối tượng rỗng `{}` mới.

```typescript
import { getObjectOrNone } from '@dxtmisha/functional-basic'

// Trả về đối tượng thành công
console.log(getObjectOrNone({ name: 'Admin' })) // { name: 'Admin' }

// Mảng không được coi là plain object, trả về {}
console.log(getObjectOrNone([1, 2, 3])) // {}

// Các kiểu thông thường và null sẽ trả về {}
console.log(getObjectOrNone(null)) // {}
console.log(getObjectOrNone('a string')) // {}
```
