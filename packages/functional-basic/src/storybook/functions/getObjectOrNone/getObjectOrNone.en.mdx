# `getObjectOrNone`

A utility that returns a non-array object unchanged, preserving its reference. Empty objects, objects with a null prototype, and class instances such as `Date` are accepted. Arrays, functions, primitives, null, undefined, and an omitted argument produce a new empty object `{}` on each call.

**Parameters:**
- `value?: T` — Any value, usually expected to be an object.

**Returns:**
`ObjectOrNoneReturn<T>` — Preserves `T & Record<string, unknown>` for non-array object inputs. Arrays, functions, primitives, nullish values, and an omitted argument use `Record<string, unknown>`, so methods of a rejected input are not exposed as callable methods of the result. Union inputs retain both the preserved-object and fallback possibilities. At runtime, the result is the original non-array object or a new empty object `{}`.

```typescript
import { getObjectOrNone } from '@dxtmisha/functional-basic'

// Successful object return
console.log(getObjectOrNone({ name: 'Admin' })) // { name: 'Admin' }

// Arrays are not considered plain objects, returns {}
console.log(getObjectOrNone([1, 2, 3])) // {}

// Primitives and null return {}
console.log(getObjectOrNone(null)) // {}
console.log(getObjectOrNone('a string')) // {}
```
