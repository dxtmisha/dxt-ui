# `hasKey`

Высокопроизводительная утилита-защитник типа (type guard), определяющая, является ли указанное свойство собственным свойством объекта или функции.

## Ключевые возможности

- **Защита от Prototype Pollution** — Строго проверяет собственные свойства через нативный `Object.hasOwn`, исключая ложные срабатывания на свойства прототипа (`toString`, `valueOf`, `constructor`, `__proto__`, `hasOwnProperty`).
- **Поддержка словарей без прототипа** — Полностью безопасна для объектов, созданных через `Object.create(null)`, у которых отсутствует метод `hasOwnProperty`.
- **Безопасность при работе с примитивами** — Никогда не выбрасывает исключений в рантайме при передаче `null`, `undefined`, чисел, строк, булевых значений, символов или BigInt, корректно возвращая `false`.
- **Поддержка всех типов ключей** — Работает со строковыми ключами, числовыми индексами, `Symbol`, а также Unicode/мультиязычными именами свойств.
- **Сужение типов в TypeScript** — Служит предикатом типа `object is T & Record<K, unknown>`, позволяя безопасно обращаться к свойству без принудительного приведения типов.
- **Функции и сложные структуры** — Корректно определяет пользовательские свойства на функциях, экземплярах классов, замороженных объектах (`Object.freeze`) и неперечислимых свойствах.
- **Изоморфность и безопасность для SSR** — Чистая функция без побочных эффектов и зависимостей от глобальных объектов браузера или DOM.

**Параметры:**
- `object: unknown` — Проверяемый объект, функция или значение любого типа.
- `key: K` (`K extends PropertyKey = PropertyKey`) — Ключ свойства (`string | number | symbol`).

**Возвращает:**
`boolean` (`object is T & Record<K, unknown>`) — Возвращает `true`, если свойство существует и принадлежит непосредственно данному объекту (собственное свойство), иначе `false`. Выступает в роли TypeScript type guard.

## Примеры

<Source
  language='typescript'
  code={`
import { hasKey } from '@dxtmisha/functional-basic'

// 1. Базовая проверка свойств объекта
const user = { name: 'Алексей', age: 30 }
hasKey(user, 'name')                   // true
hasKey(user, 'email')                  // false

// 2. Защита от Prototype Pollution (унаследованные свойства возвращают false)
hasKey({}, 'toString')                 // false
hasKey({}, 'valueOf')                  // false
hasKey({}, 'constructor')              // false
hasKey({}, '__proto__')                // false

// Явно переопределенные собственные свойства возвращают true
hasKey({ toString: 'custom' }, 'toString') // true

// 3. Словари без прототипа (Object.create(null))
const dict = Object.create(null)
dict.item = 'значение'
hasKey(dict, 'item')                   // true
hasKey(dict, 'missing')                // false
hasKey(dict, 'toString')               // false

// 4. Безопасность при работе с null, undefined и примитивами
hasKey(null, 'foo')                    // false
hasKey(undefined, 'foo')               // false
hasKey(123, 'toString')                // false
hasKey('строка', 0)                    // false
hasKey(false, 'valueOf')               // false

// 5. Символьные ключи и числовые индексы массивов
const sym = Symbol('secret')
hasKey({ [sym]: 42 }, sym)             // true
hasKey(['a', 'b', 'c'], 0)             // true
hasKey(['a', 'b', 'c'], 10)            // false
hasKey(['a', 'b', 'c'], 'length')      // true

// 6. Неперечислимые свойства и замороженные объекты
const target = Object.freeze({ key: 'val' })
hasKey(target, 'key')                  // true

// 7. Сужение типов в TypeScript (Type Guard)
function processData(data: unknown) {
  if (hasKey(data, 'title')) {
    // TypeScript автоматически сужает data, разрешая доступ к title
    console.log(data.title)
  }
}
  `}
/>
