# `intersectKey`

Анализирует два объекта или массива и возвращает новый обычный объект с общими ключами `data` и собственных свойств `comparison` (проверка через `hasKey`). Значения берутся из `data`. Для объектов перебираются собственные перечисляемые строковые ключи, для массивов — числовые индексы. Унаследованные свойства `comparison`, например методы массива, не совпадают.

Ключи `__proto__`, `constructor` и `prototype` всегда исключаются, даже когда оба аргумента содержат их как собственные свойства. Это предотвращает изменение прототипа результата при копировании `__proto__`. Остальные собственные ключи, например `toString` и `valueOf`, поддерживаются. Копирование значений поверхностное, включая `undefined`.

Функция полезна для фильтрации данных по разрешенному списку свойств или для синхронизации моделей.

**Параметры:**
- `data?: T | null` — Исходная запись или изменяемый/readonly-массив, из которого берутся значения.
- `comparison?: C | null` — Запись или изменяемый/readonly-массив, собственные ключи которого проверяются.

**Возвращает:**
Новый обычный объект, никогда не массив. Отсутствующие или nullish-аргументы дают `{}`. Ограничения generic-параметров принимают записи и readonly-массивы; примитивы остаются вне TypeScript-контракта.

- `data` — массив: `Partial<Record<number, T[number]>>`, без методов массива и `length`.
- `data` — запись, `comparison` — массив: `Partial<Pick<T, Extract<keyof T, keyof C>>>`, поскольку свойство может быть унаследованным, а не собственным свойством массива.
- Оба аргумента — записи: `Pick<T, Extract<keyof T, keyof C>>`.

```typescript
import { intersectKey } from '@dxtmisha/functional-basic'

const inputData = { id: 1, name: 'John', age: 30, _internalToken: 'xyz' }
const allowedSchema = { id: null, name: null, role: null }

// Возвратит только ключи из inputData, которые есть в allowedSchema
const result = intersectKey(inputData, allowedSchema)
console.log(result) // { id: 1, name: 'John' }
```
