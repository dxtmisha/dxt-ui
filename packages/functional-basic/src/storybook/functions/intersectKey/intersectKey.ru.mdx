# `intersectKey`

Анализирует два объекта (или массива) и возвращает новый объект, содержащий только те свойства из первого объекта, ключи которых присутствуют и во втором объекте. Значения для результирующего объекта берутся из исходного объекта (`data`). Проверка наличия ключей осуществляется строго по собственным свойствам (через `hasKey`), исключая ложные совпадения из цепочки прототипов (`toString`, `valueOf`, `constructor` и др.).

Функция полезна для фильтрации данных по разрешенному списку свойств или для синхронизации моделей.

**Параметры:**
- `data?: T | null` — Основной объект, из которого будут браться значения.
- `comparison?: C | null` — Объект, список собственных ключей которого используется для проверки наличия.

**Возвращает:**
`Pick<T, Extract<keyof T, keyof C>>` — Новый объект, в который скопированы только пересекающиеся свойства с сохранением их точных типов. Если аргументы не переданы или не являются объектами, вернет пустой объект `{}`.

```typescript
import { intersectKey } from '@dxtmisha/functional-basic'

const inputData = { id: 1, name: 'John', age: 30, _internalToken: 'xyz' }
const allowedSchema = { id: null, name: null, role: null }

// Возвратит только ключи из inputData, которые есть в allowedSchema
const result = intersectKey(inputData, allowedSchema)
console.log(result) // { id: 1, name: 'John' }
```
