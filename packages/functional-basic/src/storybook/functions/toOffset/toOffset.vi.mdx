# `toOffset`

Chuyển đổi tham số độ lệch (offset) thành số nguyên không âm. Nếu `offset` bị bỏ qua, không hữu hạn (`NaN`, `Infinity`, `-Infinity`) hoặc âm, hàm trả về `0`. Số thực dương sẽ được cắt bỏ phần thập phân.

**Tham số:**
- `offset?: number` — Độ lệch được yêu cầu.

**Trả về:**
`number` — Độ lệch số nguyên không âm.

```typescript
import { toOffset } from '@dxtmisha/functional-basic'

console.log(toOffset()) // 0
console.log(toOffset(-10)) // 0
console.log(toOffset(12.9)) // 12
console.log(toOffset(40)) // 40
```
