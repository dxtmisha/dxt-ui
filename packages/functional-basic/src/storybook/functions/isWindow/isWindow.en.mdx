# `isWindow`

Checks whether the provided value is the global browser `window` object.

First verifies via `isDomRuntime()` that the code is running in a DOM environment (preventing errors during Server-Side Rendering), and then compares `element === window`.

**Parameters:**
- `element: E` — The element or value to check.

**Returns:**
`element is Extract<E, Window>` (`boolean`) — Returns `true` if running in a browser environment and `element` is strictly equal to `window`, otherwise `false`. Acts as a TypeScript type guard narrowing `E` to `Extract<E, Window>`.

```typescript
import { isWindow } from '@dxtmisha/functional-basic'

// Valid window object
console.log(isWindow(window)) // true
console.log(isWindow(globalThis.window)) // true

// Other DOM nodes and values
console.log(isWindow(document)) // false
console.log(isWindow(document.body)) // false
console.log(isWindow({})) // false
```
