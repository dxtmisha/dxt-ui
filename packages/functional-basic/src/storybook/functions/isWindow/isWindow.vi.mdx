# `isWindow`

Kiểm tra xem phần tử hoặc giá trị được truyền vào có phải là đối tượng `window` toàn cục của trình duyệt hay không.

Trước tiên hàm kiểm tra qua `isDomRuntime()` để đảm bảo mã đang chạy trong môi trường DOM (ngăn ngừa lỗi trong quá trình Server-Side Rendering - SSR), sau đó so sánh `element === window`.

**Tham số:**
- `element: E` — Phần tử hoặc giá trị cần kiểm tra.

**Trả về:**
`element is Extract<E, Window>` (`boolean`) — Trả về `true` nếu đang chạy trong môi trường trình duyệt và `element` bằng nghiêm ngặt với `window`, ngược lại là `false`. Đóng vai trò là bộ bảo vệ kiểu (type guard) trong TypeScript, thu hẹp `E` thành `Extract<E, Window>`.

```typescript
import { isWindow } from '@dxtmisha/functional-basic'

// Đối tượng window hợp lệ
console.log(isWindow(window)) // true
console.log(isWindow(globalThis.window)) // true

// Các nút DOM và giá trị khác
console.log(isWindow(document)) // false
console.log(isWindow(document.body)) // false
console.log(isWindow({})) // false
```
