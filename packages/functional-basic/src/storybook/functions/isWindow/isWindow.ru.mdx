# `isWindow`

Проверяет, является ли переданный элемент или значение глобальным объектом браузера `window`.

Сначала выполняет проверку `isDomRuntime()`, чтобы убедиться, что код запущен в DOM-окружении (предотвращая ошибки при серверном рендеринге SSR), а затем сравнивает `element === window`.

**Параметры:**
- `element: E` — Проверяемый элемент или значение.

**Возвращает:**
`element is Extract<E, Window>` (`boolean`) — Возвращает `true`, если код выполняется в браузере и `element` строго равен `window`, иначе `false`. Выступает в качестве защитника типа (type guard) в TypeScript, сужая `E` до `Extract<E, Window>`.

```typescript
import { isWindow } from '@dxtmisha/functional-basic'

// Успешная валидация
console.log(isWindow(window)) // true
console.log(isWindow(globalThis.window)) // true

// Другие DOM-узлы и значения
console.log(isWindow(document)) // false
console.log(isWindow(document.body)) // false
console.log(isWindow({})) // false
```
