# `getObjectNull`

Tạo một từ điển không có prototype bằng `Object.create(null)`. Các khóa như `toString`, `valueOf` và `constructor` được lưu dưới dạng mục thông thường. Nếu có dữ liệu ban đầu, hàm sao chép các thuộc tính riêng có thể liệt kê của dữ liệu đó.

**Tham số:**
- `data?: Record<string, T> | null` — Dữ liệu đối tượng ban đầu tùy chọn để sao chép thuộc tính.

**Trả về:**
- `Record<string, T>` — Đối tượng sạch không có prototype.

```typescript
import { getObjectNull } from '@dxtmisha/functional-basic'

// 1. Tạo đối tượng rỗng không có prototype
const registry = getObjectNull<number>()

// Các thuộc tính như toString, valueOf, constructor không tồn tại trên prototype
console.log('toString' in registry) // false
console.log('valueOf' in registry)  // false

// Thiết lập khóa tùy ý một cách an toàn
registry.toString = 42
console.log(registry.toString)      // 42

// 2. Tạo đối tượng không có prototype với dữ liệu ban đầu
const config = getObjectNull({ port: 3000, host: 'localhost' })
console.log(config.port) // 3000
console.log(Object.getPrototypeOf(config)) // null
```
