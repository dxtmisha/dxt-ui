# `isEnter`

Проверяет, является ли нажатая клавиша `Enter` или `Space` (клавиша действия WAI-ARIA) вне полей ввода текста. Функция используется для клавиатурной активации интерактивных элементов (кнопок, ссылок, карточек).

Если фокус находится внутри поля ввода (`input`, `textarea`, `select`, `contenteditable`), функция возвращает `false`, чтобы не блокировать ввод текста и пробелов, если это поведение явно не переопределено параметром `isInputElement`.

**Параметры:**
- `event: KeyboardEvent` — объект события клавиатуры.
- `isInputElement?: boolean` — принудительный флаг: `true` — считать элемент полем ввода (вернёт `false`), `false` — разрешить обработку даже внутри полей ввода. Если не передан, определяется автоматически через `isInput(event.target)`.

**Возвращает:**
`boolean` — `true`, если нажат `Enter` или `Space` вне поля ввода (или при явном разрешении), иначе `false`.

**Поддерживаемые свойства события:**
Функция проверяет следующие свойства события:
- `key`: `'Enter'`, `' '`, `'Spacebar'`
- `code`: `'Enter'`, `'NumpadEnter'`, `'Space'`
- `keyCode`: `13`, `32`
- Защита от IME: если `event.isComposing === true`, функция всегда возвращает `false`.

```typescript
import { isEnter } from '@dxtmisha/functional-basic'

const onKeyDown = (event: KeyboardEvent) => {
  if (isEnter(event)) {
    console.log('Нажат Enter или Space')
    // Выполнить действие
  }
}
```
