# `getElementItem`

Returns the value of a specific property from a DOM element, including SVG elements (e.g., `id`, `className`, or a custom property). If `window` is passed, the utility resolves it to `document.body` in DOM runtime via `getElement`. If the element is not found or the property value is `null` or `undefined`, it returns `defaultValue` (which defaults to `undefined`). Values `0`, `false`, and `''` are preserved.

Omitting the property key or passing `null` returns the fallback. Invalid CSS selectors still propagate the native selector error.

**Parameters:**
- `element?: ElementOrString<E> | null` — A selector string, an existing DOM element, `window` (resolves to `document.body`), or `null`/`undefined`.
- `property?: K | string | number | null` — The property name or index (key) of the element whose value is required, or `null` to return the fallback.
- `defaultValue?: D` — A fallback value returned if the property is not found.

**Returns:**
`ElementResolved<E>[K] | D` — The value of the requested property or the `defaultValue`.

```typescript
import { getElementItem } from '@dxtmisha/functional-basic'

const input = document.createElement('input')
input.type = 'text'
input.id = 'my-input'

// Getting the ID
const elementId = getElementItem(input, 'id')
console.log(elementId) // 'my-input'

// If the property is missing and we provide a fallback
const testValue = getElementItem('.non-existent', 'id', 'fallback-id')
console.log(testValue) // 'fallback-id'
```
