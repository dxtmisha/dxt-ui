# `getElementItem`

Возвращает значение определенного свойства из HTML-элемента (например, `id`, `className`, пользовательское свойство, если оно определено как ключ объекта типа элемента). При передаче объекта `window` утилита через `getElement` разрешает его в `document.body` в DOM-окружении. Если элемент не найден или у него нет указанного свойства, возвращает `defaultValue` (которое по умолчанию равно `undefined`).

**Параметры:**
- `element?: ElementOrString<E> | null` — Строка селектора, готовый DOM-элемент, `window` (разрешается в `document.body`) или `null`/`undefined`.
- `property?: K | string | number` — Имя или индекс свойства элемента (ключ), значение которого требуется получить.
- `defaultValue?: D` — Значение по умолчанию, возвращаемое, если свойство не найдено.

**Возвращает:**
`ElementResolved<E>[K] | D` — Значение запрашиваемого свойства или `defaultValue`.

```typescript
import { getElementItem } from '@dxtmisha/functional-basic'

const input = document.createElement('input')
input.type = 'text'
input.id = 'my-input'

// Получение ID
const elementId = getElementItem(input, 'id') 
console.log(elementId) // 'my-input'

// Если свойство отсутствует и мы передаем fallback
const testValue = getElementItem('.non-existent', 'id', 'fallback-id')
console.log(testValue) // 'fallback-id'
```
