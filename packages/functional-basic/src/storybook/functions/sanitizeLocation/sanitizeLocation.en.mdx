# `sanitizeLocation`

Validates and trims an external locale code string. It ensures URL safety and structural compatibility with locale tags by stripping surrounding whitespace, verifying maximum length (`64` characters), and validating structural subtags separated by hyphens (`-`) or underscores (`_`) while preserving original casing and separators.

**Parameters:**
- `code?: unknown` — Candidate locale code to validate.

**Returns:**
`string | undefined` — Validated trimmed locale code (e.g., `'en-US'`, `'ru-BY_BY'`, `'VN'`) or `undefined` if the input is invalid or unsafe.

## Examples

<Source
  language='typescript'
  code={`
import { sanitizeLocation } from '@dxtmisha/functional-basic'

// 1. Trimming whitespace and preserving casing/separators
sanitizeLocation('  en-US  ')  // 'en-US'
sanitizeLocation('en_US')      // 'en_US'
sanitizeLocation('ru-BY_BY')   // 'ru-BY_BY'
sanitizeLocation('VN')         // 'VN'

// 2. Rejecting dangerous or non-locale characters
sanitizeLocation('<script>alert(1)</script>') // undefined
sanitizeLocation('../en')                     // undefined
sanitizeLocation('en;drop table')             // undefined

// 3. Rejecting non-string or structurally invalid values
sanitizeLocation(undefined)   // undefined
sanitizeLocation(null)        // undefined
sanitizeLocation('12-34')     // undefined
  `}
/>
