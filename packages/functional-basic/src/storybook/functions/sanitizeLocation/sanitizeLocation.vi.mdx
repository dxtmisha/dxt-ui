# `sanitizeLocation`

Xác thực và làm sạch chuỗi mã vị trí/ngôn ngữ bên ngoài. Hàm đảm bảo tính an toàn cho URL và cấu trúc hợp lệ của thẻ định danh bằng cách loại bỏ khoảng trắng ở hai đầu, kiểm tra độ dài tối đa (`64` ký tự) và kiểm tra cấu trúc thẻ con được phân tách bằng dấu gạch nối (`-`) hoặc gạch dưới (`_`), đồng thời giữ nguyên chữ hoa/thường và dấu phân cách gốc.

**Tham số:**
- `code?: unknown` — Mã vị trí/ngôn ngữ cần kiểm tra.

**Trả về:**
`string | undefined` — Mã vị trí hợp lệ đã cắt khoảng trắng (ví dụ: `'en-US'`, `'ru-BY_BY'`, `'VN'`) hoặc `undefined` nếu giá trị không hợp lệ hoặc không an toàn.

## Ví dụ

<Source
  language='typescript'
  code={`
import { sanitizeLocation } from '@dxtmisha/functional-basic'

// 1. Loại bỏ khoảng trắng và giữ nguyên chữ hoa/thường cùng dấu phân cách
sanitizeLocation('  en-US  ')  // 'en-US'
sanitizeLocation('en_US')      // 'en_US'
sanitizeLocation('ru-BY_BY')   // 'ru-BY_BY'
sanitizeLocation('VN')         // 'VN'

// 2. Loại bỏ các chuỗi nguy hiểm hoặc ký tự không hợp lệ
sanitizeLocation('<script>alert(1)</script>') // undefined
sanitizeLocation('../en')                     // undefined
sanitizeLocation('en;drop table')             // undefined

// 3. Loại bỏ các giá trị không phải chuỗi hoặc cấu trúc sai
sanitizeLocation(undefined)   // undefined
sanitizeLocation(null)        // undefined
sanitizeLocation('12-34')     // undefined
  `}
/>
