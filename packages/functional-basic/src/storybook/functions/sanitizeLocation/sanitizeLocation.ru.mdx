# `sanitizeLocation`

Валидирует и очищает внешнюю строку кода локали. Обеспечивает безопасность для URL и структурную корректность тегов локали: удаляет крайние пробелы, проверяет максимальную длину (`64` символа) и структуру субтегов с разделителями `-` или `_`, сохраняя исходный регистр и разделители без изменений.

**Параметры:**
- `code?: unknown` — Проверяемый код локали.

**Возвращает:**
`string | undefined` — Валидный очищенный код локали (например, `'en-US'`, `'ru-BY_BY'`, `'VN'`) или `undefined`, если значение некорректно или небезопасно.

## Примеры

<Source
  language='typescript'
  code={`
import { sanitizeLocation } from '@dxtmisha/functional-basic'

// 1. Удаление пробелов и сохранение исходного регистра/разделителей
sanitizeLocation('  en-US  ')  // 'en-US'
sanitizeLocation('en_US')      // 'en_US'
sanitizeLocation('ru-BY_BY')   // 'ru-BY_BY'
sanitizeLocation('VN')         // 'VN'

// 2. Отклонение опасных строк и некорректных символов
sanitizeLocation('<script>alert(1)</script>') // undefined
sanitizeLocation('../en')                     // undefined
sanitizeLocation('en;drop table')             // undefined

// 3. Отклонение нестроковых или структурно невалидных значений
sanitizeLocation(undefined)   // undefined
sanitizeLocation(null)        // undefined
sanitizeLocation('12-34')     // undefined
  `}
/>
