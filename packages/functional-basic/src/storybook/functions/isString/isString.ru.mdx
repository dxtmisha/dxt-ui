# `isString`

Проверяет, является ли переданное значение строкой (`string`).

Опирается на стандартную проверку `typeof value === 'string'`, гарантируя, что значение относится к строковому примитиву, и отфильтровывает числа, булевы значения, объекты, массивы, `null` и `undefined`.

**Параметры:**
- `value: T` — Входное значение для проверки.

**Возвращает:**
`value is Extract<T, string>` (`boolean`) — Возвращает `true`, если `value` является строкой, иначе `false`. Выступает в качестве защитника типа (type guard) в TypeScript, сужая `T` до `Extract<T, string>`.

```typescript
import { isString } from '@dxtmisha/functional-basic'

console.log(isString('Привет, мир!')) // true
console.log(isString('')) // true (пустая строка — это тоже строка)

// Отсеивание других типов
console.log(isString(123)) // false
console.log(isString(null)) // false
console.log(isString({})) // false
```
