# `escapeExp`

A utility that escapes all special regular expression characters in a string (`.` `*` `+` `?` `^` `$` `{` `}` `(` `)` `|` `[` `]` `\` `/` `-`), so it can be safely used inside a `RegExp` pattern or character class (`[...]`).

Useful when a search term, query, or token comes from user input or an external source and may contain characters that have special meaning in regular expressions.

### Key Features:
- **Comprehensive 16-Metacharacter Escaping**: Escapes all standard regex syntax characters (`.` `*` `+` `?` `^` `$` `{}` `()` `|` `[]` `\`) as well as forward slash (`/`) and hyphen (`-`).
- **Character Class Safety (`[...]`)**: Escapes the hyphen (`-`) as `\-`, preventing accidental character range expansion (e.g. `[0-9]`) or `SyntaxError: Range out of order in character class` when interpolating arbitrary strings into brackets (e.g. `[z-a]`).
- **Safe Type Coercion**: Accepts strings, numbers (including `0` and negative values), `null`, and `undefined`, converting them safely without throwing exceptions.
- **ReDoS Safe**: Operates with deterministic $O(N)$ linear complexity without nested quantifiers or catastrophic backtracking.
- **Isomorphic & SSR Safe**: Pure function with zero dependencies on browser globals (`window` or `document`).

**Parameters:**
- `value?: string | number | null` — The string or number to escape.

**Returns:**
`string` — A string with all special regex characters escaped, safe to use inside a `RegExp`. Returns an empty string `''` if `null` or `undefined` is provided.

```typescript
import { escapeExp } from '@dxtmisha/functional-basic'

// 1. Escaping special regex characters
console.log(escapeExp('user.name[0]')) // 'user\\.name\\[0\\]'
console.log(escapeExp('price $10.00')) // 'price \\$10\\.00'
console.log(escapeExp('C++ & C#'))     // 'C\\+\\+ & C#'
console.log(escapeExp('path/to/*.log')) // 'path\\/to\\/\\*\\.log'

// 2. Safe compilation into RegExp
const userInput = '[VIP] (Special) *promo*'
const regex = new RegExp(`^${escapeExp(userInput)}$`, 'i')
regex.test('[VIP] (Special) *promo*') // true
regex.test('VIP Special promo')       // false

// 3. Character class safety ([...] context)
// Hyphen escaping prevents syntax errors on reversed ranges
const reversedRange = 'z-a'
const safeBracketRegex = new RegExp(`[${escapeExp(reversedRange)}]`)
safeBracketRegex.test('z') // true
safeBracketRegex.test('-') // true
safeBracketRegex.test('a') // true

// 4. Safe handling of numbers and nullish values
escapeExp(0)         // '0'
escapeExp(12345)     // '12345'
escapeExp(-42)       // '\\-42'
escapeExp(null)      // ''
escapeExp(undefined) // ''
```
