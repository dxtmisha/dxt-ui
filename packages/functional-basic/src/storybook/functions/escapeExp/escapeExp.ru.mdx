# `escapeExp`

Утилита, экранирующая все специальные символы регулярных выражений в строке (`.` `*` `+` `?` `^` `$` `{` `}` `(` `)` `|` `[` `]` `\` `/` `-`), чтобы её можно было безопасно использовать внутри `RegExp` (как в основном теле шаблона, так и внутри символьных классов `[...]`).

Используется, когда поисковый запрос, токен или строка поступает от пользователя или из внешнего источника и может содержать символы, имеющие специальное синтаксическое значение в регулярных выражениях.

### Ключевые возможности:
- **Полное экранирование 16 метасимволов**: Экранирует все синтаксические метасимволы (`.` `*` `+` `?` `^` `$` `{}` `()` `|` `[]` `\`), а также прямой слэш (`/`) и дефис (`-`).
- **Безопасность внутри символьных классов (`[...]`)**: Экранирует дефис как `\-`, предотвращая непреднамеренное создание диапазонов (например, `[0-9]`) или падение с фатальной ошибкой `SyntaxError: Range out of order in character class` при подстановке строк с обратным порядком символов (например, `[z-a]`).
- **Безопасная обработка типов**: Принимает строки, числа (включая `0` и отрицательные значения), `null` и `undefined`, корректно преобразуя их без выброса исключений.
- **Защита от ReDoS**: Работает с гарантированной линейной сложностью $O(N)$ без вложенных квантификаторов и катастрофического отката (backtracking).
- **Изоморфность и SSR**: Чистая функция без побочных эффектов, не зависящая от глобальных объектов браузера (`window` или `document`).

**Параметры:**
- `value?: string | number | null` — Строка или число для экранирования.

**Возвращает:**
`string` — Строка с экранированными специальными символами, безопасная для использования в `RegExp`. Возвращает пустую строку `''`, если передано `null` или `undefined`.

```typescript
import { escapeExp } from '@dxtmisha/functional-basic'

// 1. Экранирование специальных символов регулярных выражений
console.log(escapeExp('user.name[0]')) // 'user\\.name\\[0\\]'
console.log(escapeExp('price $10.00')) // 'price \\$10\\.00'
console.log(escapeExp('C++ & C#'))     // 'C\\+\\+ & C#'
console.log(escapeExp('path/to/*.log')) // 'path\\/to\\/\\*\\.log'

// 2. Безопасное использование в конструкторе RegExp
const userInput = '[VIP] (Special) *promo*'
const regex = new RegExp(`^${escapeExp(userInput)}$`, 'i')
regex.test('[VIP] (Special) *promo*') // true
regex.test('VIP Special promo')       // false

// 3. Безопасность в контексте символьных классов ([...])
// Экранирование дефиса защищает от Range out of order
const reversedRange = 'z-a'
const safeBracketRegex = new RegExp(`[${escapeExp(reversedRange)}]`)
safeBracketRegex.test('z') // true
safeBracketRegex.test('-') // true
safeBracketRegex.test('a') // true

// 4. Безопасная обработка чисел и nullish-значений
escapeExp(0)         // '0'
escapeExp(12345)     // '12345'
escapeExp(-42)       // '\\-42'
escapeExp(null)      // ''
escapeExp(undefined) // ''
```
