# `isInput`

Checks whether an `HTMLElement` is an input field (`input`, `textarea`, `select`) or editable content. An explicit `contenteditable="false"` does not make an ordinary element editable; empty or `"true"` attributes are supported, as is the browser's `isContentEditable` state.

Returns `false` in SSR and for arbitrary values, non-HTML nodes, or non-editable HTML elements. By default, truthy `disabled` or `readOnly` properties exclude the element. Passing `true` as the second argument bypasses only these property checks; it does not make a non-input element qualify.

**Parameters:**
- `element?: unknown` — the element or value to check.
- `includeDisabled?: boolean` — (Optional) if `true`, does not check `readOnly` and `disabled` properties (returns `true` even for disabled or readonly input elements).

**Returns:**
`boolean` (`element is HTMLElement`) — `true` if the element is an input field or editable, otherwise `false`. Acts as a TypeScript type guard narrowing `element` to `HTMLElement`.

```typescript
import { isInput } from '@dxtmisha/functional-basic'

const input = document.createElement('input')
isInput(input) // true

const div = document.createElement('div')
isInput(div) // false
```
