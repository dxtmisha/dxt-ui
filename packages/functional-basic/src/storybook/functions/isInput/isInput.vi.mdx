# `isInput`

Kiểm tra xem một `HTMLElement` có phải là trường nhập liệu (`input`, `textarea`, `select`) hoặc nội dung có thể chỉnh sửa hay không. `contenteditable="false"` không làm phần tử thường trở nên có thể chỉnh sửa; hàm hỗ trợ thuộc tính rỗng, giá trị `"true"` và trạng thái `isContentEditable` của trình duyệt.

Trả về `false` khi SSR, với giá trị bất kỳ, nút không phải HTML hoặc phần tử HTML không thể chỉnh sửa. Theo mặc định, thuộc tính `disabled` hoặc `readOnly` có giá trị truthy sẽ loại phần tử. Truyền `true` cho đối số thứ hai chỉ bỏ qua các kiểm tra thuộc tính này, không biến phần tử thường thành trường nhập liệu.

**Tham số:**
- `element?: unknown` — phần tử hoặc giá trị cần kiểm tra.
- `includeDisabled?: boolean` — (Tùy chọn) nếu `true`, không kiểm tra các thuộc tính `readOnly` và `disabled` (trả về `true` ngay cả đối với các trường nhập liệu bị vô hiệu hóa hoặc chỉ đọc).

**Trả về:**
`boolean` (`element is HTMLElement`) — `true` nếu phần tử là trường nhập liệu hoặc có thể chỉnh sửa, ngược lại là `false`. Đóng vai trò là type guard trong TypeScript giúp thu hẹp kiểu của `element` về `HTMLElement`.

```typescript
import { isInput } from '@dxtmisha/functional-basic'

const input = document.createElement('input')
isInput(input) // true

const div = document.createElement('div')
isInput(div) // false
```
