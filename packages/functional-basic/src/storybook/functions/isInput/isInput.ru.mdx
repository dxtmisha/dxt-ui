# `isInput`

Проверяет, является ли `HTMLElement` полем ввода (`input`, `textarea`, `select`) или редактируемым содержимым. Явный `contenteditable="false"` не делает обычный элемент редактируемым; поддерживаются пустой атрибут, значение `"true"` и нативное состояние `isContentEditable`.

Возвращает `false` при SSR, для произвольных значений, не-HTML-узлов и нередактируемых HTML-элементов. По умолчанию истинные свойства `disabled` или `readOnly` исключают элемент. Значение `true` во втором аргументе отключает только эти проверки свойств и не превращает обычный элемент в поле ввода.

**Параметры:**
- `element?: unknown` — проверяемый элемент или произвольное значение.
- `includeDisabled?: boolean` — (Необязательно) если `true`, не проверять свойства `readOnly` и `disabled` (вернёт `true` даже для заблокированных полей ввода).

**Возвращает:**
`boolean` (`element is HTMLElement`) — `true`, если элемент является полем ввода или редактируемым, иначе `false`. Выступает в качестве защитника типа (type guard) TypeScript, сужая `element` до `HTMLElement`.

```typescript
import { isInput } from '@dxtmisha/functional-basic'

const input = document.createElement('input')
isInput(input) // true

const div = document.createElement('div')
isInput(div) // false
```
