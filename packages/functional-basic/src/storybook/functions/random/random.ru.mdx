# `random`

Генерирует и возвращает случайное целое число в заданном диапазоне от `min` до `max` (включительно).

**Параметры:**
- `min: number` — Наименьшее возможное значение.
- `max: number` — Наибольшее возможное значение.

**Возвращает:**
`number` — Случайное целое число в диапазоне `[min, max]`.

```typescript
import { random } from '@dxtmisha/functional-basic'

// Случайное целое число от 1 до 10 (включительно)
console.log(random(1, 10)) // например, 7

// Отрицательный диапазон или диапазон через ноль
console.log(random(-5, 5)) // например, -2

// Диапазон с одинаковыми min и max
console.log(random(42, 42)) // 42
```
