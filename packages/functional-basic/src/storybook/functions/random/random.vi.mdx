# `random`

Tạo và trả về một số nguyên ngẫu nhiên trong phạm vi được chỉ định từ `min` đến `max` (bao gồm cả hai giá trị).

**Tham số:**
- `min: number` — Giá trị nhỏ nhất có thể.
- `max: number` — Giá trị lớn nhất có thể.

**Trả về:**
`number` — Một số nguyên ngẫu nhiên trong phạm vi `[min, max]`.

```typescript
import { random } from '@dxtmisha/functional-basic'

// Số nguyên ngẫu nhiên từ 1 đến 10 (bao gồm cả hai giá trị)
console.log(random(1, 10)) // ví dụ: 7

// Phạm vi số âm hoặc qua số 0
console.log(random(-5, 5)) // ví dụ: -2

// Phạm vi với min và max giống nhau
console.log(random(42, 42)) // 42
```
