# `replaceRecursive`

Thực hiện hợp nhất sâu (đệ quy) đối tượng đích với dữ liệu từ một đối tượng hoặc mảng thay thế. Khi bật tham số `isMerge` (mặc định là `true`), các mảng ở cùng khóa sẽ được nối lại và loại bỏ phần tử trùng lặp qua `uniqueArray`; ngược lại, mảng từ `replacement` sẽ ghi đè mảng ban đầu.

Tích hợp sẵn cơ chế bảo vệ chống **Prototype Pollution** thông qua `forOwn` (`isPrototypeKey`), tự động bỏ qua các khóa nguy hiểm (`__proto__`, `constructor`, `prototype`) trong quá trình duyệt.

> **Cảnh báo:** Phương thức này chỉ dành riêng cho việc xử lý các đối tượng và mảng thuần túy dạng JSON (chẳng hạn như dữ liệu nhận qua API hoặc tệp cấu hình); các thực thể lớp dựng sẵn (`Date`, `RegExp`, `Map`, `Set`) và hàm (function) không được hỗ trợ.

**Tham số:**
- `target?: ObjectItem<I> | null` — Đối tượng đích mà các phần tử sẽ được thay thế hoặc hợp nhất.
- `replacement?: ObjectOrArray<I> | readonly I[] | null` — Đối tượng hoặc mảng (bao gồm cả mảng chỉ đọc `readonly`) chứa các phần tử được trích xuất để thay thế.
- `isMerge?: boolean = true` — Cờ hợp nhất các mảng cùng tên không trùng lặp (mặc định là `true`). Nếu là `false`, các mảng từ `replacement` sẽ ghi đè hoàn toàn.
- `disableCopy?: boolean = false` — Vô hiệu hóa sao chép sâu `target` (được dùng nội bộ trong đệ quy để tránh sao chép lặp lại, hoặc dùng bên ngoài khi cập nhật trực tiếp một đối tượng tích lũy cục bộ).
- `<I = unknown>` — Kiểu giá trị của các phần tử.

**Trả về:**
`ObjectItem<I>` — Một đối tượng mới là kết quả hợp nhất mà không làm biến đổi `target` (hoặc chính tham chiếu `target` đã cập nhật nếu `disableCopy` là `true`). Nếu `target` không phải là đối tượng, trả về bản sao của `replacement` (nếu là đối tượng) hoặc `{}`.

```typescript
import { replaceRecursive } from '@dxtmisha/functional-basic'

const target = { a: [1, 2], b: { x: 1 } }
const source = { a: [2, 3], b: { y: 2 } }

console.log(replaceRecursive(target, source))
// { a: [1, 2, 3], b: { x: 1, y: 2 } }

console.log(replaceRecursive(target, source, false))
// { a: [2, 3], b: { x: 1, y: 2 } }

// Hợp nhất trực tiếp vào bộ tích lũy cục bộ mà không sao chép target
const accumulator: Record<string, unknown> = { count: 1 }
replaceRecursive(accumulator, { active: true }, true, true)
// accumulator -> { count: 1, active: true }
```
