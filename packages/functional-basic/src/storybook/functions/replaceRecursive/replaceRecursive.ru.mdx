# `replaceRecursive`

Выполняет глубокое (рекурсивное) слияние целевого объекта с данными из объекта или массива замены. При включенном параметре `isMerge` (по умолчанию `true`) массивы по совпадающим ключам объединяются с удалением дубликатов через `uniqueArray`, в противном случае массивы из `replacement` перезаписывают исходные.

Включает встроенную защиту от **Prototype Pollution** через `isPrototypeKey`, автоматически пропуская опасные ключи (`__proto__`, `constructor`, `prototype`) при обходе.

**Параметры:**
- `target: ObjectItem<I>` — Целевой объект, элементы которого будут заменены или объединены.
- `replacement?: ObjectOrArray<I>` — Объект или массив, из которого будут браться элементы для замены.
- `isMerge?: boolean = true` — Флаг слияния одноименных массивов (по умолчанию `true`). При `false` массивы из `replacement` полностью перезаписывают исходные.

**Возвращает:**
`ObjectItem<I>` — Новый объединенный объект без мутации исходного `target`. Если `target` не является объектом, возвращает копию `replacement` (если это объект) или `{}`.

```typescript
import { replaceRecursive } from '@dxtmisha/functional-basic'

const target = { a: [1, 2], b: { x: 1 } }
const source = { a: [2, 3], b: { y: 2 } }

console.log(replaceRecursive(target, source)) 
// { a: [1, 2, 3], b: { x: 1, y: 2 } }

console.log(replaceRecursive(target, source, false)) 
// { a: [2, 3], b: { x: 1, y: 2 } }
```
