# `getExactSearchExp`

Утилита, создающая регистронезависимое регулярное выражение `RegExp` для поиска точного совпадения фразы (без якорей `^` и `$`).

В отличие от `getSearchExp`, эта функция ищет фразу целиком как непрерывную подстроку (с экранированием спецсимволов), не разделяя её на отдельные слова.

**Параметры:**
- `search: string` — Строка поиска для точного сопоставления фразы.

**Возвращает:**
`RegExp` — Регулярное выражение с флагом `i` (без учёта регистра) и шаблоном `(:value)`.

```typescript
import { getExactSearchExp } from '@dxtmisha/functional-basic'

const regex = getExactSearchExp('hello world')

regex.test('say hello world!')      // true — содержит точную фразу
regex.test('HELLO WORLD')           // true — без учёта регистра
regex.test('hello beautiful world') // false — слова разделены
```
