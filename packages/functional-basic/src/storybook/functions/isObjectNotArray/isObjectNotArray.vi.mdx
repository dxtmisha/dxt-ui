# `isObjectNotArray`

Kiểm tra xem giá trị được cung cấp có phải là một đối tượng (Record) và **không phải là mảng** hay không.

Vì tiện ích cơ bản `isObject` trả về `true` cho cả mảng (theo đặc tả `typeof` của JavaScript), `isObjectNotArray` kết hợp `isObject(value)` với `!isArray(value)` để loại trừ hoàn toàn các mảng.

**Tham số:**
- `value: T` — Giá trị cần kiểm tra.

**Trả về:**
`value is Exclude<Extract<T, ObjectItem>, unknown[] | undefined | null>` (`boolean`) — Chỉ trả về `true` đối với các đối tượng khác `null` và không phải mảng (như `{ key: 'value' }`), và trả về `false` đối với mảng `[]`, `null`, `undefined`, hàm và các kiểu nguyên thủy. Đóng vai trò là bộ bảo vệ kiểu (type guard) trong TypeScript, thu hẹp `T` thành `ObjectItem` đồng thời loại trừ mảng, `undefined` và `null`.

```typescript
import { isObjectNotArray } from '@dxtmisha/functional-basic'

// Đối tượng hợp lệ
console.log(isObjectNotArray({ id: 1, name: 'Test' })) // true

// Các giá trị bị loại trừ
console.log(isObjectNotArray([1, 2, 3])) // false (mảng bị loại trừ)
console.log(isObjectNotArray(null)) // false
console.log(isObjectNotArray('string')) // false
```
