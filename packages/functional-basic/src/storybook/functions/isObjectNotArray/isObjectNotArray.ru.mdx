# `isObjectNotArray`

Высокопроизводительная утилита-защитник типа (type guard), определяющая, является ли переданное значение объектом, строго исключая при этом массивы JavaScript.

## Ключевые возможности

- **Строгое исключение массивов** — Комбинирует `isObject(value)` с `!isArray(value)`, устраняя специфику JavaScript, при которой оператор `typeof []` возвращает `'object'`.
- **Широкая поддержка объектов** — Точно распознает простые объекты (`{}`), словари без прототипа (`Object.create(null)`), экземпляры классов и встроенные объекты (`Date`, `RegExp`, `Map`, `Set`, `Error`).
- **Обработка массивоподобных структур и TypedArray** — Корректно определяет массивоподобные объекты (такие как `arguments` или `{ length: 2 }`) и типизированные массивы (`Uint8Array`) как объекты, поскольку они не являются экземплярами нативного `Array`.
- **Корректность при работе с Proxy** — В соответствии со спецификацией ECMAScript Proxy возвращает `true` для `Proxy` над объектами и `false` для `Proxy` над массивами.
- **Сужение типов в TypeScript** — Служит предикатом типа `value is Exclude<Extract<T, ObjectItem>, unknown[] | undefined | null>`, гарантируя исключение типов массивов, `null` и `undefined`.
- **Безопасность к ложным и примитивным значениям** — Возвращает `false` для `null`, `undefined`, `0`, `false`, `NaN`, пустых строк, чисел, булевых значений, символов и функций.
- **Изоморфность и SSR** — Чистая функция без побочных эффектов, не зависящая от окружения браузера или DOM.

**Параметры:**
- `value: T` — Проверяемое значение.

**Возвращает:**
`value is Exclude<Extract<T, ObjectItem>, unknown[] | undefined | null>` (`boolean`) — Возвращает `true` исключительно для не-null объектов, не являющихся массивами; иначе `false`. Выступает в роли TypeScript type guard.

## Примеры

<Source
  language='typescript'
  code={`
import { isObjectNotArray } from '@dxtmisha/functional-basic'

// 1. Простые объекты и словари без прототипа
isObjectNotArray({ id: 1, name: 'Алексей' }) // true
isObjectNotArray(Object.create(null))        // true

// 2. Экземпляры классов и встроенные объекты
class User {}
isObjectNotArray(new User())                 // true
isObjectNotArray(new Date())                 // true
isObjectNotArray(new Map())                  // true
isObjectNotArray(/regex/)                    // true

// 3. Строгое исключение массивов (массивы возвращают false)
isObjectNotArray([])                         // false
isObjectNotArray([1, 2, 3])                  // false
isObjectNotArray(new Array(5))               // false

// 4. Примитивы, nullish и ложные значения
isObjectNotArray(null)                       // false
isObjectNotArray(undefined)                  // false
isObjectNotArray(0)                          // false
isObjectNotArray(false)                      // false
isObjectNotArray('')                         // false
isObjectNotArray('строка')                   // false
isObjectNotArray(123)                        // false

// 5. Функции исключаются
isObjectNotArray(() => {})                   // false
isObjectNotArray(function named() {})        // false
isObjectNotArray(User)                       // false

// 6. Сужение типов в TypeScript (Type Guard)
function processItem(item: string | number[] | { title: string }) {
  if (isObjectNotArray(item)) {
    // TypeScript сужает item до { title: string }
    console.log(item.title)
  }
}
  `}
/>
