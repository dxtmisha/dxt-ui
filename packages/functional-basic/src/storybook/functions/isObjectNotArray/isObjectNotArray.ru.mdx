# `isObjectNotArray`

Проверяет, является ли переданное значение объектом (Record) и при этом **не является массивом**.

Поскольку базовая утилита `isObject` возвращает `true` даже для массивов (согласно специфике `typeof` в JavaScript), `isObjectNotArray` комбинирует проверку `isObject(value)` с `!isArray(value)` для строгого исключения массивов.

**Параметры:**
- `value: T` — Проверяемое значение.

**Возвращает:**
`value is Exclude<Extract<T, ObjectItem>, unknown[] | undefined | null>` (`boolean`) — Возвращает `true` исключительно для не-null объектов, не являющихся массивами (например, `{ key: 'value' }`), и `false` для массивов `[]`, `null`, `undefined`, функций и всех примитивных типов данных. Выступает в качестве защитника типа (type guard) в TypeScript, сужая `T` до `ObjectItem` и исключая массивы, `undefined` и `null`.

```typescript
import { isObjectNotArray } from '@dxtmisha/functional-basic'

// Успешная валидация объекта
console.log(isObjectNotArray({ id: 1, name: 'Test' })) // true

// Значения, которые не проходят проверку
console.log(isObjectNotArray([1, 2, 3])) // false (массивы исключаются)
console.log(isObjectNotArray(null)) // false
console.log(isObjectNotArray('string')) // false
```
