# `isObjectNotArray`

Checks if the provided value is a plain object (Record) and **not an array**.

Since the base `isObject` utility returns `true` for arrays as well (in accordance with JavaScript's `typeof` behavior), `isObjectNotArray` combines `isObject(value)` with `!isArray(value)` to strictly exclude arrays.

**Parameters:**
- `value: T` — The value to check.

**Returns:**
`value is Exclude<Extract<T, ObjectItem>, unknown[] | undefined | null>` (`boolean`) — Returns `true` only for non-null, non-array objects (such as `{ key: 'value' }`), and `false` for arrays `[]`, `null`, `undefined`, functions, and primitives. Acts as a TypeScript type guard narrowing `T` to `ObjectItem` while excluding arrays, `undefined`, and `null`.

```typescript
import { isObjectNotArray } from '@dxtmisha/functional-basic'

// Valid object
console.log(isObjectNotArray({ id: 1, name: 'Test' })) // true

// Filtered out values
console.log(isObjectNotArray([1, 2, 3])) // false (arrays are excluded)
console.log(isObjectNotArray(null)) // false
console.log(isObjectNotArray('string')) // false
```
