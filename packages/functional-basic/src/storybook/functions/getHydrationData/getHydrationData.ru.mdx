# `getHydrationData`

Утилита для извлечения и парсинга JSON-данных из тега `<script>` в DOM по его `id` (обычно сгенерированного на сервере с помощью `getElementSafeScript`).

В браузерном окружении (`isDomRuntime()`) функция находит элемент `<script>` по `id`, парсит его `textContent` как JSON и опционально удаляет тег `<script>` из DOM (по умолчанию `remove = true`). Если элемент не найден, не является тегом `<script>`, функция вызвана в SSR-окружении или произошла ошибка парсинга JSON (которая регистрируется через `ErrorCenter` с `group: 'hydration'`, `code: 'error'`), функция безопасно возвращает `defaultValue`.

**Параметры:**
- `id: string` — Уникальный идентификатор (ID) тега скрипта.
- `defaultValue: T` — Значение по умолчанию, если тег скрипта не найден или данные невалидны.
- `remove?: boolean` — Удалять ли элемент скрипта из DOM после чтения (по умолчанию `true`).

**Возвращает:**
`T` — Распарсенные данные из тега скрипта или `defaultValue`.

```typescript
import { getHydrationData } from '@dxtmisha/functional-basic'

// В DOM присутствует:
// <script id="hydration-data" type="application/json">{"user":"Misha"}</script>

const data = getHydrationData('hydration-data', { user: 'Guest' })
console.log(data) // { user: 'Misha' }
// Тег <script id="hydration-data"> автоматически удаляется из DOM
```
