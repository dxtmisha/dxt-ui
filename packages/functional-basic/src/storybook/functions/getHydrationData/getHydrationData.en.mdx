# `getHydrationData`

Retrieves, deserializes, and validates JSON state payloads embedded in DOM `<script type="application/json">` elements, providing seamless state hydration from SSR to client-side runtimes.

## Key Features

- **SSR-Safe & Isomorphic** — Guarded by `isDomRuntime()`, ensuring safe execution during Server-Side Rendering (Node.js, Nitro, Bun, Cloudflare Workers) by immediately returning `defaultValue` without touching undefined browser globals.
- **Strict DOM Tag Verification** — Confirms that the target DOM element is genuinely a `<script>` tag (`script.tagName === 'SCRIPT'`), ignoring spoofed inputs or arbitrary DOM nodes with conflicting IDs.
- **Automatic Lifecycle DOM Cleanup** — By default (`remove = true`), safely removes the `<script>` element from the DOM inside a `finally` block once read, freeing memory and eliminating stale state retention.
- **Centralized Error Dispatch** — Any JSON parsing syntax errors or empty script content issues are intercepted and reported directly to `ErrorCenter` under `group: 'hydration'`, `code: 'error'`, avoiding uncaught runtime crashes.
- **Support for Numeric & String IDs** — Accepts both `string` and `number` identifiers, maintaining symmetry with server-side generation via `getElementSafeScript`.
- **Fail-Safe Fallback Contract** — Always returns a predictable value of type `T` (either the parsed payload or `defaultValue`), never returning unexpected `undefined`.

**Parameters:**
- `id: string | number` — The unique ID attribute of the target `<script>` element in the DOM.
- `defaultValue: T` — The fallback value returned when the script is missing, not a script tag, executed in SSR, or fails JSON parsing.
- `remove: boolean = true` — Whether to remove the `<script>` element from the DOM after reading.

**Returns:**
`T` — The deserialized state object, or `defaultValue`.

## Examples

<Source
  language='typescript'
  code={`
import { getHydrationData, getElementSafeScript } from '@dxtmisha/functional-basic'

// 1. Basic client-side hydration
// Suppose the server embedded:
// <script id="app-config" type="application/json">{"theme":"dark","version":2}</script>

interface AppConfig {
  theme: string
  version: number
}

const config = getHydrationData<AppConfig>('app-config', {
  theme: 'light',
  version: 1
})
console.log(config.theme) // 'dark'
// The <script id="app-config"> element is now removed from the DOM

// 2. Preserving the script tag in the DOM
const preserved = getHydrationData('static-data', { active: false }, false)
console.log(preserved)
// The <script id="static-data"> remains in the DOM because remove = false

// 3. Fallback on missing or invalid script tag
const fallback = getHydrationData('missing-id', { status: 'idle' })
console.log(fallback) // { status: 'idle' }

// 4. Safe round-trip with getElementSafeScript
document.body.innerHTML = getElementSafeScript('sync-token', { token: 'xyz123' })
const credentials = getHydrationData('sync-token', { token: '' })
console.log(credentials.token) // 'xyz123'
  `}
/>
