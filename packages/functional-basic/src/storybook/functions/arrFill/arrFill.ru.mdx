# `arrFill`

Высокопроизводительная утилита для создания и возврата плотного массива заданного размера, заполненного одинаковыми значениями или ссылками.

## Ключевые возможности

- **Быстрое нативное выделение $O(n)$** — Использует встроенный движковый метод `Array(count).fill(value)` для мгновенного непрерывного выделения памяти и наполнения массива на уровне ядра JS.
- **Гарантия плотного массива (Dense Array)** — В отличие от вызова `new Array(count)`, создающего разреженный массив с пустыми слотами («дырами»), которые пропускаются при обходе, `arrFill` формирует плотный массив, где каждый элемент гарантированно обрабатывается методами `.map()`, `.filter()`, `.forEach()` и циклом `for...of`.
- **Семантика совместного использования ссылок (Reference Sharing)** — При передаче сложных типов (объектов, массивов, функций) каждый слот ссылается на один и тот же исходный экземпляр, что минимизирует расход памяти при создании скелетонов, заглушек и неизменяемых списков по умолчанию.
- **Строгая типизация TypeScript** — Сохраняет исходный обобщенный тип `T`, возвращая строго типизированный массив `T[]` без расширения типов и необходимости явного приведения `as`.
- **Корректная обработка граничных условий** — Возвращает пустой массив `[]` при `count === 0`, а при передаче недопустимой длины (отрицательные числа, дроби, `NaN`, `Infinity`) строго следует спецификации ECMAScript и генерирует нативную ошибку `RangeError`.
- **Изоморфность и SSR** — Чистая функция без побочных эффектов, не зависящая от окружения браузера и полностью совместимая с серверным рендерингом (SSR/SSG).

**Параметры:**
- `value: T` — Значение или ссылка на объект, которым заполняется каждый элемент массива.
- `count: number` — Количество элементов в создаваемом массиве.

**Возвращает:**
`T[]` — Плотный массив длиной `count`, каждый элемент которого равен переданному значению.

## Примеры

<Source
  language='typescript'
  code={`
import { arrFill } from '@dxtmisha/functional-basic'

// 1. Примитивные значения (строки, числа, булевы значения)
const tags = arrFill('badge', 3)
console.log(tags) // ['badge', 'badge', 'badge']

const counters = arrFill(0, 4)
console.log(counters) // [0, 0, 0, 0]

const flags = arrFill(false, 2)
console.log(flags) // [false, false]

// 2. Создание заглушек для скелетонов загрузки
const skeletonItems = arrFill({ loading: true }, 5)
console.log(skeletonItems.length) // 5

// 3. Плотный массив и итерация
const denseArray = arrFill('item', 3)
const mapped = denseArray.map((item, index) => \`\${item}-\${index}\`)
console.log(mapped) // ['item-0', 'item-1', 'item-2']

// 4. Разделение ссылок на объекты
const initialConfig = { theme: 'dark' }
const configList = arrFill(initialConfig, 2)
console.log(configList[0] === configList[1]) // true (одна и та же ссылка)

// 5. Граничные значения
const emptyList = arrFill('none', 0)
console.log(emptyList) // []
  `}
/>
