# `getMouseClientX`

Trích xuất tọa độ X (vị trí ngang) của con trỏ (chuột hoặc cảm ứng) tương đối với vùng nhìn thấy của cửa sổ trình duyệt (viewport) từ đối tượng sự kiện.

Hàm này xử lý cả các sự kiện chuột tiêu chuẩn (`MouseEvent`) và các sự kiện chạm (`TouchEvent`), ưu tiên thuộc tính `clientX`. Nếu sự kiện không có `clientX`, hàm kiểm tra điểm chạm đầu tiên trong `targetTouches`, `touches` rồi `changedTouches`. Nhánh dự phòng `changedTouches` hỗ trợ sự kiện `touchend` khi không còn điểm chạm đang hoạt động. Sự kiện bị bỏ qua hoặc null trả về `0`.

**Tham số:**
- `event?: MouseEvent | TouchEvent | null` — Đối tượng sự kiện (`mousemove`, `touchmove`, `click`, v.v.).

**Trả về:**
`number` — Tọa độ X của con trỏ/điểm chạm. Nếu không tìm thấy, nó sẽ trả về `0`.

```typescript
import { getMouseClientX } from '@dxtmisha/functional-basic'

document.addEventListener('click', (event) => {
  const x = getMouseClientX(event)
  console.log(`Người dùng đã nhấp vào vị trí cách mép trái cửa sổ ${x}px`)
})
```
