# `splice`

Выполняет копирование и рекурсивное слияние собственных перечисляемых свойств из объекта замены в целевой объект. Поддерживает замену найденной по ключу или значению записи (`indexStart`) на месте с сохранением исходного порядка ключей и каскадного приоритета (свойства до точки `indexStart` перезаписываются свойствами из `replacement`, а свойства после `indexStart` накладываются поверх `replacement`, обладая наивысшим приоритетом).

Включает встроенную защиту от **Prototype Pollution** через `forOwn` (`isPrototypeKey`), автоматически блокируя небезопасные ключи (`__proto__`, `constructor`, `prototype`).

> **Внимание:** Этот метод предназначен исключительно для обработки простых JSON-подобных объектов (таких как данные, полученные через API или файлы конфигураций); экземпляры встроенных классов (`Date`, `RegExp`, `Map`, `Set`) и функции не поддерживаются.

**Параметры:**
- `array?: ObjectItem<I> | null` — Целевой объект.
- `replacement?: ObjectItem<I> | I | null` — Исходный объект со свойствами замены.
- `indexStart?: string | null` — Ключ или значение свойства, начиная с которого выполняется замена.
- `<I = unknown>` — Тип значения элементов.

**Возвращает:**
- `ObjectItem<I>` — Новый глубоко объединенный объект с примененными изменениями без мутации исходных структур.

```typescript
import { splice } from '@dxtmisha/functional-basic'

const target = { first: 1, middle: 2, last: 3 }
const replacement = { middleNew: 20 }

// Простое слияние без indexStart
console.log(splice(target, replacement))
// { first: 1, middle: 2, last: 3, middleNew: 20 }

// Замена записи на месте по ключу 'middle' с сохранением порядка полей
console.log(splice(target, replacement, 'middle'))
// { first: 1, middleNew: 20, last: 3 }

// Каскадный приоритет: свойства, объявленные после точки вставки, имеют приоритет над заменой
const base = {
  theme: 'light',
  anchor: '{link}',
  size: '14px' // Объявлено после точки anchor: наивысший приоритет
}
const injected = {
  theme: 'dark', // Перезаписывает base.theme (до anchor)
  color: 'blue',
  size: '12px' // Перекрывается base.size (после anchor)
}

console.log(splice(base, injected, 'anchor'))
// { theme: 'dark', color: 'blue', size: '14px' }
```
