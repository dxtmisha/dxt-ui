# `splice`

Выполняет копирование и рекурсивное слияние свойств из одного объекта в другой. Поддерживает замену свойств начиная с определенного ключа или значения элемента с сохранением порядка следования остальных полей.

**Параметры:**
- `array: ObjectItem<I>` — Целевой объект.
- `replacement?: ObjectItem<I> | I` — Исходный объект с новыми данными.
- `indexStart?: string` — Ключ или значение элемента, начиная с которого будет выполнена замена.

**Возвращает:**
`ObjectItem<I>` — Новый объект с примененными изменениями.

```typescript
import { splice } from '@dxtmisha/functional-basic'

const target = { first: 1, middle: 2, last: 3 }
const replacement = { middleNew: 20 }

// Простое слияние без indexStart
console.log(splice(target, replacement))
// { first: 1, middle: 2, last: 3, middleNew: 20 }

// Замена свойства по ключу с сохранением порядка остальных полей
console.log(splice(target, replacement, 'middle'))
// { first: 1, middleNew: 20, last: 3 }
```
