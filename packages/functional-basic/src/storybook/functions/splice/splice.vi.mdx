# `splice`

Sao chép và hợp nhất đệ quy các thuộc tính từ đối tượng này sang đối tượng khác. Hỗ trợ thay thế thuộc tính bắt đầu từ một khóa hoặc giá trị phần tử cụ thể trong khi vẫn duy trì thứ tự của các trường còn lại.

**Tham số:**
- `array: ObjectItem<I>` — Đối tượng đích.
- `replacement?: ObjectItem<I> | I` — Đối tượng nguồn chứa dữ liệu mới.
- `indexStart?: string` — Khóa hoặc giá trị phần tử bắt đầu thực hiện thay thế.

**Trả về:**
`ObjectItem<I>` — Đối tượng mới với các thay đổi đã được áp dụng.

```typescript
import { splice } from '@dxtmisha/functional-basic'

const target = { first: 1, middle: 2, last: 3 }
const replacement = { middleNew: 20 }

// Hợp nhất đơn giản khi không có indexStart
console.log(splice(target, replacement))
// { first: 1, middle: 2, last: 3, middleNew: 20 }

// Thay thế thuộc tính theo khóa trong khi vẫn giữ nguyên thứ tự các trường khác
console.log(splice(target, replacement, 'middle'))
// { first: 1, middleNew: 20, last: 3 }
```
