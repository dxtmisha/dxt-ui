# `eventStopPropagation`

Останавливает дальнейшее распространение события в DOM-дереве (всплытие / перехват), отменяет стандартное действие браузера по умолчанию и помечает событие как остановленное для `isEventStopped`.

Функция оборачивает вызовы `event.preventDefault()`, `event.stopPropagation()` и регистрирует объект события во внутреннем `WeakSet`, благодаря чему `isEventStopped(event)` возвращает `true` даже для неотменяемых событий.

Безопасно игнорирует `null` и `undefined`. Отмена действия подчиняется нативным правилам: не действует для неотменяемых событий и пассивных обработчиков. Остальные обработчики на том же элементе продолжают выполняться.

**Параметры:**
- `event?: Event | null` — Экземпляр события DOM, который необходимо остановить; пропущенные и nullish-значения игнорируются.

**Возвращает:**
`void`

```typescript
import { eventStopPropagation } from '@dxtmisha/functional-basic'

const link = document.createElement('a')
link.href = 'https://example.com'
link.onclick = (event) => {
  // Отменит переход по ссылке и остановит всплытие клика к родителям
  eventStopPropagation(event)
  console.log('Клик перехвачен!')
}
```
