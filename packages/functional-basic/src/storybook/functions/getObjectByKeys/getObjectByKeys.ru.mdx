# `getObjectByKeys`

Создает и возвращает новый объект, в который копируются только собственные свойства (`hasKey`) с указанными ключами из исходного объекта. Ключи прототипа (`__proto__`, `constructor`, `prototype`), отсутствующие свойства и свойства со значением `undefined` игнорируются при копировании.

**Параметры:**
- `data: T` — Исходный объект с данными (где `T extends Record<string, unknown>`).
- `keys: K[]` — Массив ключей, которые необходимо извлечь (где `K extends keyof T`).

**Возвращает:**
`Pick<T, K>` — Новый объект, содержащий только найденные собственные свойства со значениями, отличными от `undefined`.

```typescript
import { getObjectByKeys } from '@dxtmisha/functional-basic'

const user = {
  id: 1,
  name: 'Ivan',
  role: 'admin',
  age: undefined, // undefined пропускаются
  active: true
}

const result = getObjectByKeys(user, ['id', 'name', 'age'])
console.log(result) // { id: 1, name: 'Ivan' }
```
