# `hasKeys`

Утилита-предикат типа (type guard), проверяющая, содержит ли объект или функция хотя бы одно собственное перечисляемое строковое свойство. Символьные, неперечисляемые и унаследованные свойства не учитываются.

## Ключевые возможности

- **Ранний выход (Short-circuit)** — Прекращает итерацию при нахождении первого собственного перечисляемого строкового свойства, избегая создания промежуточного массива `Object.keys()`.
- **Только собственные свойства** — Проверяет свойства через `Object.hasOwn`, исключая унаследованные. Перечисляемое собственное свойство с именем `toString`, `valueOf` или `constructor` учитывается на общих основаниях.
- **Поддержка словарей без прототипа** — Корректно и безопасно работает с объектами `Object.create(null)`.
- **Безопасность для примитивов** — Возвращает `false` при передаче `null`, `undefined`, чисел, строк или других примитивов без выбрасывания исключений.
- **Сужение типов в TypeScript** — Выступает предикатом типа `object is T`, сужая тип `unknown` до непустого объекта.
- **Изоморфность для SSR** — Чистая функция без зависимостей от DOM и глобальных объектов браузера.

**Параметры:**
- `object: unknown` — Проверяемый объект или значение любого типа.

**Возвращает:**
`boolean` (`object is T`) — Возвращает `true`, если у объекта или функции есть хотя бы одно собственное перечисляемое строковое свойство, иначе `false`. Функция без пользовательских перечисляемых свойств и пустой массив возвращают `false`.

## Примеры

<Source
  language='typescript'
  code={`
import { hasKeys } from '@dxtmisha/functional-basic'

// 1. Базовые объекты
hasKeys({ name: 'Alice' }) // true
hasKeys({})                // false

// 2. Свойства с falsy-значениями
hasKeys({ count: 0 })      // true
hasKeys({ flag: false })   // true
hasKeys({ text: '' })      // true

// 3. Защита от свойств прототипа
hasKeys({})                // false (toString, valueOf не учитываются)

// 4. Безопасность примитивов и nullish-значений
hasKeys(null)              // false
hasKeys(undefined)         // false
hasKeys('hello')           // false
hasKeys(123)               // false
`}
/>
