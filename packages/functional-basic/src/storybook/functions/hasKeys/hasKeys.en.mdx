# `hasKeys`

A type guard utility that determines whether an object or function contains at least one own enumerable string-keyed property. Symbol keys, non-enumerable properties, and inherited properties are excluded.

## Key Features

- **Short-circuit Evaluation** — Terminates immediately upon detecting the first own enumerable string-keyed property, avoiding the intermediate array created by `Object.keys()`.
- **Own Properties Only** — Uses `Object.hasOwn` to ignore inherited properties. An enumerable own property named `toString`, `valueOf`, or `constructor` is counted normally.
- **Null-prototype Object Support** — Safely handles dictionary objects created via `Object.create(null)`.
- **Safe Handling of Primitives** — Safely returns `false` when receiving `null`, `undefined`, numbers, strings, or other primitives without throwing runtime errors.
- **TypeScript Type Narrowing** — Acts as a type guard predicate `object is T`, narrowing `unknown` to a populated object type.
- **SSR-Isomorphic** — Pure functional utility with zero dependencies on DOM or browser globals.

**Parameters:**
- `object: unknown` — The object or value of any type to inspect.

**Returns:**
`boolean` (`object is T`) — Returns `true` if an object or function has at least one own enumerable string-keyed property, otherwise `false`. A function without custom enumerable properties and an empty array both return `false`.

## Examples

<Source
  language='typescript'
  code={`
import { hasKeys } from '@dxtmisha/functional-basic'

// 1. Basic objects
hasKeys({ name: 'Alice' }) // true
hasKeys({})                // false

// 2. Falsy property values
hasKeys({ count: 0 })      // true
hasKeys({ flag: false })   // true
hasKeys({ text: '' })      // true

// 3. Prototype pollution protection
hasKeys({})                // false (toString, valueOf ignored)

// 4. Safe with primitives and nullish inputs
hasKeys(null)              // false
hasKeys(undefined)         // false
hasKeys('hello')           // false
hasKeys(123)               // false
`}
/>
