# `hasKeys`

Hàm tiện ích bảo vệ kiểu (type guard), kiểm tra xem đối tượng hoặc hàm có ít nhất một thuộc tính riêng có thể liệt kê với khóa chuỗi hay không. Khóa symbol, thuộc tính không thể liệt kê và thuộc tính kế thừa không được tính.

## Tính năng nổi bật

- **Đánh giá ngắt mạch (Short-circuit)** — Dừng kiểm tra khi phát hiện thuộc tính riêng đầu tiên có thể liệt kê với khóa chuỗi, tránh tạo mảng trung gian `Object.keys()`.
- **Chỉ thuộc tính riêng** — Dùng `Object.hasOwn` để bỏ qua thuộc tính kế thừa. Thuộc tính riêng có thể liệt kê mang tên `toString`, `valueOf` hoặc `constructor` vẫn được tính như bình thường.
- **Hỗ trợ đối tượng không có prototype** — Hoạt động an toàn với các đối tượng từ điển tạo bởi `Object.create(null)`.
- **An toàn với giá trị nguyên thủy** — Trả về `false` một cách an toàn khi nhận `null`, `undefined`, số, chuỗi mà không gây ra lỗi ngoại lệ.
- **Thu hẹp kiểu trong TypeScript** — Hoạt động như một type guard `object is T`, giúp thu hẹp kiểu `unknown` thành đối tượng có dữ liệu.
- **Đẳng hình cho SSR** — Hàm thuần túy không phụ thuộc vào DOM hoặc đối tượng trình duyệt toàn cục.

**Tham số:**
- `object: unknown` — Đối tượng hoặc giá trị thuộc bất kỳ kiểu nào cần kiểm tra.

**Trả về:**
`boolean` (`object is T`) — Trả về `true` nếu đối tượng hoặc hàm có ít nhất một thuộc tính riêng có thể liệt kê với khóa chuỗi, ngược lại là `false`. Hàm không có thuộc tính riêng có thể liệt kê và mảng rỗng đều trả về `false`.

## Ví dụ

<Source
  language='typescript'
  code={`
import { hasKeys } from '@dxtmisha/functional-basic'

// 1. Đối tượng cơ bản
hasKeys({ name: 'Alice' }) // true
hasKeys({})                // false

// 2. Thuộc tính có giá trị falsy
hasKeys({ count: 0 })      // true
hasKeys({ flag: false })   // true
hasKeys({ text: '' })      // true

// 3. Bảo vệ khỏi thuộc tính kế thừa
hasKeys({})                // false (toString, valueOf bị bỏ qua)

// 4. An toàn với giá trị nguyên thủy và nullish
hasKeys(null)              // false
hasKeys(undefined)         // false
hasKeys('hello')           // false
hasKeys(123)               // false
`}
/>
