# `anyToString`

A utility for safely converting any input value into a string according to deterministic conversion rules.

### Key Features:
- **Safe & Resilient**: Never throws runtime errors on `null`, `undefined`, circular object references, symbols, or BigInt values.
- **Design System Boolean Convention**: Converts `true` to `'1'` and `false` to `'0'` for reliable serialization across form attributes and query parameters.
- **Configurable Array Serialization**: Joins flat primitive arrays with commas by default, or serializes as JSON when objects are present or when `isArrayString` is disabled.
- **Circular Reference Protection**: Gracefully falls back to `String()` or `Object.prototype.toString` if `JSON.stringify` fails due to circular references.
- **Isomorphic & SSR Safe**: Pure functional implementation without dependencies on browser globals or DOM APIs.

**Parameters:**
- `value?: V` — (Optional) The value for conversion.
- `isArrayString: boolean = true` — (Optional) If `true`, flat arrays without objects are joined with commas; if `false`, serialized as a JSON string.
- `trim: boolean = true` — (Optional) If `true`, then the resulting string will be trimmed (applies to string values).

**Conversion Rules:**
- **Strings**: Returned as is (trimmed if `trim = true`).
- **Nullish values**: `null` and `undefined` return an empty string `''`.
- **Arrays**: If `isArrayString = true` and the array contains no objects, elements are joined with commas. Otherwise serialized as JSON.
- **Objects**: Converted to JSON via `JSON.stringify`. In case of circular references or serialization errors, falls back to `String()` or `Object.prototype.toString`.
- **Booleans**: `true` converts to `'1'`, `false` converts to `'0'`.
- **Other types**: Numbers, BigInt, Symbol, functions, etc. are converted via `.toString()`.

**Returns:**
`string` — The string representation of the passed value.

## Examples

<Source
  language='typescript'
  code={`
import { anyToString } from '@dxtmisha/functional-basic'

// 1. Strings & trimming
anyToString('  Hello  ')               // 'Hello'
anyToString('  Hello  ', true, false)  // '  Hello  '
anyToString('')                        // ''

// 2. Nullish & omitted values
anyToString(null)                      // ''
anyToString(undefined)                 // ''
anyToString()                          // ''

// 3. Booleans (1/0 convention)
anyToString(true)                      // '1'
anyToString(false)                     // '0'

// 4. Arrays
anyToString([1, 2, 3])                 // '1,2,3'
anyToString([1, 2, 3], false)          // '[1,2,3]'
anyToString([{ a: 1 }, 2])             // '[{"a":1},2]'
anyToString([])                        // ''

// 5. Objects & circular reference resilience
anyToString({ a: 1 })                  // '{"a":1}'

const circular: Record<string, unknown> = { id: 1 }
circular.self = circular
anyToString(circular)                  // '[object Object]'

// 6. Numbers, BigInt, and special types
anyToString(123)                       // '123'
anyToString(0)                         // '0'
anyToString(BigInt(42))                // '42'
anyToString(Symbol('test'))            // 'Symbol(test)'
  `}
/>
