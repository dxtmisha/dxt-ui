# `getArrayHighlightMatch`

A utility for splitting a string into an array of objects for highlighting matches. Each object contains the `text` and a boolean `isMatch` indicating if it matches the search query. This is useful for UI frameworks like Vue or React to render highlighted text without using `v-html`.

Zero-length matches are ignored. With Unicode flags `u` or `v`, the search advances over a complete code point, including emoji, without changing the input RegExp's state.

**Parameters:**
- `value?: unknown` — The initial value or string to process.
- `search?: string | RegExp` — The search string (supports space-separated multi-word search) or regular expression.

**Returns:**
`HighlightMatchItem[]` (`{ text: string, isMatch: boolean }[]`) — An array of text segments with match status.
