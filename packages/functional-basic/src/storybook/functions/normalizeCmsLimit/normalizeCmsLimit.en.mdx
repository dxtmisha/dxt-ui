# `normalizeCmsLimit`

Clamps and normalizes the CMS list limit parameter to a positive integer within the range `[1, maxLimit]`. If `limit` is omitted or non-finite (`NaN`, `Infinity`, `-Infinity`), it returns `defaultLimit`.

**Parameters:**
- `limit?: number` — Requested limit.
- `defaultLimit: number = 20` — Default limit when omitted or non-finite.
- `maxLimit: number = 200` — Maximum allowed limit.

**Returns:**
`number` — Normalized integer limit.

```typescript
import { normalizeCmsLimit } from '@dxtmisha/functional-basic'

console.log(normalizeCmsLimit()) // 20
console.log(normalizeCmsLimit(0)) // 1
console.log(normalizeCmsLimit(15.9)) // 15
console.log(normalizeCmsLimit(500)) // 200
console.log(normalizeCmsLimit(500, 10, 50)) // 50
```
