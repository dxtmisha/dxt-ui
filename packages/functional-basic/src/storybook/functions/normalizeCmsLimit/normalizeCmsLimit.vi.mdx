# `normalizeCmsLimit`

Giới hạn và chuẩn hóa tham số số lượng bản ghi trên mỗi trang CMS thành số nguyên dương trong khoảng `[1, maxLimit]`. Nếu `limit` bị bỏ qua hoặc không phải là số hữu hạn (`NaN`, `Infinity`, `-Infinity`), hàm trả về `defaultLimit`.

**Tham số:**
- `limit?: number` — Số lượng bản ghi được yêu cầu.
- `defaultLimit: number = 20` — Giới hạn mặc định khi bị bỏ qua hoặc không hữu hạn.
- `maxLimit: number = 200` — Giới hạn tối đa cho phép.

**Trả về:**
`number` — Giới hạn số nguyên đã được chuẩn hóa.

```typescript
import { normalizeCmsLimit } from '@dxtmisha/functional-basic'

console.log(normalizeCmsLimit()) // 20
console.log(normalizeCmsLimit(0)) // 1
console.log(normalizeCmsLimit(15.9)) // 15
console.log(normalizeCmsLimit(500)) // 200
console.log(normalizeCmsLimit(500, 10, 50)) // 50
```
