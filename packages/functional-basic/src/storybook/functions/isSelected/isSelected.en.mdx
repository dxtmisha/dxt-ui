# `isSelected`

Checks whether a given value is selected by comparing it against a single target value or an array of selected items. Supports intelligent numeric comparison for numbers and numeric strings:

1. **Null / Undefined Guard:** If `value` is `null` or `undefined` (checked via `isNull(value)`), the function immediately returns `false`.
2. **Array Comparison:** If `selected` is an array `[]`, the function checks direct inclusion via `.includes(value)` and, for numeric values (`isNumber(value)`), checks numeric equivalence against numeric elements in the array via `toNumber()`.
3. **Numeric Comparison:** If both `value` and `selected` are numeric (`isNumber(value) && isNumber(selected)`), they are converted via `toNumber()` and compared numerically (e.g., `'5'` matches `5`).
4. **Strict Equality:** In all other cases, the function compares `value === selected`.

**Parameters:**
- `value?: T` — The input value to check.
- `selected?: unknown` — The target value or array of selected values.

**Returns:**
`boolean` — `true` if `value` matches `selected`, otherwise `false`.

```typescript
import { isSelected } from '@dxtmisha/functional-basic'

// Single value comparisons
console.log(isSelected('apple', 'apple')) // true
console.log(isSelected('apple', 'banana')) // false

// Comparing against an array
console.log(isSelected(2, [1, 2, 3])) // true
console.log(isSelected('5', [1, 2, 5])) // true
console.log(isSelected('dog', ['cat', 'mouse'])) // false

// Intelligent numeric comparison (string vs number)
console.log(isSelected('5', 5)) // true

// Null / undefined check
console.log(isSelected(null, 1)) // false
```
