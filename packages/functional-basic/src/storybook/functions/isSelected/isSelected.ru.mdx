# `isSelected`

Проверяет, выбрано ли переданное значение, сравнивая его с одиночным целевым значением или массивом выбранных элементов. Поддерживает интеллектуальное числовое сравнение для чисел и числовых строк:

1. **Защита от пустых значений:** Если проверяемое значение (`value`) равно `null` или `undefined` (проверка через `isNull(value)`), функция сразу возвращает `false`.
2. **Сравнение с массивом:** Если `selected` является массивом `[]`, функция проверяет прямое вхождение через `.includes(value)`, а для числовых значений (`isNumber(value)`) дополнительно сопоставляет их числовой эквивалент через `toNumber()`.
3. **Числовое сравнение:** Если оба аргумента (`value` и `selected`) являются числовыми (`isNumber(value) && isNumber(selected)`), они преобразуются через `toNumber()` и сравниваются как числа (например, `'5'` соответствует `5`).
4. **Строгое равенство:** В остальных случаях функция использует проверку `value === selected`.

**Параметры:**
- `value?: T` — Проверяемое входное значение.
- `selected?: unknown` — Целевое значение или массив выбранных значений.

**Возвращает:**
`boolean` — `true`, если `value` соответствует `selected`, иначе `false`.

```typescript
import { isSelected } from '@dxtmisha/functional-basic'

// Одиночные сравнения
console.log(isSelected('apple', 'apple')) // true
console.log(isSelected('apple', 'banana')) // false

// Сравнение с массивом
console.log(isSelected(2, [1, 2, 3])) // true
console.log(isSelected('5', [1, 2, 5])) // true
console.log(isSelected('dog', ['cat', 'mouse'])) // false

// Интеллектуальное числовое сравнение (строка и число)
console.log(isSelected('5', 5)) // true

// Проверка на null / undefined
console.log(isSelected(null, 1)) // false
```
