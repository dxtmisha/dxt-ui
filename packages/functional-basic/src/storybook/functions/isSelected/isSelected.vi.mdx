# `isSelected`

Kiểm tra xem một giá trị có được chọn hay không bằng cách so sánh nó với một giá trị đích đơn lẻ hoặc một mảng các phần tử đã chọn. Hỗ trợ so sánh số thông minh cho cả số và chuỗi số:

1. **Bảo vệ Null / Undefined:** Nếu `value` là `null` hoặc `undefined` (kiểm tra qua `isNull(value)`), hàm trả về `false` ngay lập tức.
2. **So sánh với mảng:** Nếu `selected` là một mảng `[]`, hàm kiểm tra sự tồn tại trực tiếp qua `.includes(value)` và đối với giá trị số (`isNumber(value)`), thực hiện đối chiếu tương đương số học với các phần tử số trong mảng qua `toNumber()`.
3. **So sánh số học:** Nếu cả `value` và `selected` đều là dạng số (`isNumber(value) && isNumber(selected)`), chúng được chuyển đổi qua `toNumber()` và so sánh theo giá trị số (ví dụ: `'5'` khớp với `5`).
4. **So sánh bằng nghiêm ngặt:** Trong các trường hợp còn lại, hàm sử dụng phép so sánh `value === selected`.

**Tham số:**
- `value: T` — Giá trị đầu vào cần kiểm tra.
- `selected?: unknown` — Giá trị đích hoặc mảng các giá trị đã chọn.

**Trả về:**
`boolean` — `true` nếu `value` khớp với `selected`, ngược lại là `false`.

```typescript
import { isSelected } from '@dxtmisha/functional-basic'

// So sánh giá trị đơn
console.log(isSelected('apple', 'apple')) // true
console.log(isSelected('apple', 'banana')) // false

// So sánh với mảng
console.log(isSelected(2, [1, 2, 3])) // true
console.log(isSelected('5', [1, 2, 5])) // true
console.log(isSelected('dog', ['cat', 'mouse'])) // false

// So sánh số thông minh (chuỗi và số)
console.log(isSelected('5', 5)) // true

// Kiểm tra null / undefined
console.log(isSelected(null, 1)) // false
```
