# `toString`

Tiện ích chuyển đổi an toàn bất kỳ giá trị nào thành chuỗi. Trả về một chuỗi rỗng `''` nếu giá trị là `null` hoặc `undefined`.

Khác với các cách tiếp cận thông thường (như `value || ''` hoặc chuỗi nội suy `${value}`):
- Các giá trị falsy (`0`, `-0`, `false`, `0n`) được giữ nguyên chính xác và chuyển thành `'0'`, `'false'`, không bị biến thành chuỗi rỗng.
- Symbol (`Symbol(...)`) được chuyển đổi an toàn thành `'Symbol(...)'` mà không ném lỗi `TypeError` (khác với phép nối chuỗi `value + ''`).
- `null` và `undefined` trả về an toàn chuỗi rỗng `''` mà không gây lỗi.
- Hỗ trợ các đối tượng có phương thức `toString()` hoặc `Symbol.toPrimitive` tùy chỉnh.

**Tham số:**
- `value: T` — Giá trị cần chuyển đổi.

**Trả về:**
`string` — Biểu diễn chuỗi của giá trị, hoặc chuỗi rỗng nếu là `null` / `undefined`.

## Ví dụ

<Source
  language='typescript'
  code={`
import { toString } from '@dxtmisha/functional-basic'

// Chuỗi và kiểu nguyên thủy cơ bản
toString('Xin chào')           // 'Xin chào'
toString(123)                  // '123'
toString(true)                 // 'true'

// Xử lý an toàn các giá trị falsy (không bị mất thành chuỗi rỗng)
toString(0)                    // '0'
toString(-0)                   // '0'
toString(false)                // 'false'
toString(0n)                   // '0'

// Giá trị nullish
toString(null)                 // ''
toString(undefined)            // ''

// Symbol (không gây lỗi TypeError)
toString(Symbol('id'))         // 'Symbol(id)'

// Mảng và đối tượng
toString([1, 2, 3])            // '1,2,3'
toString([])                   // ''
toString({ a: 1 })             // '[object Object]'
toString({ toString: () => 'custom' }) // 'custom'
  `}
/>
