# `setElementItem`

Thay đổi giá trị thuộc tính hoặc thuộc tính DOM của phần tử được tìm thấy theo bộ chọn hoặc được truyền trực tiếp. Nếu thuộc tính mục tiêu là một đối tượng (và không phải là mảng), hàm sẽ thực hiện gộp với dữ liệu mới.

Hàm cung cấp khả năng bảo vệ mạnh mẽ chống lại **Prototype Pollution** (bỏ qua `__proto__`, `constructor`, `prototype`), hỗ trợ biến tùy chỉnh CSS (`--*`) và các thuộc tính kebab-case trong đối tượng kiểu dáng, loại bỏ kiểu dáng sạch sẽ khi truyền `null` / `undefined`, đồng thời định dạng chính xác các thuộc tính boolean và trạng thái ARIA.

**Tham số:**
- `element: ElementOrString<E>` — Phần tử, đối tượng `window` hoặc bộ chọn CSS.
- `index: K | string` — Khóa thuộc tính, tên thuộc tính HTML hoặc khóa kiểu dáng.
- `value: V | Record<string, V> | unknown` — Giá trị mới hoặc đối tượng để gộp.

**Giá trị trả về:**
`E | undefined` — Phần tử đã được chỉnh sửa, hoặc `undefined` nếu không tìm thấy phần tử hoặc truyền khóa prototype nguy hiểm.

```typescript
import { setElementItem } from '@dxtmisha/functional-basic'

// Thay đổi nội dung văn bản
setElementItem('#my-div', 'textContent', 'Văn bản mới')

// Gộp kiểu dáng bao gồm kebab-case và biến CSS
setElementItem(document.body, 'style', {
  backgroundColor: 'red',
  'font-size': '16px',
  '--brand-color': '#0055ff'
})

// Xóa kiểu dáng hoặc biến CSS bằng null / undefined
setElementItem(document.body, 'style', {
  backgroundColor: null,
  '--brand-color': undefined
})

// Đặt thuộc tính (nếu thuộc tính không tồn tại trên phần tử)
setElementItem('input', 'placeholder', 'Nhập dữ liệu...')

// Đặt thuộc tính ARIA ('true' / 'false')
setElementItem('button', 'aria-expanded', true)
```
