# `setElementItem`

Modifies the property value or attribute of a DOM element resolved by selector or passed directly. If the target property is an object (and not an array), merges with the new data.

The function provides robust protection against **Prototype Pollution** (ignoring `__proto__`, `constructor`, `prototype`), supports CSS custom properties (`--*`) and kebab-case keys in style objects, cleanly removes styles when `null` / `undefined` is passed, and accurately formats boolean attributes and ARIA states.

**Parameters:**
- `element: ElementOrString<E>` — Element, `window`, or CSS selector.
- `index: K | string` — Property key, attribute name, or style key.
- `value: V | Record<string, V> | unknown` — New value or object to merge.

**Returns:**
`E | undefined` — Modified element, or `undefined` if element is not found or a prototype pollution key was passed.

```typescript
import { setElementItem } from '@dxtmisha/functional-basic'

// Modifying text content
setElementItem('#my-div', 'textContent', 'New text')

// Merging styles including kebab-case and CSS variables
setElementItem(document.body, 'style', {
  backgroundColor: 'red',
  'font-size': '16px',
  '--brand-color': '#0055ff'
})

// Removing styles or CSS variables via null / undefined
setElementItem(document.body, 'style', {
  backgroundColor: null,
  '--brand-color': undefined
})

// Setting an attribute (if property does not exist on element)
setElementItem('input', 'placeholder', 'Enter data...')

// Setting ARIA attributes ('true' / 'false')
setElementItem('button', 'aria-expanded', true)
```
