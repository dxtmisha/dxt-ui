# `isIntegerBetween`

Checks whether a number belongs to the half-open interval defined by `between`.

The lower bound is `Math.floor(between)`, rounded toward negative infinity. The lower bound is included and the upper bound is excluded. If either argument is `NaN` or infinite, the function returns `false`.

Formula representation: `floor(between) <= value < floor(between) + 1`

**Parameters:**
- `value: number` — The comparative number undergoing the test.
- `between: number` — The base origin dictating the interval bounds via mathematical floor rounding.

**Returns:**
`boolean` — `true` if the value belongs to the interval, otherwise `false`.

```typescript
import { isIntegerBetween } from '@dxtmisha/functional-basic'

// Formed Interval: [5, 6)
console.log(isIntegerBetween(5.2, 5.8)) // true (Math.floor(5.8) = 5)
console.log(isIntegerBetween(5.99, 5))  // true
console.log(isIntegerBetween(6, 5))     // false
```
