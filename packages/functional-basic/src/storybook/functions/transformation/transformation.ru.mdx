# `transformation`

Преобразует строковое значение в соответствующий ему тип данных (логический, числовой, JSON-объект/массив или `null`/`undefined`). Числовые строки в пределах безопасного целочисленного или конечного диапазона преобразуются в числа (значения за пределами безопасного диапазона остаются строками для предотвращения потери точности). Ошибки парсинга JSON передаются в `ErrorCenter` (в группу `'transformation'`). Если включен флаг `isFunctionCheck` и код выполняется в DOM-окружении, проверяет наличие функции с таким именем в глобальном объекте `window`. Нестроковые значения или строки, не подходящие под правила преобразования, возвращаются без изменений.

**Параметры:**
- `value?: unknown` — Входное значение для преобразования.
- `isFunctionCheck: boolean = false` — Флаг проверки функции в глобальном объекте `window` (по умолчанию `false`).

**Возвращает:**
`T` — Преобразованное значение (`T = unknown`).

```typescript
import { transformation } from '@dxtmisha/functional-basic'

console.log(transformation('true')) // true
console.log(transformation('12.5')) // 12.5
console.log(transformation('{"a":1}')) // { a: 1 }
console.log(transformation('null')) // null
```
