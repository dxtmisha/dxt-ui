# `transformation`

Transforms a string value into its corresponding data type (boolean, numeric, JSON object/array, or `null`/`undefined`). JSON parsing errors are routed through `ErrorCenter` (under group `'transformation'`). If the `isFunctionCheck` flag is enabled and running in a DOM environment, it checks for a function with that name in the global `window` object. Non-string values or strings that do not match any conversion rule are returned as-is.

**Parameters:**
- `value: unknown` — The input value to transform.
- `isFunctionCheck: boolean = false` — Flag to check for a function in the global `window` object (defaults to `false`).

**Returns:**
`T` — The transformed value (`T = unknown`).

```typescript
import { transformation } from '@dxtmisha/functional-basic'

console.log(transformation('true')) // true
console.log(transformation('12.5')) // 12.5
console.log(transformation('{"a":1}')) // { a: 1 }
console.log(transformation('null')) // null
```
