# `initScrollbarOffset`

Измеряет ширину полосы прокрутки через `ScrollbarWidth.get()` и записывает значение в пикселях в CSS-переменную `--sys-scrollbar-offset` на `document.body`.

Значение можно использовать для компенсации места, занятого скроллбаром, при блокировке прокрутки страницы для оверлея.

Вне DOM-среды или при отсутствии `document.body` функция завершается без измерения и записи. Появления body она не ожидает. Нулевая ширина даёт `0px`, дробные значения сохраняются. Ошибка измерения отклоняет возвращённый промис.

**Параметры:**
Функция не принимает аргументов.

**Возвращает:**
`Promise<void>` — Завершается после записи CSS-переменной либо раннего выхода без DOM/body. Значение не возвращается.

```typescript
import { initScrollbarOffset } from '@dxtmisha/functional-basic'

// Инициализация при загрузке приложения
await initScrollbarOffset()

// Теперь в CSS доступен размер скроллбара
// body[data-scroll-locked] { padding-right: var(--sys-scrollbar-offset, 0px); }
```
