# `initScrollbarOffset`

Đo chiều rộng thanh cuộn qua `ScrollbarWidth.get()` rồi ghi giá trị pixel vào biến CSS `--sys-scrollbar-offset` trên `document.body`.

Giá trị này có thể dùng để bù phần diện tích thanh cuộn chiếm chỗ khi khóa cuộn trang cho một lớp phủ.

Nếu không có môi trường DOM hoặc `document.body`, hàm hoàn tất mà không đo hay ghi giá trị; hàm không chờ body xuất hiện. Chiều rộng bằng 0 được ghi thành `0px`, còn giá trị thập phân được giữ nguyên. Lỗi đo làm promise trả về bị từ chối.

**Tham số:**
Hàm này không tiếp nhận bất kỳ đối số nào.

**Trả về:**
`Promise<void>` — Hoàn tất sau khi ghi biến CSS hoặc kết thúc sớm khi không có DOM/body. Không trả về giá trị.

```typescript
import { initScrollbarOffset } from '@dxtmisha/functional-basic'

// Phát lệnh định vị ngay trong lúc khởi tạo dữ liệu khởi động app
await initScrollbarOffset()

// Gọi CSS sau này tuỳ biến:
// body[data-scroll-locked] { padding-right: var(--sys-scrollbar-offset, 0px); }
```
