# `initScrollbarOffset`

Measures scrollbar width through `ScrollbarWidth.get()` and writes the pixel value to the `--sys-scrollbar-offset` CSS custom property on `document.body`.

The value can be used to compensate for the space occupied by a scrollbar when locking page scrolling for an overlay.

Outside a DOM runtime, or when `document.body` is unavailable, the function resolves without measuring or writing. It does not wait for the body to appear. Zero-width scrollbars produce `0px`; fractional measurements are preserved. Measurement failures reject the returned promise.

**Parameters:**
This function does not accept any arguments.

**Returns:**
`Promise<void>` — Resolves after the CSS property is written or after an early exit without a DOM/body. No value is returned.

```typescript
import { initScrollbarOffset } from '@dxtmisha/functional-basic'

// Triggers sizing capture on app startup
await initScrollbarOffset()

// Utilize styling later implicitly:
// body[data-scroll-locked] { padding-right: var(--sys-scrollbar-offset, 0px); }
```
