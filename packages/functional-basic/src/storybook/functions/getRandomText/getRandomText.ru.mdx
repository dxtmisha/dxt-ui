# `getRandomText`

Генерирует строку, состоящую из случайного количества «слов». Под словом понимается последовательность одинаковых символов заданной длины. Функция полезна для заполнения интерфейса заглушками (placeholder), похожими на текст, но не имеющими смысла или языковой привязки.

Она работает на основе утилит `random` (для выбора случайных чисел) и `strFill` (для заполнения слова символами).

Каждое слово повторяет строковое представление `symbol`; границы длины задают число повторений. Для многосимвольного значения `'ab'` три повторения дают `'ababab'`. Null-символ создаёт пустые слова с сохранением пробелов-разделителей. Undefined-символ использует значение по умолчанию `'#'`.

**Параметры:**
- `min?: number` — (Необязательно) Минимальное количество слов в итоговой строке. По умолчанию `1`.
- `max?: number` — (Необязательно) Максимальное количество слов в итоговой строке. По умолчанию `10`.
- `symbol?: unknown` — (Необязательно) Значение для повторения внутри каждого слова, преобразуемое через `strFill`. По умолчанию `'#'`.
- `lengthMin?: number` — (Необязательно) Минимальное количество повторений в слове. По умолчанию `2`.
- `lengthMax?: number` — (Необязательно) Максимальное количество повторений в слове. По умолчанию `12`.

**Возвращает:**
`string` — Строку, состоящую из слов, разделённых пробелами.

```typescript
import { getRandomText } from '@dxtmisha/functional-basic'

// Сгенерирует от 2 до 5 слов, состоящих из символа '#'
// Длина каждого слова от 2 до 12 символов
console.log(getRandomText(2, 5)) // '#### ## #######'

// Генерация точного числа слов (3) из определенного символа ('*')
// Длина слов строго по 5 символов
console.log(getRandomText(3, 3, '*', 5, 5)) // '***** ***** *****'
```
