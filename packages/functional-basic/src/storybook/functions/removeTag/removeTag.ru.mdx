# `removeTag`

Высокопроизводительная утилита для удаления всех HTML/XML-тегов или заданного списка тегов из строки с сохранением текстового содержимого.

## Основные возможности

- **Полная поддержка HTML/XML и служебных структур** — удаляет стандартные элементы, самозакрывающиеся теги (`<br/>`, `<img />`), многострочные блоки, HTML-комментарии (`<!-- ... -->`, `<!-- ... --!>`), `<!DOCTYPE ...>` (включая закавыченные идентификаторы с `>`), `<![CDATA[...]]>` и `<?xml ...?>`.
- **Точечная фильтрация тегов** — возможность удалять только указанные теги (например, `'b'` или `['b', 'i']`), сохраняя остальную разметку нетронутой.
- **Поддержка минифицированного HTML и атрибутов** — безошибочно обрабатывает слитные закавыченные атрибуты без пробелов (`<img src="x"onerror="alert(1)">`, `<div class="a"id="b">`) и атрибуты, содержащие `>` или `/>` внутри кавычек.
- **Быстрый выход (Fast-Path)** — мгновенно возвращает исходную строку, если в ней отсутствует символ `<`, полностью минуя выполнение регулярных выражений.
- **Устойчивость к ReDoS** — использует непересекающиеся классы символов в шаблоне атрибутов, гарантируя детерминированную линейную сложность $O(N)$ даже на повреждённой или вредоносной разметке.
- **Безопасность спецсимволов замены** — использует функцию-реплейсер `() => replacement`, что исключает интерпретацию шаблонов подстановки (`$&`, `$1`, `$$`) и возвращает переданную строку замены буквально.
- **Кэширование скомпилированных выражений** — автоматически кэширует динамические регулярные выражения для тегов и контентных тегов в ограниченных буферах (до 128 записей в каждом) с канонической сортировкой ключей для предотвращения накладных расходов повторной компиляции.
- **Изоморфность и полная совместимость с SSR** — чистая функция без зависимостей от глобальных объектов браузера (`window`/`document`), полностью безопасная для серверного рендеринга (Node.js/Nitro).
- **Интеграция с системой подсветки** — идеально дополняет `addTagHighlightMatch`, позволяя быстро очистить теги подсветки поисковых совпадений `<span class="sys-highlight-match">`.

> **Примечание:** По умолчанию (`removeContent = true`) исполняемые теги и стили (`<script>`, `<style>`, `<noscript>`) или теги, указанные в `removeContent`, удаляются молча вместе со своим содержимым без применения `replacement`, предотвращая утечку программного кода и CSS-правил в текст. Остальные теги форматирования и разметки сохраняют текстовое содержимое, а синтаксис их тегов заменяется на `replacement`. При указании фильтра `tag` удаляются только соответствующие теги, при этом исполняемые теги по-прежнему удаляются с содержимым, если явно не указано `removeContent: false`.

**Параметры:**
- `value?: string | number | null` — Исходная строка или число для обработки.
- `options?: RemoveTagOptions` — Объект настроек удаления тегов:
  - `tag?: string | string[]` — Имя тега или массив тегов для удаления. Если опущен (`undefined`), удаляются все HTML/XML-теги.
  - `replacement?: string` — Строка, на которую будут заменены удалённые теги (не применяется к молча удаляемым блокам содержимого; по умолчанию пустая строка `''`).
  - `removeContent?: boolean | string | string[]` — Нужно ли удалять содержимое тегов `<script>`, `<style>`, `<noscript>` (или указанных тегов). По умолчанию `true`.

**Возвращает:**
`string` — Очищенная строка без тегов. Возвращает пустую строку `''`, если передано значение `null` или `undefined`.

## Примеры использования

<Source
  language='typescript'
  code={`
import { removeTag } from '@dxtmisha/functional-basic'

// 1. Удаление всех HTML-тегов (блоки script и style по умолчанию удаляются вместе с содержимым)
removeTag('<p>Привет, <b>мир</b>!</p><script>alert(1)</script>')
// => 'Привет, мир!'

// 2. Удаление вложенных и многострочных тегов
removeTag('<div class="card">\n  <span>Контент</span>\n</div>')
// => '\n  Контент\n'

// 3. Удаление самозакрывающихся тегов
removeTag('Строка 1<br/>Строка 2<hr><img src="pic.jpg" alt="фото" />')
// => 'Строка 1Строка 2'

// 4. Удаление комментариев, DOCTYPE и CDATA
removeTag('<!DOCTYPE html><!-- комментарий -->Привет <![CDATA[данные]]>')
// => 'Привет '

// 5. Удаление только указанных тегов (один тег или массив)
removeTag('<b>Жирный</b> и <i>Курсив</i> и <p>Текст</p>', { tag: 'b' })
// => 'Жирный и <i>Курсив</i> и <p>Текст</p>'

removeTag('<b>Жирный</b> и <i>Курсив</i> и <p>Текст</p>', { tag: ['b', 'i'] })
// => 'Жирный и Курсив и <p>Текст</p>'

// 6. Минифицированный HTML и слитные закавыченные атрибуты без пробелов
removeTag('<img src="x"onerror="alert(1)">Привет')
// => 'Привет'

removeTag('<div class="a"id="b">Контент</div>', { tag: 'div' })
// => 'Контент'

// 7. Кастомная строка замены (безопасна для символов доллара)
removeTag('<p>Привет</p><p>мир</p>', { replacement: ' ' })
// => ' Привет  мир '

removeTag('<p>Товар</p>', { replacement: '$100' })
// => '$100Товар$100'

// 8. Сохранение содержимого script и style (removeContent = false)
removeTag('<p>Привет</p><script>alert(1)</script>', { removeContent: false })
// => 'Приветalert(1)'

// 9. Удаление кастомных тегов вместе с содержимым (removeContent = 'pre' или массив тегов)
removeTag('<p>Статья</p><pre>const x = 10;</pre><code>var y = 20;</code>', { removeContent: 'pre' })
// => 'Статьяvar y = 20;'

// 10. Очистка подсветки поисковых совпадений
import { addTagHighlightMatch } from '@dxtmisha/functional-basic'

const highlighted = addTagHighlightMatch('Яблоко и Банан', 'яблоко')
// '<span class="sys-highlight-match">Яблоко</span> и Банан'

removeTag(highlighted, { tag: 'span' })
// 'Яблоко и Банан'
  `}
/>
