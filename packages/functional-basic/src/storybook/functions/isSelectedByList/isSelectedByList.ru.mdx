# `isSelectedByList`

Расширяет проверку `isSelected` на список значений. Проверяет, соответствуют ли **все элементы** в `values` критерию выборки `selected`.

Если `values` — одиночное значение, а не массив, функция напрямую делегирует проверку в `isSelected(values, selected)`. Если `values` является массивом, используется метод `.every()`, чтобы убедиться, что каждый элемент проходит проверку `isSelected(item, selected)`.

**Параметры:**
- `values: T | T[]` — Одиночное значение или массив значений для сравнения.
- `selected: T | T[]` — Целевое значение или массив выбранных значений для сравнения.

**Возвращает:**
`boolean` — `true`, если все переданные значения из `values` выбраны, иначе `false`.

```typescript
import { isSelectedByList } from '@dxtmisha/functional-basic'

// Проверка списка по одиночному целевому значению
console.log(isSelectedByList(['apple', 'apple'], 'apple')) // true

// Проверка того, что каждый элемент из values содержится в массиве selected
console.log(isSelectedByList(['apple', 'cherry'], ['banana', 'apple', 'cherry'])) // true

// Возвращает false, так как 'date' отсутствует в массиве selected
console.log(isSelectedByList(['apple', 'date'], ['banana', 'apple', 'cherry'])) // false

// Одиночное значение обрабатывается аналогично isSelected
console.log(isSelectedByList('apple', 'apple')) // true
```
