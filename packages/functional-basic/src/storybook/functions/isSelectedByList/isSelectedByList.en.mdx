# `isSelectedByList`

Extends the `isSelected` check to an entire list of values. It verifies whether **all elements** in `values` match the selection criteria `selected`.

If `values` is a single item rather than an array, the function delegates directly to `isSelected(values, selected)`. If `values` is an array, it uses `.every()` to ensure that every element satisfies `isSelected(item, selected)`.

**Parameters:**
- `values: T | T[]` — A single value or an array of values to check.
- `selected: T | T[]` — The target value or array of selected values for comparison.

**Returns:**
`boolean` — `true` if all provided values in `values` are selected, otherwise `false`.

```typescript
import { isSelectedByList } from '@dxtmisha/functional-basic'

// Validating a list against a single target value
console.log(isSelectedByList(['apple', 'apple'], 'apple')) // true

// Validating that every item in values is present in the selected array
console.log(isSelectedByList(['apple', 'cherry'], ['banana', 'apple', 'cherry'])) // true

// Returns false because 'date' is not in the selected array
console.log(isSelectedByList(['apple', 'date'], ['banana', 'apple', 'cherry'])) // false

// Single value behaves identically to isSelected
console.log(isSelectedByList('apple', 'apple')) // true
```
