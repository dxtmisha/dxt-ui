# `isSelectedByList`

Mở rộng phép kiểm tra `isSelected` cho toàn bộ danh sách giá trị. Hàm xác minh xem **tất cả các phần tử** trong `values` có khớp với tiêu chí lựa chọn `selected` hay không.

Nếu `values` là một giá trị đơn lẻ thay vì mảng, hàm sẽ chuyển tiếp trực tiếp sang `isSelected(values, selected)`. Nếu `values` là một mảng, hàm sử dụng `.every()` để đảm bảo mọi phần tử đều thỏa mãn `isSelected(item, selected)`.

**Tham số:**
- `values: T | T[]` — Một giá trị đơn hoặc mảng các giá trị cần kiểm tra.
- `selected: T | T[]` — Giá trị đích hoặc mảng các giá trị đã chọn để so sánh.

**Trả về:**
`boolean` — `true` nếu tất cả các giá trị trong `values` đều được chọn, ngược lại là `false`.

```typescript
import { isSelectedByList } from '@dxtmisha/functional-basic'

// Kiểm tra danh sách với một giá trị đích duy nhất
console.log(isSelectedByList(['apple', 'apple'], 'apple')) // true

// Kiểm tra mọi phần tử trong values đều nằm trong mảng selected
console.log(isSelectedByList(['apple', 'cherry'], ['banana', 'apple', 'cherry'])) // true

// Trả về false vì 'date' không có trong mảng selected
console.log(isSelectedByList(['apple', 'date'], ['banana', 'apple', 'cherry'])) // false

// Giá trị đơn hoạt động tương tự như isSelected
console.log(isSelectedByList('apple', 'apple')) // true
```
