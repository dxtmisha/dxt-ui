# `toCountry`

Извлекает и валидирует двухбуквенный ISO-код страны в верхнем регистре из строк локаций, тегов локалей или кодов стран через справочник `GeoList`.

## Основные возможности

- **Поддержка субтегов BCP-47** — Корректно извлекает двухбуквенный код региона из стандартных и расширенных BCP-47 тегов (например, `'zh-Hans-CN'` -> `'CN'`, `'en-US-u-ca-gregory'` -> `'US'`).
- **Гибкие форматы тегов локали** — Поддерживает классические (`'en-US'`), с разделителем подчеркивания (`'en_US'`), регистронезависимые (`'en-gb'` -> `'GB'`) и инвертированные (`'RU-ru'` -> `'RU'`) форматы.
- **Разрешение альтернативных кодов стран** — Автоматически сопоставляет нестандартные или альтернативные коды, зарегистрированные в `GeoList` (например, `'UK'` -> `'GB'`, `'EN'` -> `'US'`, `'BY_BY'` -> `'BY'`).
- **Строгая верификация через `GeoList`** — Отличает коды стран от строчных кодов языков (`'en'` -> `''`, `'ru'` -> `''`) и проверяет наличие извлеченного региона в базе поддерживаемых стран.
- **Изоморфность и безопасное приведение типов** — Чистая функция без побочных эффектов, использующая `toString()` для безопасной обработки нестроковых значений, `null` и `undefined` без риска runtime-ошибок.

**Параметры:**
- `code?: unknown` — Проверяемая строка локации или код страны.

**Возвращает:**
- `string` — Двухбуквенный код страны в верхнем регистре (например, `'US'`, `'GB'`, `'VN'`) или пустая строка, если страна не найдена.

## Примеры

<Source
  language='typescript'
  code={`
import { toCountry } from '@dxtmisha/functional-basic'

// 1. Прямые коды стран
toCountry('US') // 'US'
toCountry('VN') // 'VN'

// 2. Стандартные и обратные теги локалей
toCountry('en-US') // 'US'
toCountry('en_US') // 'US'
toCountry('RU-ru') // 'RU'
toCountry('en-gb') // 'GB'

// 3. Расширенные субтеги BCP-47
toCountry('zh-Hans-CN')          // 'CN'
toCountry('en-US-u-ca-gregory')  // 'US'

// 4. Альтернативные коды стран (через GeoList)
toCountry('UK')    // 'GB'
toCountry('en-UK') // 'GB'
toCountry('BY_BY') // 'BY'

// 5. Одиночные коды языков и невалидные значения
toCountry('en')       // '' (код языка, не страны)
toCountry('')         // ''
toCountry(undefined)  // ''
  `}
/>
