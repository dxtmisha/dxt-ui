# `encodeLiteAttribute`

Кодирует базовые специальные символы HTML в строке (`<`, `>`, `&`) в соответствующие HTML-сущности (`&lt;`, `&gt;`, `&amp;`), сохраняя кавычки (`"` и `'`) без изменений. Обычно используется для тегов заголовков HTML (`<title>`), мета-описаний и облегченного форматирования текста.

> **Примечание:** Эта функция намеренно НЕ экранирует кавычки (`"` и `'`). Для экранирования пользовательского ввода внутри HTML-атрибутов используйте `encodeAttribute` во избежание уязвимостей инъекции атрибутов.

### Ключевые возможности:
- **Сохранение кавычек**: Сохраняет одинарные (`'`), двойные (`"`) и обратные (`` ` ``) кавычки нетронутыми, что идеально подходит для заголовков страниц и естественного отображения текста.
- **Высокая производительность (Fast-Path)**: Использует предварительную быструю проверку на наличие спецсимволов, мгновенно возвращая исходную строку при их отсутствии.
- **Безопасное приведение типов и null-safety**: Корректно обрабатывает строки, числа (включая `0` и отрицательные значения), `null` и `undefined` без выброса исключений.
- **Поддержка Unicode и диакритики**: Корректно сохраняет кириллицу, вьетнамские диакритические знаки, CJK-символы и эмодзи.

**Параметры:**
- `text?: unknown` — Значение для кодирования. Перед экранированием преобразуется в строку через `String`; `null` и `undefined` дают пустую строку.

**Возвращает:**
`string` — Закодированная строка, либо пустая строка `''`, если передано `null` или `undefined`.

```typescript
import { encodeLiteAttribute } from '@dxtmisha/functional-basic'

// 1. Сохранение кавычек в заголовках страниц при экранировании HTML-символов
const title = 'Книга "Война & Мир" <Том 1>'
const encodedTitle = encodeLiteAttribute(title)
console.log(encodedTitle)
// 'Книга "Война &amp; Мир" &lt;Том 1&gt;'

// 2. Безопасная обработка чисел и пустых значений
encodeLiteAttribute(0)         // '0'
encodeLiteAttribute(123)       // '123'
encodeLiteAttribute(null)      // ''
encodeLiteAttribute(undefined) // ''
```
