# `getElementImage`

Used to safely retrieve an `HTMLImageElement` node. If a string (an image URL) is passed as input, the function creates a new `<img>` tag, optionally attaches `onload` and `onerror` event listeners, and then assigns the URL to its `src` attribute. If an `HTMLImageElement` object is already passed, it returns it immediately unchanged.

**Parameters:**
- `image?: HTMLImageElement | string` — An image element or a string source (URL / Base64 / Blob URL).
- `onload?: GetElementImageCallback` (`(image: HTMLImageElement, event?: Event | string) => void`) — Optional callback invoked on successful image loading.
- `onerror?: GetElementImageCallback` (`(image: HTMLImageElement, event?: Event | string) => void`) — Optional callback invoked on image load error.

**Returns:**
`HTMLImageElement | undefined` — A ready-to-use `<img>` tag, or `undefined` if the environment does not allow its creation (e.g., SSR) or if `image` was omitted.

```typescript
import { getElementImage } from '@dxtmisha/functional-basic'

// 1. Simple creation from a string URL
const img1 = getElementImage('/path/to/image.png')
console.log(img1 instanceof HTMLImageElement) // true
console.log(img1?.src) // 'http://.../path/to/image.png'

// 2. Creation with load and error lifecycle callbacks
const imgWithEvents = getElementImage(
  '/path/to/avatar.jpg',
  (image) => console.log('Image loaded successfully:', image.naturalWidth),
  (image) => console.error('Image load failed:', image.src)
)

// 3. Passing an existing img tag (returned directly without modifications)
const existingImg = document.createElement('img')
const img2 = getElementImage(existingImg)
console.log(img2 === existingImg) // true
```
