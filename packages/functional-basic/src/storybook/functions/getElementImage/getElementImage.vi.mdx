# `getElementImage`

Dùng để lấy nút `HTMLImageElement` một cách an toàn. Nếu truyền vào một chuỗi (URL / Base64 / Blob URL), hàm sẽ tạo thẻ `<img>` mới, tùy chọn gắn các hàm xử lý sự kiện `onload` và `onerror`, sau đó gán chuỗi đó cho thuộc tính `src`. Nếu giá trị truyền vào đã là một đối tượng `HTMLImageElement`, hàm sẽ trả về đối tượng đó ngay lập tức mà không thay đổi.

**Tham số:**
- `image?: HTMLImageElement | string` — Phần tử hình ảnh hoặc nguồn chuỗi (URL / Base64 / Blob URL).
- `onload?: GetElementImageCallback` (`(image: HTMLImageElement, event?: Event | string) => void`) — Hàm callback tùy chọn khi tải hình ảnh thành công.
- `onerror?: GetElementImageCallback` (`(image: HTMLImageElement, event?: Event | string) => void`) — Hàm callback tùy chọn khi xảy ra lỗi tải hình ảnh.

**Trả về:**
`HTMLImageElement | undefined` — Một thẻ `<img>` đã sẵn sàng để sử dụng, hoặc `undefined` nếu môi trường không cho phép tạo (ví dụ: trong SSR) hoặc nếu không truyền tham số `image`.

```typescript
import { getElementImage } from '@dxtmisha/functional-basic'

// 1. Tạo thẻ đơn giản từ đường dẫn URL
const img1 = getElementImage('/path/to/image.png')
console.log(img1 instanceof HTMLImageElement) // true
console.log(img1?.src) // 'http://.../path/to/image.png'

// 2. Tạo với hàm theo dõi sự kiện tải và lỗi
const imgWithEvents = getElementImage(
  '/path/to/avatar.jpg',
  (image) => console.log('Tải ảnh thành công:', image.naturalWidth),
  (image) => console.error('Lỗi khi tải ảnh:', image.src)
)

// 3. Truyền vào thẻ img có sẵn (trả về trực tiếp không thay đổi)
const existingImg = document.createElement('img')
const img2 = getElementImage(existingImg)
console.log(img2 === existingImg) // true
```
