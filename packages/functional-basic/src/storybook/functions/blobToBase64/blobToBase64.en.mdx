# `blobToBase64`

An asynchronous isomorphic utility that converts binary `Blob` or `File` instances into Base64-encoded strings, supporting both formatted Data URLs and raw Base64 payloads across browser and server environments.

## Key Features

- **Isomorphic Dual-Engine Architecture** — Automatically determines runtime environment via `isDomRuntime()`: utilizes browser `FileReader` in client contexts and Node.js `Buffer` alongside `blob.arrayBuffer()` in SSR/server contexts.
- **Flexible Payload Formatting** — Generates complete RFC 2397 Data URLs (e.g. `data:image/png;base64,...`) by default for direct image `src` binding, or extracts clean Base64 payloads via `clean = true` for network API payloads.
- **Permissive Nullish Guard** — Gracefully handles `null`, `undefined`, empty Blobs (`new Blob([])`), and zero-byte slices by returning `undefined` instead of throwing unhandled exceptions.
- **MIME Type Preservation** — Faithfully retains the original Blob MIME type (`blob.type`) in the formatted Data URL scheme.
- **Comprehensive Multilingual & Binary Support** — Accurately encodes UTF-8 Unicode characters (Cyrillic, Vietnamese, CJK, Emoji) and arbitrary raw binary buffers without data corruption.
- **Safe & Non-Crashing** — Fully encapsulated in `try...catch` blocks to protect against aborted reads or missing environment APIs.

**Parameters:**
- `blob?: Blob | null` — The `Blob` or `File` object to convert. Safely returns `undefined` if nullish or empty.
- `clean: boolean = false` — When set to `true`, strips the leading Data URL scheme (`data:<mime>;base64,`) and returns only the Base64-encoded string.

**Returns:**
`Promise<string | undefined>` — A Promise resolving to the Base64 string or Data URL, or `undefined` if the input is empty or conversion fails.

## Examples

<Source
  language='typescript'
  code={`
import { blobToBase64 } from '@dxtmisha/functional-basic'

// 1. Image preview binding (Data URL)
const fileInput = document.querySelector<HTMLInputElement>('#avatar')
const file = fileInput?.files?.[0]

const previewUrl = await blobToBase64(file)
if (previewUrl) {
  // Directly bindable to <img :src="previewUrl" />
  console.log(previewUrl) // 'data:image/png;base64,iVBORw0KGgo...'
}

// 2. Clean Base64 payload for JSON REST API
const rawBase64 = await blobToBase64(file, true)
if (rawBase64) {
  await fetch('/api/upload', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ fileData: rawBase64 })
  })
}

// 3. Permissive nullish handling (no runtime crashes)
const emptyResult = await blobToBase64(null)
console.log(emptyResult) // undefined
  `}
