# `writeClipboardData`

Writes a text string to the user's clipboard in a DOM environment. It uses the modern `navigator.clipboard.writeText(text)` API, falling back to a temporary hidden `<textarea>` and `document.execCommand('copy')` while reporting the error via `ErrorCenter` (under group `'clipboard'`) if the modern API fails.

**Parameters:**
- `text: string` — The text to write.

**Returns:**
`Promise<void>` — A promise that resolves after a successful write.

```typescript
import { writeClipboardData } from '@dxtmisha/functional-basic'

await writeClipboardData('Copied text')
```
