# `writeClipboardData`

Ghi một chuỗi văn bản vào bộ nhớ tạm của người dùng trong môi trường DOM. Hàm sử dụng API `navigator.clipboard.writeText(text)` hiện đại, và nếu xảy ra lỗi sẽ chuyển sang phương thức dự phòng sử dụng phần tử `<textarea>` ẩn tạm thời cùng với `document.execCommand('copy')`, đồng thời báo cáo lỗi qua `ErrorCenter` (nhóm `'clipboard'`).

**Tham số:**
- `text: string` — Văn bản cần ghi.

**Trả về:**
`Promise<void>` — Một promise sẽ hoàn thành sau khi ghi thành công.

```typescript
import { writeClipboardData } from '@dxtmisha/functional-basic'

await writeClipboardData('Văn bản đã sao chép')
```
