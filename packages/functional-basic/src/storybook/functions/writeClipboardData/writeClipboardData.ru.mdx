# `writeClipboardData`

Записывает текстовую строку в буфер обмена пользователя в DOM-окружении. Использует современный API `navigator.clipboard.writeText(text)`, а в случае ошибки переключается на резервный метод со скрытым временным элементом `<textarea>` и `document.execCommand('copy')`, передавая ошибку в `ErrorCenter` (группа `'clipboard'`).

**Параметры:**
- `text: string` — Текст для записи.

**Возвращает:**
`Promise<void>` — Промис, который завершается после успешной записи.

```typescript
import { writeClipboardData } from '@dxtmisha/functional-basic'

await writeClipboardData('Скопированный текст')
```
