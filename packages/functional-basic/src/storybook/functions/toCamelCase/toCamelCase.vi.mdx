# `toCamelCase`

Chuyển đổi một chuỗi văn bản thành định dạng `camelCase`. Hàm loại bỏ các ký tự đặc biệt, thay thế khoảng trắng, dấu chấm và dấu gạch dưới bằng dấu gạch nối, viết hoa các chữ cái sau dấu gạch nối và đảm bảo chữ cái đầu tiên của chuỗi là chữ thường.

**Tham số:**
- `value?: string` — Chuỗi đầu vào cần chuyển đổi.

**Trả về:**
`string` — Chuỗi ở định dạng `camelCase`.

```typescript
import { toCamelCase } from '@dxtmisha/functional-basic'

console.log(toCamelCase('Hello World')) // 'helloWorld'
console.log(toCamelCase('user-profile-data')) // 'userProfileData'
console.log(toCamelCase('user_profile_data')) // 'userProfileData'
console.log(toCamelCase('Some_Special@String')) // 'someSpecialString'
```
