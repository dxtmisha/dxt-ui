# `toCamelCase`

Converts a text string into `camelCase` format. The function removes special characters, replaces spaces, dots, and underscores with hyphens, capitalizes letters following hyphens, and ensures that the first letter of the string is lowercase.

**Parameters:**
- `value?: string` — Input string for conversion.

**Returns:**
`string` — String in `camelCase` format.

```typescript
import { toCamelCase } from '@dxtmisha/functional-basic'

console.log(toCamelCase('Hello World')) // 'helloWorld'
console.log(toCamelCase('user-profile-data')) // 'userProfileData'
console.log(toCamelCase('user_profile_data')) // 'userProfileData'
console.log(toCamelCase('Some_Special@String')) // 'someSpecialString'
```
