# `getLast`

Возвращает последний элемент массива или объекта. Если значение является примитивом, возвращает само значение.

Пустые массивы и объекты, а также пустой последний слот массива возвращают `undefined`. Значения объекта следуют порядку `Object.values`: учитываются только собственные перечисляемые строковые свойства; наследуемые свойства и символы исключены.

**Параметры:**
- `value?: T | readonly T[] | Record<PropertyKey, T>` — входное значение.

**Возвращает:**
`T` — объявленный в TypeScript тип последнего элемента или неизменённого входного значения. Во время выполнения пустая коллекция также может вернуть `undefined`.

```typescript
import { getLast } from '@dxtmisha/functional-basic'

console.log(getLast([1, 2, 3])) // 3
console.log(getLast({ a: 1, b: 2 })) // 2
console.log(getLast('string')) // 'string'
console.log(getLast([])) // undefined
```
