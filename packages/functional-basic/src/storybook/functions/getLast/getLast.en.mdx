# `getLast`

Returns the last element of an array or object. If the value is a primitive, returns the value itself.

Empty arrays and objects, as well as an empty final array slot, return `undefined`. Object values follow `Object.values` order: only own enumerable string-keyed properties are included; inherited properties and symbols are excluded.

**Parameters:**
- `value?: T | readonly T[] | Record<PropertyKey, T>` — input value.

**Returns:**
`T` — the declared TypeScript return type for the last element or unchanged input value. At runtime, empty collections can also return `undefined`.

```typescript
import { getLast } from '@dxtmisha/functional-basic'

console.log(getLast([1, 2, 3])) // 3
console.log(getLast({ a: 1, b: 2 })) // 2
console.log(getLast('string')) // 'string'
console.log(getLast([])) // undefined
```
