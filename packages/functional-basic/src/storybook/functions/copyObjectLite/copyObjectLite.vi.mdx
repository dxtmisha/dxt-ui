# `copyObjectLite`

Tạo một bản sao nông (shallow copy) của một đối tượng đơn giản bằng cú pháp object spread. Nó có thể tùy chọn hợp nhất các thuộc tính bổ sung từ đối số thứ hai `source`.

Các thuộc tính riêng có thể liệt kê, bao gồm symbol và `__proto__`, được sao chép dưới dạng dữ liệu mà không thay đổi prototype chuẩn `Object.prototype` của kết quả.

> Vì đây là sao chép nông, các đối tượng và mảng lồng nhau sẽ được sao chép theo tham chiếu (reference), chứ không phải theo giá trị.

**Tham số:**
- `value?: T | null` — Đối tượng cần sao chép.
- `source?: Record<PropertyKey, unknown> | null` — Các thuộc tính bổ sung để hợp nhất với đối tượng `value`. Các thuộc tính từ `source` sẽ ghi đè các thuộc tính từ `value` nếu chúng có cùng khóa (key).

**Trả về:**
`R` (mặc định là `T`) — Bản sao nông mới của đối tượng.

```typescript
import { copyObjectLite } from '@dxtmisha/functional-basic'

const original = { a: 1, b: { c: 2 } }

// Sao chép nông đơn giản
const copy = copyObjectLite(original)
console.log(copy.b === original.b) // true (tham chiếu đến cùng một đối tượng lồng nhau)

// Sao chép với các thuộc tính hợp nhất bổ sung
const merged = copyObjectLite(original, { a: 10, d: 4 })
console.log(merged) // { a: 10, b: { c: 2 }, d: 4 }
```
