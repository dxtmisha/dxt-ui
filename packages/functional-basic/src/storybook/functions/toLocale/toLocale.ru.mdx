# `toLocale`

Приводит полную строку локали к стандартному каноническому формату `aa-AA` (например, `'en-US'`, `'ru-RU'`, `'vi-VN'`). Если строка содержит неполный формат (только страну или только язык) либо является невалидной, функция возвращает пустую строку `''`.

## Основные возможности

- **Канонический формат `aa-AA`** — Гарантирует результат в виде `[двухбуквенный язык]-[двухбуквенная страна]` (строчный язык, заглавный код страны).
- **Строгая проверка полного формата** — Требует наличия и языка, и страны. Если передан только код страны (`'US'`) или только код языка (`'ru'`), возвращает пустую строку `''`.
- **Поддержка субтегов BCP-47** — Корректно извлекает компоненты из расширенных тегов (например, `'zh-Hans-CN'` -> `'zh-CN'`, `'en-US-u-ca-gregory'` -> `'en-US'`).
- **Гибкие форматы строк** — Поддерживает классические (`'en-US'`), с подчеркиванием (`'en_US'`), регистронезависимые (`'en-gb'` -> `'en-GB'`) и инвертированные (`'RU-ru'` -> `'ru-RU'`) форматы.
- **Изоморфность и безопасность** — Безопасно обрабатывает `null`, `undefined`, пустые строки и нестроковые значения без runtime-ошибок.

**Параметры:**
- `code?: unknown` — Проверяемая строка локали.

**Возвращает:**
- `string` — Канонический код локали в формате `aa-AA` или пустая строка, если формат не полный или значение невалидно.

## Примеры

<Source
  language='typescript'
  code={`
import { toLocale } from '@dxtmisha/functional-basic'

// 1. Полные стандартные и инвертированные теги локалей
toLocale('en-US') // 'en-US'
toLocale('ru_RU') // 'ru-RU'
toLocale('RU-ru') // 'ru-RU'
toLocale('en-gb') // 'en-GB'

// 2. Расширенные субтеги BCP-47
toLocale('zh-Hans-CN')         // 'zh-CN'
toLocale('en-US-u-ca-gregory') // 'en-US'

// 3. Неполные форматы (только страна или только язык) возвращают пустую строку
toLocale('US') // ''
toLocale('RU') // ''
toLocale('ru') // ''
toLocale('vi') // ''

// 4. Невалидные значения
toLocale('')         // ''
toLocale(undefined)  // ''
toLocale(null)       // ''
  `}
/>
