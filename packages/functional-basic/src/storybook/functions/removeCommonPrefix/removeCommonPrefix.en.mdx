# `removeCommonPrefix`

Removes the common prefix from the beginning of the main string. If `mainString` starts with the full `prefix` or shares a partial leading character sequence with `prefix`, the matching leading characters are stripped, and the result is optionally trimmed.

**Parameters:**
- `mainString: string` — The main string.
- `prefix: string` — The prefix string to remove.
- `trim?: boolean = true` — If `true`, trims leading and trailing whitespace from the resulting string (defaults to `true`).

**Returns:**
`string` — A new string without the common prefix.

```typescript
import { removeCommonPrefix } from '@dxtmisha/functional-basic'

console.log(removeCommonPrefix('Hello, world!', 'Hello, ')) // 'world!'
console.log(removeCommonPrefix('user_name', 'user_')) // 'name'
console.log(removeCommonPrefix('prefix   suffix   ', 'prefix', false)) // '   suffix   '
```
