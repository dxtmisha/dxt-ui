# `removeCommonPrefix`

Xóa tiền tố chung khỏi phần đầu của chuỗi chính. Nếu `mainString` bắt đầu bằng toàn bộ `prefix` hoặc có chuỗi ký tự đầu trùng khớp một phần với `prefix`, các ký tự trùng khớp ở đầu sẽ bị loại bỏ và kết quả được tùy chọn cắt bỏ khoảng trắng ở hai đầu.

**Tham số:**
- `mainString: string` — Chuỗi chính.
- `prefix: string` — Chuỗi tiền tố cần xóa.
- `trim?: boolean = true` — Nếu `true`, loại bỏ khoảng trắng ở đầu và cuối chuỗi kết quả (mặc định là `true`).

**Trả về:**
`string` — Một chuỗi mới không có tiền tố chung.

```typescript
import { removeCommonPrefix } from '@dxtmisha/functional-basic'

console.log(removeCommonPrefix('Xin chào, thế giới!', 'Xin chào, ')) // 'thế giới!'
console.log(removeCommonPrefix('user_name', 'user_')) // 'name'
console.log(removeCommonPrefix('prefix   suffix   ', 'prefix', false)) // '   suffix   '
```
