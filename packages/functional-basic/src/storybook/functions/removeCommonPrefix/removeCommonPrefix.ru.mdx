# `removeCommonPrefix`

Удаляет общий префикс из начала основной строки. Если `mainString` начинается с полного `prefix` или имеет общую начальную последовательность символов с `prefix`, совпадающие начальные символы удаляются, а результат опционально обрезается от пробелов по краям.

**Параметры:**
- `mainString: string` — Основная строка.
- `prefix: string` — Строка префикса для удаления.
- `trim?: boolean = true` — Если `true`, обрезает пробельные символы в начале и в конце результирующей строки (по умолчанию `true`).

**Возвращает:**
`string` — Новая строка без общего префикса.

```typescript
import { removeCommonPrefix } from '@dxtmisha/functional-basic'

console.log(removeCommonPrefix('Привет, мир!', 'Привет, ')) // 'мир!'
console.log(removeCommonPrefix('user_name', 'user_')) // 'name'
console.log(removeCommonPrefix('prefix   suffix   ', 'prefix', false)) // '   suffix   '
```
