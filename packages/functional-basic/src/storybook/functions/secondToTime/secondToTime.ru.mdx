# `secondToTime`

Преобразует переданное количество секунд в отформатированную строку времени `MM:SS` (или `HH:MM:SS`, если включен параметр `hasHour`). Дробная часть секунд безопасно отсекается.

Если значение секунд меньше или равно нулю, или оно не было передано, возвращается значение по умолчанию (`00:00` или `00:00:00` при `hasHour = true`).

**Параметры:**
- `second: number | string | undefined` — Общее количество секунд (поддерживаются числа, числа с плавающей точкой и их строковые представления).
- `hasHour?: boolean` — Флаг принудительного включения формата с часами (`HH:MM:SS`).

**Возвращает:**
`string` — Отформатированная строка времени (например, `02:05` или `01:01:05`).

```typescript
import { secondToTime } from '@dxtmisha/functional-basic'

console.log(secondToTime(125)) // '02:05'
console.log(secondToTime(65.4)) // '01:05' (дробная часть отсекается)
console.log(secondToTime(3665, true)) // '01:01:05'
console.log(secondToTime(125, true)) // '00:02:05'
console.log(secondToTime(0, true)) // '00:00:00'
console.log(secondToTime(undefined)) // '00:00'
```
