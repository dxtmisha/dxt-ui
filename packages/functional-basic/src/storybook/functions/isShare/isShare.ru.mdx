# `isShare`

Проверяет, поддерживается ли Web Share API в текущей среде.

Возвращает `false` вне DOM-среды, при отсутствии `navigator` или `navigator.share`. Проверка не вызывает `share()` и `canShare()` и не проверяет конкретные данные, разрешения или пользовательскую активацию, требуемую браузером для отправки.

**Возвращает:**
`boolean` — `true`, если Web Share API поддерживается, иначе `false`.

```typescript
import { isShare } from '@dxtmisha/functional-basic'

if (isShare()) {
  console.log('Обмен данными поддерживается!')
}
```
