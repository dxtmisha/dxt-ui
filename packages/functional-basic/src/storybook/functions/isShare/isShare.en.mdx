# `isShare`

Checks if the Web Share API is supported in the current environment.

Returns `false` outside a DOM runtime, when `navigator` is unavailable, or when `navigator.share` is absent. The check does not call `share()` or `canShare()` and does not validate specific data, permissions, or the user activation required by the browser for a share operation.

**Returns:**
`boolean` — `true` if the Web Share API is supported, otherwise `false`.

```typescript
import { isShare } from '@dxtmisha/functional-basic'

if (isShare()) {
  console.log('Sharing is supported!')
}
```
