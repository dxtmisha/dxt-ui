# `getImageSrc`

Служит для безопасного извлечения строки источника (`src`) из объекта изображения `HTMLImageElement`, объекта со свойством `src` или строкового значения (URL / Data URL). Если на вход подана строка, она возвращается без изменений. Если передан элемент `<img>` или объект со свойством `src`, возвращается строковое значение его `src`. Для неподдерживаемого значения или нестрокового `src` возвращается пустая строка.

**Параметры:**
- `image?: unknown` — Элемент изображения, объект со строковым `src` или строковый источник (URL). Для неподдерживаемых значений, включая `null` / `undefined`, возвращается пустая строка.

**Возвращает:**
`string` — Строка источника изображения или пустая строка `''`.

```typescript
import { getImageSrc } from '@dxtmisha/functional-basic'

// Передаем строку - URL
const src1 = getImageSrc('https://example.com/photo.png')
console.log(src1) // 'https://example.com/photo.png'

// Передаем существующий тег img
const imgElement = document.querySelector('img')
const src2 = getImageSrc(imgElement)
console.log(src2) // 'https://example.com/...'

// Передаем объект со свойством src
const src3 = getImageSrc({ src: 'https://example.com/item.png' })
console.log(src3) // 'https://example.com/item.png'

// Передаем null или undefined
console.log(getImageSrc(undefined)) // ''
console.log(getImageSrc(null)) // ''
```
