# `getImageSrc`

Служит для безопасного извлечения строки источника (`src`) из объекта изображения `HTMLImageElement` или строкового значения (URL / Data URL). Если на вход подана строка, она возвращается без изменений. Если передан элемент `<img>`, возвращается значение его атрибута `src`. При отсутствии значения возвращается пустая строка.

**Параметры:**
- `image?: HTMLImageElement | string` — Элемент изображения, строковый источник (URL) или `undefined`.

**Возвращает:**
`string` — Строка источника изображения или пустая строка `''`.

```typescript
import { getImageSrc } from '@dxtmisha/functional-basic'

// Передаем строку - URL
const src1 = getImageSrc('https://example.com/photo.png')
console.log(src1) // 'https://example.com/photo.png'

// Передаем существующий тег img
const imgElement = document.querySelector('img')
const src2 = getImageSrc(imgElement)
console.log(src2) // 'https://example.com/...'

// Передаем undefined
console.log(getImageSrc(undefined)) // ''
```
