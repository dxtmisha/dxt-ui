# `getImageSrc`

Dùng để lấy chuỗi nguồn (`src`) một cách an toàn từ đối tượng `HTMLImageElement`, đối tượng có thuộc tính `src`, hoặc chuỗi (URL / Data URL). Nếu truyền vào một chuỗi, hàm sẽ trả về chính chuỗi đó. Nếu truyền vào một phần tử `<img>` hoặc đối tượng có `src`, hàm sẽ trả về giá trị chuỗi của `src`. Nếu không có giá trị, hàm trả về chuỗi rỗng.

**Tham số:**
- `image?: HTMLImageElement | Record<string, unknown> | string | null` — Phần tử hình ảnh, đối tượng có `src`, nguồn chuỗi (URL) hoặc `null` / `undefined`.

**Trả về:**
`string` — Chuỗi nguồn hình ảnh hoặc chuỗi rỗng `''`.

```typescript
import { getImageSrc } from '@dxtmisha/functional-basic'

// Truyền vào chuỗi URL
const src1 = getImageSrc('https://example.com/photo.png')
console.log(src1) // 'https://example.com/photo.png'

// Truyền vào phần tử img
const imgElement = document.querySelector('img')
const src2 = getImageSrc(imgElement)
console.log(src2) // 'https://example.com/...'

// Truyền vào đối tượng có thuộc tính src
const src3 = getImageSrc({ src: 'https://example.com/item.png' })
console.log(src3) // 'https://example.com/item.png'

// Truyền vào null hoặc undefined
console.log(getImageSrc(undefined)) // ''
console.log(getImageSrc(null)) // ''
```
