# `getImageSrc`

Safely extracts the source URL or Data URL string from an `HTMLImageElement`, an object with a `src` property, or a string value. If a string is provided, it is returned directly. If an `<img>` element or object with a `src` property is provided, its `src` string is returned. Returns an empty string for unsupported values or a non-string `src`.

**Parameters:**
- `image?: unknown` — An image element, object with a string `src`, or string source (URL). Unsupported values, including `null` / `undefined`, return an empty string.

**Returns:**
`string` — The image source string or an empty string `''`.

```typescript
import { getImageSrc } from '@dxtmisha/functional-basic'

// Passing a string URL
const src1 = getImageSrc('https://example.com/photo.png')
console.log(src1) // 'https://example.com/photo.png'

// Passing an HTMLImageElement
const imgElement = document.querySelector('img')
const src2 = getImageSrc(imgElement)
console.log(src2) // 'https://example.com/...'

// Passing an object with src property
const src3 = getImageSrc({ src: 'https://example.com/item.png' })
console.log(src3) // 'https://example.com/item.png'

// Passing null or undefined
console.log(getImageSrc(undefined)) // ''
console.log(getImageSrc(null)) // ''
```
