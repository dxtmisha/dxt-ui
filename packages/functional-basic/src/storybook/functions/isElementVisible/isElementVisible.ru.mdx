# `isElementVisible`

Проверяет, является ли элемент видимым (не скрыт через CSS и находится в DOM).
Элемент может находиться за пределами экрана и при этом считаться видимым.

При поддержке в браузере функция использует нативный `checkVisibility({ checkOpacity: true, checkVisibilityCSS: true })`. Иначе фолбэк проверяет вычисленные `display`, `visibility` и `opacity` самого элемента, доступные геометрические размеры и `opacity: 0` у обычных предков по `parentElement`. Положительная прозрачность предка, например `0.5`, сохраняет видимость. `visibility: visible` потомка может переопределять `visibility: hidden` предка, поэтому видимость предков безусловно не отсекается.

Обход предков во фолбэке следует по `parentElement`. Назначение слотов и переходы через shadow-host остаются частью нативной браузерной проверки. Вне DOM-среды, без целевого элемента или для отключённого от DOM элемента возвращается `false`.

**Параметры:**
- `elementSelectors?: ElementOrString<E> | null` — селектор, Element, Window (преобразуется в `document.body`) или null.

**Возвращает:**
`boolean` — `true`, если элемент является видимым, иначе `false`.

```typescript
import { isElementVisible } from '@dxtmisha/functional-basic'

const div = document.createElement('div')
document.body.appendChild(div)
console.log(isElementVisible(div)) // true

div.style.display = 'none'
console.log(isElementVisible(div)) // false
```
