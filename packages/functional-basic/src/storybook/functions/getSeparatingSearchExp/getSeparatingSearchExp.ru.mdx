# `getSeparatingSearchExp`

Утилита, строящая регистронезависимое глобальное регулярное выражение `RegExp` для поиска строк, содержащих **любое** из слов поисковой строки (разделение пробелом), либо клонирующая переданный `RegExp` с сохранением его шаблона и флагов.

Уникальные слова разбиваются пробелами, сортируются по убыванию длины, экранируются и объединяются оператором «или» `|` внутри захватывающей группы `(...)`. Это полезно для поиска или подсветки совпадений хотя бы по одному из введённых слов.

**Параметры:**
- `search: string | RegExp` — Строка поиска, состоящая из одного или нескольких слов, разделённых пробелами, или объект `RegExp`.
- `limit?: number` — (Необязательно) Максимальная длина строки поиска (игнорируется, если передан `RegExp`). По умолчанию `128`.

**Возвращает:**
`RegExp` — Регулярное выражение с флагами `ig` (без учёта регистра, глобальный) для строковых запросов или клонированный `RegExp`, если был передан `RegExp`. Если строка поиска пуста, `limit <= 0`, превышает `limit` или передан пустой `RegExp` (`/(?:)/`), возвращается `/(?!)/` (регулярное выражение, которое никогда ничего не находит).

```typescript
import { getSeparatingSearchExp } from '@dxtmisha/functional-basic'

const regex = getSeparatingSearchExp('foo bar')

'foo bar baz'.match(regex) // ['foo', 'bar']
'bar'.match(regex)         // ['bar']
'something'.match(regex)   // null

// Специальные символы экранируются автоматически
const regex2 = getSeparatingSearchExp('$10 .')
'$10 .'.match(regex2) // ['$10', '.']
```
