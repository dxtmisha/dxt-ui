# `getSeparatingSearchExp`

Утилита, строящая регистронезависимое глобальное регулярное выражение `RegExp` для поиска строк, содержащих **любое** из слов поисковой строки (разделение пробелом), либо клонирующая переданный `RegExp` с сохранением его шаблона и флагов.

Уникальные слова разбиваются пробелами, сортируются по убыванию длины, экранируются и объединяются оператором «или» `|` внутри захватывающей группы `(...)`. Это необходимо для поиска, фильтрации и подсветки совпадений (highlighting) хотя бы по одному из введённых слов.

### Ключевые возможности:
- **Многословный поиск по дизъюнкции (OR-logic)**: Разделяет строку по любым пробельным символам (`/\s+/`) и объединяет слова оператором `|` внутри захватывающей группы `(слово1|слово2)`.
- **Защита от затенения префиксов (Prefix Shadowing)**: Автоматическая сортировка токенов по убыванию длины гарантирует, что длинные слова имеют приоритет над своими префиксами в регулярном выражении (`caterpillar` совпадет полностью, а не обрежется до `cat`).
- **Регистронезависимая дедупликация**: Устранение повторяющихся слов без учёта регистра предотвращает разрастание шаблона и создание избыточных альтернативных ветвей (например, `apple Apple APPLE` превращается в компактный `(apple)` с флагом `ig`).
- **Надежное экранирование специальных символов**: Автоматически экранирует все метасимволы регулярных выражений через `escapeExp`, предотвращая синтаксические сбои и уязвимости ReDoS при вводе спецсимволов (`.`, `*`, `+`, `?`, `$`, `[`, `]`, `(`, `)`, `|` и др.).
- **Безопасное клонирование RegExp**: При передаче существующего объекта `RegExp` создаёт новый экземпляр со сбросом `lastIndex = 0`, исключая взаимное влияние и состояние гонки между независимыми вызовами.
- **Гарантированный безопасный fallback `/(?!)/`**: При пустом вводе, строке только из пробелов, превышении лимита длины или передаче пустого регулярного выражения `/(?:)/` возвращает отрицательный lookahead `/(?!)/`, который никогда ни с чем не совпадает (в отличие от опасного `/(?:)/`, приводящего к бесконечным циклам).
- **Изоморфность и полная SSR-совместимость**: Чистая функция без побочных эффектов, не зависящая от окружения браузера (`window` или `document`).

**Параметры:**
- `search: string | RegExp` — Строка поиска, состоящая из одного или нескольких слов, разделённых пробелами, или объект `RegExp`.
- `limit?: number` — (Необязательно) Максимальная длина строки поиска (игнорируется, если передан `RegExp`). По умолчанию `128`.

**Возвращает:**
`RegExp` — Регулярное выражение с флагами `ig` (без учёта регистра, глобальный) для строковых запросов или клонированный `RegExp`, если был передан `RegExp`. Если строка поиска пуста, `limit <= 0`, превышает `limit` или передан пустой `RegExp` (`/(?:)/` или `new RegExp('')`), возвращается `/(?!)/` (регулярное выражение, которое никогда ни с чем не совпадает).

```typescript
import { getSeparatingSearchExp } from '@dxtmisha/functional-basic'

// 1. Стандартный многословный поиск (OR-логика)
const searchExpression = getSeparatingSearchExp('apple banana')

console.log('an apple and banana'.match(searchExpression)) 
// ['apple', 'banana']

// 2. Предотвращение затенения префиксов (сортировка по длине)
// 'caterpillar' проверяется раньше, чем 'cat'
const prefixExpression = getSeparatingSearchExp('cat caterpillar')
const matchedWord = 'caterpillar'.match(prefixExpression)?.[0]
console.log(matchedWord) // 'caterpillar'

// 3. Автоматическое экранирование метасимволов
const symbolsExpression = getSeparatingSearchExp('C++ $10 .')
console.log(symbolsExpression.test('Code in C++')) // true
console.log(symbolsExpression.test('Total: $10'))  // true

// 4. Клонирование существующего RegExp с изоляцией lastIndex
const originalRegExp = /match/g
originalRegExp.lastIndex = 3

const clonedExpression = getSeparatingSearchExp(originalRegExp)
console.log(clonedExpression.lastIndex) // 0
console.log(originalRegExp.lastIndex)   // 3 (исходный не изменился)

// 5. Безопасная обработка пустых строк и лимита длины
getSeparatingSearchExp('').toString()      // '/(?!)/' (никогда не совпадает)
getSeparatingSearchExp('   ').toString()   // '/(?!)/'
getSeparatingSearchExp('text', 0)          // '/(?!)/'

// 6. Подсветка текста и токенизация
const highlightExpression = getSeparatingSearchExp('vue vite')
const sourceText = 'Awesome vue and vite setup'

const highlightedHtml = sourceText.replace(
  highlightExpression,
  matchedText => `<mark>${matchedText}</mark>`
)
// 'Awesome <mark>vue</mark> and <mark>vite</mark> setup'

const tokens = sourceText.split(highlightExpression)
// ['Awesome ', 'vue', ' and ', 'vite', ' setup']
```
