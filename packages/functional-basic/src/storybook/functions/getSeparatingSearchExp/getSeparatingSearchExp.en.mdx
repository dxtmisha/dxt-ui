# `getSeparatingSearchExp`

A utility that builds a case-insensitive global `RegExp` for searching strings containing **any** of the words from the search string (separated by spaces), or clones a provided `RegExp` preserving its pattern and flags.

Unique words are split by whitespace, sorted by length in descending order, escaped, and joined with the OR operator `|` inside a capturing group `(...)`. This is useful for finding or highlighting matches for any of the entered words.

**Parameters:**
- `search: string | RegExp` — A search string consisting of one or more space-separated words, or a `RegExp` object.
- `limit?: number` — (Optional) The maximum allowed length of the search string (ignored if a `RegExp` is passed). Defaults to `128`.

**Returns:**
`RegExp` — A regular expression with flags `ig` (case-insensitive, global) for string queries, or a cloned `RegExp` if a `RegExp` was passed. If the search string is empty, `limit <= 0`, exceeds `limit`, or an empty `RegExp` (`/(?:)/`) is passed, it returns `/(?!)/` (a regex that never matches anything).

```typescript
import { getSeparatingSearchExp } from '@dxtmisha/functional-basic'

const regex = getSeparatingSearchExp('foo bar')

'foo bar baz'.match(regex) // ['foo', 'bar']
'bar'.match(regex)         // ['bar']
'something'.match(regex)   // null

// Special characters are escaped automatically
const regex2 = getSeparatingSearchExp('$10 .')
'$10 .'.match(regex2) // ['$10', '.']
```
