# `toKebabCase`

Converts an ASCII identifier to `kebab-case`: removes characters other than A–Z/a–z letters, digits, dashes, dots, underscores and spaces; replaces runs of spaces, dots and underscores with a dash and converts letter case. Existing dashes are preserved. Returns `''` for `null`, `undefined` and an empty string. Adjacent uppercase letters are grouped: `XMLHttpRequest` → `xmlhttp-request`.

**Parameters:**
- `value?: string | null` — The original string to convert.

**Returns:**
`string` — The string in `kebab-case` format.

```typescript
import { toKebabCase } from '@dxtmisha/functional-basic'

console.log(toKebabCase('Hello World')) // 'hello-world'
console.log(toKebabCase('userProfileData')) // 'user-profile-data'
console.log(toKebabCase('Some_Special@String')) // 'some-special-string'
```
