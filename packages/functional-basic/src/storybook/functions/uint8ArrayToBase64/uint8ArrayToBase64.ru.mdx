# `uint8ArrayToBase64`

Преобразует массив бинарных данных `Uint8Array` в строку в кодировке Base64. Поддерживает работу в среде Node.js (через `Buffer`), современный стандарт ECMAScript (`Uint8Array.prototype.toBase64`) и браузеры/воркеры (через порционный вызов `btoa`). Возвращает пустую строку (`''`), если `bytes` равен `null`, `undefined` или пуст.

**Параметры:**
- `bytes?: Uint8Array | null` — Бинарные данные в виде `Uint8Array`.

**Возвращает:**
`string` — Строка в формате Base64.

```typescript
import { uint8ArrayToBase64 } from '@dxtmisha/functional-basic'

const data = new Uint8Array([72, 101, 108, 108, 111])
console.log(uint8ArrayToBase64(data)) // 'SGVsbG8='
```
