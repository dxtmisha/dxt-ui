# `uint8ArrayToBase64`

Converts a `Uint8Array` of binary data into a Base64 encoded string. Supports Node.js environments (via `Buffer`), modern ECMAScript (`Uint8Array.prototype.toBase64`), and browsers/workers (via chunked `btoa`). Returns an empty string (`''`) if `bytes` is `null`, `undefined`, or empty.

**Parameters:**
- `bytes?: Uint8Array | null` — The binary data as a `Uint8Array`.

**Returns:**
`string` — The Base64 encoded string.

```typescript
import { uint8ArrayToBase64 } from '@dxtmisha/functional-basic'

const data = new Uint8Array([72, 101, 108, 108, 111])
console.log(uint8ArrayToBase64(data)) // 'SGVsbG8='
```
