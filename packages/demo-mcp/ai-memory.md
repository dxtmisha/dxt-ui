# Package Memory: @dxtmisha/demo-mcp

## Overview
Demo and showcase implementation package for Model Context Protocol (MCP) servers and tools built on top of `@dxtmisha/mcp`.

## Guidelines
- Class structure follows project standards (English/Russian bilingual JSDoc).
- Auto-generate library exports via `npm run library`.
- All tools must use descriptive naming without abbreviations and provide strict typing schemas.
